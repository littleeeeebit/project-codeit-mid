`fuse` applies weighted reciprocal-rank fusion (`rrf_fuse`, k=`rrf_k`, dense weight `dense_weight`). With `fusion == 'keyword_first'`, the top `keyword_head` BM25 rows stay in BM25 order ahead of the RRF order, so a dense row never displaces a protected keyword match. The result is cut to `fused_top_k`. Per the README, the serving values are keyword head 6, k 60, dense weight 1.0, 50 candidates per channel and 50 fused.
