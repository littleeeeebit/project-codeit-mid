First, requirement codes found by `CODE_RE` (for example SFR-001) select exact rows ahead of every ranker, with detail rows first, and notes such as `code_not_found:` and `code_ambiguous:` are added. Then BM25 runs over the admitted rows with Kiwi tokens. `scope_redundant_terms` drops query terms present in more than half of the scope's chunks, and a selected project's restated name when one or two documents are selected. It never drops codes, digits or negations, and drops nothing unless a kept term still matches. `_name_only` detects questions that only name a project and switches to dense ranking within the named documents.
