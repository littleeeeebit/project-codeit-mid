`dense.query_vector` looks up the query vector by normalized text, model and dimensions. A miss is embedded locally on the GPU for free, through Gemini under its own cap, or through OpenAI as a metered `embedding` attempt, and only when `allow_paid` is true (paid answers). `PgDenseIndex.search` returns the top k cosine matches among the admitted row orders. Hybrid mode skips the dense channel when there is no lexical or exact match (`no_lexical_match:dense_not_used`), so arbitrary nearest neighbours never become evidence.
