`retrieval.retrieve`, called from `service.retrieve`, takes a question and a scope of (DocRef, extraction ID) pairs and returns ranked, packed evidence. Modes: `whitespace_bm25` (K0), `kiwi_bm25` (K1), `dense` (D), `hybrid` (H) and `hybrid_rerank` (HR). `_available_mode` downgrades visibly, recording why in `fallback`, when the dense set, query vector or reranker is missing or mismatched. According to the README, serving is currently hybrid with keyword-first fusion over exact pgvector search, through run `H-0fffb2a6ec`.
