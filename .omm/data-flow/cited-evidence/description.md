Answers store an evidence map (`result_json.evidence`, keyed E1..En, holding the source_hash, extraction_id, chunk_id, element_ids, quote and location the answer was built from). GET /api/requests/{id}/evidence/{eid} → `open_evidence` resolves context from that persisted map only: the cited elements ±1 neighbour from the loaded index, or from the preserved extraction artifact if a newer index dropped that revision. It adds warnings when the source version or extraction changed, the source is unreviewed or flagged, or the text came from OCR. The model never supplies a URL, path or page.
