`embedding_payloads` holds one verified unit vector per payload hash for each model, dimension count and prefix policy, with a checksum and provenance. It serves both corpus and query vectors. `embedding_sets` and `embedding_set_rows` map row order to chunk ID for one keyword index. `PgDenseIndex.load` re-verifies every vector and that the row order matches the keyword index's chunk order. `search` runs exact cosine search (`EXACT_SQL`), or HNSW with a strict-order iterative scan only when the activated run chose `dense_search: hnsw`.
