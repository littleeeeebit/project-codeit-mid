`ingest` (ingestion.py:836) parses each unique source once with `ingest_source` (ingestion.py:687). HWP goes through `hwp5proc` XML (`parse_hwp`, `walk_hwp`); if pyhwp fails but a Hancom print exists, the print's text layer is used, labeled `hwp_print`. PDF goes through PyMuPDF (`parse_pdf`). `ocr.merge` adds `image_text` elements. A source is reparsed only when its `input_key` changes (original bytes, parser fingerprint, native print, OCR cache, converter) or with `--force`. `assign_revision` binds the extraction ID to the actual output: the same output keeps its revision and review; different output becomes a new revision beside the old one, and review resets to `unreviewed`. Old artifacts stay for pinned gold rows and issued citations. A failure quarantines the source with a reason code; one crashing file is recorded as `error` while the run continues. A report is written to `.runtime/reports/ingest-*.json`. `recover-source` registers an approved PDF conversion for a quarantined original.
