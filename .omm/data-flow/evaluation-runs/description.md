`evaluate-retrieval` and `compare.run_matrix` (the `lexical`, `chunking`, `embedding` and `reranker` matrices in `compare.MATRICES`) score each configuration on source spans over three populations: development questions in their own document, development over the whole corpus, and the needle set. Each run is frozen as `.runtime/runs/<run_id>/` (`config.json`, `traces.jsonl`, `scores.json`, `report.md`), and each table as `.runtime/compare/tables/<matrix>.json` and `.md`. Uncached paid corpus builds stop as `needs_approval` rows until `compare --approve` is run. `compare.regression` re-measures K1 and the serving configuration on the served and the rebuilt index for maintenance.
