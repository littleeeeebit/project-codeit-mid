`evaluate-retrieval` and `compare --matrix` score frozen populations (dev set on own documents, dev over the whole corpus, needle set) for every variant. They write `.runtime/runs/<run_id>/` (config, traces, scores) and `.runtime/compare/tables/<matrix>.json`, which 검증 → 실험 비교 lists through `service.experiments`. Answer-level evaluation (service/answers.py), judges and the sealed run feed the release report.
