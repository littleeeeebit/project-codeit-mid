`activate-run`, the 실험 비교 activate action (`service.activate_experiment`) and decision files all go through `evaluation.activate_decision`. It checks `decision_errors` (index and matrix verify, current EVAL_VERSION, pinned embedding revision and prefixes), then in one transaction sets `active_run` (serving config, limits, embedding, reranker, activated_at) and `active_index`, and appends `activations` with the previous config for rollback.
