`sealed.freeze_release` (owner CLI, role `sealed_evaluator`) records the activated run, the code, metric, prompt, model, rate and settings fingerprints, and the frozen dev/test manifests. The sealed answer run then executes once under that freeze through `run_answers` with a `sealed` estimate (`S-` run dir under `sealed/runs`). Any later run on the same test set is labeled a post-test regression and requires a reason. The UI exposes only the sealed set's size and freeze state.
