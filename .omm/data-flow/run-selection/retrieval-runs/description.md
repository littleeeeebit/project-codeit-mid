`evaluation.evaluate_retrieval` (K0/K1/D/H) and `trial-reranker` score hit@k, recall, complete coverage, nDCG@5, MRR, packed coverage, qualifier losses, code checks and wrong scope against source spans, with Wilson intervals. Only independently reviewed dev rows are scored, and the sealed split is refused. `run_errors` blocks a run whose population, policy (`EVAL_VERSION`) or corpus route has changed. `recommend` keeps K1 unless another mode on the same population gains at least `MIN_SELECTION_GAIN` (0.03) nDCG@5 with no new critical failure.
