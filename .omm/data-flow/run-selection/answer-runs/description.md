`answers.plan_run` prices every remaining attempt (estimate with fingerprint and expiry). `begin_answers` publishes `config.json`, and `run_answers` creates one `PinnedResources` per finalist. That owner serves the finalist's recorded configuration, charges `gold_eval`, borrows the owner's transport, and takes its stop from the owner's `_closed`. Each row goes through `service.answer` with key `<run>:<finalist>:<qid>:<attempt_no>`. `_answer_row` retries only attempts with no billed call and never resends a key whose billing is open. It stops on the first budget refusal or new unknown billing. Scoring (`score_record`, `aggregate_answers`) keeps denominators; text claims wait for blind human review (`export-review`/`import-review`). Started from the UI by `start_answer_evaluation` (dev finalists only) or by the CLI (`run-answers`, UI stopped).
