`compare.run_matrix` → `Runner.run` over the named `MATRICES` (lexical, chunking, embedding with 13 models × dense/hybrid, reranker with 8 models × whole/below_head) or a custom JSON. Each row varies only its declared axes and keeps every other limit at the serving run's values (`serving_base`, `AXIS_LIMITS`). It is measured on dev-in-scope, dev-whole-corpus and needles-whole-corpus. Rows are cached in `compare/cells/`; local models refuse to run without CUDA, and an OOM halves the batch. A paid corpus build stops as `needs_approval` until `compare --approve`. Output goes to `compare/tables/<matrix>.json|md`, which 실험 비교 (`service.experiments`) displays. `compare.regression` is the maintenance table.
