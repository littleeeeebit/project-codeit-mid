`release.release_report` is read-only. It reports `ready` only if every hard check passes and every quality target is met on sealed gold; otherwise `limited` (unverified, unmeasured, missed or pilot-only) or `blocked` (a failed hard check). `release.backup` (pg_dump custom format plus mutable trees, with a manifest of table digests and artifact hashes) and `restore_check` (into an empty isolated database with paid admission off and the fake provider) provide the rollback evidence.
