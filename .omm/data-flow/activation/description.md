From the 실험 비교 table (`activate_experiment`) or `activate-run`, the person's chosen run becomes `active_run` (see `state-transitions/serving-activation`). Serving then uses that run's index, embedding model and dimensions, depths, fusion, evidence limits and reranker, whatever the process configuration says. If its matrix fails verification or a query vector is unavailable, the request falls back to K1 and the trace records why.
