`cli activate-run --run-id --decision-file` → `evaluation.activate_run` validates the decision (`decision_errors`: a current policy, ready artifacts, a passed gate for HR). In one transaction it writes `active_run` (the serving config, including `finalist_run_id`), `active_index` and an `activations` history row holding the previous config. `Resources.serving()` re-reads these on every call, so the running server switches without a restart. `index()` and `dense()` reload when the version changes. Before any activation, the `kiwi_bm25` keyword default serves.
