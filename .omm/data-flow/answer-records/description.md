`requests` rows keep the input snapshot, the config snapshot (index, serving, prompt version, model, rate version, settings fingerprint), the full trace (retrieval, evidence, admission, usage, settlement) and the validated result. `attempts` rows link to each request by `request_id`. `export_request` returns a redacted copy. Stage-review generation workers write requests under `<run>:<candidate>:` idempotency keys, which is how `paid_items` and `lost_answers` detect billed work on resume.
