`RFP_SOURCE_DIR` (default `<repo>/원본 데이터`) holds `data_list.csv` and `files/`. The originals are never modified. A changed byte sequence is detected in `ingest_source` (`original bytes changed …; rerun manifest`). The originals are served back to members only through `GET /api/originals/{doc_id}/{source_hash}` (`service.original_download`), for pairs the service manages.
