`evaluate-retrieval` and `compare --matrix` write frozen runs under `.runtime/runs/<run_id>/` (config, traces, scores, report). Each run is bound to the dataset hash, the evaluated population, the index manifest, the analyzer, the dense version and the limits, and is scored on source spans. `compare` writes `.runtime/compare/tables/<matrix>.json|md`, which the 실험 비교 view lists through `service.experiments`. A paid corpus embedding in a matrix stops as a `needs_approval` row until `compare --approve`.
