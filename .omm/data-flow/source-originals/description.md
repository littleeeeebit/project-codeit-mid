`RFP_SOURCE_DIR` (default `<repo>/원본 데이터`) holds `data_list.csv` and `files/`. `import_manifest` normalizes each CSV row (`normalize_row`: typed amounts and dates with flags), hashes each original, and records `documents` (per CSV association, `doc_id_for(filename)`) and `sources` (per unique byte hash). Byte-identical associations share one extraction but keep their own metadata. `resolve_metadata` records a canonical value with a rationale when CSV values conflict.
