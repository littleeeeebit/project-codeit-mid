`answer-parts.tsx` numbers citations in order of appearance and calls `GET /api/requests/{id}/evidence/{evidence_id}`. `service.open_evidence` returns the exact stored quote, the neighbouring elements (from the loaded index, or from the preserved artifact when a newer index no longer holds that revision), the location, the review status, and warnings: `source_version_changed`, `extraction_revised`, `source_unreviewed`/`auto_flagged`/`needs_recovery`, and `ocr_text`. A download link appears only while the cited source hash is still the active one.
