result_json.evidence maps E<n> (or R<n> for the inventory) to {doc_id, source_hash, extraction_id, chunk_id, element_ids, quote, location, token_count}. It is persisted with the request, so citations stay stable across later reindexing. open_evidence warns with source_version_changed, extraction_revised, the source review status, or ocr_text. A follow-up re-supplies up to 8 cited units from it (_with_carried), dropping units whose chunk left the serving index.
