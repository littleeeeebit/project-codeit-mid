How content moves from the original files to the citation a member opens. Each hop is content-addressed and versioned, so an issued citation keeps resolving after re-parses and re-indexes. Originals are identified by SHA-256. Extraction revisions are bound to their output. Index versions are hashes of their config. Embedding sets are bound to an index manifest. The activation pins one index and one dense version. A request stores its full evidence map. `open_evidence` reads the request's stored evidence, not the current index, and warns when the source or extraction has since changed.
