How corpus data becomes cited answers. Original files become immutable extraction revisions (`extractions`, `elements` and an `elements.jsonl` artifact). Those become a versioned keyword index (`indexes`, `chunks`, `requirements` and an index directory), then embedding sets in pgvector keyed to that index. Frozen retrieval runs measure each configuration. A person's activation writes `active_run` and `active_index`, which serving reads on every request. Serving packs evidence units that point back to `extraction_id`, `element_ids` and `source_hash`, so a citation opens the exact elements and the original file.
