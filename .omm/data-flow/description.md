How content and decisions move between persisted forms. Originals become content-addressed extractions. Index versions are built from active extractions, and vector sets from index versions. Frozen runs score index and vector combinations, and a person's activation turns one run into the serving configuration that every request reads. Requests and the ledger record what each answer used and cost. Stage-review generation answers and the person's notes and decisions flow into `.runtime/review` for the coding agent to read.
