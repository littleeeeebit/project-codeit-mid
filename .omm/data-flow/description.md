Corpus data flow from the original files to what a request serves. Every step is an owner CLI command, and each produces immutable, hash-addressed outputs, so retrieval runs, citations and gold rows stay pinned to exact revisions. The README lists the order: manifest, ingest (then ocr, ingest again), fidelity run, build-keyword, plan-embeddings, build-dense, evaluate-retrieval / trial-reranker, compare-runs, draft-activation, activate-run.
