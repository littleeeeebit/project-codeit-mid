How content moves from originals to a cited answer, and how measurement flows back into what serves. Originals are hashed and parsed into immutable extraction revisions (element rows plus JSONL artifacts). Keyword indexes chunk the active extractions into versioned, hash-verified directories plus `chunks` rows. Embedding sets map each index row to a cached pgvector payload. A request's retrieval packs chunk bodies into evidence units, which are persisted inside `result_json` and later re-opened by `open_evidence`. Evaluation reads approved gold rows and frozen indexes, writes run directories and comparison tables, and a person's activation writes `active_run`/`active_index`, which every later retrieval reads through `active_serving`. Old revisions, indexes and vectors are never deleted by these flows, so issued citations and pinned gold evidence keep resolving.
