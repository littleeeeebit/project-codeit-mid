`cli build-keyword [--include-unreviewed|--reviewed-only] [--profile]` → `retrieval.build_keyword_index`. The `reviewed_only` scope admits only `auto_verified`, `sample_checked` and `reviewed` sources; the operating index also admits `unreviewed` and `auto_flagged` sources, labelled. `chunking.build_profile` creates `structural` (the default serving profile) or fixed comparison profiles with linked split pieces and a requirement inventory. Comparison profiles never become serving. Once an `activate-run` selection exists, a rebuild does not change serving until another activation.
