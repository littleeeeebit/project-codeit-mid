`build_keyword_index` (retrieval.py:144) selects parsed sources by review policy: `--reviewed-only` (auto_verified, sample_checked, reviewed) or `--include-unreviewed` (the operating index, labeled `index_includes_unreviewed_sources`). It chunks each extraction with `chunking.build_profile` (structural by default; fixed-256/512/800 profiles for comparison only) and tokenizes with the Kiwi analyzer (`kiwi-bm25-2`). It freezes each document's title and institution terms into scope-terms.json, and the version is the hash of the configuration. It writes chunks, tokens, requirements and scope-terms plus a manifest atomically into `.runtime/indexes/<version>/`, then inserts the indexes, chunks and requirements rows. An identical configuration is reused.
