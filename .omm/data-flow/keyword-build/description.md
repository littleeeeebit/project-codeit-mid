`build_keyword_index` selects parsed sources by review policy, chunks each active extraction (`chunking.build_profile`, profile structural or fixed-*), tokenizes with Kiwi, and freezes the per-document title and institution terms (`scope-terms.json`). It writes `.runtime/indexes/<version>/` atomically (tmp dir, then rename) with the version = hash of the config, then inserts the `indexes`, `chunks` and `requirements` rows. A ready index with the same version is reused.
