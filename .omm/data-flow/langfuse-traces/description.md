Each executed request produces one Langfuse trace. It contains the retrieved chunks with scores and text, the assembled evidence, the generation with usage and ledger cost, and the validation result. It is tagged with user or member, environment (`server` or `local`) and release (`<branch>@<commit>`). Traces go to the shared stack on codeit through an SSH tunnel at 127.0.0.3:3300, or to a stack on 127.0.0.2:3100. The application never reads them back.
