`evaluate-retrieval` runs frozen retrieval-only runs (K0, K1, D, H; HR through `trial-reranker`) on a reviewed dataset. A run is bound to the dataset hash, evaluated population, index manifest, analyzer, dense version and limits, and stored under `.runtime/runs/<run_id>/`. Metrics are graded on source spans: hit@k, complete coverage, nDCG@5, MRR, packed coverage, critical failures and Wilson intervals. `compare-runs` writes a comparison and recommendation from recorded scores. `draft-activation` writes an inert decision file. `activate-run` switches serving (see state-transitions/serving-activation). `report --phase 2` and `release-report` print the active run.
