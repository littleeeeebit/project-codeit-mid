Each embedding set is tied to one keyword index version, model, dimensions and prefix policy, and is stored in pgvector (vector_store.publish, then PgDenseIndex). Corpus vectors come from build-dense (a paid OpenAI estimate, reserved per batch), from compare.ensure_dense (local GPU models free; paid models stop at needs_approval) or from the maintenance embedding step. A set becomes ready only after every row is verified. Query vectors are cached by payload hash.
