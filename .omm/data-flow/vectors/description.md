`plan-embeddings` prices the unique payloads that are not cached, as an estimate bound to the index, model, dimensions and rates. `build-dense` reserves and settles each batch in the `embedding` envelope and refuses while any embedding attempt is unknown. `build_local_dense` embeds on the GPU for free. `publish_dense` and `vector_store.publish` store a verified set in pgvector, tagged with model, dimensions and prefix policy. Corpus and query vectors are cached by payload hash and reused across rebuilds.
