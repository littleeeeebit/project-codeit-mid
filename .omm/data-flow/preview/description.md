storage/hwp_loader.py load_hwp_hwpx(Path) wraps langchain_hwp_hwpx.HwpHwpxLoader in elements mode with tables, notes, memos and hyperlinks. It returns (elements, warnings, reason) in the same tuple shape as parse_hwp and parse_pdf. Elements are path loader/e<i>, kind paragraph, and location.order_basis loader_grouped_elements with native_order_verified false. A bad extension or missing file raises. A missing langchain_hwp_hwpx or hwp_hwpx_parser propagates ImportError. A loader exception returns hwp_loader_failed. A malformed result returns hwp_loader_result_invalid and discards all partial output. Whitespace-only output returns hwp_empty_output. Every successful result carries the warning hwp_loader_structure_limited. In this branch nothing in src/ calls it; only tests/test_hwp_loader.py exercises it.
