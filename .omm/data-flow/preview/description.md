storage/hwp_loader.py load_hwp_hwpx(Path) wraps langchain_hwp_hwpx.HwpHwpxLoader in elements mode with notes, memos and hyperlinks; separate table elements are not requested because the body element already holds table text. It returns (elements, warnings, reason) in the same tuple shape as parse_hwp and parse_pdf. Elements are path loader/e<i>, kind paragraph, location.format hwp_loader (hwpx_loader for .hwpx), and location.order_basis loader_grouped_elements with native_order_verified false. A bad extension or missing file raises. A missing langchain_hwp_hwpx or hwp_hwpx_parser propagates ImportError. A loader exception returns hwp_loader_failed. A malformed result returns hwp_loader_result_invalid and discards all partial output. Whitespace-only output returns hwp_empty_output. Every successful result carries the warning hwp_loader_structure_limited. corpus/ingestion._parse_source calls it when parse_hwp returns a failure reason; a loader failure quarantines the source with the loader's reason.
