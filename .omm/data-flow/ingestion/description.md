`ingest_source` reuses the prior extraction when `input_key` is unchanged (original, parser revision, print, OCR cache, converter) and the artifact hash still matches. Otherwise it parses: HWP through `hwp5proc` (`parse_hwp`), falling back to the Hancom-printed PDF's text layer (`recovered_from_native_print`); PDF through PyMuPDF (`parse_pdf`). It then merges OCR `image_text` regions (`ocr.merge`). `assign_revision` binds the extraction ID to the actual output, so a different output under the same fingerprint gets its own revision, and the old artifact stays for pinned citations and gold rows. Elements are written to `elements.jsonl` and the `elements` table. Diagnostics go to `.runtime/reports/ingest-*.json`. A crashing file is recorded as `error`, the run continues, and the exit code is 1.
