`import_manifest` reads `data_list.csv` from `RFP_SOURCE_DIR` into `documents` (CSV metadata, conflicts) and `sources` (by sha256; byte-identical files share one source). `ingest` → `ingest_source` reparses only when the original, parser fingerprint, native print, OCR cache or converter changed (`input_key`). HWP goes through `hwp5proc` XML and `walk_hwp`; PDF goes through PyMuPDF `parse_pdf`. `assign_revision` binds the extraction ID to the actual output, so a different output creates a new revision and resets review while old artifacts stay for pinned citations. `ocr.py` (PaddleOCR-VL with a Gemini fallback under its own $0.50 ledger) feeds `image_text` elements into the next ingest. A crashing file is recorded as `error` or quarantined, and the run continues. Reports go to `.runtime/reports/ingest-*.json`.
