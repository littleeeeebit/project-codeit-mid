`원본 데이터/data_list.csv` plus `files/` (`RFP_SOURCE_DIR`). `ingestion.import_manifest` reads every CSV association, normalizes metadata (typed amounts and dates with flags), hashes each original, and writes `documents` (`doc_id` derived from the filename) and `sources` (`source_hash` primary key, so byte-identical files share one source and one extraction). It reports duplicates and conflicts. `resolve-metadata` records canonical values in `metadata_resolutions`, which override CSV values for filters, ranking and display.
