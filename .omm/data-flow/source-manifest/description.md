`ingestion.import_manifest` (CLI `manifest`) reads all 100 CSV rows from `data_list.csv`, normalizes typed fields (amounts, dated values with precision, flags), hashes each original under `files/`, and records documents, sources, duplicates and conflicts. Byte-identical files share one source and extraction but keep their own metadata and scope. `resolve-metadata` stores a canonical value with rationale in `metadata_resolutions`; search, filters and display then use it, while `csv_metadata` keeps the CSV value.
