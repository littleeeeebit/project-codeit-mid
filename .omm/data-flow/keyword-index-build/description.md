`build_keyword_index` selects parsed sources by review policy (reviewed_only, or includes_unreviewed for the operating index), chunks them with the profile (structural, fixed-*), tokenizes with Kiwi, and freezes per-document title and institution terms. It writes an immutable versioned index. With `activate=True` (the phase-1 default) it moves `active_index`; maintenance and comparisons build with `activate=False`.
