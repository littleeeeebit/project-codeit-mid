Every `/api/ask` request snapshots `_config_snapshot` (index version, serving run/mode/dense version, prompt version, model, reasoning effort, rate version, max output, settings fingerprint) into `trace_json`, and `config_hash` into the row, so each answer records the exact configuration it was produced under. Evidence maps persisted in `result_json` let citations resolve later through `open_evidence`, even after a newer index (`_ordered_elements` falls back to the preserved extraction artifact).
