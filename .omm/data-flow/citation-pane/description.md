`GET /api/requests/{id}/evidence/{eid}` → `open_evidence` returns the exact quote, the neighbouring elements (one before and one after the cited span), the location, and warnings: `source_version_changed`, `extraction_revised`, `source_unreviewed`, `source_auto_flagged` or `ocr_text`. `GET /api/originals/{doc_id}/{source_hash}` → `original_download` accepts only a UUID doc ID and a 64-hex hash of the current version. The resolved path must sit directly in the managed `files_dir`, and the bytes must hash back to the source hash before they are returned.
