Each `extractions` row (`extraction_id`, `parser_fingerprint`, `artifact_path`) owns ordered `elements` rows (kind, `raw_text`, `search_text`, location, table). `sources.active_extraction_id` points at the newest revision. Older revisions stay in place for pinned gold rows and issued citations. `review_status` (`unreviewed`, `auto_verified`, `auto_flagged`, `sample_checked`, `reviewed`) decides which index scope a source joins.
