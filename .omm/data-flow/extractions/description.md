`ingest_source` skips unchanged inputs (`input_key` covers the original, parser revision, print, OCR cache and converter) and keeps recovered sources. Otherwise it parses HWP via hwp5proc or PDF via PyMuPDF. On failure it quarantines the source with a reason. `assign_revision` binds `extraction_id` to the actual output: identical output keeps its id and review, while different output under the same fingerprint gets a new content id, and the old artifact and element rows stay for pinned gold rows and citations. The function writes `elements.jsonl`, `extractions`, `elements` and `extraction_inputs`, and resets review on a new revision.
