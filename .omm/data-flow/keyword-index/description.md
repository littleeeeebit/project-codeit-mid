`indexes/<version>/` holds `chunks.jsonl`, `tokens.jsonl`, `requirements.jsonl`, `scope-terms.json` and `manifest.json`, with matching `chunks` and `requirements` rows. The version hashes the chunker, analyzer, IDF policy, review scope, extractions and metadata terms, so the same inputs reuse the same index. Because `KeywordIndex.source_extraction` pins which extraction an index serves for each source, a re-parse does not change serving until a new run is activated.
