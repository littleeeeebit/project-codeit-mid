`build_keyword_index(profile, include_unreviewed)` chunks each eligible extraction (`chunking.build_profile`: `structural` or the fixed baselines) and tokenizes payloads with the Kiwi analyzer. It freezes title/institution terms (`metadata_term_snapshot`) and writes `chunks.jsonl`, `tokens.jsonl`, `requirements.jsonl`, `scope-terms.json` and a manifest into `.runtime/indexes/<sha16 of config>/` via a temp directory and rename. It then inserts `indexes`/`chunks`/`requirements` rows. The version is a hash of the config, so an identical rebuild is reused. `KeywordIndex.load` re-hashes the manifest and every file before serving.
