`retrieval.build_keyword_index` selects parsed sources whose review status passes the policy (`--include-unreviewed` adds `unreviewed`/`auto_flagged`, which are labeled in traces). It chunks each active extraction with `chunking.build_profile` (structural or fixed-256/512/800) and tokenizes with Kiwi. It freezes title and institution terms (`metadata_term_snapshot` → `scope-terms.json`), writes the files to a temp directory, renames it to `indexes/<version>` and inserts `indexes`/`chunks`/`requirements` in one transaction. The version is the hash of the config (chunker, profile, analyzer, review scope, extraction list, metadata-terms hash), so an unchanged input reuses the index. The requirement inventory feeds the free `inventory` mode.
