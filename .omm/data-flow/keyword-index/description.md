An immutable directory `.runtime/indexes/<version>/` whose manifest hashes are recorded in `indexes`, together with `chunks` and `requirements` rows. `KeywordIndex.load` verifies the manifest hash and every file hash. It builds `BM25Okapi` from the persisted Kiwi tokens and loads the elements for location context. `source_extraction` maps each original to the extraction this index holds, so a reparse does not change serving before activation.
