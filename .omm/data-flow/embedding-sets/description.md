`embedding_sets` and `embedding_set_rows` map each keyword-index row to an `embedding_payloads` vector (model, dimensions, prefix policy, checksum). The set is published as `ready` only after every row is verified (`vector_store.publish`). Query vectors are cached by normalized text, model and dimensions. OpenAI corpus builds go through `plan-embeddings` -> `build-dense` and are billed in the `embedding` envelope; local models embed on the GPU.
