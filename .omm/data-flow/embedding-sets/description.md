`plan-embeddings` and `build-dense` (paid OpenAI, against the `embedding` envelope), `build_local_dense` (GPU) and `build_gemini_dense` (own cap) fill `embedding_payloads`, keyed by payload hash, model, dimensions and prefix policy. `vector_store.publish` then writes `embedding_sets` and `embedding_set_rows` in state building, verifies them with `PgDenseIndex.load(require_ready=False)` and flips the set to ready. The README states that all 18,983 active vectors are in pgvector.
