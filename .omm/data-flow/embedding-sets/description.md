`embedding_payloads` caches verified unit vectors keyed by `payload_hash(text, model, dims, kind)` with checksum and provenance, so a rebuild reuses every cached vector. `embedding_sets`/`embedding_set_rows` bind a set version to a source keyword index row by row. `publish` inserts it as `building`, verifies it through `PgDenseIndex.load(require_ready=False)`, then marks it `ready`. Query vectors are cached the same way, so free retrieval uses only cached ones.
