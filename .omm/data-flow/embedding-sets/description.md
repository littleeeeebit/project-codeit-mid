`plan_embeddings` counts unique payloads, subtracts verified cache hits and stores an estimate valid for 24 hours. `build_dense` refuses a stale or over-envelope estimate and reserves and settles each batch through the ledger (`embedding` envelope). `build_local_dense` embeds on the GPU, never on the CPU. Vectors are cached in `embedding_payloads` by `payload_hash` (model, dimensions, prefix policy) with checksums. `publish_dense` writes `embedding_sets` and `embedding_set_rows` keyed to the keyword index. Query vectors are cached by text, model and dimensions; free retrieval uses only cached ones.
