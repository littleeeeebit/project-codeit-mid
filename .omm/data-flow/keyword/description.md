build_keyword_index chooses parsed sources by review policy. It chunks each active extraction with chunking.build_profile (structural by default) and tokenizes the payloads with Kiwi. It writes chunks.jsonl, tokens.jsonl, requirements.jsonl, scope-terms.json and a manifest.json with per-file hashes into a temporary directory, then renames it to .runtime/indexes/<version>. The version is the hash of the config. Rows are inserted into indexes, chunks and requirements. active_index moves only when activate is true. KeywordIndex.load re-verifies the manifest and every file hash before serving.
