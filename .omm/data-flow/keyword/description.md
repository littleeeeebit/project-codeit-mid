`build_keyword_index` selects parsed sources by review policy (with `--include-unreviewed`, also `unreviewed` and `auto_flagged`). It chunks each extraction with `chunking.build_profile`, freezes each document's title and institution terms (`metadata_term_snapshot`), and derives the version from the hash of the config (chunker, profile, analyzer, IDF, review scope, extractions, metadata terms). Files are written to a temporary directory and renamed into place. In one transaction it replaces the `indexes`, `chunks` and `requirements` rows. An identical ready version is reused.
