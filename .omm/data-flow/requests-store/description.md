`requests`: `request_json` snapshot (question, scope, mode, as_of, config/verifier IDs, generation ID, previous request, idempotency key, capabilities; no member ID inside the snapshot), `result_json` (`AnswerResult` with claims, evidence map, billing_state, error) and `trace_json` (config snapshot, rewrite record, retrieval, evidence-token estimate, admission/usage/settlement, billing attempts, `raw_output` on validation failure). Also `attempts` (member_id, purpose, price_json with billing scope). Exported per request by `/api/requests/{id}/export` through `service.redact`.
