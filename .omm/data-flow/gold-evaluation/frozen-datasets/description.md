`validate-gold` checks a split. It rejects unreviewed or self-approved rows, missing quotes, families spanning splits, paraphrases, unverified negatives and source failures labeled as absence. A set below the 60 + 60 targets is labeled `pilot`. `freeze-dataset` freezes the dataset, review log and family map. `evaluation.assign_families` groups byte-identical files and related revisions (same notice number) so splits never share a family.
