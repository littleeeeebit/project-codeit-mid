UI: `start_drafting` → `drafting._generate` with the service's transport and tracer. CLI: `drafting.generate`, which takes the gateway lock itself and requires the `sealed_evaluator` capability and the private sealed directory for split=test. `drafting.source_slots` resolves each slot's source elements, and `drafting.messages` adds the lessons from rejections. Each call drafts up to five slots and is reserved and settled in `gold_eval` within the consented maximum. Output goes to `drafts/<run_id>/output/`: `candidates.jsonl`, `invalid.json` and `receipt.json`. `drafting_runs` derives the status (running, completed, failed or interrupted) from those files and the live thread registry.
