Drafting runs (`service.start_drafting`, gpt-6-luna, `gold_eval`) write candidates to a draft run folder. `submit_drafts` and `gold.submit` put them into `gold_candidates`. `gold.decide` requires a note, and the person who started the drafting run cannot approve it. In the deciding transaction it renders approved rows into the dataset file (`datasets/dev.jsonl`) and rejected rows into rejection wiki pages. Sealed `test` candidates are reviewed only through the owner CLI.
