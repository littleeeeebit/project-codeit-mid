`cli plan-embeddings --index` counts unique payloads, subtracts verified cache hits and stores a 24-hour estimate bound to the index, model, dimensions, payload set, rates and batch limits. `cli build-dense --estimate-id` runs only while the UI is stopped (it claims the gateway). It refuses a stale or over-envelope estimate and any open embedding attempt. It then reserves and settles each bounded batch in the `embedding` envelope via `metered_embed`, caches settled vectors even if a later batch fails, and publishes the matrix (`publish_dense`, or `vector_store.publish` on PostgreSQL) only after every row is verified.
