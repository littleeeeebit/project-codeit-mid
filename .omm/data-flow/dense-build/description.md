plan-embeddings counts unique payloads with cl100k_base, subtracts verified cache hits in embedding_payloads and stores a 24 h estimate bound to index, model, dimensions, rates and batches. build-dense refuses stale or over-envelope estimates and any open embedding attempt. It reserves and settles each batch through metered_embed (purpose embedding), caches verified unit vectors in embedding_payloads (cache_put refuses to overwrite a different vector) and finally publishes an embedding_sets / embedding_set_rows set. The set is verified by PgDenseIndex.load before being marked ready.
