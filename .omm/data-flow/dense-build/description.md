`plan-embeddings` (`dense.plan_embeddings`) counts unique chunk payloads with cl100k_base, subtracts verified cache hits and stores an estimate bound to the index, model, dimensions, payload set, rates and batch limits for 24 h. `build-dense` (`dense.build_dense`, paid, UI stopped) refuses a stale or over-envelope estimate or any open embedding attempt. It embeds misses in bounded batches through `metered_embed` (embedding envelope, reserve → dispatch → settle) and writes each vector with `vector_store.cache_put`, which verifies the unit norm and checksum and refuses to overwrite a different vector. `publish` writes `embedding_sets` and `embedding_set_rows` in row order, verifies with `PgDenseIndex.load(require_ready=False)` and only then marks the set `ready`. Nothing here changes serving.
