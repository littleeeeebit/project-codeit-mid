`plan_embeddings` prices the uncached unique payloads for one index (cl100k token counts, an estimate valid for 24 h). `build_dense` reserves and settles each batch in the `embedding` envelope and refuses while any embedding attempt is unknown. Local models embed on the GPU for free (`build_local_dense`), and Gemini runs under its own ledger. `vector_store.publish` writes `embedding_sets` and `embedding_set_rows` (state building, then ready) referencing `embedding_payloads` vectors, verified row by row on load.
