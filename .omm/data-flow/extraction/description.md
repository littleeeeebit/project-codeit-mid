An extraction revision is an elements.jsonl artifact under .runtime/extracted/<source_hash>/<fingerprint>/ plus matching rows in elements (element_id, source_order, kind, raw_text, search_text, location_json, table_json). load_elements reads them for chunking and evidence context. KeywordIndex.served_extraction resolves a source to the extraction the active index holds, not to sources.active_extraction_id, which a reparse moves before activation.
