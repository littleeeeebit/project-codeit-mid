`ingestion.ingest` → `ingest_source` per unique source. The source is reused when `extraction_inputs.input_key` (original, parser fingerprint, native print, OCR cache, converter) and the artifact hash are unchanged. HWP goes through `hwp5proc` XML (`parse_hwp`/`walk_hwp`); if pyhwp fails and a Hancom print exists, the print's PDF text layer is used (`recovered_from_native_print`). PDF goes through PyMuPDF (`parse_pdf`). `ocr.merge` adds cached `image_text` elements. `assign_revision` binds the extraction ID to the actual output: identical output keeps its revision and review, different output gets a new revision and resets review to `unreviewed`. Failures quarantine the source (`needs_recovery`) with a reason; one crash is an `error` row, and the run continues. Diagnostics go to `.runtime/reports/ingest-*.json`.
