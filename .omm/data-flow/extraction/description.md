ingest_source skips work when input_key (original, parser fingerprint, native print, OCR cache, converter) is unchanged and the artifact hash still matches. HWP goes through hwp5proc XML and walk_hwp; PDF goes through PyMuPDF. If HWP conversion fails but a Hancom print exists, the print's text layer is parsed instead. ocr.merge inserts image_text elements from the PaddleOCR-VL / Gemini cache. assign_revision writes elements.jsonl under a revision ID bound to the actual output, and the elements table mirrors it. A failure quarantines the source with a reason. One crashing file is recorded as error and the run continues (CLI exit 1).
