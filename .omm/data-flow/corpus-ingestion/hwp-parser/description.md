`parse_hwp` runs `hwp5proc` (pyhwp 0.1b15; `RFP_HWP_CONVERTER` or the environment's `Scripts\hwp5proc.exe`) to XML and `walk_hwp` produces paragraphs, tables (with cells), boxes and equations with section paths. When conversion fails and a Hancom print exists (`reviews/printed/<hash16>.pdf`), the print's text layer is parsed instead: location format `hwp_print`, warning `recovered_from_native_print`, fingerprint suffix `-hancom-print`. Such a source stays unreviewed because no independent witness remains.
