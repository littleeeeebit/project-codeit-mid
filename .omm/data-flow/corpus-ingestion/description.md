`manifest` → `ingestion.import_manifest` hashes every original and writes `documents` (normalized CSV metadata, quality flags, provenance conflicts) and `sources`. `ingest` → `ingestion.ingest` parses every unique source once. A source is reparsed only when `input_key` changes (original, parser revision, native print, OCR cache, converter) or with `--force`. One crashing file is recorded as `error` and the run continues (exit 1). Results with diagnostics go to `.runtime/reports/ingest-*.json`.
