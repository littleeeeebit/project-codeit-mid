`ocr.merge(settings, source_hash, raw, rendering)` inserts one `image_text` element per finished OCR region next to the print text around the picture. Only reads whose region still has the same pixels at the same place are used. It adds a fingerprint suffix, so OCR changes create a new revision. OCR itself (`cli ocr` → `ocr.run`) reads raster regions with PaddleOCR-VL on the GPU and re-reads only regions that fail the fallback test with `gemini-3.5-flash-lite`. Results are cached per region under `.runtime/ocr/<hash>/` and the run resumes.
