`assign_revision` derives the extraction ID from source hash plus fingerprint. If a stored artifact under that ID has different content, it uses a content-hashed ID in a subdirectory, so the old artifact and its element rows stay for pinned gold rows and citations. `ingest_source` then writes `extractions`, replaces `elements` for that revision, upserts `extraction_inputs`, and updates `sources` (parsed, active extraction, review reset unless unchanged). It records `diagnose` flags (`short_output`, `no_tables`, `thin_tail`, `blank_pages`, `replacement_characters`, …), which point at problems but never mark a source reviewed.
