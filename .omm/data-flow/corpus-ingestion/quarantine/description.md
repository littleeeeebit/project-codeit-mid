On a parse failure `ingest_source` sets `parse_status='quarantined'`, `review_status='needs_recovery'`, `reason_code` and warnings, and records the input key with an empty extraction, so an unchanged rerun reuses the quarantine. `recover-source` registers an approved PDF conversion with a review JSON. A passed comparison becomes a new unreviewed revision whose pages refer to the converted PDF; a failed one keeps the quarantine.
