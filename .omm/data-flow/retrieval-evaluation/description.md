`cli evaluate-retrieval --dataset --runs K0,K1,D,H` (with `--allow-paid-queries` for uncached query vectors, charged to `gold_eval`) and `trial-reranker` freeze each run under `.runtime/runs/<run_id>/` (`config.json`, `traces.jsonl`, `scores.json`, `report.md`), bound to the dataset hash, evaluated population, index manifest, analyzer, dense version, limits and `EVAL_VERSION='retrieval-eval-4'`. An index failing `index_compatibility` is refused. `compare-runs` → `evaluation.recommend` keeps K1 unless another mode on the same population has no new critical failure and at least +0.03 nDCG@5. Pending pool review keeps K1 provisional with no finalist. `draft-activation` writes a decision file with empty `decided_by` and `rationale`, so it activates nothing until the owner fills them in.
