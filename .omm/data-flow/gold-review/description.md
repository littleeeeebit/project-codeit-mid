`start_drafting` runs `drafting._generate` in a background thread. It uses `gpt-6-luna` through the shared gateway under the `gold_eval` envelope, never above the consented maximum, and writes `output/candidates.jsonl`, `invalid.json` and `receipt.json`. `submit_drafts` calls `evaluation.assign_families`, then `gold.submit` into `gold_candidates` as `pending`. Approval (`gold.decide`) rewrites the dataset JSONL that `validate-gold`, `evaluate-retrieval` and the compare populations read.
