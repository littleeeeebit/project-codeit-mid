`ingest_source` checks that the original's bytes still match the source_hash, skips a recovered source, and reuses the earlier outcome when `input_key` (original, parser revision, OCR cache, converter) is unchanged. `_parse_source` parses HWP with pyhwp (`run_hwp_converter` → `walk_hwp`) and merges OCR text at the picture markers (`ocr.merge_hwp`). If pyhwp fails, it uses `load_hwp_hwpx` (fingerprint `hwp_loader`, warning `pyhwp_failed`, no image text). PDF goes through `parse_pdf` plus `ocr.merge`. A parse that fails marks the source `quarantined`/`needs_recovery` with its reason. `assign_revision` ties the extraction id to the actual output: different text under the same fingerprint gets a new revision, and the old artifact stays for pinned citations. The step writes `extracted/.../elements.jsonl`, replaces the `elements` rows, and resets review to `unreviewed` for a new revision. One crashing file is recorded as `error` and the run continues.
