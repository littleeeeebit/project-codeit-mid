parse_hwp runs the hwp5proc xml converter (settings.hwp_converter) as a subprocess with a timeout into a temporary directory. It parses the XML, fills EqEdit slots from the equation records, and walk_hwp emits paragraph and table elements in native order with section paths. Failure codes: hwp_converter_missing, hwp_converter_timeout, hwp_converter_decode_error, hwp_converter_failed, hwp_empty_output and hwp_xml_malformed.
