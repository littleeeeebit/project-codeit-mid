`cli fidelity run` → `fidelity.verify_all` / `verify_source`. `print_hwp` drives Hancom Viewer to print each HWP to PDF through the Windows 'Microsoft Print to PDF' printer, answering the save dialog itself (20–30 s per document, viewer windows visible). The prints are kept in `.runtime/reviews/printed/`. `compare` checks both directions: every extracted paragraph and cell line must appear in the rendering, every rendered line and ruled cell must appear in the extraction (6-character shingles), and digit runs must match exactly. Metrics and findings go to `fidelity_checks` (one per extraction and method), and the source becomes auto_verified or auto_flagged unless a human status exists. The UI reads `fidelity_overview` and `rendered_page_png` (PyMuPDF page at 110 dpi) and confirms with `confirm_fidelity`.
