`fidelity.verify_source` prints each HWP through Hancom Viewer to PDF (Windows only, using the 'Microsoft Print to PDF' default printer) and compares in both directions with 6-character shingles and exact digit runs. The verdict `auto_verified`/`auto_flagged` is written to `fidelity_checks` and the review status, and never overwrites a human review. The 검증 원문 대조 tab (`/api/verify/fidelity`, `/confirm`) lets a person mark `sample_checked`. The review status decides index inclusion (`build-keyword --reviewed-only`) and labels such as `source_unreviewed` on every answer.
