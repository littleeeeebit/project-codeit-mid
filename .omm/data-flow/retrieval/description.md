Per request, service.retrieve returns EvidenceUnits (E1..En) carrying doc_id, source_hash, extraction_id, chunk_id, element_ids, quote and location. They are embedded in the prompt and stored in result_json.evidence. GET /api/requests/{id}/evidence/{evidence_id} (open_evidence) re-reads the ordered elements of that extraction to show context, and /api/originals/{doc_id}/{source_hash} serves the original file.
