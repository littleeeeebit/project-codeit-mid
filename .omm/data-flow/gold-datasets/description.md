Approved development rows live in `.runtime/datasets/dev.jsonl` (also `dev-pilot`), and the sealed rows in `.runtime/sealed/test.jsonl`. Both are rendered from `gold_candidates`/`gold_reviews` by `gold.decide`. Labels are evidence groups of source spans (hash, extraction, element, offsets, quote), never chunk IDs, so they survive re-chunking. `gold repin` moves pending rows to a new extraction by element path.
