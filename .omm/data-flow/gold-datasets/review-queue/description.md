`gold.submit` stores a batch file's rows in `gold_candidates` as pending, with the row hash, batch hash and `drafted_by`; `submit_drafts` first calls `evaluation.assign_families`. The UI queue lists development candidates only (`gold.queue`). `candidate_review` shows the draft, its required claims, the cited spans inside the original element text (`candidate_spans`), the PDF pages, the CSV metadata and the current validation errors.
