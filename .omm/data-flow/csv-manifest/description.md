ingestion.import_manifest reads data_list.csv under RFP_SOURCE_DIR. It normalizes metadata (amounts, dates, institutions), hashes each original (sha256 as source_hash) and creates documents (doc_id from filename) and sources rows. Byte-identical files share one sources row, while each document keeps its own metadata. Conflicting field values stay visible in quality_json, and resolve-metadata records canonical values with rationale in metadata_resolutions.
