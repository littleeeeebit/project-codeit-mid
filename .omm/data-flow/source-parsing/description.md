ingest_source reuses an unchanged input_key (original, parser fingerprint, print, OCR cache, converter) unless --force. It parses HWP through hwp5proc XML (falling back to the Hancom print's text layer) or PDF through PyMuPDF and merges OCR text. A failure quarantines the source (`needs_recovery`). Success writes elements.jsonl and an extractions row. A changed output gets a new content-addressed extraction ID beside the old one, and review resets to unreviewed.
