`read_window` opens psycopg with `default_transaction_read_only=on` and `conn.read_only = True`, in one transaction. It reads requests with stored request and result JSON, status in (completed, failed), and `created_at >= since`. It also reads every distinct `member_id` in `requests` and every document title from `normalized_metadata_json`. It keeps only Ask requests: idempotency key is a UUID equal to the generation ID, with no `verifier_run_id`. That excludes evaluation, stage-review and sealed-set requests.
