`traffic_review.run` freezes real Ask answers from a serving database into one review run. It never writes to that database, never calls a model, and never records the DSN, only the variable's name. Trigger: `stage-review run traffic --since <YYYY-MM-DD> --sample <n> --source-dsn-env <VAR>`, usually codeit's database through the SSH tunnel. Output: `<data>/review/runs/traffic-<stamp>-<hex>/` with `inputs/requests.jsonl.gz`, `view.json` and `run.json`. The review app shows it like a one-candidate generation run.
