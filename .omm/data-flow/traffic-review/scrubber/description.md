`scrub` walks every key and string. A string naming no member at any decoding level (`decodings` repeatedly applies JSON escapes, including `\u005c`, and joins surrogates) stays unchanged. A string that parses as JSON is cleaned value by value and re-serialised. Other text gets plain and JSON-escaped spellings replaced. If an ID can still be recovered, the whole string becomes `WITHHELD`. Lone surrogates become U+FFFD.
