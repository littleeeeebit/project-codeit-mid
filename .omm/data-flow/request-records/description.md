`requests` rows hold the input snapshot (`request_json`), the config snapshot and trace (`trace_json`: retrieval, rewrite, metadata query, billing, raw output on validation failure), and the outcome (`result_json`, with listings in `request_listings`). Attempts link by `request_id`. Langfuse receives the same steps as observability only, with secrets masked on export. `GET /api/requests/{id}/export` returns a redacted copy.
