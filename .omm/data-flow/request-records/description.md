`requests.request_json` holds the input snapshot. `trace_json` holds the config snapshot (index version, serving run, prompt version, model, rate version, settings fingerprint), retrieval, rewrite and billing attempts. `result_json` holds the `AnswerResult` with its `evidence` map (evidence_id → doc, source hash, extraction, chunk, element IDs, quote, location). Export routes pass these through `service.redact`, which removes keys, paths and messages.
