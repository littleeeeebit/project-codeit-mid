`requests` rows carry the input snapshot, a config snapshot (index version, serving run, prompt version, model, rate version, settings fingerprint), `trace_json` (retrieval candidates, evidence, rewrite, billing attempts, raw output on failure) and `result_json` (answer plus the evidence map). `export_request` redacts secrets through `redact`. The evidence map is the only source for `open_evidence`, so a citation never depends on the model supplying a path or page.
