Each request persists its input snapshot (`request_json`), its config snapshot and hash, its full trace (`trace_json`: retrieval candidates, evidence, limitations, rewrite record, admission, usage, settlement, billing attempts) and its result, including the evidence map, in `requests`. Ledger rows go to `attempts`. Evidence views (`open_evidence`) and exports (`export_request`, redacted) read only these stored records plus the pinned extraction's elements. The model never supplies a path, URL or page.
