`requests` row: `request_json` (input snapshot including capabilities and the previous request), `trace_json` (config snapshot, retrieval, rewrite, billing, raw output on validation failure), and `result_json` (the `AnswerResult` including the `evidence` map `E# → EvidenceUnit`). `GET /api/requests/{id}/export` returns a redacted copy. Langfuse receives the same steps when enabled, with the trace ID derived from request_id and secret-shaped values masked.
