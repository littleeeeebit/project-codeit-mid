`requests.result_json` stores the `AnswerResult`: status, summary, `summary_evidence_ids`, claims with their evidence IDs, missing fields, conflicts, next action, facts or inventory for free modes, coverage, limitations, `standalone_question`, billing state, attempt IDs, and the full `evidence` map keyed by evidence ID. `trace_json` keeps the config snapshot, retrieval, rewrite, admission, usage and settlement. `export_request` returns both with secrets redacted.
