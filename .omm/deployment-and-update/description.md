Runtime topology as described in source and the README. The team VM `codeit` runs `bidmate.service` (tools/infra/bidmate.service), a single uvicorn worker on port 8501 serving API and screens, with sign-in through the JupyterHub on :8000 of the same host. Settings come from `/etc/bidmate/server.env`. PostgreSQL runs from tools/infra/start-postgresql.sh (Linux) or start-postgresql.ps1 (Docker on loopback 55432, locally). An optional local Langfuse stack (`compose.langfuse.yaml`, started by tools/infra/start-langfuse.ps1) listens on 127.0.0.2:3100. The owner's OCR and paid CLI runs may happen on a personal machine against codeit's ledger through a tunnel (`--ledger-dsn-env`).
