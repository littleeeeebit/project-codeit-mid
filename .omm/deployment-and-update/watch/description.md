`UpdateWatch` records the commit from `build_head()` at startup and calls `compare` against GitHub without a token: main's head, then compare/{running}...{latest}. It offers an update only when main is strictly ahead (a fast-forward is possible). Network failures keep the last known check with a note. `last_result` reads the updater's root-owned result.json for display only, and reports a `running` result older than 30 minutes as `interrupted`.
