BidMate is the hub's OAuth client `bidmate`. /api/auth/login redirects to the registered address first (for visits through a tunnel), then to the hub with a state cookie. /api/auth/callback compares the state, exchanges the code from the server and reads the hub user. Only usernames on the allowlist get the HttpOnly session cookie on /api/. Local development sets BIDMATE_LOCAL_MEMBER instead; `auth.Login.from_env` refuses that next to the hub settings.
