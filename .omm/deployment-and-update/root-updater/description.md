`tools/infra/bidmate-update.path` watches the marker and starts `bidmate-update.service`, which runs `tools/infra/update.sh`. Per the module docstring in `update.py`, the script fast-forwards the checkout to origin/main, rebuilds, restarts `bidmate`, health-checks it, rolls back on failure, and writes `result.json` and `update.log` into a root-owned state directory that the service only reads. The script itself was not read in this analysis.
