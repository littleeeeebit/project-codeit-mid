`cli backup --destination` → `release.backup` writes a manifest of the ledger summary and referenced artifacts. `cli restore-check --backup` → `release.restore_check` restores into fresh staging with paid work disabled; for PostgreSQL it uses a distinct empty `RFP_RESTORE_DATABASE_DSN` and never connects to the primary (README). `cli check --phase all --provider fake --save` records test results in `releases/checks/`. `cli release-report --latest` → `write_release_report` is read-only and decides with `decide_status`: `ready` only when every hard check passes and every quality target is met on sealed gold, `limited` when something is unverified, unmeasured, missed or pilot-only, and `blocked` when any hard check fails.
