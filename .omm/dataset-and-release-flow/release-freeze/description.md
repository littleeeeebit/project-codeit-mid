`cli freeze-dataset` freezes dev and test manifests. `cli freeze-release` → `sealed.freeze_release` records the release candidate: activated run, development answer run, code, metric, prompt, model, rate and settings hashes, and frozen manifests. `plan-run --action sealed --freeze-id` plus `run-answers` executes the sealed set once (`sealed.begin`). Per the README, any later run is labelled a post-test regression (`post_test_regression`, `S-` run IDs under `.runtime/sealed/runs`).
