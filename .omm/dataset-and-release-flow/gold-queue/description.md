`gold.submit` stores each candidate in `gold_candidates` as `pending` with `row_json`, `row_sha256` and the batch hash. `gold status` reports `pending_invalid` rows that no longer pass shared checks, and `gold repin` moves pending rows to a new extraction by element path after a parser revision. `service.candidate_review` assembles the review view: the draft, the cited spans inside their element text (`candidate_spans`, preferring recorded offsets), the PDF pages, CSV metadata and conflicts, and `current_errors`.
