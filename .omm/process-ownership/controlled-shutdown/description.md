Resources.close, called from the FastAPI lifespan or an atexit hook: it rejects new submissions (runner() raises), drains RequestRunner within shutdown_wait_seconds, joins drafting, evaluation and judge threads against the same deadline, and re-runs recover_requests and budget.recover if any thread is still alive. It then closes the transport and flushes Langfuse, and only then releases the gateway lock and the pool. In-flight calls that return after close still settle. Calls that do not are reported unknown by the next owner.
