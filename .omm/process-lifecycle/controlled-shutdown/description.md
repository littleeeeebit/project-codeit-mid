Uvicorn's SIGINT/SIGTERM ends the lifespan, which calls `res.close()`; the `threading` atexit hook does too. `close()` marks the object closed under `_runner_lock` (new submissions and `set_api_key` are refused), runs `runner.shutdown(shutdown_wait_seconds)`, and joins the background jobs until the deadline. If any thread is still alive, it runs the recovery marks immediately; a call that later returns can still settle from `unknown`. It then closes the transport and flushes tracing, releases the gateway owner, and exits the database lifecycle.
