Budget administration commands use `Resources(dispatch=False)`: no transport, no lock and no recovery, so they run beside the app. Paid CLI commands use `Resources(settings)` and fail with `GatewayLockError` while the app is running. `drafting.generate`, the CLI path, takes `gateway_lock` itself, whereas the UI path calls `drafting._generate` under the app's existing ownership. `check` and `load-check` use temporary databases on `RFP_POSTGRES_TEST_DSN`.
