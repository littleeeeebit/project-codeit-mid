`Resources._own` borrows this process's existing `GatewayOwner` if there is one; otherwise it creates one, and `pg_try_advisory_lock` failing raises `GatewayLockError`. A transport always forces ownership, including the per-browser `OpenAITransport` created on the first `set_api_key`. `paid on` sets both the ledger switch and `database_control.paid_admission`. Dispatch needs both, plus a held lock.
