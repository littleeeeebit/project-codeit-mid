SIGINT → uvicorn ends → the lifespan's `res.close()`, which also runs via the `threading._register_atexit` hook so it executes before the executor join. The sequence: set `_closed` (new submissions and job starts are refused, and checkpoints now return 'interrupted'), `RequestRunner.shutdown(shutdown_wait_seconds=20)`, join job threads up to the same deadline, re-run recovery if any job is still alive, close the transport, then flush and close tracing, then release the lock and the pool. Calls already dispatched may still settle if they return before the transport closes; otherwise their attempts become unknown at the next startup.
