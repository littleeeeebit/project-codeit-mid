tools/infra/bidmate.service runs as user bidmate with `EnvironmentFile=/etc/bidmate/server.env` (DSN, paths, BIDMATE_* sign-in settings, and deliberately no OPENAI_API_KEY). `ExecStartPre` runs tools/infra/start-postgresql.sh, then `uvicorn rfp_assistant.api:app --host 0.0.0.0 --port 8501 --workers 1`. It uses `KillSignal=SIGINT`, `TimeoutStopSec=120` and `Restart=on-failure`. It binds all addresses because every /api route requires a hub sign-in.
