`service.Resources(settings, dispatch=False)` is used by `reconcile`, `unresolved` and the other owner budget actions (`settle`, `adjust`, `paid`, `audit`), each with `--actor` and a reason recorded in the audit log. It validates the database like any startup, but takes no gateway lock, builds no client and refuses recovery. It can therefore run beside the serving app, and any paid stage through it is refused at admission.
