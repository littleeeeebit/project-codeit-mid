`settle` (budget.py:383) runs exactly once. It prices usage with the rates frozen at reservation (uncached, cached, cache-write and output tokens) from dispatching, unknown or reconciled; a duplicate returns the stored amount. Settling a reconciled attempt adds a negative late-settlement adjustment so it is not counted twice. A cost above the reservation sets `budget_settings.frozen_reason`, which stops all new paid work until the owner inspects it.
