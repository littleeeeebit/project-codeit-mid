Whenever a `Resources` acquires a fresh gateway lock (`_own` without a borrowable owner), it runs `recover_requests`: queued and running rows become `interrupted` with a restart note. It also runs `budget.recover`: dispatching attempts become unknown and reserved ones released, for OpenAI and for the Gemini `external_attempts`. `Resources.close` runs both again if job threads are still alive after the bounded wait. Nothing is ever re-sent.
