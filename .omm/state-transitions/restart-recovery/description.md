Runs only when `Resources._own` takes a fresh gateway lock, not when it borrows this process's lock, because borrowed work is still live. `recover_requests` marks queued and running requests `interrupted`. `budget.recover` marks dispatching attempts `unknown` and reserved ones `released`, in both ledgers. `Resources.close()` performs the same recovery itself if background jobs outlive `shutdown_wait_seconds`. Background job files are not rewritten: drafting runs without a receipt or error list as `interrupted`, and answer and judge runs list `running: false` and resume on the next start with a new estimate.
