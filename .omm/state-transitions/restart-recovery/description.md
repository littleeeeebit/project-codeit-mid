Runs only after the gateway advisory lock is acquired (`Resources._own`). If another `Resources` in the same process owns the lock, its work is live and nothing is recovered. `recover_requests` interrupts queued and running rows, and `budget.recover` turns `dispatching` into `unknown` and `reserved` into `released` (and the same for Gemini). `close()` also runs both recoveries when job threads outlive the shutdown wait.
