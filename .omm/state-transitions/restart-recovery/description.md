On gaining the gateway lock, `Resources._own` runs `recover_requests` (queued and running → interrupted, with a note that nothing reruns) and `budget.recover` (dispatching → unknown, reserved → released, also for Gemini `external_attempts`). On controlled stop, `close()` → `RequestRunner.shutdown` marks unstarted rows interrupted, and running rows too if workers did not finish in time. If jobs are still alive after the join deadline, both recoveries run again.
