app_settings.active_run holds evaluation.serving_config (run_id, mode, index_version, dense_version, reranker, embedding, limits, eval_version) and is written only by evaluation.activate_decision (CLI activate-run or POST /api/verify/experiments/activate), together with active_index and an activations row. service.active_serving reads it on every request. It serves the keyword default when no run is active or the run's corpus_route differs from corpus_route_record(). It drops to kiwi_bm25 for an unregistered embedding model, and demotes hybrid_rerank to hybrid under a superseded EVAL_VERSION. Resources.retire_inactive unloads GPU models the new configuration no longer uses. build-keyword with activation only moves active_index, the phase-1 default path.
