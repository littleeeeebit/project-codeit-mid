What a question is served with, resolved by `service.active_serving` on every request. With no `active_run`, the keyword default (`settings.retrieval_mode`, fallback `kiwi_bm25`) runs over `active_index`. After `activate_decision`, the stored run config serves. Three stored-config downgrades apply: a corpus-routing record that differs from `corpus_route_record()` serves the default with `fallback_reason` (and `activated_run_stale:corpus_route` in limitations); an embedding model outside `ALLOWED_EMBEDDING_MODELS` serves `kiwi_bm25`; and an HR run from an older `EVAL_VERSION` serves hybrid without the reranker. Per request, `retrieval._available_mode` further falls back to `kiwi_bm25` when the dense matrix, query vector or dimensions are unavailable, and to `hybrid` when the reranker is unavailable.
