With no `active_run`, serving uses the keyword default over `active_index` (moved by `build_keyword_index` with `activate=True`). `activate_decision` sets `active_run` and `active_index` atomically and appends to `activations` with the previous value; rollback means activating an earlier run. At read time, `active_serving` degrades a stored activation without rewriting it: a stale corpus route serves the keyword default, an unknown embedding serves `kiwi_bm25`, and a stale reranker policy serves `hybrid`. Each degradation is reported by `describe_serving` and in retrieval limitations.
