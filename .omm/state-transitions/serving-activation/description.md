`app_settings.active_run` (JSON from `evaluation.serving_config`) plus `active_index` define what requests retrieve with. `activate_decision` validates the run (`decision_errors`: index/matrix verify, current `EVAL_VERSION`, pinned embedding revision) and writes both settings plus an append-only `activations` row (with `previous_json`) in one transaction. It is triggered by CLI `activate-run` or `POST /api/verify/experiments/activate` (`service.activate_experiment`). The next `retrieve` sees the change through `active_serving`. `retire_inactive` unloads GPU models no longer used, and `index()`/`dense()` reload by version. Each request records the serving run and index version it used in `trace_json.config`.
