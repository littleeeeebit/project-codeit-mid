Stored in `app_settings`: `active_index` (keyword pointer; `build-keyword` may move it) and `active_run` (JSON from `activate_decision`: mode, index/dense versions, embedding, limits, reranker, eval_version, corpus_route). `active_serving` evaluates three cases at read time. With no run, it serves the keyword default. With a run whose corpus route no longer matches, it serves the keyword default and every result carries `activated_run_stale:corpus_route`. With an unknown embedding model it serves kiwi_bm25. An HR row from an old policy is demoted to hybrid. At request time the dense matrix or a missing query vector may still fall back to K1, recorded in `fallback`. Only a person's activation changes the stored row.
