`app_settings.active_run` and `active_index` are switched only by `activate_decision`, in one transaction with an `activations` history row. `active_serving` downgrades at read time: a run measured under another `corpus_route_record()` serves the keyword default with `fallback_reason`; an unknown embedding model serves `kiwi_bm25`; a `hybrid_rerank` run from an older `EVAL_VERSION` serves hybrid without the reranker. `_config_snapshot` freezes the serving run and mode, index, prompt version, model, rates and settings fingerprint into each request's trace.
