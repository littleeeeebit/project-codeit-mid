evaluation.activate_run validates the owner's decision file (decision_errors and run_errors: complete run, current EVAL_VERSION, passed gate for HR, ready artifacts). In one transaction it then sets active_run and active_index and appends to activations with the previous config. service.active_serving reads it on every call. With no run it serves the keyword default (kiwi_bm25). A run measured under another corpus_route serves the default with activated_run_stale:corpus_route. A run whose embedding identity differs from settings serves kiwi_bm25. An HR run from an older EVAL_VERSION serves hybrid without the reranker. build-keyword --activate moves only active_index.
