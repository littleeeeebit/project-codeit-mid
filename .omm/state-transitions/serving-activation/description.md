With no `active_run`, the keyword default serves on `active_index`. `activate_decision` writes `active_run` and `active_index` together and appends to `activations`. `active_serving` can then derive fallback states without changing the stored row: a stale corpus route gives the keyword default, an unknown embedding gives `kiwi_bm25`, and a stale HR policy gives hybrid. At request time, a missing dense matrix or query vector falls back per request with a recorded `fallback`. Rollback means activating an earlier run.
