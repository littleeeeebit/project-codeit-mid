`active_run` (JSON from `evaluation.serving_config` with run_id, mode, limits, embedding, dense_version, reranker, eval_version) and `active_index`. Changed only by `evaluation.activate_decision`, from `activate-run` or the 실험 비교 activate action, each recorded in `activations` with the previous value. Building a keyword index with `activate=True` moves `active_index` only. `active_serving` applies the corpus-route, embedding-model and eval-version fallbacks at read time, so a stale activation degrades to the keyword default or plain hybrid instead of serving something it would refuse. `maintenance.run` records serving before and after and asserts it never changed.
