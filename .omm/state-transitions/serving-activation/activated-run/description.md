Written by `evaluation.activate_run(run_id, decision_file)`. It requires an absolute decision file whose `decided_by` and `rationale` the owner completed (`draft-activation` leaves them empty). `decision_errors` checks index and matrix verification, the current `EVAL_VERSION` and a passed gate for HR. One transaction sets `active_run` (the run's serving config: mode, index, dense version, embedding, limits, reranker, finalist) and `active_index`, and appends an `activations` row holding the previous config. `Resources.run_settings` then applies the run's measured limits regardless of the process configuration.
