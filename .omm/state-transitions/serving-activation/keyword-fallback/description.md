Two routes lead here. Config level: `active_serving` downgrades to kiwi_bm25 with `fallback_reason='activated_embedding_identity_requires_migration'` when the run's embedding model or dimensions differ from settings. Request level: `retrieve` downgrades a dense mode with `fallback='<mode>->kiwi_bm25:<problem>'` when the matrix failed to load (`stage_errors['dense']`, cached in `_dense_failed` until a new activation or restart), the matrix does not match the index, or no query vector is available (a free cache miss, a refused paid embedding, or a dimension mismatch).
