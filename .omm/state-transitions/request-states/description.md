Request status values: `queued`, `running`, `completed`, `failed`, `cancelled`, `interrupted`. Transitions are written by `_create`, `run_queued`, `_finish`, `cancel_request`, `RequestRunner.shutdown` and `recover_requests`. The domain outcome (`result_json.status`, e.g. `insufficient_evidence`, `budget_blocked`, `clarification_required`, `technical_error`) is separate from the row status.
