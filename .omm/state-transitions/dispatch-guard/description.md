`_dispatch_guard(res, request_id)` returns `lambda conn: _stop_reason(res, conn, request_id)`. `_stop_reason` gives `cancelled` when `cancel_requested` is set or the status is cancelled, and `interrupted` when `res._closed` is set or the status is no longer running. It runs inside `mark_dispatching`'s transaction and inside `_checkpoint` before each paid stage. `dense.query_vector` passes the same guard into `metered_embed` and `gemini_embed`. Drafting uses its own guard (`interrupted` when the service is closed).
