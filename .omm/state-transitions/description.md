Several coupled state machines govern behaviour. Request status (the `requests` table) decides what the screen shows and whether more paid stages may start. Each paid stage creates a billing attempt whose state decides spending, recovery and whether any new dispatch is allowed. Global budget controls gate every reservation. The update fence gates admission while a self-update is pending. On the corpus side, source review status decides index eligibility, gold candidate status decides which questions score runs, and the serving activation decides the retrieval configuration every request uses.
