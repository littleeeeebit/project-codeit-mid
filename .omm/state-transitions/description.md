Four persisted state machines decide paid behaviour: the request status (`requests.status`), the billing attempt state (`attempts.state`), the serving activation (`app_settings.active_run`) and the stage-review run state (`run.json`). They are coupled. Every paid stage of a request opens an attempt guarded by the request's status. The request's displayed `billing_state` is rolled up from its attempts. Each request snapshots the serving configuration in `config_hash` and `trace_json`. Paid stage-review workers reserve in the same ledger.
