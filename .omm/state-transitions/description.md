Four persisted state machines change behaviour: the request status (requests.status plus cancel_requested), the paid attempt state (attempts.state) that the request's billing_state is derived from, the serving activation (app_settings.active_run and active_index), and gold candidates (gold_candidates.status). The request stop state gates attempt dispatch; attempt states gate future admission; activation selects what retrieval serves; approved gold populates the evaluation runs that activation requires.
