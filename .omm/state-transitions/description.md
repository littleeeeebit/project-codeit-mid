Four persisted state machines govern behavior: request execution status (`requests.status` + `cancel_requested`), per-call billing (`attempts.state`), paid gateway ownership and admission switches, and the serving activation. They interact at dispatch time. `budget.mark_dispatching` evaluates the request's stop reason, ownership, `paid_admission` and the global unknown-attempt count in one transaction. `_finish` derives the request's `billing_state` from its attempts.
