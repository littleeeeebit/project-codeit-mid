Four persisted state machines decide what may run or pay. Request status (`requests.status`) gates billing dispatch: `mark_dispatching` runs the request's stop check in the same transaction. Billing attempts (`attempts.state`) produce each request's billing state, and an unknown attempt blocks all dispatch. Paid stage-review runs (`run.json` state plus `estimate.json` approval) reserve through the same gateway. Serving activation (`active_run`) is snapshotted into each request's config hash.
