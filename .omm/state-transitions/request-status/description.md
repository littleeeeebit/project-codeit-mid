The `requests.status` values are queued, running, completed, failed, cancelled and interrupted. They are written by `_create`, `run_queued`, `_finish`, `cancel_request`, `RequestRunner.shutdown`, `recover_requests` and `_fail_unscheduled`. `cancel_requested` is a separate flag. The domain outcome (`answered`, `insufficient_evidence`, `budget_blocked`, `technical_error`, ...) lives in `result_json.status`.
