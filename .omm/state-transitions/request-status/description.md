`requests.status`. Paid requests are created `queued` and free ones `running`. `run_queued` claims queued -> running. `_finish` writes the terminal status: completed, failed, or cancelled when `cancel_requested` was set and the outcome would have been completed. A status that is no longer `running` (interrupted by shutdown, or cancelled) is kept. `cancel_request` on a queued request sets cancelled directly. `RequestRunner.shutdown` and `recover_requests` set queued/running -> interrupted. Nothing is replayed after a restart.
