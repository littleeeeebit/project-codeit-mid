`run_queued` sets this state for paid modes, and `_create` sets it directly for free modes. `cancel_request` only sets `cancel_requested=1`. The next `_checkpoint`, or the dispatch guard inside `mark_dispatching`, then raises `_Stop('cancelled')`. A call already dispatched still settles. `_stop_reason` also treats closing resources, or a row that is no longer `running`, as `interrupted`.
