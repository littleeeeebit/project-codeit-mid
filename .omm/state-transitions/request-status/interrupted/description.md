Set by `RequestRunner.shutdown` (queued always; running only if futures are still pending after the wait), by `recover_requests` at startup under fresh gateway ownership (every queued and running request, nothing replayed), by `Resources.close` when job threads outlive the deadline, and by `_Stop('interrupted')` when the service is closing. `_finish` keeps interrupted even when a late worker finishes, so the outcome is stored for history only.
