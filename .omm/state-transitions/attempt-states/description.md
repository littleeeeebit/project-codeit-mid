`attempts.state` moves through these transitions: `reserved` (`reserve`) → `dispatching` (`mark_dispatching`) or `released` (a refusal at dispatch, a missing provider, or restart recovery). `dispatching` → `settled` (`settle`), `unknown` (`mark_unknown`: provider error after execution, missing usage, settlement failure, or restart recovery), or `released` (a pre-execution provider error with `confirmed_pre_execution`). `unknown` → `reconciled` (`reconcile` with provider totals) → `settled` (late usage, which adds a negative adjustment). Any unknown attempt blocks `mark_dispatching` and `paid on`. An overrun at settlement sets `frozen_reason`, which blocks `reserve`.
