`maintenance.run` writes `state.json` after each step. A run moves from `running` to `complete`, `failed` (the first step that raised, with its reason and traceback), `needs_approval` (a paid embedding or regression row stopped at its estimate) or `unverified` (a re-parse cost pinned questions their evidence). `maintenance_status` reports `interrupted` when the state says running but no thread is alive. The run records serving before and after, and the provider calls made.
