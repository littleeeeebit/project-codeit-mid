The `gold_candidates.status` column. Drafting runs (`service.start_drafting` → `drafting._generate`) write candidates.jsonl under the drafts directory. They become `pending` only through `gold.submit` (`service.submit_drafts`, or the CLI). `gold.decide` moves `pending → approved | rejected`; the reviewer must be independent of the drafter and the run starter. `approved` rows can receive a `second_review`. `rejected` rows await `gold.infer`. `repin` moves pending rows to a newer extraction. `validate-gold` admits only approved rows.
