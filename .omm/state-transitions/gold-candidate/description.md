`gold_candidates` rows enter as pending through `gold.submit` (batch file plus rows). `gold.decide` lets the first decision win, checked against `expected_sha`. It refuses an approver who drafted the row or started the drafting run, and requires a note. An approval rewrites the dataset JSONL from the database (`dataset_rows`). A rejection renders the rejection wiki page and index. `second_review` can mark an approved row as disputed, which keeps it out of valid gold. Sealed (`test`) candidates are decided only through the owner CLI.
