`sources.parse_status` moves pending, then parsed or quarantined (`ingest_source`; a quarantine also sets `review_status=needs_recovery` and `reason_code`). `review_status` is `unreviewed` for any new revision; the automatic fidelity check sets `auto_verified` or `auto_flagged`; humans set `sample_checked` or `reviewed`, which automatic checks never overwrite. Eligibility for `build-keyword --reviewed-only` is auto_verified, sample_checked or reviewed; the operating index also includes unreviewed and auto_flagged sources, labelled as such. Evidence from such sources carries `source_unreviewed` or `source_auto_flagged` warnings in `open_evidence`.
