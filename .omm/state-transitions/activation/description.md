app_settings.active_run and active_index change only through evaluation.activate_decision, and the change is appended to activations. active_serving reads them on every request. It falls back to the keyword default when the run's corpus_route differs from the current rule (activated_corpus_route_requires_rerun) or its embedding model is not allowed. It drops the reranker of a hybrid_rerank run recorded under an older EVAL_VERSION.
