Serving changes only when a person acts. `evaluation.activate_decision`, called by `activate-run` or by POST /api/verify/experiments/activate, validates the decision (`decision_errors`: index and matrix verify, current EVAL_VERSION, pinned embedding revision). In one transaction it writes `active_run` and `active_index` and appends an `activations` row that keeps the previous configuration. `build-keyword` moves `active_index` only while no run is activated, or when it is called with activate. Readers always go through `service.active_serving`, which applies the fallbacks described under the retrieval serving node.
