Paid dispatch requires all of the following: `budget_settings.paid_enabled`; `database_control.paid_admission`, set together with it by `paid on` and closed by a failed validation; no `frozen_reason`; no open recovery fence (`bidmate_recovery.control` not verified); and a passing `migration_validation`. `configure-budget` records project dates, prior use, allowance, cap and confirmed rates before paid use can be enabled (README). The Settings page changes only the shared cumulative limit (`set_budget_limit`), preserving spending and reservations.
