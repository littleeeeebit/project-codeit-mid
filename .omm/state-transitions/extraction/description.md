sources.parse_status is parsed or quarantined. sources.review_status is unreviewed, auto_verified, auto_flagged, sample_checked, reviewed or needs_recovery. ingest_source keeps the review status only when the extraction ID did not change, so a new revision resets review to unreviewed. fidelity writes the automatic verdicts and never overwrites a human status. build_keyword_index includes unreviewed and auto_flagged sources only with --include-unreviewed, and the index's review_scope is recorded as a limitation on every retrieval.
