`Resources.update_fence` is `UpdateWatch.fenced`, read under `_runner_lock` by `RequestRunner.try_admit`, `_start_job`, `start_drafting` and `start_maintenance`. While an accepted update has not ended, no new paid work is admitted. `request_update` refuses while `open_paid_work` sees any queued or running request, live job, or open or unknown attempt, so a restart never cuts a paid call off.
