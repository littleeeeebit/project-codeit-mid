`UpdateWatch.fenced()` is true while a request is being accepted (`accepting`), the marker file exists, or the updater's `result.json` says running (younger than 30 min). While fenced, `RequestRunner.try_admit`, `_start_job` and `start_maintenance` refuse with `UPDATING`. `request_update` refuses while `open_paid_work` reports open work. After `update.sh` restarts the service, the new process reads the result file to decide whether it is still fenced.
