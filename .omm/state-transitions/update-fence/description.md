The self-update protocol between the app and the root updater. `request_update` moves idle → accepting under `_runner_lock`, refuses while `open_paid_work` reports anything, and writes the marker atomically. tools/infra/bidmate-update.path triggers bidmate-update.service, which runs tools/infra/update.sh. The script writes result.json `running` before it removes the marker, then fast-forwards to origin/main, installs dependencies, rebuilds web/out when needed, restarts `bidmate` and health-checks it. It ends `succeeded`, `up_to_date`, `failed`, `rolled_back` or `rollback_failed`. `UpdateWatch.fenced()` is true while accepting, while the marker exists, or while result.json says `running`. A running result older than 30 minutes is treated as cut off.
