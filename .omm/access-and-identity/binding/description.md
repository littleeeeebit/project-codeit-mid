`service.bind_request(res, member)` sets the contextvars `generation.KEY_SESSION`, `generation.REQUEST_MODEL` and `budget.BILLING_SCOPE` from the member's current key session, and resets them when the HTTP request ends. `RequestRunner.submit` and every background job run under `contextvars.copy_context()`, so a worker uses the key and model that were in effect when the request was submitted.
