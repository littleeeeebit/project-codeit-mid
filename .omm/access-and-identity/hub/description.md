`/api/auth/login` redirects to the registered `redirect_uri` host first if needed, sets a 10-minute state cookie on `/api/auth/`, and redirects to `Hub.authorize_url`. `/api/auth/callback` compares the state in constant time. `Hub.username` then exchanges the code at `/hub/api/oauth2/token` and reads `/hub/api/user` from the server side, with a 10 s timeout. Hub failures render `_login_page` with 502 or 403.
