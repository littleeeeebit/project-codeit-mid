Append-only JSONL per run under `<data>/review/annotations/` (schema review-annotation-1), outside the run folder and git. It records notes on exact code-point spans of an answer field, edits, deletions and reviewed marks, with run, question, candidate, commit, author (git user.name) and time. `check_annotations` refuses offsets that do not select the stored text, and duplicate ids. Failure types live under taxonomy/: history.jsonl and versions/v<N>.json. Counts go to the release report as 'Human error analysis (not a sealed metric)'.
