A separate offline comparison loop: CLI `stage-review` in src/rfp_assistant/evaluation/stage_review.py plus the local review app (review/server.py serving the review/ Next.js export on a free loopback port via review.cmd). A coding agent's branch (retriever, chunking, generation or OCR) is compared with a baseline ref on identical frozen inputs. The person records a decision the agent reads. The app never runs pipelines, loads models or pays.
