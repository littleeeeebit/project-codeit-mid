review/server.py is a standard-library HTTP server. It rebuilds review/out only when the lockfile or sources changed, binds 127.0.0.1, and accepts only loopback Hosts and same-origin writes. GET routes serve runs, views, annotations, taxonomy, progress and suggestions. POST routes append notes, write decisions (`review/decisions/<run-id>.md` and `.json` with a short agent prompt) and import or export run zips. All writes take `write_lock(root)`, so two app windows over one data folder never overwrite each other.
