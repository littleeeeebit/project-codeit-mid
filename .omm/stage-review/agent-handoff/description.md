`error-analysis export` or the app's copy-prompt button writes unassigned notes to `taxonomy/exports/<id>/notes.jsonl` plus prompt.md. The coding agent groups them into `proposal.json`, and `error-analysis propose` validates it strictly: Korean name, one-sentence definition, existing unassigned notes only, no extra fields. The person accepts, renames, merges, splits or rejects types in the app. Similar-case suggestions follow the same path (`suggest`); an approved suggestion never counts as reviewed.
