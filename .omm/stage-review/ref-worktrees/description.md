`checkout` runs `git worktree add --detach` at the candidate's commit under `<data>/review/worktrees/<run>-<id>`. `read_variant` reads a committed `review-variant.json` that overrides the frozen config for this comparison only. A GPU-requiring candidate on a host without CUDA is recorded as `refused` and kept in the run. `remove_worktree` (force plus prune) always runs in `finally`.
