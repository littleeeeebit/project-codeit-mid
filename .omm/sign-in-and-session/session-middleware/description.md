`_Session.__call__` checks in this order: a non-GET with a foreign Origin → 403 (trusted origins are the request Host, plus :8510 only in local mode); `login.problem` → 503; the SIGN_IN routes pass through; no session → 401; `X-BidMate-Account` ≠ the session's member → 409 with `X-BidMate-Account-Changed: 1` (the screen reloads); a state-changing call without the header → 428. Otherwise it sets `scope.state.member` and wraps the downstream call in `bind_request`/`reset`.
