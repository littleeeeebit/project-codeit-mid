GET /api/auth/login first redirects the browser to the registered redirect URI's host if it arrived through another host (for example an SSH tunnel). It then sets the `bidmate_login_state` cookie (600 s, path /api/auth/) and sends a 303 to `Hub.authorize_url(state)`. GET /api/auth/callback compares the state with `secrets.compare_digest`, calls `Login.sign_in(code)`, and sets `bidmate_session` (HttpOnly, SameSite=Lax, path `/api/`). Failures render `_login_page` with status 400, 403 or 502. The callback also deletes any legacy `bidmate_session` cookie at path `/`. With a local member, both routes simply redirect to `/`.
