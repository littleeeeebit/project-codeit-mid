`service.bind_request(res, member_id)` sets `generation.KEY_SESSION` to the member's current key session, `generation.REQUEST_MODEL` to that session's chosen model, and `budget.BILLING_SCOPE` to the key's project, and returns a reset callback. Routes resolve the `Principal` through `service.visitor(member)`, which returns a principal with every capability, named after the hub username. That name is recorded on requests, attempts, audit rows, reviews and corrections.
