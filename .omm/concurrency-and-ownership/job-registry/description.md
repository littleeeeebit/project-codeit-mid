`_EVAL_JOBS`, `_JUDGE_JOBS`, `_MAINTENANCE_JOB` and `_DRAFT_JOBS` are module-level dictionaries/lists of threads that live only in this process. Evaluation and judge runs exclude each other (`_EVAL_LOCK` + `_refuse_closed_or_busy`). Maintenance and drafting each allow one run at a time but do not exclude the others (see the background-jobs concern). Every job thread is added to `res._jobs` under `_runner_lock`, so `close()` can join it.
