`create_app`'s lifespan calls `service.app_resources()` → `load_settings()` (repository-relative paths, optional `RFP_CONFIG_FILE` JSON whose unknown keys are rejected, validated model allowlist and limits) → `get_resources(settings)`, which builds one shared `Resources(settings, recover=True)` per process. `Resources.__init__` enters `store.database_lifecycle` (the pool) before anything else. Tests inject `resources` instead, and the app then does not close them.
