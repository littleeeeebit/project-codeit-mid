With `provider='fake'` the process uses `FakeTransport(delay_seconds=fake_delay_seconds)`. Otherwise `read_api_key('OPENAI_API_KEY')` (process environment, then the repository `.env`, never printed) builds `OpenAITransport(owner_check=owner.check)` and `Tracing.from_settings`. Without a key, free routes work (search, filters, evidence, verifier traces) and paid stages report `provider_note`. The shared Kiwi analyzer is created once per process by `shared_analyzer()`.
