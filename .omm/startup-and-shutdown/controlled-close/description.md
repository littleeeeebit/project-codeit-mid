`Resources.close()` is triggered by lifespan exit, the threading atexit hook (which runs before executor joins) or `atexit`. It sets `_closed`, so new submissions are refused, and any `_stop_reason` check now returns interrupted. `RequestRunner.shutdown(shutdown_wait_seconds=20)` marks queued requests interrupted, and running ones too if they are still pending. It joins background job threads until the deadline. If any thread is still alive it runs `recover_requests` and `budget.recover` again. Then it closes the transport, flushes and closes tracing after the workers, releases the gateway owner (the last user closes the lock connection) and exits the database lifecycle. A worker still inside a provider call keeps its attempt dispatching. If the call returns it still settles; if the process dies first, the next start marks the attempt unknown.
