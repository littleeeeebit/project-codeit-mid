`postgres.require_imported_database` refuses to start on any of: an open recovery fence, a missing or incomplete `migration_import`, a failing `migration_validation`, or any referenced artifact or index file whose hash changed. Every connection also checks the PostgreSQL 18.6 and pgvector 0.8.6 versions. Then `init_schema` (idempotent, never resets spending) and `ensure_budget_row` run.
