`store.init_schema` → `postgres.init_schema` runs under `pg_advisory_xact_lock(SCHEMA_LOCK)`. It refuses a schema newer than the application and applies the idempotent DDL with TEXT columns using C collation, then the vector schema, `application_mutex`, `schema_migrations` and `database_control` (paid_admission defaults to false). `budget.ensure_budget_row` inserts the single allowance row, paid-disabled, without touching an existing one. Spending is never reset.
