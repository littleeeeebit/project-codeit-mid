`answers.run_answers` uses `PinnedResources`, a `service.Resources` subclass that serves a finalist run's recorded configuration, charges `gold_eval`, uses the run's recorded model, and borrows the owner's transport and stop flag. It calls `service.answer` for each dev row, so evaluation exercises the production answer path. Resuming skips finished rows and rows with unknown billing. Judge comparisons (`judges.run`, Luna versus Jev) run the same way from 검증 → 판정 비교.
