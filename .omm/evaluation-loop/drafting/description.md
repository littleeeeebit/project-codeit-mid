`service.start_drafting` checks the plan against `consented_max_micro_usd` and confirms it fits. It writes `.runtime/…/drafts/<draft-YYYYMMDD-xxxxxx>/request.json` and runs `drafting._generate` on a thread through the gateway (`gold_eval` envelope), producing `output/candidates.jsonl`, `invalid.json` and `receipt.json`. The run's status (running, completed, failed, interrupted) is derived from those files and the live thread.
