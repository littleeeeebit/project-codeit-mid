`_finish` persists the validated `AnswerResult` and pops `res.partials`. While the request runs, `/api/requests/{id}/stream` emits `generation.partial_answer(content)`, but only if the request is running, not cancel-requested, and owned by the same `generation_id`. The 1 s poll on `/api/requests/{id}` returns `RequestView` (status, reserved/settled micro-USD, billing state, result) plus `attachable = service.may_attach(owned, target, view)`. The screen renders the validated answer only when it is attachable; otherwise the request stays history under 내 최근 요청, and its billing still settles.
