`_finish` writes the status, trace_json and result_json and pops the partial. A running request with `cancel_requested` that completed is stored as `cancelled`. The stream route emits partials until `finished`. TurnView's poll gets `RequestOut{view, attachable}`, and `may_attach` requires the same target, request and generation and no cancellation. An unattachable outcome stays in history ('내 최근 요청'). Citations open through GET /api/requests/{id}/evidence/{eid}, which adds `source_version_changed`, `extraction_revised`, review-status and `ocr_text` warnings. Originals download only for managed (uuid, sha256) pairs whose bytes still hash-match.
