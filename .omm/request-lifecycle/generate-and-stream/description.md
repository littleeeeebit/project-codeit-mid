`_generate` runs `_metered_chat(stage='generation')` with an `on_delta` that writes the growing content to `res.partials[request_id]`. GET /api/requests/{id}/stream polls `answer_progress`. That returns `generation.partial_answer(content)` only while the request is running, has no cancel request, and is still owned by the same generation_id; otherwise it returns `null`, which withdraws the provisional text. The stream sends `event: done` once the status is terminal.
