Corpus mode only and never for frozen runs: `metadata_answers.route` is tried before passage retrieval. Its paid calls go through the same `_metered_chat`. A refused translation call ends the request with that outcome, and a translation that fails validation returns `None`, so the request continues as a passage answer after another `_checkpoint`. A metadata answer has `status='answered'`, a Korean count summary, the listing (matched rows plus 확인 필요 rows with reasons) and evidence for the described rows.
