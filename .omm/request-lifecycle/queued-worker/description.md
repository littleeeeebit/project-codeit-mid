`RequestRunner._run` → `run_queued` atomically claims `queued → running` only if `cancel_requested = 0`. A request cancelled or interrupted meanwhile is simply skipped. It rebuilds `AnswerRequest` and `Principal` from the persisted `request_json` snapshot (never from UI state) and calls `_execute`, which opens the Langfuse trace and dispatches on mode. `_paid_answer` first answers `ingestion_unavailable` when every selected document is quarantined or not indexed. It then resolves a frozen verifier run (whose evidence is reused with no new retrieval) and takes a `_checkpoint`.
