Routing by request: a frozen verifier run uses `_frozen_prep` (re-price the frozen evidence, no retrieval). `compare` uses `_prepare_compare`, which retrieves each side separately with single-document limits, renumbers E1..En, and records per-side coverage and limitations. `corpus` uses `prepare_answer(all_documents=True)`, after which the prompt names only the documents that contributed evidence. `single` uses `prepare_answer`. Carried evidence from the previous turn is appended after fresh evidence by `_with_carried`, but only if its chunk is still in the serving index. `_priced` builds the messages with `generation.build_messages`, counts tokens exactly (`count_request_tokens`, o200k_base), and estimates the maximum cost including any uncached OpenAI query embedding. Empty evidence finishes as `insufficient_evidence`, and nothing is paid for generation.
