`_validated` → `generation.validate_answer`. Every cited evidence ID must exist, belong to an allowed document and match its stored quote. Claims, conflicts and summaries need evidence. In compare mode both represented documents must appear. A failure becomes `technical_error` (cost recorded, `citation_valid=0`) with the raw output kept in the trace. On success, `done` stores the status, summary, claims, merged missing fields, conflicts, evidence map, coverage and limitations. `_finish` computes `billing_state` from the attempts, converts `completed` to `cancelled` when a cancel arrived meanwhile, and keeps an interrupted status.
