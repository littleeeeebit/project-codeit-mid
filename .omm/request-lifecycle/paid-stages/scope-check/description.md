`_resolve_scope` requires every selected `(doc_id, source_hash)` to match the document's current `active_source_hash`. Otherwise it raises the 'document version changed, select again' `ServiceError`. Documents not parsed or not in the loaded index are listed as `ingestion_unavailable` missing fields. If no document is usable, the request ends `ingestion_unavailable`, quoting the quarantine reason (`QUARANTINE_TEXT`), without any paid stage.
