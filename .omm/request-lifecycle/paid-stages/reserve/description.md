A second `_checkpoint` runs, then `budget.reserve(stage='generation', purpose=res.paid_purpose)`. `paid_purpose` is `interactive` for the app and `gold_eval` for `answers.PinnedResources`. For frozen runs the reservation is capped by `ceiling_micro_usd`. The outcomes are: `above_consented_maximum` → `clarification_required`; any other refusal (`paid_disabled`, `frozen`, `cap_exhausted`, `envelope_exhausted`, `unknown_rate`, `ledger_unavailable`, `postgresql_maintenance`, ownership loss) → `budget_blocked`, with the evidence map still returned so search and evidence remain usable; no transport → the attempt is released as `provider_unavailable` and the request ends `technical_error`.
