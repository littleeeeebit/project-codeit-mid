The screen posts `{scope: [{doc_id, source_hash}], question, mode, previous_request_id}` (`postAsk`). `service.ask` sets `as_of` to today and creates `generation_id = uuid4()`, which also serves as the idempotency key. It returns `{request_id, generation_id, target}`, where `target = target_key(scope, question, mode, as_of, previous)`. The screen keeps that ownership record for attachment checks.
