`_metered_chat` → `budget.reserve` (on refusal: `budget_blocked`, or `clarification_required` when above a consented maximum). `paid_refusal()` without a key releases the attempt (`provider_unavailable`). `budget.mark_dispatching` with `_dispatch_guard` raises `_Stop` for cancelled or interrupted requests, and returns `budget_blocked` for ledger refusals. `_call_and_settle` streams `transport.chat` with `on_delta` writing `res.partials[request_id]`, then settles, releases or marks unknown. A failure returns `technical_error` and is never retried.
