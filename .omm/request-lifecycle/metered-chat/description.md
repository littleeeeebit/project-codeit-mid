`_metered_chat(stage, …)` runs reserve → `paid_refusal` (no key: release `provider_unavailable`) → `mark_dispatching` with the request's stop guard → `_call_and_settle`. The generate stage passes `on_delta=streamed`, which writes each accumulated chunk to `res.partials[request_id]`. Refusals become answers: `budget_blocked` (cap, envelope, paid switch, ledger busy or unknown billing), `clarification_required` (above the consented maximum) or `technical_error` (provider failure). None is retried. A `DispatchRefused` caused by cancellation or interruption raises `_Stop`, which ends the request as cancelled or interrupted.
