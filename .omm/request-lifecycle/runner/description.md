RequestRunner wraps a ThreadPoolExecutor of request_workers threads (6 in the README) and a BoundedSemaphore of request_admission slots (12). Workers receive only a request_id and run in a copied contextvars context, so the member's key session carries over. run_queued moves queued to running only when cancel_requested = 0, rebuilds the Principal from the snapshot and calls _execute. shutdown() waits shutdown_wait_seconds, cancels futures that have not started and marks queued rows interrupted, plus running rows if any worker is still busy.
