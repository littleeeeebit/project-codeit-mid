`_generate` calls `_metered_chat(stage='generation', on_delta=streamed)`. Each streamed delta replaces `res.partials[request_id]` with the content so far. The reservation uses `generation_max_output_tokens` (default 4,000, reasoning included) at the cache-write input rate. Budget refusals return `budget_blocked` with free search and evidence still usable; provider failures return `technical_error` with the billing state preserved.
