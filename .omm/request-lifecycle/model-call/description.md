`res.transport.chat(model=gpt-6-luna, messages, response_format=answer_json_schema() (strict AnswerPayload), max_completion_tokens, reasoning_effort)` runs inside the `generate-answer` trace step. A `ProviderError` with `pre_execution` releases the attempt; otherwise the attempt is marked unknown. Either way the result is `technical_error` with 'not retried automatically'. Any other exception (for example the transport closed by shutdown) is marked unknown with 'cost pending until confirmed'. A response without usage is marked unknown. With usage, `budget.settle`; a settlement failure is marked unknown and returns technical_error.
