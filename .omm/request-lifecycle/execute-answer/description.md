`run_queued` claims `queued → running` only when `cancel_requested = 0`, so a request cancelled while queued never starts. It rebuilds `AnswerRequest` and `Principal` from `request_json`, then `_execute` opens the Langfuse trace and `_execute_traced` dispatches by mode: `_metadata_answer` (CSV facts, free), `_inventory_answer` (requirement inventory, free), or `_paid_answer`. Every exit goes through `done` and `_finish`. A `_Stop` raised at a checkpoint keeps the request's cancelled or interrupted status. A `ServiceError` ends the request failed with `clarification_required`. Any other exception ends it failed with `technical_error` and the error text truncated to 300 characters.
