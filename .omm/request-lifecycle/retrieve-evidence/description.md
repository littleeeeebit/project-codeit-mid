`prepare_answer` → `retrieve` (activated mode; a dense miss may embed the query with `allow_paid=True`, its own metered `embedding` attempt guarded by the request) → `_with_carried` → `_priced`. `_priced` builds the messages with `generation.build_messages` (`PROMPT_VERSION grounded-answer-13`) and the strict JSON schema, counts tokens with o200k_base plus framing margin, and estimates the maximum cost (plus a query embedding when one would still be needed). The trace records the retrieval and the token estimate.
