`tracing.run(res.tracing, 'answer-question', seed=request_id, …)` opens one trace per executed request. Its child steps are `retrieve-evidence` (retriever), `assemble-evidence`, `rewrite-question` and `generate-answer` (generations with usage and the ledger cost), and `validate-answer` (guardrail). The scores are `citation_valid`, `insufficient_evidence` and `evidence_tokens`. A client is created only when all three `LANGFUSE_*` values are present, and a mask redacts secret-shaped values on export.
