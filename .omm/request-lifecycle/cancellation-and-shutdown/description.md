cancel_request: queued → `cancelled` immediately with no paid call; running → cancel_requested = 1, so the next _checkpoint or dispatch guard stops new paid stages. An in-flight provider call still settles. abandon_request cancels only a queued request when the screen releases ownership. Controlled stop (SIGINT from systemd, KillSignal=SIGINT, TimeoutStopSec=120) runs Resources.close: no new admission, a bounded wait, queued and running requests become interrupted, and a running worker's next dispatch is refused in the same transaction as the marker.
