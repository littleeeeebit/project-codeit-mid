`AskPage.submit` posts `{scope:[{doc_id, source_hash}], question, mode, previous_request_id}` to `/api/ask` with the member captured at click time. `api.ask` calls `service.ask`, which creates a fresh `generation_id`, uses it as the idempotency key, calls `submit_answer`, and returns `target = target_key(scope, question, mode, as_of=today, previous)`. Changing documents, scope or starting 새 대화 calls `release()`. That invalidates a POST still in flight and calls `/api/requests/{id}/abandon` with `keepalive`, which cancels the request only while it is still `queued`; a running request continues and settles as history.
