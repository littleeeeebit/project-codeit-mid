`GET /api/requests/{id}` (`service.request_status`) is read-only and allows only the owning member or a verifier. It returns the `RequestView` (status, billing state, reserved and settled micro-USD, result) and `attachable = may_attach(owned, target, view)`: same request, generation and target, and not cancelled. `GET /api/requests/{id}/stream` streams `answer_progress`, which shows partial text only while the request is running, uncancelled and owned by that generation. `POST /cancel` cancels a queued request outright, or sets `cancel_requested` on a running one. `POST /abandon` cancels only a queued request.
