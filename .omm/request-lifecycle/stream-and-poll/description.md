`TurnView` (ask-page.tsx:306) polls GET /api/requests/{id}?generation_id&target every 1,000 ms through `usePoll` until the status is terminal. The server returns the view plus `attachable = may_attach(...)`, which is false once the target, request or generation differs or a cancel was requested. While the turn is live and attachable, `useAnswerStream` reads GET /api/requests/{id}/stream with fetch, because EventSource cannot send the X-Member header. The route (api.py:370) loops over `service.answer_progress` every 150 ms. It emits `data: <partial>` whenever `generation.partial_answer` (parsing the incomplete JSON in `res.partials`) changes, `data: null` to withdraw text after cancellation or a lost generation, and `event: done` when the request is no longer queued or running. `done` triggers an immediate status reload. The validated answer renders only from the poll; streamed text is provisional.
