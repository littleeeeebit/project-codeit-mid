End-to-end flow of one 질문하기 turn, from POST /api/ask to the validated answer and its citations. Free modes (`metadata`, `inventory`) execute inline inside `submit_answer`. Paid modes (`single`, `compare`, `corpus`) are persisted as `queued` and run on the `RequestRunner`. The screen polls GET /api/requests/{id} every second and, for paid turns, also reads the SSE stream. The validated outcome is shown only while `may_attach` holds.
