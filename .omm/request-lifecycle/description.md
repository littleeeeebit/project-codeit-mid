This is the path of one paid question from the ask page to a validated, cited answer. The trigger is the composer's submit: `postAsk`, then `POST /api/ask` with scope, question, mode and `previous_request_id`. What crosses each step: an `AnswerRequest` persisted as `requests.request_json`; a `RetrievalResult` with numbered `EvidenceUnit`s; a prompt priced as a reservation; a streamed provider response; and a validated `AnswerResult` stored in `requests.result_json` together with the request's ledger billing state. The screen never receives the answer directly. It polls `GET /api/requests/{id}` and attaches the result only while it still owns the request, and it follows the SSE stream for provisional text.
