The end-to-end path of one Ask (질문하기) turn in a paid mode (single, compare or corpus). The composer's submit triggers it, and the screen owns only {request_id, generation_id, target}. The turn completes when the request row reaches a terminal status and its `result_json` holds the validated answer and evidence map. Streamed text is provisional and never authoritative. Cancellation or shutdown prevents the next paid stage, but an already dispatched call still settles or stays unknown.
