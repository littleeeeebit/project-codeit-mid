How one 질문하기 question becomes a stored, metered and validated answer. The page POSTs /api/ask. service.ask mints generation_id (also the idempotency key) and target = target_key(scope, question, mode, as_of), then calls submit_answer. Validation (_validate_request) checks mode, length, scope count (corpus: none; compare: exactly 2; others: 1–2) and any frozen verifier run. Free modes execute inline. Paid modes insert a queued row under (member_id, idempotency_key) with the config snapshot and input hash, taking an admission slot in the same transaction, then hand the request ID to the executor. The browser polls read-only status until a terminal state.
