This traces a question from the 질문하기 screen to a rendered answer. `AskPage.submit` posts `/api/ask` with scope pairs `(doc_id, source_hash)`, the question and the mode. `service.ask` mints a fresh `generation_id` (also used as the idempotency key) and calls `submit_answer`, which persists the request before any work. Paid modes are queued on the bounded executor; free modes complete inline on the HTTP thread. The screen keeps the returned ownership record `{request_id, generation_id, target}` plus the member name, polls `GET /api/requests/{id}` every second until the status leaves `queued`/`running`, and renders the result only when `attachable` is true.
