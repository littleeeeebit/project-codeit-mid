api._Session handles every /api path. A state-changing request whose Origin does not match the Host is refused with 403; the dev origins on :8510 are trusted only with BIDMATE_LOCAL_MEMBER. A login configuration problem returns 503. With no valid bidmate_session cookie it returns 401, using Login.member, whose sessions live in memory for 12 hours. An X-BidMate-Account header that names a different member returns 409. A state-changing call without that header returns 428. Otherwise it sets scope.state.member and runs service.bind_request, which binds that member's key session and model for the request. The sign-in routes go through the hub's OAuth (Hub.username exchanges the code server-side) and accept only names on BIDMATE_ALLOWED_USERS.
