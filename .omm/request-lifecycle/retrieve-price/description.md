`_prepare_paid` dispatches by mode. `prepare_answer` handles `single` and `corpus` (`all_documents=True`); `_prepare_compare` retrieves each of two documents with single-document limits. A frozen verifier run reuses its stored evidence through `_frozen_prep`, with no new retrieval. `_priced` builds the messages (`generation.build_messages`), counts tokens (`count_request_tokens`, o200k plus schema plus margin) and computes `budget.estimate`, adding a query-embedding estimate when the vector was a cache miss. No evidence at all finishes the request as `insufficient_evidence`. `_above_consented` refuses a frozen run whose prompt now costs more than its consented estimate.
