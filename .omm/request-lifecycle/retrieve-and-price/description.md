`_prepare_paid` takes one of three branches. Single uses `prepare_answer` over the scope. Compare uses `_prepare_compare`, one retrieval per side at single-document limits, with a missing side reported. Corpus uses `prepare_answer(all_documents=True)`, and the prompt names only the documents whose passages were retrieved. A frozen run uses `_frozen_prep` with no retrieval. `_with_carried` appends the previous answer's cited units the fresh retrieval lacks, renumbered after it, and drops any whose chunk left the index. `_priced` builds the messages inside the `assemble-evidence` trace step, counts tokens with o200k_base plus per-message and schema margins, and estimates the reservation, adding a query-embedding estimate on a paid cache miss. Retrieval failure becomes `technical_error`. No evidence becomes `insufficient_evidence` with no paid call. A frozen prompt now above its consented estimate becomes `clarification_required`.
