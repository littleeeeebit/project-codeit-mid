`_prepare_paid` calls `prepare_answer` or `_prepare_compare`. Those run `service.retrieve` (which may pay for an uncached query embedding, with `allow_paid`) and `_with_carried`, then `_priced`. `_priced` builds the prompt with `generation.build_messages` from the document briefs, evidence and limitations, counts its tokens exactly (`count_request_tokens`, o200k_base), and estimates the cost with `budget.estimate`. Compare retrieves each side with the single-document limits and records coverage per side. When no evidence is packed, the request ends as `insufficient_evidence`, with `not_found_in_context` per document and no generation call.
