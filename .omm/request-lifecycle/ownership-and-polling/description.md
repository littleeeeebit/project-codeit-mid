GET /api/requests/{id} calls service.request_status, which builds RequestView with billing state, reserved (open states) and settled sums. The route also computes attachable = may_attach(owned, target, view): same request, same generation, same target hash, and not cancelled. A mismatched answer is never rendered as the current one but stays in history, and its billing still settles. cancel_request: queued becomes cancelled at once with no cost. Running sets cancel_requested, so no further paid stage starts and an in-flight call still settles. abandon_request cancels only queued requests.
