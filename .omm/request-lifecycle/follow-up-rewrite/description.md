When `_conversation` returns history, `_rewrite` builds `generation.build_rewrite_messages` and calls `_metered_chat` with stage `query_rewrite` (max 1500 output tokens). `generation.validate_rewrite` must accept the output. The standalone question then replaces the asked one for retrieval and is stored as `standalone_question` on the result. The previous answer's cited evidence, up to `CARRIED_EVIDENCE = 8` units, is carried into retrieval. An unusable rewrite ends the request as `technical_error`, billed and not retried.
