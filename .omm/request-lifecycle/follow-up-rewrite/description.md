Only when `_conversation` returns history (and no frozen run). `_rewrite` builds `build_rewrite_messages(history, question, selected titles)` with `REWRITE_PROMPT_VERSION = standalone-query-1` and a strict `{query}` schema. It sends this as one metered call, stage `query_rewrite`, `max_output_tokens` 1500, reasoning included. `validate_rewrite` rejects refusal, truncation, schema errors or a length outside 1..`question_max_characters`; such a request ends `technical_error`, billed and never retried. The standalone question replaces the question for retrieval and the answer prompt. It is stored as `standalone_question` and shown as '검색에 쓴 질문'. Another `_checkpoint` follows.
