For a turn with history, _rewrite builds generation.build_rewrite_messages (prompt standalone-query-1) and pays one `query_rewrite` stage through _metered_chat (REWRITE_MAX_OUTPUT_TOKENS 1500). validate_rewrite requires a non-empty JSON `query` within question_max_characters. The standalone question replaces the user's text for retrieval and the answer, and is returned as `standalone_question`. A refusal, truncation or schema failure ends the request as technical_error (billed, not retried). The previous answer's cited units (up to CARRIED_EVIDENCE = 8) are appended after fresh retrieval by _with_carried and renumbered; units whose chunk left the index are dropped.
