GET /api/requests/{id}/stream?generation_id returns a `StreamingResponse` from a synchronous generator. Every 0.15 s it calls `service.answer_progress`, which re-reads the request via `request_status` and returns `partial = generation.partial_answer(res.partials[id])` only while the request is running, not cancel-requested, and still owned by this generation. It emits `data: <json>` when the partial changes, `data: null` when attachment is revoked, and `event: done` when the request is finished. `useAnswerStream` reads the stream with fetch and an `AbortController`, shows the partial as provisional text, and calls `status.reload()` on done so the validated result arrives immediately.
