`GET /api/requests/{id}/stream?generation_id=` first calls `answer_progress` once, so a request the caller may not see is refused before the stream opens. It then emits `data: <partial>` whenever `generation.partial_answer(res.partials[id])` changes, `data: null` when cancellation or a lost generation withdraws the text, and `event: done` once the status is no longer queued or running. The text is only provisional: `use-answer-stream.ts` renders it as 작성 중 · 검증 전 and calls `status.reload` on `done`. If the stream drops, the 1 s status poll still delivers the outcome.
