`useAnswerStream` reads `/api/requests/{id}/stream` with fetch and parses `data:` events (a partial `{summary, summary_evidence_ids, claims}` from `generation.partial_answer`, or `null` to withdraw it) and the `done` event. `done` triggers an immediate status reload. If the stream drops, polling still delivers the outcome. `answer_progress` returns a partial only while the request is running, not cancel-requested, and owned by the same generation ID.
