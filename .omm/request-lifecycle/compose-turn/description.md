`useConversation.ask` in ask-page.tsx builds the scope from the selected documents (none for corpus), posts /api/ask with `previous_request_id` set to the last turn, and appends a `Turn` with the returned `Owned`. Leaving the conversation abandons the latest owned request; the server cancels it only while it is still queued. Only the latest turn can be unfinished, because the composer stays busy until it is terminal.
