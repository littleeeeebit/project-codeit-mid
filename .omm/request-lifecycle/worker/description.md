`run_queued` claims the row from `queued` to `running` exactly once; a cancelled or already-claimed row is skipped. `_execute` opens the Langfuse trace and dispatches by mode. `_execute_traced` turns `_Stop` into cancelled or interrupted, `ServiceError` into `clarification_required`/`failed`, and any other exception into `technical_error`/`failed`. A request is never left `running`.
