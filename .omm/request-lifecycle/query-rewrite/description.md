Runs only when `_conversation` returned history. `_rewrite` builds `generation.build_rewrite_messages(history, question, titles)` and makes a separate paid `_metered_chat(stage="query_rewrite")`. `validate_rewrite` caps the result at `question_max_characters`. The rewritten question drives retrieval and the answer, and is returned as `standalone_question`; the trace records it under `trace.rewrite`. Unusable output ends the request as `technical_error`; it has been billed and is not retried.
