This runs only for follow-ups that are not frozen runs. `_conversation` walks up to `CONVERSATION_TURNS` (6) previous turns, renders each answer as the screen showed it (`_answer_text`; the latest gets 6,000 characters, older turns 1,200), and carries up to 8 cited evidence units of the previous answer. `_rewrite` builds `build_rewrite_messages` and makes one `_metered_chat` call (stage `query_rewrite`, 1,500 max output tokens), then `validate_rewrite`. A refused, failed or unusable rewrite ends the request (billed, not retried). The standalone question then drives retrieval and is stored as `standalone_question`.
