Only for a follow-up with history. `build_rewrite_messages` takes up to 6 earlier turns: each answer rendered by `_answer_text` (summary, claims, facts, conflicts, requirement rows in screen order), with 6,000 characters for the latest and 1,200 for older ones. `_metered_chat` uses stage `query_rewrite`, prompt `standalone-query-1` and 1,500 output tokens; `validate_rewrite` bounds the result to `question_max_characters`. A failure ends the request as technical_error (billed, never retried). On success, `standalone_question` is attached to the result and used for retrieval and the answer, and the previous answer's up to 8 cited units are carried forward (`_with_carried`).
