`_finish` runs one transaction. It computes the request's billing from its `attempts`, with precedence unknown > pending > reconciled > settled > released. It keeps `interrupted` or `cancelled` if the row is no longer running, and turns `completed` into `cancelled` if a cancel arrived while it ran. It writes `trace_json` and `result_json`, then removes `res.partials[request_id]`. The stored outcome is what /api/requests and /export return.
