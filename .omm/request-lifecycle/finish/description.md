`_finish` runs in one `tx(immediate=True)`. It reads every attempt of the request and reduces them to `billing_state` with precedence unknown > pending > reconciled > settled > released; open reservations show as pending. It keeps an `interrupted` or `cancelled` status set by others, turns `completed` into `cancelled` when `cancel_requested` was set mid-run, and writes `status`, `trace_json` and `result_json`. `GET /api/requests/{id}` → `request_status` → `_view` reports the status, reserved and settled micro-USD and the stored `AnswerResult`. Evidence opens through `open_evidence`, which builds a server-side citation (exact quote, neighbouring elements, warnings for a changed source or extraction, unreviewed or OCR text). Originals download only as managed `(doc_id, source_hash)` pairs whose bytes re-hash to `source_hash`.
