`run_queued` moves the row from `queued` to `running` exactly once, with `UPDATE ... WHERE status = 'queued' AND cancel_requested = 0`, then rebuilds `AnswerRequest` and `Principal` from the snapshot. A request already cancelled or claimed simply returns. `_execute` opens the trace, and `_paid_answer` resolves the scope. If every selected document is unparsed or not in the serving index, the request finishes as `ingestion_unavailable` with no paid call. `_checkpoint` runs before each paid stage.
