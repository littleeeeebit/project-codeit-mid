`run_queued` atomically claims `queued` to `running` only if `cancel_requested=0`, rebuilds the `AnswerRequest` and the `Principal` from `request_json` (worker threads never touch UI state), and calls `_execute`. That opens the Langfuse root trace and `_execute_traced`. `_paid_answer` first answers `ingestion_unavailable` when every selected document is unparsed or unindexed, and records partial unavailability as missing fields. `_checkpoint` stops a cancelled or interrupted request before the first paid stage.
