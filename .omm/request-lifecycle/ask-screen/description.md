`AskPage.submit` (ask-page.tsx:133) requires a question for paid modes. Free modes (metadata, inventory) send an empty question. It POSTs /api/ask with the scope (`doc_id` and `source_hash` pairs; empty for All documents), mode, question and `previous_request_id` set to the last turn's request, under the member captured at submit time. A `pending` attempt token plus a `mounted` ref make sure a response that arrives after the user left the conversation is abandoned, not attached. `release()` runs when the documents, scope or 새 대화 (new conversation) change, or on unmount; it clears the turns and calls POST /abandon for the latest owned request. Input is disabled while the latest turn is unfinished, so only the newest turn can be in flight and every follow-up continues from a finished turn.
