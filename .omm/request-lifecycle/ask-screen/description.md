`ask-page.tsx` posts `AskIn {scope (≤2 refs, empty for corpus), question, mode, previous_request_id}`. `api.ask` adds today's date as `as_of`. The response `Owned` is kept as the screen's current request. If the screen changes scope, question or mode, it posts `/abandon`: `abandon_request` cancels the request only while it is still queued, and otherwise the request stays in 내 최근 요청 as history while its billing settles.
