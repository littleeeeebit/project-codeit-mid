`postAsk` in `ask-page.tsx` sends `POST /api/ask` with `{scope: [{doc_id, source_hash}], question, mode, previous_request_id}` and keeps the returned `Owned` (`request_id`, `generation_id`, `target`) as a conversation turn. Each turn polls `GET /api/requests/{id}?generation_id&target` through `usePoll` until the status leaves queued or running. It shows the result only when `attachable` is true. Paid modes also open `useAnswerStream`. The free modes in `FREE_QUESTION` (metadata, inventory) do not. The cancel button calls `POST /cancel`. Leaving the screen calls `POST /abandon` with `keepalive`. Citation markers open `GET /api/requests/{id}/evidence/{evidence_id}` in the evidence pane, which is a bottom sheet below 1024 px.
