Triggered by the form submit in `AskPage.submit`. It blocks resubmission while a POST is pending or the owned request is queued or running. For paid modes it requires a non-empty question; free modes send an empty question. It captures `readMember()` once and calls `release()` on any previous ownership before posting. If the context changed while the POST was in flight (`pending.current.valid=false`) or the page unmounted, it immediately abandons the returned request instead of taking ownership.
