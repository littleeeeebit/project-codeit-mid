`TurnView` runs `usePoll(key=request_id/generation_id, 1000 ms)` against GET /api/requests/{id}?generation_id&target and stops once the status leaves queued or running. The server returns `RequestOut{view, attachable}`, where `attachable = service.may_attach(owned, target, view)`: same request, same generation, same target, not cancel-requested, not cancelled. A non-attachable finished request stays in '내 최근 요청' history (GET /api/requests), and its billing still settles.
