`GET /api/requests/{request_id}` → `service.request_status` is read-only. The owner, or any principal with verifier capability, can read it, and every visitor has that capability. `_view` derives billing from the attempts, showing open reservations as `reserved_micro_usd` and the settled sum as `settled_micro_usd`. `attachable = bool(target) and may_attach(owned, target, view)` requires the same request and generation, no cancel request and status ≠ cancelled. `POST …/cancel` → `cancel_request`: a queued request becomes cancelled with no paid call. A running one gets `cancel_requested=1`, so no further paid stage starts, the result is not attached, and an already dispatched call still settles. `POST …/abandon` cancels only if the request is still queued. Evidence: `open_evidence` reads the request's persisted evidence map and returns the exact quote, neighbouring elements from the loaded index or the preserved artifact, and warnings (`source_version_changed`, `extraction_revised`, `source_unreviewed`, `source_auto_flagged`, `ocr_text`). Downloads: `original_download` accepts only a UUID doc_id and hex source_hash of the current version and a path inside `files_dir`, and re-hashes the bytes before serving.
