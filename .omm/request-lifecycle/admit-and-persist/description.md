`service.ask` -> `submit_answer`. Validation and the conversation checks run before any write, so a refused question costs nothing and queues nothing. `_create` inserts the `requests` row in status queued and takes an admission slot in the same transaction. `runner.submit(request_id)` hands the id to the executor; if it fails, the slot is released and `_fail_unscheduled` marks the row failed. The route returns the ownership record at once.
