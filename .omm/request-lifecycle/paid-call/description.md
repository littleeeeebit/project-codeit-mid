`_checkpoint` runs, then `_generate` → `_metered_chat(stage='generation')` with `on_delta` writing `res.partials[request_id]`. The SSE route reads that through `answer_progress`, which exposes text only while the request is running, not cancelled and still owned by the same generation. Budget refusal ends the request as `budget_blocked`. A provider failure ends it as `technical_error`, with the attempt released if pre-execution or marked unknown otherwise.
