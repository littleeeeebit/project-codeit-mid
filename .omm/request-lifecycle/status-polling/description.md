TurnView polls GET /api/requests/{id} (service.request_status → _view, which joins attempts for billing_state, reserved and settled totals) every second while queued or running. useAnswerStream follows /stream. answer_progress returns generation.partial_answer(res.partials[id]) only while the status is running, not cancel_requested, and the generation_id matches. When the request finishes, the poll's `attachable` decides whether the result renders as the answer or stays under 내 최근 요청.
