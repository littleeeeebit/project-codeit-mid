This runs only when `_conversation` returned earlier turns. `_rewrite` builds `build_rewrite_messages(history, question, titles)` and runs `_metered_chat(stage='query_rewrite')`, and `validate_rewrite` checks that the output is one standalone question. That question drives retrieval and is stored as `standalone_question`. An unusable output ends the request as technical_error; it is billed and not retried. Earlier answers enter the history through `_answer_text`: the latest one up to 6,000 characters, older ones up to 1,200. Up to 8 evidence units cited by the previous answer are carried into the next evidence set.
