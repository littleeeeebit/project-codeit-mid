`AskPage.submit` POSTs `{scope:[{doc_id, source_hash}], question, mode, previous_request_id: last turn}`. It keeps the returned `Owned {request_id, generation_id, target}` as a turn. If the conversation was abandoned while the POST was in flight (`pending.valid=false`), it calls `/abandon` instead. `release()` runs on document, scope or new-conversation changes and on unmount: it clears the turns and POSTs `/api/requests/{id}/abandon` (keepalive) for the latest turn, which the server cancels only if it is still queued. Each `TurnView` polls its own request with its own `generation_id` and `target`, opens `useAnswerStream` for paid turns while the turn is live and not revoked, renders `view.result` only when `attachable`, and offers cancel through POST /cancel.
