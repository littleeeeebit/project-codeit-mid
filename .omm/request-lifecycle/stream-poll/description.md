`useAnswerStream` reads `/api/requests/{id}/stream?generation_id=` with fetch and an AbortController. `data:` events carry `generation.partial_answer` of the unvalidated content, shown as provisional. `data: null` withdraws it when the request is cancelled or the generation no longer owns it. `event: done` triggers an immediate status fetch. Independently, the page polls `GET /api/requests/{id}` (read-only) every second. `RequestOut.attachable = service.may_attach(owned, target, view)` decides whether the validated result may replace the screen's answer, which requires the same target key (scope, question, mode, date, previous turn).
