`GET /api/requests/{id}` (`request_status` plus `may_attach`) is read-only and safe to poll. `may_attach` requires the same request, generation and target, no cancel request and a status other than cancelled. `GET /api/requests/{id}/stream` emits `generation.partial_answer(res.partials[id])` while the request is running, not cancelled, and owned by the given generation. Otherwise it emits `null`, followed by `done` when the request finishes. The validated answer comes only from `result_json`.
