`GET /api/requests/{id}` (polled every second) returns `RequestView` (status, reserved and settled micro-USD, `billing_state`, `result`) and `attachable` from `may_attach`: same request, generation and target, and not cancelled. The SSE route exposes `generation.partial_answer(res.partials[id])` only while the request is running, not cancel-requested and owned by that generation. The screen shows it as '작성 중 · 검증 전' and replaces it with the validated result once the poll sees a terminal status. A non-attachable result stays in 내 최근 요청 as history; its billing still settles.
