_rewrite runs only for a follow-up, meaning the previous_request_id chain is not empty. It builds the rewrite messages (REWRITE_PROMPT_VERSION standalone-query-1) and makes a paid query_rewrite call through _metered_chat with at most 1500 output tokens. generation.validate_rewrite checks the result. Invalid output ends the request as technical_error; it has already been billed and is never retried. The standalone question is then used for retrieval and is recorded on the answer.
