`_metered_chat` makes one paid chat stage (stage `query_rewrite` or `generation`, purpose `interactive`). It calls `budget.reserve` with the exact prompt token count (`count_request_tokens`, tiktoken o200k plus a margin) and the maximum output tokens. A refusal returns `budget_blocked`, or `clarification_required` when the reservation exceeds the consented maximum. With no key it releases the reservation and returns a technical error. `budget.mark_dispatching(guard=_dispatch_guard)` makes the stop check and the dispatching marker one transaction. `_call_and_settle` then calls the transport inside a `generate-answer` trace step. A pre-execution error releases the reservation. Any other error, or a response without usage, marks the attempt unknown. A successful response settles, and a failed settlement also marks the attempt unknown.
