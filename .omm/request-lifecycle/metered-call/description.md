`_metered_chat`: `budget.reserve` (maximum cost, purpose `interactive`) → `paid_refusal` → `budget.mark_dispatching(attempt, _dispatch_guard)` → `_call_and_settle`: `transport.chat(stream when on_delta)` → `settle` from usage. A pre-execution provider error releases the reservation. Other errors and missing usage mark the attempt unknown. A settlement exception also marks it unknown. Each outcome maps to a user-facing status (`budget_blocked`, `technical_error`, `clarification_required`) while the trace records admission, usage and settlement. Streamed deltas update `res.partials[request_id]`, which `answer_progress` serves to the SSE route only while the row is running, not cancel-requested, and owned by the same generation.
