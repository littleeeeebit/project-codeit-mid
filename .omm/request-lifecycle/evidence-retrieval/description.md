`prepare_answer` (single or corpus) or `_prepare_compare` (one retrieval per document with single-document limits, renumbered E1..En, with per-side coverage) calls `service.retrieve(allow_paid=True)`. It then runs `_with_carried` and `_priced`: `generation.build_messages` builds the prompt, `count_request_tokens` counts it exactly, and `budget.estimate` plus a possible query-embedding estimate sets the maximum. No evidence means `insufficient_evidence`, with no generation call. A failure here returns `technical_error` ('검색 또는 비용 추정에 실패').
