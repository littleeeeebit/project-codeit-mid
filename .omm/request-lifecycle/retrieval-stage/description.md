There are four branches. A frozen verifier run prices its stored evidence (`_frozen_prep`) without retrieving again, and refuses if the estimate now exceeds the consented one. `compare` runs `_prepare_compare`: one scoped retrieval per document at single-document limits, with each side's coverage. `corpus` runs `prepare_answer(all_documents=True)`, and the prompt lists only documents that contributed evidence. `single` runs `prepare_answer`. `_with_carried` appends the previous answer's cited units that the fresh retrieval lacks, renumbered after it, and only if their chunk is still in the serving index. `_priced` builds the grounded messages (`generation.build_messages`, `PROMPT_VERSION grounded-answer-12`), counts tokens with o200k plus framing margin, and estimates the maximum, including a query embedding on a cache miss. No evidence ends the request as `insufficient_evidence` without a generation call. Retrieval or estimate exceptions end it as `technical_error`.
