`_paid_answer` → `_checkpoint` → optional `_rewrite` (a paid `query_rewrite` stage through `_metered_chat`, max 1,500 output tokens, validated by `validate_rewrite`) → `_prepare_paid`. That calls `prepare_answer` (`retrieve` + `_with_carried`, which appends the previous answer's cited units renumbered after the fresh evidence) or `_prepare_compare` (one scoped retrieval per document at single-document limits). `_priced` builds the messages with `generation.build_messages`, counts tokens, and estimates the reservation with `budget.estimate` plus any uncached paid query embedding. No evidence ends the request with `insufficient_evidence` and no model call.
