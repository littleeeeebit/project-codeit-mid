`_paid_answer` resolves the scope and short-circuits `ingestion_unavailable` when every selected document is unparsed or unindexed. It then prepares: from a frozen verifier run (no new retrieval), through `_prepare_compare`, through `prepare_answer(all_documents=True)` for corpus, or through `prepare_answer` for single. A dense mode may pay for an uncached query embedding here (`dense.query_vector` → `metered_embed`, a separate ledger attempt with stage `embedding`, guarded by `_dispatch_guard`). With no evidence the request ends `insufficient_evidence` with no generation call. A frozen run whose new estimate exceeds the frozen one is refused as `clarification_required`.
