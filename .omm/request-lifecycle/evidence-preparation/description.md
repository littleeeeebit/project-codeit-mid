`prepare_answer` (single/corpus) or `_prepare_compare` (two sides, each with single-document limits) calls `retrieve`, then `_priced`. `_priced` builds `generation.build_messages(question, as_of, doc briefs, evidence, limitations, conversation)` with prompt `grounded-answer-12`, counts tokens exactly (`count_request_tokens`, o200k + per-message + schema + margin) and estimates the maximum reservation. No evidence → `insufficient_evidence` with no generation call. A frozen verifier run (`_frozen_run_for`) reuses its stored evidence and refuses if the new estimate exceeds the consented one.
