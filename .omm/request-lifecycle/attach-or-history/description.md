GET /api/requests/{id}?generation_id&target returns `RequestOut{view, attachable}`. `service.may_attach` is true only for the same request, the same generation and the same target, with no cancellation. The screen renders the validated `result` only when it is attachable. Otherwise the outcome stays in the history (GET /api/requests), and its billing still settles. Citations open through `open_evidence`, which serves the persisted quote, the neighbouring elements and any warnings: source_version_changed, extraction_revised, source_unreviewed or ocr_text.
