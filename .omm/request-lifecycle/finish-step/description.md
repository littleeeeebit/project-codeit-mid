`validate_answer` runs, then `_finish` takes the ledger view of all of the request's attempts (`_billing`: `unknown` beats `pending` beats `reconciled` beats `settled` beats `released`). A running request becomes `completed`, or `cancelled` if `cancel_requested` was set. A request already marked interrupted or cancelled keeps that status. `_finish` writes `trace_json` and `result_json` and drops `res.partials`.
