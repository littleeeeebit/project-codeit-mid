A refusal ends as `budget_blocked` (or `clarification_required` for `above_consented_maximum`), and evidence remains browsable. `mark_dispatching(attempt, _dispatch_guard)` re-checks cancellation, shutdown, ownership, admission and unknown attempts in the same transaction. `transport.chat` follows; `settle(usage, response_id)` records success, while a missing usage or a non-pre-execution failure calls `mark_unknown`. A missing transport releases the reservation with `provider_unavailable`.
