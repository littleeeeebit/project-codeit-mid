`_generate` → `_metered_chat(stage="generation")`. `budget.reserve` refusal yields `budget_blocked`, or `clarification_required` for `above_consented_maximum`. A missing key releases the attempt (`provider_unavailable`). `budget.mark_dispatching` runs with `_dispatch_guard`; a stop reason raises `_Stop`, and a ledger refusal yields `budget_blocked`. `_call_and_settle` then calls `res.transport.chat(..., on_delta=streamed)`, where `streamed` writes into `res.partials[request_id]`. A pre-execution `ProviderError` releases the attempt. Any other failure, or a missing usage, marks it `unknown`. Usage is settled, and a settlement failure is downgraded to `unknown` instead of being lost.
