`_metered_chat(stage='generation', step='generate-answer', on_delta=streamed)` follows the paid-gateway protocol. While the stream runs, each delta overwrites `res.partials[request_id]`. Outcomes: admission refused → `budget_blocked` (request status remains `completed`); no key → reservation released, `technical_error`; `DispatchRefused` for cancel/interrupt → `_Stop`; provider failure → `technical_error`, with billing released or unknown by error class.
