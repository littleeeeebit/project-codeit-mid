`TurnView` polls `GET /api/requests/{id}?generation_id&target` every second until the status leaves queued/running, and renders `view.result` only when `attachable`. `useAnswerStream` shows provisional text marked 작성 중 · 검증 전 and reloads the poll on `event: done`. `POST /cancel` on a queued request cancels it before any dispatch. On a running request it sets `cancel_requested`: the next `_checkpoint` or dispatch guard stops further paid stages, while a call already dispatched still settles.
