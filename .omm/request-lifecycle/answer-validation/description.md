`generation.validate_answer(response, evidence, allowed_doc_ids, stored_quotes, required_doc_ids)` rejects the following: refusal, truncation, schema errors, unknown evidence IDs, evidence from another document, quotes that no longer match the stored chunk body (`_stored_quote` reads the active index), claims, conflicts or a summary without evidence, and a comparison that drops a side. It runs inside the `validate-answer` trace step, which records `citation_valid`. A failure stores `raw_output` in the trace and ends `technical_error`; the cost stays recorded and nothing retries. Otherwise the outcome merges model-reported and server-detected missing fields (`ingestion_unavailable`, `not_found_in_context`).
