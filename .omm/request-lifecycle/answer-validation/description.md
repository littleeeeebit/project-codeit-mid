`service._validated` builds `stored` quotes from the loaded index (`_stored_quote`) and calls `generation.validate_answer` inside the `validate-answer` guardrail step, which scores `citation_valid`. On success the payload's status, summary, claims, conflicts and next action plus merged missing fields (`_merged_missing`) become the result. On `TechnicalError` the raw output (up to 4,000 characters) is kept in the trace and the request fails as `technical_error`; the call stays billed.
