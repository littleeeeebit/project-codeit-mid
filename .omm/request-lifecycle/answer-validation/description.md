`generation.validate_answer(response, evidence, allowed_doc_ids, stored_quotes, required_doc_ids)` enforces several rules. Every claim, summary and conflict must cite known evidence IDs from the allowed documents, and quotes must match the stored chunk (`_stored_quote`). In compare mode, both represented documents must appear. A `CITATION_ERRORS` failure scores `citation_valid=0`. Failure → `technical_error` with the raw output kept in the trace (billed, not retried). Success → `done(payload.status, ...)`. `_finish` writes `status`, `trace_json` and `result_json` in one transaction, computes billing from attempts, preserves an already `interrupted`/`cancelled` row status, turns `completed` into `cancelled` when cancel was requested mid-run, and pops the partial.
