`_validated` calls `generation.validate_answer` with the evidence list, allowed doc_ids and each unit's stored chunk body (`_stored_quote`). Citation errors (`unknown_evidence_id`, `evidence_scope_mismatch`, `evidence_quote_mismatch`, `claim_without_evidence`, `conflict_without_evidence`, `summary_without_evidence`) score `citation_valid=0` and end the request as technical_error, with the raw output (capped at 4,000 characters) kept in the trace. A valid payload is merged with server-side missing fields (unavailable documents, `not_found_in_context`) and stored with the evidence map, so citations resolve server-side.
