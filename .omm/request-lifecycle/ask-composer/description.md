`AskPage.submit` sends `POST /api/ask` with scope pairs `(doc_id, source_hash)`, question, mode and `previous_request_id` (the last turn, which makes the request a follow-up), under the member name captured at submit. It stores the returned `Owned {request_id, generation_id, target}` as a new `Turn`. `release()`, triggered by a document toggle, a scope change, 새 대화 or unmount, invalidates any POST still pending and calls `POST /api/requests/{id}/abandon` with `keepalive`. Each `TurnView` polls its own request and follows its own stream. Citation markers open `GET /api/requests/{id}/evidence/{evidence_id}` in the evidence pane. The input stays disabled while the latest turn is queued or running.
