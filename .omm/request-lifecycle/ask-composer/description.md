The screen sends `{scope (≤2 refs), question, mode, previous_request_id}` and receives `Owned {request_id, generation_id, target}`. `target` is `service.target_key`, a hash of the scope, the whitespace-normalized question, the mode, the date and the previous turn. Each turn keeps its own ownership, so a late result renders only in the turn that asked it. Leaving the conversation abandons the latest turn, which cancels it only if it is still queued and therefore never dispatched.
