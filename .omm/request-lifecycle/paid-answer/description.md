Runs checkpoint → optional `_rewrite` (`query_rewrite` stage) → checkpoint → `_prepare_paid` (retrieval, carried evidence, prompt, estimate) → an `insufficient_evidence` short-circuit → checkpoint → `_generate` → `_validated`. Failure outcomes are `ingestion_unavailable`, `insufficient_evidence`, `budget_blocked`, `clarification_required` and `technical_error`. A validation failure keeps the raw model output in the trace for later review.
