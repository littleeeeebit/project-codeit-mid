`_paid_answer` calls `_checkpoint` before each paid stage. It then retrieves, assembles messages and counts tokens (`_priced`), and returns `insufficient_evidence` for free if retrieval packed nothing. Otherwise it calls `_metered_chat` with `on_delta` writing `res.partials`, and validates the structured output with `generation.validate_answer`. A citation failure (unknown evidence ID, scope mismatch, quote mismatch, or a claim, conflict or summary without evidence) scores `citation_valid=0` and ends the request as `technical_error` with the raw output kept in the trace. On success, the server-detected missing fields (`ingestion_unavailable`, `not_found_in_context`) are merged into the model's.
