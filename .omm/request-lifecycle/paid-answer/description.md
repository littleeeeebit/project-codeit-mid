`_paid_answer` first returns `ingestion_unavailable` if no scoped document is parsed and indexed. It then checks for a frozen verifier run and runs `_checkpoint`. A follow-up is rewritten with `_rewrite` (paid `query_rewrite`, `validate_rewrite`), and the standalone question drives retrieval. Preparation is one of `_frozen_prep`, `_prepare_compare` (one scoped subquery per document at single-document limits), `prepare_answer(all_documents=True)` for corpus, or `prepare_answer` for single. A follow-up's carried evidence is appended as later E-numbers (`_with_carried`). No evidence returns `insufficient_evidence` with no generation call.
