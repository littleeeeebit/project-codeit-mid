A frozen verifier run reuses exactly the evidence it showed (`_frozen_prep`), with no new retrieval or query embedding, and refuses if the new estimate exceeds the frozen consented maximum. Otherwise, for a follow-up, `_rewrite` makes a paid `query_rewrite` call through `_metered_chat` (max 1,500 output tokens) and validates the single standalone question, which is then used for retrieval and recorded as `standalone_question`. Retrieval and pricing run through `prepare_answer` (single or corpus) or `_prepare_compare` (two balanced sides), with `allow_paid=True` so a cache miss may pay for the query embedding. No evidence ends as `insufficient_evidence` without a generation call. `_checkpoint` runs before the rewrite, after it, and before generation.
