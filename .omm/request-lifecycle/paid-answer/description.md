`_paid_answer`, in order: resolve the scope (`_resolve_scope` refuses a stale source_hash). If every selected document is unparsed or unindexed, return `ingestion_unavailable` (request completed). Load the frozen verifier run, if any. Run `_checkpoint`, because the query embedding may be the first paid stage. Prepare: `_frozen_prep` (re-price the frozen evidence, no retrieval), `_prepare_compare`, or `prepare_answer`, which retrieves with `allow_paid=True`, builds messages with `generation.build_messages` (system prompt plus a JSON user payload of question, as_of, documents, limitations, allowed evidence IDs and evidence) and counts tokens with `count_request_tokens` plus a margin. A preparation exception returns `technical_error` (failed). A frozen run whose new estimate exceeds the frozen one returns `clarification_required`. No evidence returns `insufficient_evidence` (completed, no generation). Then `_checkpoint` again, and `budget.reserve(stage='generation', purpose=res.paid_purpose, ceiling=frozen estimate)`. `above_consented_maximum` returns clarification_required (failed); any other refusal returns `budget_blocked` (completed, with evidence shown). No transport releases the attempt and returns technical_error. Finally `mark_dispatching` with the stop guard; `DispatchRefused` becomes `_Stop`.
