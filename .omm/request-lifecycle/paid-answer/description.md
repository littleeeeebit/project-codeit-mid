`_paid_answer` resolves the scope. If every selected document is unparsed or not indexed, it returns `ingestion_unavailable` without paying. Before each paid stage it calls `_checkpoint`. For a follow-up, `_rewrite` makes a paid `query_rewrite` call (`build_rewrite_messages`, `validate_rewrite`) and uses the standalone question from then on. `_prepare_paid` then prepares the prompt for the mode: frozen evidence (`_frozen_prep`); compare (one scoped retrieval per document with single-document limits, `_prepare_compare`); corpus (`all_documents=True`); or single. Each path retrieves, possibly embedding the query (paid only for an OpenAI or Gemini miss), builds messages with `generation.build_messages`, counts tokens exactly (`count_request_tokens`) and estimates the maximum cost. No evidence returns `insufficient_evidence` with no generation charge.
