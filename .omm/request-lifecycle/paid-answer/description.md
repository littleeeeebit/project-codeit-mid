`_paid_answer` runs in this order. (1) Documents that are not parsed or not indexed: all unavailable → `ingestion_unavailable` with the quarantine text. (2) `_frozen_run_for` (verifier-generated requests reuse frozen evidence; no retrieval, no query embedding). (3) `_checkpoint`. (4) For a follow-up, `_rewrite` → standalone question, then `_checkpoint`. (5) `_prepare_paid` → retrieval, which may pay a query embedding, plus `generation.build_messages`, `count_request_tokens` and `budget.estimate`. A failure here yields `technical_error`. (6) For a frozen run, refuse when the new estimate exceeds the consented one. (7) No evidence → `insufficient_evidence` with server-side missing fields. (8) `_checkpoint`, then `_generate`.
