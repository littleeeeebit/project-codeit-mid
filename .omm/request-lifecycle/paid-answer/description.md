`_paid_answer` resolves the scope documents. When every selected document is unparsed or unindexed it answers `ingestion_unavailable` without paying. It applies a frozen verifier run if one is named. At `_checkpoint` (stop when cancelled or interrupted) it rewrites a follow-up into a standalone question with its own metered call. `_prepare_paid` builds the mode-specific prompt: `_prepare_compare` gives each side single-document limits; corpus mode searches all documents. With no evidence it returns `insufficient_evidence`, free. It checkpoints again before generation.
