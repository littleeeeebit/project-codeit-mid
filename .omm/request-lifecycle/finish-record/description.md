`_finish` reads the request's attempts and derives `billing_state` with the precedence unknown > pending > reconciled > settled > released. It keeps an `interrupted`/`cancelled` status set concurrently and converts completed to cancelled if `cancel_requested` was set while running. It writes status, trace_json and result_json in one transaction, then pops `res.partials`. `_trace_outcome` writes the Langfuse output and scores.
