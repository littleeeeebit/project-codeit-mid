`api.ask` takes `AskIn {scope: ScopeRef[≤2], question, mode}` and calls `service.ask(res, member, scope, question, mode, date.today())`. `service.ask` mints `generation_id = uuid4`, uses it as the idempotency key too, calls `submit_answer`, and returns `{request_id, generation_id, target: target_key(scope, question, mode, as_of)}`. A refusal raises `ServiceError` (HTTP 400) with a Korean message the screen shows.
