`api.ask` calls `service.ask(res, member, scope, question, mode, date.today(), previous_request_id)`. `service.ask` mints a fresh UUID used as both idempotency key and generation ID, calls `submit_answer`, and returns `{request_id, generation_id, target}`. `target` is `target_key`, a SHA-256 of scope, normalized question, mode, date and previous turn, which identifies what the screen is asking.
