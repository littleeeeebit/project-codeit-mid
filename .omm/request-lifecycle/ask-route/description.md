`api.ask` (api.py:353) passes today's date as `as_of` (the 기준일 / as-of-date control was removed) and calls `service.ask` (service.py:2677). That creates a uuid4 `generation_id`, uses it as the idempotency key, calls `submit_answer`, and returns `Owned{request_id, generation_id, target}`. `target` is `target_key(scope, question, mode, as_of, previous)`, a SHA-256 of what the screen asked, which the screen later sends back so the server can decide attachment.
