Triggered by the form submit in `AskPage.submit`. It sends scope pairs `{doc_id, source_hash}` (an empty list for 전체 문서), the trimmed question (empty for free modes), the mode, and `previous_request_id` (the latest turn, if any) with `X-Member`. A `pending` guard stops double submits. If the screen moved on before the POST returned (`attempt.valid` is false), the new request is abandoned immediately.
