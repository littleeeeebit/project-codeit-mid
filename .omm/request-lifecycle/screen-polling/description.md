`TurnView` polls `GET /api/requests/{id}?generation_id&target` every second. The server returns `RequestView` (status, billing state, reserved, settled, result) and `attachable` from `may_attach`, which requires the same request, generation and target and no cancellation. While the request runs and remains attachable, `useAnswerStream` shows provisional text from `answer_progress`, which reads `res.partials` only for a running, non-cancelled request with the same generation, parsed by `generation.partial_answer`. On `event: done` the poll reloads. The validated result renders only when attachable. Otherwise the turn says the result stays in recent requests, and its billing still settles.
