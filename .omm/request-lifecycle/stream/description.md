The /stream route checks permission once through answer_progress, then loops every 0.15 s. Each tick reads the request's status from the database and the partial text from memory. It sends `data: <json>` whenever the text grows, `data: null` when cancellation or a lost generation withdraws it, and `event: done` once the status is terminal. useAnswerStream calls onDone at that point, and the poll fetches the validated outcome. The streamed text is never treated as the answer.
