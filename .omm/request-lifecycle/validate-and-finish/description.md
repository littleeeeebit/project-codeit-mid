`_validated` runs `generation.validate_answer` inside the `validate-answer` guardrail step. Every claim, summary and conflict must cite allowed evidence IDs. Quotes must match the stored chunk body (`_stored_quote`). Compare answers must keep both represented documents, and only inferences may cite both. It scores `citation_valid`. A failure becomes `technical_error` with the raw output kept in the trace (billed, not retried). Success yields the payload's status, summary, claims, conflicts and next action, with the server's missing fields merged. `_finish` reads every attempt of the request to derive `billing_state` (`unknown` beats `pending`, which beats settled). It keeps a status already set to `cancelled` or `interrupted`, turns completed into `cancelled` when `cancel_requested`, stores `trace_json` and `result_json`, and pops the partial.
