`_validated` runs `generation.validate_answer` inside a `validate-answer` guardrail step. It parses the strict JSON payload and requires every evidence ID to be a known one in the allowed documents. Each quote must match the stored chunk body (`_stored_quote`), and every claim, conflict and summary needs evidence. In compare mode, both represented documents are required. Citation failures score `citation_valid=0`. A failure becomes `technical_error` with the raw output kept in the trace. Success stores the claims, merged missing fields (`_merged_missing`), conflicts, next action and the evidence map. `_finish` computes the billing state from the request's attempts (precedence unknown > pending > reconciled > settled > released). It keeps a status that was already `interrupted` or `cancelled`, turns `completed` into `cancelled` when `cancel_requested` is set, writes `trace_json` and `result_json`, and drops the partial text.
