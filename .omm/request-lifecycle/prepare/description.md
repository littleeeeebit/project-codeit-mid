In `_paid_answer`: if no document in scope is parsed and indexed, the request ends as `ingestion_unavailable`. Next come the frozen verifier run lookup and `_checkpoint`. For a follow-up, `_rewrite` makes a paid `query_rewrite` call that produces a standalone question, then checks the checkpoint again. `_prepare_paid` branches by mode. Compare runs `_prepare_compare`: one scoped retrieval per document with the single-document limits, as the retrieval gate measured them. Corpus runs `prepare_answer(all_documents=True)`. Single runs a scoped `prepare_answer`. `_priced` builds the messages, counts tokens and estimates the cost, including an uncached query embedding. If no evidence is found, the request ends as `insufficient_evidence` with no generation call. A frozen run whose new estimate exceeds its consented maximum is refused.
