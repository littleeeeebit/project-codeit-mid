`_finish` reads the request's attempts and computes the overall billing state, writes `trace_json` and `result_json`, and sets the final status. A `running` row becomes the outcome's request status, or `cancelled` when `cancel_requested` was set and the outcome was completed. A row already marked `interrupted` or `cancelled` keeps that state, and its outcome is stored only as history. The function then removes `res.partials[request_id]`, so the stream stops serving provisional text.
