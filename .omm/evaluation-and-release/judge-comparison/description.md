judges.py imports a read-only reference (750 blind-reviewed items of dev run A-9ef59b566d64, hash-checked against the archived receipt) and splits it once, seeded, into calibration and held-out parts. Three arms: luna (gpt-6-luna, judge_eval envelope), jev_bridged (gpt-6-luna translation with a glossary and placeholder round-trip, then Jev) and jev_raw (a Korean control sample). Thresholds are fitted on calibration, and uncertain or failed items abstain. Value correctness is decided by deterministic code. replacement_verdict applies the rule declared in docs/rag/judges.md.
