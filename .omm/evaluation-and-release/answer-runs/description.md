plan_run prices every remaining attempt (generation plus uncached query embeddings; no paid judge) and stores an eval_estimates row. run_answers / _answer_row call service.answer with a per-attempt idempotency key '<run>:<finalist>:<qid>:<n>'. A key whose billing is inconclusive is never resent. A key that ended unbilled (blocked, or released before execution) gets attempt n+1. A finished key returns its stored answer. _link_validity opens each cited evidence through service.open_evidence. score_record applies typed deterministic verdicts, and the latest blind human review (export-review / import-review) overrides them. latency_run measures concurrent waves as a preliminary sample.
