release.backup writes a pg_dump custom-format dump plus the mutable runtime trees to an absolute empty directory (postgres_backup.backup). release.restore_check restores into the empty RFP_RESTORE_DATABASE_DSN with paid admission off and the fake provider, then compares tables, ledger, files and artifacts. This is the documented rollback path. release-report is read-only and returns ready only when every hard check passed and every quality target was met on sealed gold, limited when something is unverified, unmeasured, missed or pilot-only, and blocked when a hard check failed (decide_status).
