The review screens (`review/src/app/page.tsx`, with `generation-view.tsx`, `retriever-view.tsx`, `chunking-view.tsx`, `ocr-view.tsx`, `annotations.tsx`, `decision-panel.tsx`) use plain `fetch` through `review/src/lib/api.ts`. In a generation run, a person selects a span of a summary, claim, conflict value, next action or missing field and writes a note. `check_annotations` refuses offsets that do not select exactly that text in the stored answer, and duplicate ids. Notes are append-only `review-annotation-1` records (note, edit, delete, reviewed) in `review/annotations/<run-id>.jsonl`. `annotation_state.version` is the record count, which the app uses to keep the newest snapshot it has seen.
