`review/server.py` is a `ThreadingHTTPServer` on 127.0.0.1. `_local` refuses any Host other than loopback on its own port, and refuses writes whose Origin is another site. GET /api/runs lists runs that have a view.json. GET /api/runs/{id} serves the view; /docs/{n}, /images/{n}.png, /export (a zip including annotations.jsonl), /annotations (folded state) and /decision serve the rest. POST /api/import validates the zip (one run folder, no path traversal, consistent run.json and view.json, valid annotations), stores the notes first, then renames the run into place under the write lock. POST /api/runs/{id}/decision runs `write_decision`, which needs a reason for every rejected candidate and writes the `.md` before the `.json`. POST /api/runs/{id}/annotations runs `add_annotation`, with the author taken from `git config user.name`. `ensure_build` runs `npm ci` and `npm run build` only when the lockfile or the sources change.
