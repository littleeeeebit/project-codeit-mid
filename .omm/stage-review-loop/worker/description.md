`execute` starts `python -I -B worker.py` with the environment stripped of OPENAI_, GEMINI_, LANGFUSE_ and HF_TOKEN secrets, HF offline mode set, and a one-hour timeout. Retriever, chunking and OCR estimate workers get `PGOPTIONS=-c default_transaction_read_only=on`. In paid mode, a generation worker builds its own `service.Resources`, so it takes the gateway lock, and answers through `answers.PinnedResources` under `capped_reservations`, which never lets a reservation exceed the approved maximum less what is already spent. Idempotency keys have the form `<run-id>:<candidate>:<question>:<n>`.
