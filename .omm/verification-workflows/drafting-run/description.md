`start_drafting` refuses when the re-planned maximum exceeds the consented one or does not fit the `gold_eval` envelope or the cap. It also refuses while another drafting job is alive or the gateway is unavailable. The thread calls `drafting._generate`, which per drafting.py lines 391–428 runs `budget.reserve(stage='gold_drafting', purpose='gold_eval')`, then `mark_dispatching(guard)`, then the call, then settle, release or unknown. Output (candidates.jsonl, invalid.json, receipt.json) goes to the run directory, which `drafting_runs` reads back. `submit_drafts` sends a completed run's valid rows to `gold.submit` once.
