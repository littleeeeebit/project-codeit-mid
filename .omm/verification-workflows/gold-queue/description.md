Covers `gold.queue`/`recent`/`candidate`/`decide`/`second_review`. Decisions are recorded under the member's hub name; the requester of a drafting run cannot approve its own drafts. The dataset file (`.runtime/datasets/dev.jsonl`) and the rejection wiki pages are re-rendered from the database on each decision. Disputed approved rows wait for an independent second review (`gold_awaiting_second_review`). The CLI `gold check` verifies that the files equal their database rendering.
