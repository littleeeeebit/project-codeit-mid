`POST /api/verify/traces` → `run_trace` → `verifier_trace` produces a free, frozen retrieval run, which can be compared with another (`/api/verify/compare`). `POST /api/verify/traces/{run_id}/generate` → `generate_from_run_id` submits one idempotent paid request (`vgen-<run_id>`) through the normal request pipeline in the `interactive` envelope. It is refused when `run_generation_block` finds no price, or when serving has changed since the run was frozen.
