In src/rfp_assistant/api.py, create_app registers four route groups. _auth_routes: /api/auth/login, /callback, /logout and /me. _routes: /api/ask, /api/requests/*, /api/originals/*, /api/budget, /api/settings/* and /api/documents. _verify_routes: /api/verify/* for traces, evaluation, judges, maintenance, experiments, fidelity and corrections. _dataset_routes: /api/drafting/* and /api/gold/*. The Pydantic models are read-only mirrors of the service dataclasses (from_attributes). The lifespan opens service.app_resources() and closes it on stop. ServiceError maps to HTTP 400, and the auth errors in service.SHELL_ERRORS map to 403. The _Session ASGI middleware guards every /api path (see request-lifecycle/session).
