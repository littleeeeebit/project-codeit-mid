`api.create_app`: the lifespan builds `service.app_resources()` (`get_resources(load_settings())` → `Resources(recover=True)`), sets `res.update_fence = UpdateWatch.fenced`, starts the GitHub poll thread, and closes both on stop. The ASGI middleware `_Session` guards /api/*. A state-changing call from another origin gets 403 (only :8510 dev origins are trusted, and only with BIDMATE_LOCAL_MEMBER). `login.problem` gets 503. The sign-in routes are open. A call with no session gets 401, one whose `X-BidMate-Account` names a different member gets 409, and a state-changing call that names no account gets 428. The middleware then calls `service.bind_request`, which sets the context variables `generation.KEY_SESSION`, `generation.REQUEST_MODEL` and `budget.BILLING_SCOPE`, and resets them when the call ends. Route groups: `_auth_routes` (JupyterHub OAuth login, callback with a state cookie, logout, me); `_account_routes` (info, update status/request, budget and its limit, API key and model); `_ask_routes` (documents, ask, requests, stream); `_request_routes` (cancel, abandon, export, evidence, originals); `_verify_routes`; `_dataset_routes`. `ServiceError` maps to 400 and the `SHELL_ERRORS` auth errors to 403. The /stream route is SSE: it polls `service.answer_progress` every 0.15 s, emits the partial when it changes, then `event: done`.
