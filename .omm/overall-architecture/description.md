RFP assistant (입찰메이트): one Python process answers grounded questions about historical Korean RFPs. `uvicorn rfp_assistant.api:app --workers 1` serves two things: the static Next.js export (`web/out`, mounted last in `create_app`) and the `/api/*` routes. Each route calls one `service` function. The service core owns one process-wide `Resources`, which holds the paid-gateway lock, the OpenAI transport, Langfuse tracing, the cached keyword and dense indexes, and a bounded executor. Paid answers run on that executor as persisted requests: they retrieve evidence under the activated retrieval configuration, reserve their maximum cost in the PostgreSQL ledger, call OpenAI once (never retried) and are validated against the evidence they cite. The corpus pipeline (ingest, OCR, fidelity, index builds) and evaluation (gold, frozen runs, comparison matrices, activation, release) run mainly from `cli.py`. The 검증 screen can also start some of them on background threads. A separate loopback review app (`review/`) shows stage-review run folders and writes decision files.
