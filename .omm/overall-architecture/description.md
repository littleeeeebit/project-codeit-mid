BidMate (입찰메이트) is a single-process RFP question-answering assistant over about 100 historical Korean RFP originals (HWP/PDF). A static Next.js export in web/out is served by the same FastAPI process that exposes /api/* (src/rfp_assistant/api.py). Every route calls one function in src/rfp_assistant/service.py, which owns the process-wide Resources. Resources covers the loaded keyword index, verified pgvector set, Kiwi analyzer, the OpenAI transport, the PostgreSQL gateway advisory lock, the bounded request executor and background job threads. Free paths are document search, metadata/inventory answers, evidence and original download, and verifier retrieval traces. They read PostgreSQL and the immutable index/extraction artifacts under RFP_DATA_DIR. Paid paths are answer generation, follow-up rewriting, query embedding, drafting, evaluation, judges and maintenance embeddings. Each goes through budget.reserve → budget.mark_dispatching → transport call → budget.settle / mark_unknown / release. Offline corpus work runs from the owner CLI (src/rfp_assistant/cli.py): ingest, fidelity and OCR, build-keyword, embeddings, evaluation, compare, activate-run, gold review, sealed release, backup/restore and budget administration. Serving changes only when activate-run (or the 실험 비교 activate route) writes app_settings.active_run. Langfuse tracing is optional observability and never feeds admission or settlement.
