BidMate (입찰메이트) runs as one process. `rfp_assistant.api:create_app` builds a FastAPI app that serves the static Next.js export in `web/out` and the `/api/*` routes. Each route calls exactly one function in `src/rfp_assistant/service/service.py`. The owner CLI (`python -m rfp_assistant.cli`) drives the same service and pipeline modules. All mutable state lives in one validated PostgreSQL 18.6 + pgvector 0.8.6 database: documents, extractions, chunks, requests, attempts, audit events and embedding vectors. Immutable artifacts sit under `RFP_DATA_DIR` (default `.runtime`) and the database references them by hash: extraction JSONL, keyword index folders, run folders, the maintenance state and gold files. The only provider call site is `gateway/generation.py`, and every call first goes through the reservation ledger in `gateway/budget.py`. What retrieval serves is whatever `activate-run` or the 실험 비교 activate action last wrote to `app_settings.active_run`. With no activation it is the keyword default `kiwi_bm25`.
