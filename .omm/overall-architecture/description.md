BidMate (입찰메이트) is a single-process RFP assistant. One uvicorn worker runs the FastAPI app (`src/rfp_assistant/api.py`), which also serves the static Next.js export in `web/out`. On startup, `create_app` lifespan calls `service.app_resources()` → `get_resources(load_settings())` → `Resources(settings, recover=True)`. That process-wide owner holds the PostgreSQL gateway advisory lock, the Kiwi analyzer, the loaded keyword index, the dense/reranker models, the OpenAI transport with per-member key sessions, and Langfuse tracing. Every HTTP route calls exactly one `service` function (enforced by `tests/test_api.py`). The owner CLI (`cli.py`) calls the same service, corpus, retrieval and evaluation modules directly. For budget administration it uses a ledger-only `Resources(dispatch=False)` beside the serving app. All durable state lives in PostgreSQL 18.6 + pgvector 0.8.6 (`RFP_DATABASE_DSN`), plus content-addressed files under `RFP_DATA_DIR` (`.runtime/`): extraction artifacts, keyword index directories, run directories and comparison tables. Paid model calls pass through one choke point (`service._metered_chat` / `dense.metered_embed` → `gateway/budget.py` → `gateway/generation.py`). Serving retrieval is whatever `activate-run` / `activate_decision` last recorded in the `active_run` app setting; until then it is the keyword default.
