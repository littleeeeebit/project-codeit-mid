BidMate (입찰메이트) is one FastAPI process, `uvicorn rfp_assistant.api:app --workers 1`. `api.create_app` mounts the static Next.js export from `web/out` at `/` and the `/api/*` routes. Each route calls exactly one function in `service/service.py`. On startup the lifespan hook calls `service.app_resources()`, which builds a single `Resources` owner. That owner refuses to start unless the PostgreSQL database has a validated import (`storage/postgres.require_imported_database`). It then takes the database-wide paid-gateway advisory lock (`GatewayOwner`) and recovers whatever a previous process left unfinished. Every durable record lives in PostgreSQL: documents, extractions, chunks, requests, attempts (the ledger), activations, audit rows and pgvector sets. Content-addressed artifacts live under `.runtime/`: extracted elements, keyword index directories, run folders and review files. The only paid OpenAI call site is `gateway/generation.OpenAITransport`, and every paid call is first admitted by `gateway/budget.reserve`. Offline work runs from `cli.py`: ingest, OCR, fidelity, index builds, evaluations, activation, budget administration and stage review. `review/server.py` is a separate standard-library-only server. It reads stage-review run folders and appends human notes and decisions to files under `.runtime/review`. It never opens the database and never pays.
