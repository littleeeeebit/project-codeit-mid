BidMate (the RFP assistant) runs as a single process. FastAPI in src/rfp_assistant/api.py serves both the /api routes and the Next.js static export from web/out, and each route calls one function in service/service.py. The service builds one Resources object per process (Resources._initialize). It holds the Kiwi analyzer, the active KeywordIndex, the pgvector index, an optional GPU reranker, the OpenAI or Fake transport, the Langfuse tracer and the PostgreSQL gateway advisory lock. It also owns a bounded RequestRunner executor. Durable state lives in PostgreSQL 18.6 with pgvector 0.8.6, using the schema in storage/store.py. Immutable artifacts sit under the data directory (.runtime): extraction elements.jsonl, keyword index directories, retrieval runs, drafts and maintenance reports. Database rows point to those files by path and hash. The owner CLI (cli.py) uses the same database and modules to run the corpus pipeline, evaluation, activation and budget administration. The only paid provider path goes through gateway/budget.py reservations into gateway/generation.py.
