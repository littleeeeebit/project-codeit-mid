RFP assistant (입찰메이트) is one Python process that serves both the API and the built Next.js screens. Uvicorn runs `rfp_assistant.api:app` with exactly one worker. `create_app` mounts `web/out` as static files after every `/api/*` route. Its lifespan calls `service.app_resources()`, which loads settings and builds one `service.Resources` with `recover=True`. That object owns the PostgreSQL pool, the paid-gateway advisory lock, the provider transport, the loaded keyword index, the dense and reranker models, the bounded request executor and the background jobs. Every HTTP route is a thin wrapper around a single `service` function. `tests/test_api.py` enforces that `api.py` imports nothing else from the package. Retrieval runs locally over immutable index files under `.runtime/indexes/` and over pgvector rows. All paid OpenAI work (chat and query embeddings) goes through one ledger in PostgreSQL: each call is reserved before dispatch and settled once afterwards. The owner CLI (`python -m rfp_assistant.cli`) drives the offline pipeline (manifest, ingest, fidelity, OCR, keyword and dense builds, evaluation, activation, backup) and the budget administration against the same database.
