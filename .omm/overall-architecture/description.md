BidMate (입찰메이트) is a single-process RFP assistant. One uvicorn worker serves FastAPI routes (src/rfp_assistant/api.py) and the statically exported Next.js screens (web/out, mounted last at '/'). Every /api route calls exactly one function in src/rfp_assistant/service/service.py. That module owns the process-wide `Resources`: the Kiwi analyzer, the loaded keyword and dense indexes, the provider transport, Langfuse tracing and the PostgreSQL paid-gateway advisory lock. It runs paid questions on its own bounded `RequestRunner` thread pool. Retrieval (src/rfp_assistant/retrieval/retrieval.py) serves whichever evaluated run a person activated (app_settings `active_run` / `active_index`). Every OpenAI or embedding call is reserved, marked dispatching, then settled or held unknown in the `attempts` ledger by src/rfp_assistant/gateway/budget.py. Corpus upkeep (backup, restore check, ingest, fidelity, keyword index, embeddings, regression) runs as one background maintenance thread from the 검증 screen, or through the CLI `maintain` command. The owner CLI (src/rfp_assistant/cli.py) builds the same `Resources` for paid commands, so it contends for the same gateway lock. All durable state is in PostgreSQL 18.6 with pgvector 0.8.6, plus files under RFP_DATA_DIR (.runtime): extraction artifacts, index payloads, run folders and maintenance state.json.
