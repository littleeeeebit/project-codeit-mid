BidMate (입찰메이트) is a single-process RFP assistant for historical Korean RFPs. You search documents, pick zero to two of them, ask a scoped question and get one metered answer whose citations point back to the original. The deployed form is one uvicorn process (`python -m uvicorn rfp_assistant.api:app --workers 1`). `api.create_app` serves the FastAPI routes under `/api/*` and mounts the static Next.js export in `web/out` at `/`, so one port serves both. Every route calls exactly one function in `service.py`. That module owns the process-wide `Resources`: the Kiwi analyzer, the loaded keyword index, the pgvector dense index, the optional reranker, the OpenAI or fake transport, the Langfuse tracer and the PostgreSQL gateway advisory lock. It runs paid answers on a bounded in-process executor (`RequestRunner`). Retrieval (`retrieval.retrieve`) is free unless a dense mode needs an uncached query embedding. Every paid call (query embedding, answer generation, drafting, evaluation answers, judges) goes through the shared ledger in `budget.py`: reserve the maximum cost, mark dispatching under a stop guard, make one transport call, then settle once or record the cost as unknown. All durable state lives in one validated PostgreSQL 18.6 + pgvector 0.8.6 database (`postgres.py`, `store.py`, `vector_store.py`). Large immutable artifacts (extraction element files, keyword index files, run directories, drafts, datasets, sealed sets) live under `.runtime/`, bound to the database by recorded SHA-256 hashes. The owner CLI (`cli.py`) runs the offline pipeline: manifest, ingest, OCR, fidelity, build-keyword, build-dense, evaluate, activate-run, backup/restore. It also runs budget administration. Its paid commands open the same `service.Resources` and so the same gateway lock. Langfuse tracing is observability only: admission and settlement never read it.
