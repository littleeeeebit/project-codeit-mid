BidMate (RFP assistant) is a single-process FastAPI service over PostgreSQL 18.6 with pgvector 0.8.6. It answers scoped questions about about 100 historical Korean RFP originals (HWP/PDF) with metered, citation-validated gpt-6-luna answers. One uvicorn worker (`rfp_assistant.api:app`, `--workers 1`) serves both the JSON API and the static Next.js export in `web/out`. At lifespan start, `api.create_app` calls `service.app_resources()` -> `get_resources(load_settings())` -> `Resources(settings, recover=True)`. That call takes the database-wide paid-gateway advisory lock, recovers requests and attempts left unfinished by a previous process, and builds the OpenAI transport (or `FakeTransport`) and the optional Langfuse client. Every HTTP route calls exactly one `service` function. Free work (document search, retrieval traces, metadata and inventory modes, evidence browsing) never touches the ledger. Paid work (answers, query embeddings, drafting, answer evaluation, judges) always reserves its maximum cost in the `attempts` ledger before dispatch and settles it from reported usage. Corpus preparation, embedding builds, comparison matrices, evaluation, sealed runs and budget administration run through the owner CLI (`python -m rfp_assistant.cli`), not on a schedule. What serves users changes only when a person activates a recorded run (`activate-run` or the 실험 비교 activate button).
