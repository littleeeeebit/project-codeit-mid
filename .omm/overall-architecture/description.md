BidMate (입찰메이트) is an internal assistant for historical Korean RFPs. A consultant finds a project, scopes a question to one or two documents (or all documents) and gets one metered answer grounded in the source, with citations into the original evidence. At runtime it is one uvicorn process run with exactly one worker. In `api.create_app`, FastAPI serves the JSON routes under /api/* and mounts the static Next.js export in web/out last. Each route calls one function in `service/service.py`, and `tests/test_api.py` checks that api.py imports nothing else from the package. The service layer owns a process-wide `Resources` object: the loaded keyword index, the dense index, the reranker, the OpenAI transport, Langfuse tracing and the PostgreSQL gateway advisory lock. Retrieval reads hash-verified index files under RFP_DATA_DIR/indexes and vector sets in pgvector. Every paid model call goes through the budget ledger in a fixed order: reserve, mark dispatching, call, then settle, release or mark unknown. PostgreSQL 18.6 with pgvector 0.8.6 is the only database: `postgres.require_imported_database` refuses to start on a database without a validated import marker and unchanged artifact hashes. The owner CLI (`cli.py`) runs the corpus pipeline, evaluation, activation, budget administration and stage-review runs. The separate stage review app (`review/server.py`) only reads run folders and writes decision and annotation files.
