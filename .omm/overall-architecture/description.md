BidMate (입찰메이트) runs as one Python process: `uvicorn rfp_assistant.api:app --workers 1`. `create_app()` in src/rfp_assistant/api.py mounts the static Next.js export (`web/out`) at `/` and registers every `/api/*` route. Each route calls exactly one function in `rfp_assistant.service.service`, and tests/test_api.py enforces that import boundary. The service module owns the process-wide `Resources`: the Kiwi analyzer, the loaded keyword index, the pgvector dense set, the reranker, the OpenAI transport, Langfuse tracing and the gateway advisory lock. It also owns the bounded `RequestRunner` executor and the module-level background-job registries. All durable state lives in PostgreSQL 18.6 with pgvector 0.8.6, reached through `storage/postgres.py` pools, plus immutable artifacts under `.runtime/` (extractions, index manifests, runs, datasets, compare tables). Every paid provider call is metered by `gateway/budget.py` and can only be dispatched by the process that holds the database-wide advisory lock. The owner CLI (src/rfp_assistant/cli.py) runs the same service and pipeline functions out of process, either as a ledger-only owner or as a full gateway owner that is refused while the app holds the lock. In production the unit file tools/infra/bidmate.service runs this on the `codeit` VM at :8501 behind JupyterHub OAuth sign-in.
