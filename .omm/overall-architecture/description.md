BidMate (입찰메이트) is a single-process FastAPI service over one PostgreSQL 18.6 + pgvector 0.8.6 database, plus a separate local stage-review app. `src/rfp_assistant/api.py` serves the statically exported Next.js screens from `web/out` and exposes `/api/*`. Each route calls one function in `service/service.py`. The service owns one `Resources` object per process: the keyword index, the dense set and reranker, the provider transport, the paid-gateway advisory lock and the bounded request executor. Paid model calls go only through `gateway/budget.py` (reserve → dispatching → settle/unknown/release) and `gateway/generation.py` (the only OpenAI SDK call site). The owner CLI (`cli.py`) runs everything that is not interactive: corpus ingestion, OCR and fidelity, index and embedding builds, evaluation, comparison matrices, activation, answer and sealed runs, maintenance, budget administration and stage-review runs. These use the same `Resources` and ledger, so the CLI refuses paid work while the server holds the gateway lock. The review app (`review/server.py`, standard library only) reads stage-review run folders under `<data>/review` and writes decisions, span notes and failure-taxonomy decisions to files. It never runs a pipeline or pays.
