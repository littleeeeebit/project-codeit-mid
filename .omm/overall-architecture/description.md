BidMate (the RFP assistant) is one Python package, `src/rfp_assistant`, with two entry points. The first is `api.py`, a FastAPI app served by `uvicorn --workers 1`. It mounts the static Next.js export from `web/out` at `/` and exposes `/api/*`, and every route calls exactly one function in `service/service.py`. The second is `cli.py`, the owner's operational CLI. At startup `api.create_app` runs its lifespan hook, which calls `service.app_resources()` → `get_resources(load_settings())` → `Resources(settings, recover=True)`. That one process-wide object owns: the PostgreSQL database lifecycle; the database-wide gateway advisory lock (`postgres.GatewayOwner`); the OpenAI transport; the cached keyword index, pgvector set and reranker; the bounded request executor; the background job threads; and the in-memory per-member API keys. Answers retrieve evidence from immutable keyword-index files plus pgvector sets. Each paid call is reserved, dispatched and settled through the ledger in `gateway/budget.py`, and the only OpenAI SDK call site is `gateway/generation.py`. Corpus preparation, index builds, evaluation runs and activation are CLI-driven. The 검증 page can also start some of these as background jobs (maintenance, answer evaluation, judges, activation). The stage review app (`review/server.py`) is a separate standard-library HTTP server. It only reads the run folders that `cli stage-review run` writes and records the person's decision.
