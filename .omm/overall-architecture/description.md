BidMate (RFP assistant) is a single-process Python application over a historical Korean RFP corpus. A Next.js static export in web/ talks only to the FastAPI shell src/rfp_assistant/api.py. Each route calls exactly one function in src/rfp_assistant/service.py. The service owns process-wide resources (the Kiwi analyzer, the loaded keyword index, the pgvector dense set, the OpenAI transport, Langfuse tracing and the PostgreSQL paid-gateway advisory lock). It orchestrates free retrieval and metered gpt-6-luna generation. Every record lives in one validated PostgreSQL 18.6 + pgvector 0.8.6 database: documents, extractions, chunks, requests, the billing ledger, gold candidates, verifier runs and embeddings. Immutable index manifests and extraction artifacts live on disk under RFP_DATA_DIR (.runtime) and are hash-checked on load. Offline work (manifest import, ingestion, fidelity, OCR, index building, embeddings, evaluation, activation, sealed runs, backups, budget administration) runs through the owner CLI src/rfp_assistant/cli.py. The CLI calls the same modules and the same ledger. The README and the api.py docstring require uvicorn to run with exactly one worker, because paid work runs on in-process executors and the process holds the database-wide gateway lock.
