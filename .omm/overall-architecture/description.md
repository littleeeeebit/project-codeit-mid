BidMate (the RFP assistant) is one Python process. `rfp_assistant.api:app` runs under uvicorn with exactly one worker. It serves the exported Next.js screens and a `/api` surface where every route calls one function in `src/rfp_assistant/service/service.py`. The FastAPI lifespan in `create_app` calls `service.app_resources()` -> `get_resources(load_settings())`, which builds one process-wide `Resources(settings, recover=True)`. That object holds a reference to the PostgreSQL pool (`store.database_lifecycle`) and takes the paid-gateway advisory lock (`postgres.gateway_lock`). It also recovers what a previous process left (`recover_requests` and `budget.recover`), holds the OpenAI transport, and caches the activated keyword index, dense set and reranker. It owns the bounded `RequestRunner` and every background job thread. Offline work runs through `cli.py` against the same database: manifest, ingestion, OCR, fidelity, index and embedding builds, evaluation, activation and budget administration. PostgreSQL 18.6 with pgvector 0.8.6 is the only database. Immutable artifacts (extraction JSONL, keyword index directories, run directories, maintenance reports) live under `RFP_DATA_DIR` (`.runtime`). Their hashes are re-verified when they are loaded and at startup (`require_imported_database`).
