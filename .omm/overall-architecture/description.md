BidMate (입찰메이트) is an internal assistant for about 100 historical Korean public-procurement RFPs in HWP and PDF. It has three entry points. The first is the FastAPI app `rfp_assistant.api:app` (`create_app`), which serves `/api/*` and the static Next.js export from `web/out` on one port. The second is the operator CLI `python -m rfp_assistant.cli` (ingest, build-keyword, activate-run, maintain, compare, stage-review and others). The third is the standalone stage-review server `review/server.py`. The API is a thin layer: each route calls one `service.service` function with the signed-in member that the session middleware bound. The service core owns one process-wide `Resources` object, which holds the keyword index, dense matrix, reranker, provider transport, request executor and in-memory member keys. A request reaches a paid model only one way: `_metered_chat` calls `budget.reserve`, then `mark_dispatching`, then `OpenAITransport.chat`, then `settle`, all against the PostgreSQL ledger. The corpus pipeline turns originals into extractions and keyword indexes. Serving reads them only through the activated run (`active_serving`).
