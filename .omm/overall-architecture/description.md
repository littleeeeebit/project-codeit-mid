BidMate (입찰메이트) answers grounded questions about historical Korean RFPs. It is one Python process: `uvicorn rfp_assistant.api:app --workers 1` (tools/infra/bidmate.service). That process serves a statically exported Next.js app from `web/out` and the FastAPI `/api/*` routes in `src/rfp_assistant/api.py`. Each route calls exactly one function in `service/service.py`. A process-wide `Resources` object owns the PostgreSQL pool, the loaded keyword index, the dense set and reranker, the OpenAI transport and the bounded request executor. Paid work runs in that process's own threads. It is allowed only while the process holds the database-wide gateway advisory lock (`postgres.GatewayOwner`), and every provider call is reserved and settled in the `attempts` ledger (`gateway/budget.py`). All durable state lives in PostgreSQL 18.6 with pgvector 0.8.6, plus hashed file artifacts under `RFP_DATA_DIR` (`.runtime/`): extractions, index directories and run folders. Startup refuses a database without a validated import (`postgres.require_imported_database`). Corpus building, evaluation, activation and budget administration are offline pipelines, started from the owner CLI (`cli.py`) or from background jobs on the 검증 and 데이터셋 screens. Serving changes only when a person activates a run.
