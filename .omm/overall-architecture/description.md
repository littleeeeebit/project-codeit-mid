BidMate (RFP assistant) is a single-process FastAPI service. It serves a Next.js static export from web/out and the JSON API from src/rfp_assistant/api.py on one port. Members search historical Korean RFPs, ask a scoped question, and get one metered, citation-validated answer from gpt-5-mini. Every route calls one function in src/rfp_assistant/service/service.py. Paid questions are persisted as `requests` rows and executed on an in-process bounded executor (RequestRunner). Each provider call passes through the budget ledger in src/rfp_assistant/gateway/budget.py: reserve the maximum cost, mark the attempt dispatching inside a guarded transaction, call, then settle, release or mark unknown. All state lives in one validated PostgreSQL 18.6 + pgvector 0.8.6 database: sources, extractions, elements, chunks, requests, attempts, activations and audit rows. Immutable artifacts (extraction JSONL, index directories, OCR cache, run folders) live under RFP_DATA_DIR (.runtime). The corpus pipeline (ingest, OCR, fidelity, keyword index build, activation) and budget administration run only through the owner CLI (src/rfp_assistant/cli.py). A separate stage review runner and loopback app compare git refs on frozen inputs and record a person's decision.
