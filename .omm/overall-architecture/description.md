RFP assistant (입찰메이트) is a question-answering service over about 100 historical Korean RFP originals. It runs as one Python process: `uvicorn rfp_assistant.api:app --workers 1`. `api.create_app` mounts the static Next.js export (`web/out`) at `/` and registers every `/api/*` route before it, so one port (8501) serves both. Every route calls one function in `service.py`. That module holds a process-wide `Resources` object, which owns the loaded keyword index, the Kiwi analyzer, the OpenAI transport, Langfuse tracing and the PostgreSQL gateway advisory lock. All records live in PostgreSQL 18.6 with pgvector 0.8.6: documents, extractions, chunks, requests, the billing ledger, activations and vectors. Immutable content-addressed artifacts live under `RFP_DATA_DIR` (`.runtime/`): extraction JSONL, keyword index directories, runs and comparison tables. The owner CLI (`cli.py`) builds everything that serves: ingest, keyword index, embeddings, evaluation, activation, budget administration. In the UI, `검증 → 유지보수` and `실험 비교` start the same maintenance and activation code on background threads.
