BidMate (입찰메이트) runs as a single process: one uvicorn worker (`tools/infra/bidmate.service`) hosts the FastAPI app from `create_app` in `src/rfp_assistant/api.py`. That app serves the static Next.js export from `web/out` and the `/api/*` routes. Each route calls exactly one function in `src/rfp_assistant/service/service.py`; tests/test_api.py checks that api.py imports nothing else from the package. The service owns the shared runtime objects (`Resources`): the Kiwi analyzer, the loaded keyword/dense indexes and reranker, the paid transport, Langfuse tracing and the PostgreSQL gateway advisory lock. It runs paid work on in-process threads, which is why there must be exactly one worker. All durable state lives in PostgreSQL 18.6 with pgvector 0.8.6 (`storage/postgres.py`), plus immutable artifacts under `RFP_DATA_DIR` (`.runtime`). Offline pipelines (ingest, build-keyword, build-dense, evaluate-retrieval, compare, activate-run, maintain, backup) run from the owner CLI `src/rfp_assistant/cli.py`. Some of them can also be started from the 검증 screen as background jobs inside the serving process.
