The Next.js screens live under web/src/app: page.tsx (ask), verify/page.tsx (verification), dataset/page.tsx (dataset building) and settings/page.tsx. `npm run build` exports them to web/out. create_app mounts that folder at / last, so /api/* always stays with the API. web/src/lib/api.ts is an openapi-fetch client typed from the generated schema, with two middlewares. `expired` redirects the browser to /api/auth/login on a 401. `sameAccount` adds X-BidMate-Account to every call and reloads the page on a 409 that carries X-BidMate-Account-Changed. ask-page.tsx submits with POST /api/ask. It then follows the request two ways: usePoll on GET /api/requests/{id}, and useAnswerStream reading the SSE endpoint /api/requests/{id}/stream through fetch so the stream can be aborted.
