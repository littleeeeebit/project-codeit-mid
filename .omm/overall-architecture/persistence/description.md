Everything reaches the database through `store.open_db(settings.db_path)` and `store.tx(conn, immediate)`. `Settings.db_path` always returns a `postgres.Target`, whose DSN comes from `RFP_DATABASE_DSN` in the environment (the application database `bidmate_app`). PostgreSQL is the only backend. The Phase 4 pilot runtime is a separate, paid-disabled database, `bidmate_pilot_archive`, that no code opens. Bulk artifacts live under `RFP_DATA_DIR` (`.runtime`) and are referenced from the database by path and hash.
