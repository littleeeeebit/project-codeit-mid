Pinned PostgreSQL 18.6 with pgvector 0.8.6 on loopback port 55432 (`tools/start-postgresql.ps1`, per README). `postgres.init_schema` translates the shared SQL schema (INTEGER→BIGINT, TEXT→`COLLATE "C"`) and adds the vector schema, `application_mutex` and `database_control(paid_admission default false)`. When `Resources` starts it calls `require_imported_database`, which refuses unless the recovery control is verified, `migration_import.state='complete'`, `migration_validation` passed, and `postgres.references_valid` re-hashes every referenced artifact, including index payload files. `mark_dispatching` also refuses any dispatch while any attempt in the database is `unknown`.
