`vector_store.SCHEMA` defines `embedding_payloads` (vector, dimension check, checksum, normalized payload hash, provenance), `embedding_sets` (`building`→`ready`, foreign key to `indexes`) and `embedding_set_rows` (row order → chunk, foreign key to `chunks`). `cache_put` refuses to overwrite a different verified entry. `publish` inserts a `building` set, verifies it through `PgDenseIndex.load(require_ready=False)`, then marks it `ready`. `tools/import_embedding_cache.py` (README) transfers verified settled caches from the SQLite runtime into a paid-disabled import.
