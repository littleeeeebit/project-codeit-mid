postgres.lifecycle() owns a reference-counted process pool; open_db() refuses access without that owner. Connections require PostgreSQL 18.6 and pgvector 0.8.6. bind_sql() translates application qmark parameters and rejects unsupported legacy SQL. tx(immediate=True) locks application_mutex for short serialized mutations. GatewayOwner uses a dedicated connection to hold the database-wide advisory lock and refuses to reconnect after ownership loss.
