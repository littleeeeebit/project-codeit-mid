`postgres.GatewayOwner` opens a dedicated autocommit connection and takes `pg_try_advisory_lock(GATEWAY_LOCK)`. A failure raises `LockHeld`, which `Resources._own` turns into `GatewayLockError`. `check()` (run before each provider call) confirms the lock is still granted to that backend and that recovery and validation are still ready. On any loss it sets `lost=True` and never reconnects. `owner_guard(conn)` repeats the check inside the admission and dispatch transactions in `budget.reserve` and `mark_dispatching`. `gateway_lock` always returns a `GatewayOwner`.
