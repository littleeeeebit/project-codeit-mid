useAnswerStream reads GET /api/requests/{id}/stream?generation_id through fetch, not EventSource, so the submitting member's X-Member header goes with it. Each `data:` event replaces the provisional answer (summary, claims). `data: null` withdraws it after cancellation or a lost generation. `event: done` calls the poll's reload so the validated outcome is fetched at once. Stream errors are swallowed because the status poll still delivers the outcome. It runs only for live paid turns that are not revoked.
