Next.js pages in web/src/app (질문하기 page.tsx, verify/page.tsx, dataset/page.tsx, settings/page.tsx), built to web/out and mounted by api.create_app as StaticFiles after all /api routes. Every component calls the typed openapi-fetch client in web/src/lib/api.ts. That client's middleware adds `X-Member` (the name typed in the header, read by web/src/lib/member.ts). The pages hold only presentation and ownership state. Every decision is a service call.
