`generation.py` is the only runtime SDK call site. `OpenAITransport` keeps one `openai.OpenAI` client per browser session (`set_key`) plus an optional default from the server environment. `_client` chooses by the `KEY_SESSION` contextvar. With no client it raises a pre-execution `ProviderError`, so nothing is charged. Before every call `chat` and `embed` run the gateway `owner_check`. A 4xx is classified as `pre_execution=True`; timeouts, 5xx and errors during a stream as `False`. Streaming uses `stream_options.include_usage`, so usage arrives in the last chunk. `check_api_key` reads model metadata for free and records the key's `openai-project` header as the attempt's `billing_scope`. `FakeTransport` is the test seam that `provider=fake` selects.
