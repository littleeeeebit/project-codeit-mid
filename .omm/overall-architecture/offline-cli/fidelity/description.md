`fidelity run` has Hancom Viewer print each HWP to PDF as an independent witness. It compares extraction and rendering both ways (6-character shingles, exact runs of 3+ digits) and sets `auto_verified` or `auto_flagged`, never overwriting a human status. `build-keyword --reviewed-only` uses these statuses. Behaviour is taken from README and function names; the module was not read.
