`python -m rfp_assistant.cli` has about 56 subcommands, including `init`, `manifest`, `ingest`, `fidelity`, `ocr`, `build-keyword`, `plan-embeddings`, `build-dense`, `evaluate-retrieval`, `compare`, `activate-run`, `maintain`, `gold *`, `run-answers`, `freeze-release`, `backup`, `restore-check`, `check`, `load-check`, `release-report` and the budget commands. Commands that can dispatch build `service.Resources(settings)` and therefore claim the gateway lock. `reconcile`, `unresolved` and the other ledger-only owner actions use `Resources(dispatch=False)` and run beside the serving app. `check`, `load-check` and `restore-check` use temporary or isolated databases.
