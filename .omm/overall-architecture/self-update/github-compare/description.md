`compare(running, fetch)` makes unauthenticated GETs to `/repos/{repo}/commits/main` (Accept `application/vnd.github.sha`), then `/repos/{repo}/compare/{running}...{latest}`. It offers an update only when the status is `ahead`; for 404, behind or diverged it returns a Korean `note` and no offer. The repository defaults to `littleeeeebit/project-codeit-mid` and can be overridden by `BIDMATE_UPDATE_REPO`; the API base comes from `BIDMATE_UPDATE_GITHUB_API`, which `tools/verify.py` points at a stand-in (`tests/fake_github.py`).
