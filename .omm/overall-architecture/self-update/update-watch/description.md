`UpdateWatch.from_env(service.build_head())` holds the running commit, the last `Check`, the marker path and the state directory. `start()` runs a daemon thread that calls `refresh()` every `POLL_SECONDS` (300). An `OSError` keeps the previous check and sets a 'could not connect' note. `last_result()` parses `result.json` defensively (fields cut to 500 characters) and reports a `running` state older than `STALE_RUN_SECONDS` (30 min) as `interrupted`. `in_progress()` reads the marker first and the result second, so it cannot miss both. `fenced()` returns `accepting or in_progress()`.
