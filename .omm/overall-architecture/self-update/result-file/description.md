`$STATE/result.json` (default /var/lib/bidmate-update) is written atomically through a .tmp file and mode 644. It contains {state, from_commit, to_commit, started_at, finished_at, message}, and `update.log` is rotated to `update.log.1` on each run. The app only reads these files. If the first `result running` write fails, the script exits with the marker still present, so the fence stays up until someone investigates.
