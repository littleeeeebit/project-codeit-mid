The feature on this branch: a member can move the shared server to the latest GitHub main from the header. The app process never runs git or systemctl. It only compares commits (`update.compare`), checks for open paid work, writes a marker file and reads the root updater's `result.json`/`update.log`. `UpdateWatch.configured` is true only when both `BIDMATE_UPDATE_REQUEST` and `BIDMATE_UPDATE_STATE_DIR` are set; otherwise the banner hides and `POST /api/update` is refused.
