This is the external OpenAI API. It is reached only through `OpenAITransport.chat` and `embed`, which `_call_and_settle`, `metered_embed` and the drafting, evaluation and judge jobs call. Answers use `gpt-6-luna` through Chat Completions with strict JSON schema output (`answer_json_schema`), `reasoning_effort: low` and 4000 maximum output tokens. Rates come from `budget_settings.rates_json`. Embeddings serve only API embedding models. Gemini (OCR fallback and Gemini embeddings) is a separate external provider with its own ledger in `retrieval/models.py`.
