RFP_DATA_DIR (default <repo>/.runtime) holds content-addressed and immutable artifacts that the database references by path and hash. extracted/<source_hash>/<fp>/elements.jsonl holds extraction revisions. indexes/<version>/ holds manifest.json, chunks.jsonl, tokens.jsonl, requirements.jsonl and scope-terms.json. Other trees: reviews/printed (Hancom PDF prints), ocr/<hash> (per-region OCR cache and gemini-ledger.jsonl), runs/<run_id> (frozen retrieval runs), datasets and sealed (gold JSONL rendered from the database), drafts/<run_id> (drafting runs), releases/<freeze_id>, and archive/ (cold PostgreSQL dumps). Writes go through store.write_*_atomic. migration_validation.references_json lists artifact hashes, and startup refuses if any changed.
