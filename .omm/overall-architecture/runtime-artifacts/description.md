These are files under `RFP_DATA_DIR` (default `<repo>/.runtime`), bound to database rows by SHA-256. `extracted/<source_hash>/<fingerprint>/[<content_id>/]elements.jsonl`: one immutable artifact per extraction revision. `indexes/<version>/`: `manifest.json`, `chunks.jsonl`, `tokens.jsonl`, `requirements.jsonl` and `scope-terms.json`, each hash listed in the manifest and checked by `KeywordIndex.load`. `runs/<run_id>/`: retrieval runs (config, traces, scores, report), answer runs (`A-*`) and comparisons. `drafts/<run_id>/`: request.json and output/. `datasets/*.jsonl` plus validation files. `sealed/` (test set, sealed runs). `releases/<id>/`. `reviews/printed/<hash16>.pdf` and rendered PNGs. `ocr/<hash>/` with the Gemini ledger. `archive/`: cold PostgreSQL dumps that no code references. Originals live in `RFP_SOURCE_DIR` (`원본 데이터/files`, `data_list.csv`) and are never modified.
