The data directory (`RFP_DATA_DIR`, default `<repo>/.runtime`) holds immutable or atomically written files that PostgreSQL rows refer to by version and hash. These are: `indexes/<version>/` (chunks.jsonl, tokens.jsonl, requirements.jsonl, scope-terms.json, manifest.json), extraction artifacts, `runs/<run_id>/` (config, traces, scores, report, answer-run rows), `compare/` (cells, estimates, tables), `datasets/` (dev.jsonl and its validation) and `sealed/test.jsonl`. It also holds `drafts/<run_id>/`, `maintenance/` (state and reports), `ocr/<hash>/` with the Gemini ledger JSONL, `reviews/printed` and `reviews/rendered`, `releases/` and the cold `archive/` dumps. Writers use `write_text_atomic`/`write_jsonl_atomic`; index builds write to a `.tmp-*` directory and rename it.
