`RFP_DATA_DIR` (default `<repo>/.runtime`) holds immutable or atomically written files that the database rows point to and hash. These include `extracted/<hash>/<fp>/elements.jsonl`, `indexes/<version>/` (manifest, chunks, tokens, requirements, scope-terms), `runs/<run_id>/` (config, traces, scores, report, answer rows), `compare/` (cells, tables, estimates), `datasets/*.jsonl` and `sealed/` (projections of the gold tables), `drafts/<run>/`, `judges/`, `maintenance/` (state.json, backups.json, reports), `reviews/printed/*.pdf` (Hancom prints), `ocr/<hash>/` and `releases/`. `store.write_text_atomic`/`write_jsonl_atomic` write a temp file and rename it. Backups go to `RFP_BACKUP_DIR`, or a `-backups` sibling, never inside the runtime.
