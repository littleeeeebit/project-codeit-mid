GET /api/auth/login redirects to the registered callback origin when necessary, creates a ten-minute state cookie and redirects to JupyterHub authorization. The callback compares state, calls Login.sign_in(code), exchanges the code at /hub/api/oauth2/token and retrieves /hub/api/user through Hub.username(). Only allowlisted usernames receive an opaque HttpOnly SameSite=Lax session cookie scoped to /api/. Logout removes the in-memory session.
