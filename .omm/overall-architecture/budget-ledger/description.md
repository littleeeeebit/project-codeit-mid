`budget.py` manages a micro-USD ledger in PostgreSQL: `budget_settings` (cap, envelopes per purpose, rates, `paid_enabled`, `frozen_reason`), `attempts` (one row per paid call) and `adjustments` (reconciliations, external adjustments, late settlements). `reserve` admits a call only when the gateway owner is valid, paid use is enabled, `database_control.paid_admission` is true, the ledger is not frozen, a rate is known, the purpose has an envelope, and both the cap and the envelope cover `max_cost`. That cost prices every input token at the cache-write rate. Owner CLI commands `unresolved`, `settle`, `reconcile`, `adjust`, `paid` and `audit` resolve the ledger. `reconcile` refuses intervals that mix projects unless `--unscoped` decides.
