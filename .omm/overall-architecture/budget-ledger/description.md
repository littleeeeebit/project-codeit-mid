src/rfp_assistant/budget.py is the only spending authority. reserve() checks the gateway owner (require_owner and owner_guard), paid_enabled, database_control.paid_admission, frozen_reason, known rate, purpose envelope (interactive, embedding, gold_eval, judge_eval) and cap minus spent minus pending. It inserts an attempts row in state reserved priced at max_cost (all input at the cache-write rate plus full output allowance). mark_dispatching runs the caller's guard, owner_guard and the 'no unknown attempts' check in the same transaction, then either releases or moves to dispatching. settle() prices reported usage exactly once. A cost above the reservation sets budget_settings.frozen_reason, which stops all new paid work. recover() at owner startup turns dispatching into unknown and reserved into released. reconcile() and add_adjustment() are append-only owner corrections.
