`budget.py` manages a micro-USD ledger in PostgreSQL: `budget_settings` (cap, envelopes per purpose, rates, `paid_enabled`, `frozen_reason`), `attempts` (one row per paid call) and `adjustments` (reconciliations, external adjustments, late settlements). `reserve` admits a call only when the gateway owner is valid, paid use is enabled, `database_control.paid_admission` is true, the ledger is not frozen, a rate is known, the purpose has an envelope, and both the cap and the envelope cover `max_cost`. That cost prices every input token at the cache-write rate. Owner CLI commands `unresolved`, `settle`, `reconcile`, `adjust`, `paid` and `audit` resolve the ledger. `reconcile --file <record.json>` imports one dated provider total for one project (`scope`) and subtracts only settled attempts billed to that project. Attempts with no recorded project (the server-environment key) count only when the record's `unscoped_attempts` is `include`; an interval holding them is refused while that field is missing. Every covered unknown attempt must be billed to the same project, or be unscoped with `include` (runbook section 5).
