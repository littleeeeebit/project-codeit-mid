`plan-run` prices every remaining attempt. `run-answers` (CLI, UI stopped) or `start_answer_evaluation` (verify screen, development set only) answers each row through the service's own answer path, with the finalist retrieval configuration pinned and the cost charged to `gold_eval`. A resumed run never resends a finished row or a row whose billing is unknown. An embedding comparison (`E-…`) adds McNemar and Holm statistics against the first run.
