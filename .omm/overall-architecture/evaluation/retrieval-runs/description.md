`evaluate_retrieval` writes `.runtime/runs/<run_id>/` (`config.json`, `traces.jsonl`, `scores.json`, `report.md`). Each run is frozen by dataset hash, evaluated population, index manifest, analyzer, dense version and limits, and graded against source spans (hit@k, nDCG@5, MRR, packed coverage, critical, code and scope failures, latency, Wilson intervals). `run_errors` blocks runs from another policy (`EVAL_VERSION`), corpus route or population.
