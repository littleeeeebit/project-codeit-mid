`evaluate-retrieval` writes `runs/<run_id>/` (`config.json`, `traces.jsonl`, `scores.json`, `report.md`). Each run is frozen by dataset hash, evaluated population, index manifest, analyzer, dense version, limits and `EVAL_VERSION`, and graded against source spans: hit@k, nDCG@5, MRR, packed coverage, critical failures and Wilson intervals. `run_errors` blocks runs whose population or policy is stale.
