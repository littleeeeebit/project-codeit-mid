POST /api/verify/maintenance/start (or the CLI command maintain) runs maintenance.run in one background thread. The steps are backup, restore_check, ingest, fidelity, keyword (built with activate=False), embedding, regression (compare.regression) and report. The sequence stops at the first failure or at a NeedsApproval paid estimate. Progress goes to a state file and the result to reports/<run_id>.json and .md, including whether serving was unchanged. It never activates anything.
