`activate_decision` loads the run, checks `decision_errors`, and in one immediate transaction sets `app_settings.active_run` (from `serving_config`) and `active_index`, and appends an `activations` row with the previous config. The next `res.serving()` read switches serving: `res.index()` reloads the index, `res.dense()` re-verifies, and `retire_inactive` frees GPU models that are no longer used.
