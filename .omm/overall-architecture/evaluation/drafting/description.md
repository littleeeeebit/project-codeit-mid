POST /api/drafting/start calls service.start_drafting. It re-plans the slots, refuses if the maximum now exceeds the consented amount or does not fit, and writes request.json with requested_by. It then runs drafting._generate in a background thread through the process's transport, charged to the gold_eval envelope. The output (candidates.jsonl, invalid.json, receipt.json) goes under the drafts directory. POST /api/drafting/runs/{id}/submit sends the valid rows to gold.submit with drafted_by set to drafting.DRAFTER.
