Evaluation code lives in `src/rfp_assistant/evaluation/` plus `service/answers.py` and `service/drafting.py`. It builds reviewed gold datasets, freezes retrieval and answer runs, compares variants in axis matrices, and records the person's activation, the only path that changes what serves. It also runs the sealed test and writes the release report. Pipelines run every variant, and a person picks a row and activates it; nothing runs on a schedule.
