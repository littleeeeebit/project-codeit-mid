On startup, `lifespan` calls `service.app_resources()`, which runs `get_resources(load_settings())` → `Resources(settings, recover=True)`. It wires `res.update_fence = app.state.update.fenced` and starts the `UpdateWatch` GitHub poller. On shutdown it stops the poller and calls `res.close()`. That rejects new work, waits up to `shutdown_wait_seconds` for workers, marks unfinished requests interrupted, closes the transport and Langfuse, and releases the gateway lock.
