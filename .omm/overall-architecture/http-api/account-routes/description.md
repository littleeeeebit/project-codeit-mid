`/api/info` returns `build_head()`, the git HEAD read once, plus today's date and the question length limit. `/api/budget` returns `budget_snapshot` with `visible_warnings`. `PUT /api/budget/limit` calls `set_budget_limit`, which changes the shared cap and keeps existing spending. The `/api/settings/api-key` and `/api/settings/model` routes manage the member's in-memory key session and answer model; the model must be in `ALLOWED_GENERATION_MODELS`.
