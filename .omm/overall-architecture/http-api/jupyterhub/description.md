The external JupyterHub on the same VM (:8000). `auth.Hub.username(code)` exchanges the code at /hub/api/oauth2/token, called from the server (at BIDMATE_HUB_API_URL, or the hub URL). It then calls GET /hub/api/user with the bearer token. Network or response-shape errors become `LoginError(502)`. `Login.sign_in` gives a 12-hour in-memory session only to names in BIDMATE_ALLOWED_USERS; any other name gets 403. BidMate never sees passwords and keeps no user table.
