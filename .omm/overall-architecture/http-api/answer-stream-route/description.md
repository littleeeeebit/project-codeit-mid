`GET /api/requests/{id}/stream` first calls `service.answer_progress` once, so an unauthorized request is refused before the stream opens. A sync generator then polls `answer_progress` every 0.15 s. It emits `data: <json>` when the partial changes and `event: done` once the request leaves queued or running. The partial is `generation.partial_answer(res.partials[request_id])`. It is shown only while the request is running, not cancel-requested, and still owned by the same generation ID.
