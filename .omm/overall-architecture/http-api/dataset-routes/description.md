The drafting and gold review routes. They are registered after `/api/gold/recent` and `/api/gold/reject-categories`, so that `/api/gold/{candidate_id}` does not shadow them. `/api/drafting/start` is the only paid route in the group. `/api/gold/{id}/decide` passes `expected_sha` (an optimistic check of the row hash), the note and the categories to `service.gold_decide`, which refuses approval by whoever started the drafting run.
