`_dataset_routes` serves the 데이터셋 만들기 page. It maps to the drafting and gold functions in `service.py`: `draft_documents`, `draft_elements`, `plan_drafting`, `start_drafting` (gpt-6-luna drafts under a consented maximum, charged to `gold_eval`), `submit_drafts`, `gold_queue`, `gold_candidate`, `gold_decide` and `gold_second_review`. `create_app` registers this group last because `/api/gold/{candidate_id}` would otherwise shadow fixed paths. These route bodies were not traced line by line. The mapping comes from the service function names and the registration comment.
