/api/auth/login redirects to the hub's authorize URL with a state cookie, first moving to the registered redirect host if the request came through another address. /api/auth/callback compares the state with `secrets.compare_digest`, then `Login.sign_in(code)` exchanges the code at the hub and reads /hub/api/user. An allow-listed user receives an HttpOnly SameSite=Lax `bidmate_session`. With BIDMATE_LOCAL_MEMBER set, both routes redirect to '/' and the local member is used.
