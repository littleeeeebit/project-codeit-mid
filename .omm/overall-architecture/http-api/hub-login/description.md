/api/auth/login redirects to the hub's authorize URL with a state cookie on /api/auth/. A visit through another host (a tunnel) is first moved to the registered redirect host. /api/auth/callback compares state with compare_digest and calls Login.sign_in(code): a server-side code exchange plus /hub/api/user lookup checked against BIDMATE_ALLOWED_USERS. It then sets the HttpOnly SameSite=Lax session cookie, which lives 12 hours in server memory according to README.md. With BIDMATE_LOCAL_MEMBER set, both routes just redirect home.
