UpdateWatch.from_env(build_head()) records the running commit and polls GitHub main in a background thread. POST /api/update (update.request_update) writes a request marker for a root updater path unit. It is refused while open_paid_work finds slots, request rows, live jobs or open ledger attempts. fenced() (accepting or in progress) is read under Resources._runner_lock by RequestRunner.try_admit and _start_job, so no new paid work starts while an accepted update may restart the process.
