`update.UpdateWatch` records the running commit (`service.build_head`) and polls the public GitHub API every 300 s for main's head and the commits in between. `request_update` refuses while paid work is open (`open_paid_work`: pending ledger cost, open attempts, active requests, background jobs). Otherwise it writes only a marker file at `BIDMATE_UPDATE_REQUEST`. The root-owned systemd units (`bidmate-update.path` and `.service`) run `tools/infra/update.sh`, which fast-forwards, rebuilds, restarts, health-checks and rolls back. This module only reads `result.json` from `BIDMATE_UPDATE_STATE_DIR`. While an accepted update may restart the process, `fenced` is true. `RequestRunner.try_admit`, `start_drafting`, `start_maintenance` and the other job starts call `_refuse_while_updating` under `_runner_lock`.
