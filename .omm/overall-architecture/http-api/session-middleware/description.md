`_Session` guards every /api/* path. It refuses state-changing cross-origin calls (403); the dev origin :8510 is trusted only with `BIDMATE_LOCAL_MEMBER`. It returns 503 when `Login.problem` is set (sign-in is not configured). Requests without a valid `bidmate_session` get 401, a mismatched `X-BidMate-Account` gets 409, and a missing account header on a non-GET gets 428. Otherwise it stores `scope.state.member` and calls `service.bind_request(res, member)`, which sets the contextvars `KEY_SESSION`, `REQUEST_MODEL` and `BILLING_SCOPE` for the request and every executor task copied from its context.
