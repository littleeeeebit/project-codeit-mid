`_Session.__call__` guards every /api/ path. A non-safe method whose Origin is not the Host (or a dev origin under `BIDMATE_LOCAL_MEMBER`) gets 403. A misconfigured login (`login.problem`) gets 503. A missing session gets 401. An `X-BidMate-Account` header that names another account gets 409 with `X-BidMate-Account-Changed`. A state-changing call without that header gets 428. On success it calls `service.bind_request(res, member)`, which sets the `KEY_SESSION`, `REQUEST_MODEL` and `BILLING_SCOPE` context variables for the request and for all work it starts, then resets them. The executor copies the context (`contextvars.copy_context().run`), so a background answer pays with the key, model and billing scope the member had at submission.
