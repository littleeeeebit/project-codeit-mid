`_Session.__call__` runs on every `/api/` request and checks four things. A state-changing call whose Origin is not this host gets 403; :8510 is also trusted, but only with a local member. A missing or expired `bidmate_session` cookie gets 401. An `X-BidMate-Account` that differs from the session's member gets 409 with `X-BidMate-Account-Changed`. A state-changing call without that header gets 428. After that it stores the member in `scope.state` and calls `service.bind_request`. That sets the contextvars `generation.KEY_SESSION`, `generation.REQUEST_MODEL` and `budget.BILLING_SCOPE` from the member's current key session, and they are reset when the request ends. Executor workers inherit these values because `RequestRunner.submit` runs work under `contextvars.copy_context()`.
