`_Session.__call__` runs on every `/api/` path. (1) It returns 403 for a non-GET/HEAD/OPTIONS request whose `Origin` netloc is not the request Host (or `127.0.0.1:8510`/`localhost:8510` with `BIDMATE_LOCAL_MEMBER`). (2) It returns 503 when `login.problem` is set, i.e. hub settings are missing. (3) It passes through `/api/auth/login|callback|logout`. (4) It resolves the `bidmate_session` cookie through `login.member`, else 401. (5) It returns 409 with `X-BidMate-Account-Changed` when `X-BidMate-Account` names a different member, and 428 when an unsafe method omits it. (6) It stores the member in `scope.state` and calls `service.bind_request(res, member)`. That sets the `KEY_SESSION`, `REQUEST_MODEL` and `BILLING_SCOPE` contextvars for this request and any work it starts, and resets them afterwards.
