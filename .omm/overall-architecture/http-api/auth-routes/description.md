JupyterHub OAuth. `GET /api/auth/login` redirects to the hub's authorize URL with a 10-minute state cookie. `GET /api/auth/callback` checks the state, then `Login.sign_in(code)` exchanges the code at `/hub/api/oauth2/token`, reads `/hub/api/user` and checks `BIDMATE_ALLOWED_USERS`, issuing a 12-hour in-memory token as an HttpOnly cookie on path /api/. `POST /api/auth/logout` and `GET /api/auth/me` complete the set. Sessions are memory only, so a restart signs everyone out.
