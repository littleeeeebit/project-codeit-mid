`lifespan` sets `app.state.res = service.app_resources()`, which runs load_settings -> get_resources -> `Resources(recover=True)`. Startup therefore claims the gateway lock and marks requests and attempts left by a previous process as interrupted or unknown before the first request is served. On shutdown it calls `Resources.close()`. `app.state.login = service.Login.from_env()` is evaluated when the module-level `app = create_app()` runs. Tests inject `resources` and `login` instead.
