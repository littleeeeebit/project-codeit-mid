The startup and shutdown hook. When no test resources are injected it calls `service.app_resources()`, which runs `get_resources(load_settings())` with `Resources(recover=True)`. That takes the gateway lock and recovers the previous process's requests and attempts. It then sets `res.update_fence = app.state.update.fenced` and starts the UpdateWatch polling thread. On stop it calls `update.stop()` and `res.close()`. `app.state.update` is built before startup from `UpdateWatch.from_env(service.build_head())`, so the running commit is read once from `git rev-parse HEAD`.
