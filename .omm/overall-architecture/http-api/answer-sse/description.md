GET /api/requests/{id}/stream first calls service.answer_progress to refuse before opening. A synchronous generator then re-reads answer_progress every 0.15 s and emits a `data:` frame whenever the partial changes. A null partial withdraws the text when the request is no longer running for this generation_id. One `event: done` follows once status leaves queued/running. Partials come from res.partials, an in-memory dict filled by the streaming on_delta callback and cleared by _finish.
