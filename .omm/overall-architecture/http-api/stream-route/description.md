`GET /api/requests/{id}/stream` first calls `service.answer_progress` once, so an unauthorized or unknown request is refused before the stream opens. It then returns a `StreamingResponse` over a synchronous generator that calls `answer_progress` every 0.15 s. When the partial changes, it emits `data: <json>`; it emits `data: null` when the text is revoked while the request still runs. A finished request keeps its last text, and the generator emits `event: done` and returns. It never returns the validated outcome; that comes only from the request route.
