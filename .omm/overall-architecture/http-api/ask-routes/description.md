These routes come from `_account_routes`, `_ask_routes` and `_request_routes`. `GET /api/documents` calls `find_documents`, which lists askable documents first. `POST /api/ask` calls `service.ask` with today's date as `as_of` and returns `Owned`. `GET /api/requests` and `GET /api/requests/{id}` are read-only. The latter returns `attachable` from `service.may_attach` for the generation and target the screen owns. `GET /api/requests/{id}/stream` streams progress as server-sent events. `POST cancel` calls `cancel_request` and `POST abandon` calls `abandon_request`. Other routes cover the export, evidence (`open_evidence`), original download (`original_download`, managed (doc_id, source_hash) pairs only), budget and budget limit, API key and model settings, and update status and request.
