These are `_account_routes`, `_ask_routes` and `_request_routes`. `POST /api/ask` calls `service.ask` with today's date as `as_of` and returns the ownership record. `GET /api/requests/{id}` calls `service.request_status` and computes `attachable` with `service.may_attach`. `GET /api/requests/{id}/stream` is a synchronous generator returned as a `StreamingResponse`. It calls `service.answer_progress` every 0.15 s, emits `data:` whenever the partial text changes, and finishes with `event: done`. It refuses before opening when the request is not the caller's. The remaining routes cover cancel, abandon, export, evidence, originals, budget, budget limit, API key, model, info and update.
