`POST /api/ask` sets `as_of` to today and calls `service.ask`, which returns `Owned{request_id, generation_id, target}`. `GET /api/requests/{id}` returns `RequestOut{view, attachable}`, where `attachable = service.may_attach(owned, target, view)`. It is safe to poll because it is read-only. `POST /cancel` → `cancel_request`. `POST /abandon` cancels only while the request is queued. `GET /export` redacts secrets. `GET /evidence/{evidence_id}` → `open_evidence`. `GET /api/originals/{doc_id}/{source_hash}` streams the managed original after re-hashing it. Budget routes return `BudgetSnapshot` with `visible_warnings`.
