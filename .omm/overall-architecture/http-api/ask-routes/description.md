`GET /api/documents` calls `find_documents`, a free project search with filters. `POST /api/ask` calls `service.ask` with as_of fixed to today. `GET /api/requests` and `GET /api/requests/{id}` are read-only `RequestView` reads with an `attachable` flag. The `cancel` and `abandon` routes, export, `GET /api/requests/{id}/evidence/{evidence_id}` (`open_evidence`, the quote with its surrounding elements) and `GET /api/originals/{doc_id}/{source_hash}` (`original_download`) complete the set.
