Account routes: `/api/info`, `/api/update/status`, `POST /api/update`, `/api/budget`, `PUT /api/budget/limit`, `/api/settings/api-key`, `/api/settings/model`. Ask routes: `GET /api/documents` → `service.find_documents`; `POST /api/ask` → `service.ask`, with `as_of` always `date.today()` because the 기준일 control was removed. Request routes: `GET /api/requests[/{id}]` → `request_status` plus `may_attach`; `/cancel`, `/abandon`, `/export`; `/evidence/{evidence_id}` → `open_evidence`; `/api/originals/{doc_id}/{source_hash}` → `original_download`. `GET /api/requests/{id}/stream` first calls `service.answer_progress` so a refusal happens before the stream opens. A sync generator then re-reads progress every 0.15 s and yields `data:` whenever the partial changes, then `event: done`.
