GET /api/documents -> service.find_documents (free metadata filters plus keyword snippets). POST /api/ask -> service.ask with as_of = today. GET /api/requests and /api/requests/{id} -> list_requests and request_status; the latter also computes may_attach(owned, target, view). POST /cancel and /abandon, GET /export, GET /evidence/{evidence_id} -> open_evidence. GET /api/originals/{doc_id}/{source_hash} -> original_download. Account routes cover /api/budget, PUT /api/budget/limit, and PUT /api/settings/api-key and /model. The key route stores the member's key in transport memory under a new key session.
