`GET /api/documents` calls `service.find_documents`. `POST /api/ask` calls `service.ask` with today's date and returns `Owned`. `GET /api/requests` and `GET /api/requests/{id}` return `RequestView` plus `attachable`, computed by `service.may_attach`. `GET /api/requests/{id}/stream` is a synchronous generator. It calls `service.answer_progress` once to refuse before opening, then every 0.15 s, and yields `data:` when the partial text changes and `event: done` once the request leaves queued or running. Cancel, abandon, export, evidence (`service.open_evidence`) and original download (`service.original_download`, which accepts only managed `(uuid, sha256)` pairs and re-hashes the bytes) complete the group. The account routes (`/api/info`, `/api/budget`, `/api/budget/limit`, `/api/settings/*` and `/api/update*`) sit beside them in `_account_routes`.
