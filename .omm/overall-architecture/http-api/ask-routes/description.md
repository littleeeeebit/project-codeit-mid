These routes cover the account, ask and request groups. `/api/ask` → `service.ask`, with `as_of` set to the server's today. `/api/requests/{id}` → `request_status` plus `may_attach(owned, target, view)`. `/api/requests/{id}/stream` is a synchronous generator that calls `answer_progress` every 0.15 s and yields `data:` whenever the partial changes, then a final `event: done`. The cancel, abandon and export routes, `/evidence/{evidence_id}` → `open_evidence`, and `/api/originals/{doc_id}/{source_hash}` → `original_download` follow the same one-call pattern. The account routes `/api/budget`, `/api/settings/*` and `/api/update*` are in this group too.
