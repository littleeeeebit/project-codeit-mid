`_ask_routes` and `_request_routes`. `GET /api/documents` calls `find_documents`. `POST /api/ask` calls `service.ask` with today's date. `GET /api/requests` and `GET /api/requests/{id}` (with `attachable` from `may_attach`) cover history and status. `GET /api/requests/{id}/stream` is an SSE generator that calls `answer_progress` every 0.15 s until the request finishes. The rest are `POST .../cancel`, `POST .../abandon`, `GET .../export`, `GET .../evidence/{evidence_id}` and `GET /api/originals/{doc_id}/{source_hash}`.
