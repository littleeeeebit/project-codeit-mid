`/api/auth/login` sets a `bidmate_login_state` cookie and redirects the browser to the hub's `/hub/api/oauth2/authorize`. `/api/auth/callback` compares the state in constant time, then `Login.sign_in(code)` calls `Hub.username`. That exchanges the code at `/hub/api/oauth2/token` from the server and reads `/hub/api/user`. A username on `BIDMATE_ALLOWED_USERS` gets a random 12-hour token held in `Login._sessions`, which is memory only; anyone else gets a 403 login page. `/api/auth/logout` removes the token. `/api/auth/me` returns the member and whether the server runs in local mode.
