src/rfp_assistant/api.py is a thin HTTP shell. `create_app` builds the app, and its lifespan opens `service.app_resources()` (the data directory's single owner, `Resources(recover=True)`) and closes it on stop. `service.ServiceError` maps to 400 and `auth.AuthError` to 403. The routes are registered in three groups: `_routes` (ask, requests, stream, evidence, originals, budget, documents), `_verify_routes` and `_dataset_routes`. The dataset routes are registered last so `/api/gold/{candidate_id}` does not shadow `/api/gold/recent`. Pydantic `_Read` models mirror the service's dataclasses read-only for the OpenAPI schema the screens are typed from.
