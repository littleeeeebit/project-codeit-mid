src/rfp_assistant/api.py. create_app's lifespan opens service.app_resources() → service.get_resources(load_settings()), which builds Resources(recover=True), and closes it on shutdown. The _KeySession ASGI middleware reads the `bidmate_key_session` cookie and calls service.bind_request. That fixes the contextvars generation.KEY_SESSION, generation.REQUEST_MODEL and budget.BILLING_SCOPE for the request and for any work it starts. The `_member` dependency turns X-Member into service.visitor(name), a Principal with every capability. Pydantic `_Read` models mirror service dataclasses read-only. Route groups: _routes (info, budget, settings, documents, ask, requests, stream, cancel, abandon, evidence, originals), _verify_routes and _dataset_routes. _dataset_routes is registered last so /api/gold/{candidate_id} does not shadow /api/gold/recent. /api/requests/{id}/stream is a synchronous generator that polls service.answer_progress every 0.15 s and emits SSE `data:` then `event: done`.
