`src/rfp_assistant/api.py` is the FastAPI wrapper. It imports only `service` (enforced by `tests/test_api.py`), and each route calls exactly one service function. On startup, `lifespan` calls `service.app_resources()` → `get_resources(load_settings())`, which builds `Resources(settings, recover=True)`. On stop it calls `Resources.close()`. The `_member` dependency turns the percent-encoded `X-Member` header into `auth.visitor(name)`. `ServiceError` maps to 400 and `AuthError` to 403. The Pydantic models (`Answer`, `RequestView`, `TraceRun`, `MaintenanceRun`, `JudgeResults`, …) mirror what the service already returns; they never change it. Route groups: ask and requests (`_routes`), 검증 (`_verify_routes`), and drafting and gold (`_dataset_routes`, registered last so that `/api/gold/{candidate_id}` does not shadow `/api/gold/recent`).
