`src/rfp_assistant/api.py` builds the FastAPI app (`create_app`). The ASGI middleware `_Session` guards every `/api/` path. It then registers the sign-in, account, ask, request, verify and dataset routes, and finally mounts `web/out` as static files when that directory exists. `ServiceError` maps to 400, and the other `service.SHELL_ERRORS` (authorization errors) map to 403. Response models are read-only Pydantic mirrors of service dataclasses; tests/test_api.py checks that the module imports only `service` from the package.
