src/rfp_assistant/api.py `create_app`. The lifespan opens `service.app_resources()`, which runs `get_resources(load_settings())` → `Resources(settings, recover=True)`. It wires `res.update_fence = UpdateWatch.fenced`, starts the GitHub poll thread, and on stop closes Resources (drains workers and releases the gateway lock). `ServiceError` maps to 400 and `AuthError` to 403. Pydantic models such as `Answer`, `RequestView` and `MaintenanceRun` are read-only mirrors of service dataclasses, and web/openapi.json is generated from them (tools/openapi.py).
