src/rfp_assistant/api.py is a thin FastAPI wrapper: each route calls exactly one `service` function, and tests/test_api.py checks that it imports nothing else from the package. The lifespan handler creates `service.app_resources()` (one process-wide Resources) and closes it on shutdown. The `_KeySession` ASGI middleware reads the `bidmate_key_session` cookie and calls `service.bind_request`, which sets the KEY_SESSION, REQUEST_MODEL and BILLING_SCOPE context variables for that request and every executor task it submits. The `_member` dependency turns the percent-encoded `X-Member` header into a principal holding every capability. `ServiceError` maps to 400; `AuthError` maps to 403. Pydantic models (`Answer`, `RequestView`, `Evidence` and others) are read-only mirrors of service dataclasses and change nothing. Key routes: POST /api/ask → service.ask; GET /api/requests/{id} → request_status plus may_attach; GET /api/requests/{id}/stream → server-sent events from answer_progress; POST /api/requests/{id}/cancel and /abandon; GET /api/requests/{id}/evidence/{eid}; GET /api/originals/{doc_id}/{source_hash}. Verify routes are registered in _verify_routes and dataset routes in _dataset_routes. _dataset_routes is registered last so that /api/gold/{candidate_id} does not shadow /api/gold/recent.
