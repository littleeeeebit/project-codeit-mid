`src/rfp_assistant/api.py`. `create_app(resources=None)` has a lifespan that owns `service.app_resources()` and calls `Resources.close()` on stop; tests inject resources. `service.ServiceError` maps to HTTP 400 and the other `service.SHELL_ERRORS` (`auth.AuthError`) to 403, both as `{detail}`. Routes are registered in three groups. `_routes`: info, budget, budget limit, documents, `POST /api/ask`, request list, status, cancel, abandon and export, evidence, and originals download with an RFC 5987 filename. `_verify_routes`: `/api/verify/*` plus `/api/gold/recent`, reject categories and second review. `_dataset_routes`: `/api/drafting/*`, `/api/gold/pending`, `/api/gold/{candidate_id}` and decide. `_dataset_routes` is registered after the gold routes because `/api/gold/{candidate_id}` would otherwise shadow `/api/gold/recent`. Pydantic `_Read` models (`from_attributes=True`) mirror the service's dataclasses for typing only. `POST /api/ask` always passes today's date as `as_of` (the 기준일 control was removed).
