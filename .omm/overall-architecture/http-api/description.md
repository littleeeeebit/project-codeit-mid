`create_app()` registers three route groups in a fixed order: `_routes` (info, budget, documents, ask, requests, evidence, originals), `_verify_routes` (`/api/verify/*`, `/api/gold/recent`, reject categories, second review) and `_dataset_routes` (`/api/drafting/*`, `/api/gold/pending`, `/api/gold/{candidate_id}`). The dataset group comes last so `/api/gold/{candidate_id}` cannot shadow the fixed gold paths. `service.ServiceError` maps to HTTP 400 and `auth.AuthError` to 403, with the Korean message in `detail`, which the screens display through `errorText`. Response models are read-only Pydantic mirrors (`_Read`, `from_attributes=True`) of the service dataclasses; they never change behaviour. The `_member` dependency URL-decodes `X-Member` into `service.visitor(...)`. `GET /api/originals/{doc_id}/{source_hash}` streams bytes only after `service.original_download` verifies the UUID/hex format, confirms the path is inside the managed `files/` directory, and checks the SHA-256 against the recorded source hash.
