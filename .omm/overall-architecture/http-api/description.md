src/rfp_assistant/api.py. `create_app` installs the `_Session` ASGI middleware, maps `ServiceError` to 400 and authorization errors to 403, and registers route groups: auth, account, ask, request, verify (trace, evaluation, operation, review) and dataset. It mounts web/out last. The module docstring states that it imports nothing from the package except `service` and `update`, and that tests/test_api.py enforces this. Routes are thin: each one calls one `service.*` function with the request-scoped `Resources` (`_res`) and the member `Principal` (`_member` → `service.visitor`).
