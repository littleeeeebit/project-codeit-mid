`create_app` in `src/rfp_assistant/api.py` builds the FastAPI app. Its lifespan creates `service.app_resources()` (the single owner, with `recover=True`), wires `res.update_fence = UpdateWatch.fenced`, and closes the resources on stop. The ASGI middleware `_Session` gates every `/api/` path. It returns 403 for a state-changing call from a foreign Origin, 503 when the login configuration has a problem, and 401 without a session (except `/api/auth/login|callback|logout`). It returns 409 with `X-BidMate-Account-Changed` when the account header names another member, and 428 for a write without that header. After the checks it calls `service.bind_request(res, member)`, which binds the member's key session, answer model and billing scope into contextvars for the request and any work it starts. Routes are thin: `/api/ask` → `service.ask`; `/api/requests/{id}` → `request_status` plus `may_attach`; `/api/requests/{id}/stream` → an SSE generator over `service.answer_progress`; plus budget, settings, documents, evidence, originals, verify, dataset and update routes. `service.ServiceError` maps to 400, and the other `SHELL_ERRORS` map to 403.
