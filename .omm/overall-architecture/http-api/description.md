src/rfp_assistant/api.py builds the app with create_app(). The lifespan opens the single process owner (service.app_resources -> get_resources(load_settings()) with recover=True). It wires res.update_fence to UpdateWatch.fenced and starts the GitHub poll; on stop it closes Resources. ServiceError maps to 400; the auth errors in service.SHELL_ERRORS map to 403. Route groups are registered in a fixed order so /api/gold/recent is not shadowed by /api/gold/{candidate_id}, and the static mount comes last.
