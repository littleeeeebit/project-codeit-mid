`api.py` defines `create_app(resources=None)`. Its lifespan sets `app.state.res = service.app_resources()` (that is, `get_resources(load_settings())` with `recover=True`) and calls `res.close()` on stop. `service.ServiceError` maps to HTTP 400 and `auth.AuthError` to 403. The `X-Member` header is percent-decoded and turned into a `Principal` by `service.visitor`. Route groups: ask and requests (`/api/info`, `/api/budget`, `/api/budget/limit`, `/api/documents`, `/api/ask`, `/api/requests*`, `/api/originals/{doc_id}/{source_hash}`); verification (`/api/verify/*`, `/api/gold/recent`, `/api/gold/reject-categories`, `/api/gold/{id}/second-review`); dataset (`/api/drafting/*`, `/api/gold/pending`, `/api/gold/{id}`, `/api/gold/{id}/decide`). The dataset routes are registered last so `/api/gold/{candidate_id}` does not shadow `/api/gold/recent`. Pydantic `_Read` models are read-only mirrors of the service's dataclasses. `POST /api/ask` always answers as of `date.today()`.
