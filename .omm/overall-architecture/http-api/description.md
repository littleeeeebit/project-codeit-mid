`src/rfp_assistant/api.py`. The `_Session` ASGI middleware guards every `/api/*` path except `/api/auth/login|callback|logout`. It returns 403 for a cross-origin state-changing call (the hub's notebooks on :8000 count as the same site), 503 when the sign-in configuration is broken, 401 without a session, 409 when `X-BidMate-Account` names a different member, and 428 for a write that names no account. It then runs `service.bind_request`, which pins the member's key session, answer model and billing scope into contextvars (`generation.KEY_SESSION`, `REQUEST_MODEL`, `budget.BILLING_SCOPE`) for the request and any work it submits. The route groups are auth, account (budget, API key, model, update), ask and requests (including the SSE stream), verify, gold and drafting. `ServiceError` maps to 400 and the authorization errors to 403.
