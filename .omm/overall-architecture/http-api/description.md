`api.py` `create_app()` builds the app. The lifespan opens `service.app_resources()` once and closes it on stop. The `_Session` ASGI middleware guards every /api path. Each route calls one service function. `service.ServiceError` becomes 400, and `auth.AuthError` (the rest of `service.SHELL_ERRORS`) becomes 403. Last, when the build exists, `StaticFiles(web/out, html=True)` is mounted at /. Request and response models are Pydantic mirrors of the service dataclasses (`_Read`, `from_attributes`) and never change behaviour.
