`create_app(resources, login, update)` in `src/rfp_assistant/api.py`. It adds the `_Session` ASGI middleware, maps `ServiceError` to 400 and `auth.AuthError` to 403, and registers the auth, account/ask/request, verify and dataset route groups. The static export is mounted last so /api/* stays API. Pydantic response models are the contract the web types are generated from (`tools/openapi.py`).
