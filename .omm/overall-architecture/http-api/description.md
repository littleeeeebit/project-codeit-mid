`create_app` in `src/rfp_assistant/api.py`. The lifespan opens `service.app_resources()` (the single `Resources` with `recover=True`), wires `res.update_fence` to `UpdateWatch.fenced` and starts the update poller. On stop it closes `Resources`, which drains the workers and releases the gateway lock. `ServiceError` maps to 400 and `auth.AuthError` to 403. Routes are registered in groups. The static `web/out` mount comes last, so `/api/*` always reaches the API. The routes stay thin: they validate pydantic shapes (`AskIn`, `BudgetLimitIn`, …) and return read-only mirrors (`RequestView`, `Answer`, `Evidence`) of service dataclasses.
