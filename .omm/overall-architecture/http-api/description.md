`create_app()` in `api.py` installs the `_Session` ASGI middleware. It maps `service.ServiceError` to 400 and `auth.AuthError` to 403, registers route groups in order (auth, account/ask/request, verify, dataset) and mounts `web/out` last, so `/api/*` stays the API's. Response shapes are read-only pydantic mirrors (`_Read`, `from_attributes=True`) of the service's dataclasses. They never change service output.
