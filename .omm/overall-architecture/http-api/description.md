`create_app` builds the FastAPI app and installs `_Session` as raw ASGI middleware. It maps `service.ServiceError` to 400 and the other `SHELL_ERRORS`, such as `AuthError`, to 403. It then registers the route groups and mounts `StaticFiles(web/out)` last, so `/api/*` always reaches the API. The routes are thin wrappers that hold no logic beyond shape conversion. The response models in `api.py` are read-only Pydantic mirrors (`_Read` with `from_attributes`) of the dicts and dataclasses the service already returns.
