`create_app` builds the FastAPI app. Its lifespan opens `service.app_resources()`, the data directory's single owner, binds `res.update_fence` to `UpdateWatch.fenced`, and starts or stops the update watch. Routes are registered in this order: `_auth_routes`, `_routes` (account, ask, request), `_verify_routes` (trace, evaluation, operation, review), `_dataset_routes`, and finally the static mount. `ServiceError` maps to HTTP 400 and the auth errors in `service.SHELL_ERRORS` map to 403. Response models such as `Answer`, `RequestView` and `Evidence` are read-only pydantic mirrors (`from_attributes`) of what the service already returns.
