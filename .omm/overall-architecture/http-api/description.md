`src/rfp_assistant/api.py` builds the FastAPI app in `create_app`. On startup, `lifespan` takes the process-wide `Resources` (`service.app_resources()`, which recovers what a previous process left), wires the update fence (`res.update_fence = UpdateWatch.fenced`) and starts the GitHub poll. On stop it closes both. `ServiceError` maps to 400 and `AuthError` to 403. Routes are registered in groups: auth, account, ask, requests, verify and dataset. The dataset routes are added last so that `/api/gold/{candidate_id}` does not shadow `/api/gold/recent`. Pydantic models such as `Answer` and `RequestView` mirror the service's dataclasses read-only, using `from_attributes`.
