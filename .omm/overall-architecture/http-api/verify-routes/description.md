`_verify_routes` covers traces, comparison, evaluation and judge plan/start, maintenance, experiments and activation, fidelity pages and confirmations, ingestion, corrections and history. `_dataset_routes` covers drafting documents, elements, slots, plan, start, runs, submit, the gold pending list, candidates and decisions. Each route is one service call. The paid ones (evaluation, judges, drafting, maintenance) start background threads registered on `Resources._jobs`.
