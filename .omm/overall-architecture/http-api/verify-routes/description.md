These are the `/api/verify/*` routes for the 검증 page. Traces: `run_trace`, `verifier_runs` and `compare_verifier_runs`, plus `POST /traces/{run_id}/generate`, which is paid and creates at most one idempotent request per run. Answer evaluation and judges: the `plan` routes give free estimates and the `start` routes launch background jobs that never spend above the consented estimate. Maintenance: status, start and cancel. Experiments: the comparison tables, missed questions, and `activate_experiment`, which records the signed-in member as `decided_by`. Review: fidelity overview, rendered page PNG and confirm, ingestion overview, corrections and history.
