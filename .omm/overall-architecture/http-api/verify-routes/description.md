`_verify_routes` registers `/api/verify/*`: overview, trace runs and their generation, comparisons, evaluation plan and start, judges, maintenance, experiments and activation, fidelity pages and confirmation, ingestion, corrections and history. It also registers the gold second-review route. `_dataset_routes` registers drafting and the gold queue last, so `/api/gold/{candidate_id}` does not shadow `/api/gold/recent`. Each route forwards to one service function under the session member.
