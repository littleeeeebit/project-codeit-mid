GET /api/auth/login first moves the browser to the registered redirect host. It then redirects to the hub's /hub/api/oauth2/authorize, with a 32-byte state cookie scoped to /api/auth/ for 10 minutes. GET /api/auth/callback compares the state with `secrets.compare_digest`, calls `Login.sign_in(code)`, and sets `bidmate_session` (HttpOnly, SameSite=Lax, path /api/ so the cookie never reaches the :8000 notebooks). It also deletes any legacy cookie at /. Every refusal renders a small HTML page with the reason. POST /api/auth/logout drops the in-memory session, and GET /api/auth/me returns {name, local}. With BIDMATE_LOCAL_MEMBER, login and callback redirect home and every caller is that name.
