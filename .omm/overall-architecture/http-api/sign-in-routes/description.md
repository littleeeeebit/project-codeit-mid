`/api/auth/login` redirects to the hub's authorize URL with a 32-byte state cookie scoped to `/api/auth/`. A visit through any address other than the registered `redirect_uri` host is first redirected there. `/api/auth/callback` compares the state in constant time, then calls `Login.sign_in(code)`, which exchanges the code with the hub from the server and reads `/hub/api/user`. Only usernames on `BIDMATE_ALLOWED_USERS` receive a session token. The token is kept in memory for `SESSION_SECONDS` and set as an HttpOnly, SameSite=Lax cookie on path `/api/`, so it never reaches the hub's notebook servers on :8000. `/api/auth/logout` drops the token.
