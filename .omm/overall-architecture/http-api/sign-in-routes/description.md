`/api/auth/login` redirects to the hub's authorize URL with a 10-minute state cookie scoped to `/api/auth/`. If the visit came through a different host, it first redirects to the registered redirect host. `/api/auth/callback` compares the state with `secrets.compare_digest` and calls `Login.sign_in(code)` (`service/auth.py`), which exchanges the code, reads `/hub/api/user` and checks `BIDMATE_ALLOWED_USERS`. It then sets the HttpOnly SameSite=Lax session cookie and deletes the legacy cookie at `/`. A `LoginError` renders `_login_page` with its status. `/api/auth/logout` ends the session, and `/api/auth/me` returns `{name, local}`. With `BIDMATE_LOCAL_MEMBER` set, login and callback simply redirect to `/`.
