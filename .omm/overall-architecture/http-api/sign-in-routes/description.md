`/api/auth/login` redirects to the hub's `/hub/api/oauth2/authorize` with a random `state` cookie, scoped to `/api/auth/`. If the visit arrived through another host (an SSH tunnel), it first redirects to the registered redirect host. `/api/auth/callback` compares the state, then `auth.Login.sign_in` exchanges the code server-side and reads `/hub/api/user`. A user outside `BIDMATE_ALLOWED_USERS` gets 403; an allowed user gets a 12-hour in-memory session token. `/api/auth/logout` drops the session. With `BIDMATE_LOCAL_MEMBER`, login and callback simply redirect home, and `Login.member` always returns the local name. `Login.from_env` refuses the local name and hub settings together.
