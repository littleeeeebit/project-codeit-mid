`GET /api/auth/login` redirects to the hub's `authorize_url(state)` and sets a 10-minute `bidmate_login_state` cookie. A visit through a different host is first moved to the registered redirect host. `GET /api/auth/callback` compares state with `secrets.compare_digest`, then `Login.sign_in(code)` exchanges the code at the hub token endpoint server-side and reads `/hub/api/user`. Only `BIDMATE_ALLOWED_USERS` get a session; others get a `LoginError` page. It then sets an HttpOnly SameSite=Lax cookie and deletes the legacy `/` cookie. `POST /api/auth/logout` drops the session. `GET /api/auth/me` returns `{name, local}`.
