GET /api/requests/{id}/stream first calls `service.answer_progress` once, so authorization failures are raised before the stream opens. A synchronous generator then polls `answer_progress` every 0.15 s and yields `data:` when the partial changes, including `null` to withdraw it. It yields `event: done` once the request is no longer queued or running. Headers are `Cache-Control: no-cache` and `X-Accel-Buffering: no`.
