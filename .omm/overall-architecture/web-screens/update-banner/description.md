The header strip for self-update. It polls `GET /api/update/status` every 15 s and renders nothing unless `configured` is true and there is a newer main, an update in progress, or a failure in the last 24 h. The 업데이트 button is disabled while `paid_work.open` is true, and the reason is shown. After confirmation it sends `POST /api/update`. `useUpdateWait` then polls `/api/update/status` every 2 s with raw fetch, so the session middleware's 401 redirect does not fire. It reloads the page on 401/409 (a restarted process has lost the session), on the first good answer after the server was down, or on `succeeded`. It shows the result for `up_to_date`, `failed`, `rolled_back`, `rollback_failed` and `interrupted`, and gives up after 15 minutes.
