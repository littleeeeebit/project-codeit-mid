The browser application in web/src, built to web/out and served by the API process. It has four pages (app/page.tsx Ask, app/verify, app/dataset, app/settings) plus the header components. Screens call the API through a typed openapi-fetch client generated from web/openapi.json, and they own no business rules. Long-running work is followed by polling (`usePoll` in web/src/lib/use-poll.ts) or by the SSE answer stream.
