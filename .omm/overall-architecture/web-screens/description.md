Next.js App Router pages. In production they are a static export (`next.config.ts`: `output: export`). In development, rewrites forward /api/* to RFP_API_URL, which defaults to 127.0.0.1:8511. `app/layout.tsx` wraps every page in `SignedIn`. `SignedIn` calls GET /api/auth/me and `bindAccount(name)` before any page renders. Every call goes through the typed `openapi-fetch` client generated from `web/openapi.json`. The answer SSE stream is the only exception, and it adds the same account header by hand. Screens hold presentation state only. A screen owns a request through the `Owned` record ({request_id, generation_id, target}) the server returned, and the server decides through `attachable` whether a result may render.
