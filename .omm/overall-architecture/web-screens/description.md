The Next.js app in `web/` (pages: 질문하기 `web/src/app/page.tsx`, 검증 `web/src/app/verify/page.tsx`, 데이터셋 만들기 `web/src/app/dataset/page.tsx`, 설정 `web/src/app/settings/page.tsx`). `npm run build` exports it statically to `web/out`, and `create_app` mounts that directory last, so `/api/*` stays with the API. Types come from `web/openapi.json` (`tools/openapi.py`), and `tests/test_api.py` fails while that file is stale. `ask-page.tsx` posts `/api/ask`, keeps the returned `{request_id, generation_id, target}` ownership record, polls `/api/requests/{id}` every second, follows `/api/requests/{id}/stream` through `useAnswerStream`, and posts `/cancel` or `/abandon`. Every call carries the `X-BidMate-Account` header (`web/src/lib/api.ts` `accountHeaders`), so a tab never acts for another signed-in account.
