Next.js app in `web/`, built as a static export into `web/out` and served by the API itself. There are four pages: 질문하기 (`web/src/app/page.tsx` → `AskPage`), 검증 (`web/src/app/verify/page.tsx`), 데이터셋 만들기 (`web/src/app/dataset/page.tsx`) and 설정 (`web/src/app/settings/page.tsx`). Every call goes through the `openapi-fetch` client typed from `web/openapi.json` / `api-schema.d.ts`. A middleware stamps every request with the `X-Member` header (the visitor's typed name, percent-encoded). Screens never change server state by reading: polling and streaming are read-only, and ownership actions (cancel, abandon) send the member name that was captured when the request was submitted.
