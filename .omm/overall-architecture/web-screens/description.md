A Next.js app in `web/` with the pages ask (`web/src/app/page.tsx`), verify, dataset and settings. It is exported statically to `web/out`, and `create_app` mounts that export at `/` after every API route. The screens call `/api/*` through the typed client in `web/src/lib/api.ts`. Its types are generated from `web/openapi.json`, which `tools/openapi.py` regenerates. During development, `npm run dev` on :8510 forwards `/api/*` to `RFP_API_URL`.
