A Next.js app (`web/src/app`) with four routes: `/` (질문하기), `/verify` (검증), `/dataset` (데이터셋 만들기) and `/settings`. A static export to `web/out` is served by the API process itself. During screen work, `npm run dev` on port 8510 forwards `/api/*` to `RFP_API_URL` (default `http://127.0.0.1:8511`). The screens are presentation only. Every decision that is not rendering lives in `service.py` and comes back through typed responses generated from `web/openapi.json` (`web/src/lib/api-schema.d.ts`). Polling uses one keyed hook, so a late response for an old key never lands on a screen that has moved on.
