Next.js static export (`web/out`) with four routes: 질문하기 (`web/src/app/page.tsx` → `components/ask/ask-page.tsx`), 검증 (`app/verify`), 데이터셋 만들기 (`app/dataset`) and 설정 (`app/settings`). All calls go through `web/src/lib/api.ts` (openapi-fetch, typed from `web/openapi.json` / `api-schema.d.ts`). A middleware adds `X-Member` (the typed name from localStorage, `lib/member.ts`) to every call. Ownership actions (ask, poll, cancel, abandon, stream) pin the member captured at submission through `memberHeaders`. Reads are polled with `lib/use-poll.ts`. The header polls `/api/budget` every 2 s. The ask page polls `/api/requests/{id}` every 1 s and follows `/api/requests/{id}/stream` through `lib/use-answer-stream.ts`, which uses fetch rather than EventSource so it can send the header.
