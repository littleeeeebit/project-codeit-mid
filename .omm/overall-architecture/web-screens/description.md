A Next.js app in `web/src`, statically exported to `web/out` and mounted last by `create_app` (`StaticFiles(directory=WEB, html=True)`), so `/api/*` always reaches the API first. It has four pages: 질문하기 (`app/page.tsx` → `components/ask/ask-page.tsx`), 검증 (`app/verify/page.tsx`), 데이터셋 만들기 (`app/dataset/page.tsx`) and 설정 (`app/settings/page.tsx`). The header holds `UpdateBanner`. Every call goes through the typed `openapi-fetch` client in `web/src/lib/api.ts`, generated from `web/openapi.json` (`python tools/openapi.py`). The screens only render; every decision is made server-side.
