A Next.js app in web/src, built as a static export (`npm run build` → web/out) that api.create_app mounts at `/` after every /api route. The pages are 질문하기 (Ask, app/page.tsx → components/ask/ask-page.tsx), 검증 (Verify, app/verify → components/verify/*), 데이터셋 만들기 (Build dataset, app/dataset → components/dataset/*) and 설정 (Settings, app/settings/page.tsx). All calls go through the typed openapi-fetch client in web/src/lib/api.ts. Its types come from web/src/lib/api-schema.d.ts, generated from web/openapi.json by tools/openapi.py, and tests/test_api.py fails while that schema is stale. Middleware adds `X-Member: encodeURIComponent(readMember())`; ownership actions pin the member captured at submission (memberHeaders). Read-only state is polled through usePoll (lib/use-poll.ts), which drops late results when the watched key changes. Answers stream through useAnswerStream (lib/use-answer-stream.ts). Header budget: GET /api/budget (app-header.tsx). Settings: PUT /api/settings/api-key, PUT /api/settings/model, PUT /api/budget/limit. Verify: overview, fidelity, ingestion, traces, compare, evaluation plan/start, judges, maintenance, experiments and activate, history, corrections, gold second review. Dataset: drafting documents, elements, slots, plan, start, runs, submit; gold pending, candidate, decide.
