Next.js app in web/ built as a static export (web/out) that api.py mounts last at '/'. Pages: ask (web/src/app/page.tsx), verify, dataset and settings. The pages are typed from web/openapi.json via web/src/lib/api-schema.d.ts. All server calls go through the openapi-fetch client in web/src/lib/api.ts. The only exception is the answer stream, which uses raw fetch with the same account header.
