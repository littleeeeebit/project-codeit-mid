The Next.js app in `web/` has four pages: 질문하기 (`/`), 검증 (`/verify`), 데이터셋 만들기 (`/dataset`) and Settings (`/settings`). `npm run build` exports it statically to `web/out`, which `api.create_app` mounts last at `/` so that `/api/*` stays the API's. The screens only present data. Every decision is a service call, and response types come from the generated `web/src/lib/api-schema.d.ts` (`tools/openapi.py`; `tests/test_api.py` fails while the schema is stale).
