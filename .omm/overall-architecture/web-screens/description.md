The Next.js app in `web/src` is statically exported to `web/out` and served by the API process. It has four pages: 질문하기 (`app/page.tsx` → `AskPage`), 검증 (`app/verify/page.tsx`), 데이터셋 만들기 (`app/dataset/page.tsx`) and 설정 (`app/settings/page.tsx`). Every call goes through the `openapi-fetch` client in `web/src/lib/api.ts`. Its types come from `api-schema.d.ts`, which is generated from `web/openapi.json` by `tools/openapi.py`. The screens only present data: every decision and validation lives in `service.py`.
