The Next.js app in `web/src`, exported statically to `web/out` and served by the API process. Screens are presentation only. Every action is one typed call through `openapi-fetch` (`lib/api.ts`), typed from `web/src/lib/api-schema.d.ts`, which `tools/openapi.py` regenerates from the FastAPI schema. Most reads use `usePoll` (`lib/use-poll.ts`), which polls on an interval and drops late responses for an owner that has changed. The one push channel is the answer SSE stream.
