A Next.js app (web/src) built with `npm run build` into a static export in web/out. The FastAPI app mounts that export last, so /api/* stays with the API. The screens hold no server state. They call the API through a typed openapi-fetch client and poll read-only status endpoints. Paid answers stream over server-sent events. In development, `npm run dev` serves port 8510 and forwards /api/* to `RFP_API_URL`. The API trusts that origin only when `BIDMATE_LOCAL_MEMBER` is set (`DEV_ORIGINS` in api.py).
