A Next.js app in `web/src`, statically exported to `web/out` and served by the API itself. The pages are 질문하기 (`components/ask/ask-page.tsx`), 검증 (`components/verify/*`), 데이터셋 만들기 (`components/dataset/*`) and 설정 (`app/settings/page.tsx`). Calls go through a typed client (`lib/api.ts`, types generated from `web/openapi.json` by `tools/openapi.py`), which sends the `X-BidMate-Account` header. Ask posts `/api/ask`. Each turn then polls `GET /api/requests/{id}` every second (`usePoll`) and reads the SSE stream `/api/requests/{id}/stream` through fetch (`lib/use-answer-stream.ts`) to show provisional text. A result renders as the answer only when the server reports `attachable`. Otherwise it stays in '내 최근 요청'. When the screen leaves a turn it calls `/abandon`, and the 취소 button calls `/cancel`.
