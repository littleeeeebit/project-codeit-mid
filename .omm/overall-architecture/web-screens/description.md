A Next.js app in `web/`. It is built as a static export to `web/out`, which the API itself mounts at `/` (in local dev, `npm run dev` on :8510 proxies `/api/*`). Calls are typed from `web/openapi.json` (written by `tools/openapi.py`) through `openapi-fetch`. Every screen talks only to `/api/*`. The 질문하기 page runs a conversation of owned requests. The 검증 page drives verification and operations. 데이터셋 만들기 runs gold drafting and review, and 설정 holds the member's key, model and shared cap.
