Next.js client pages (질문하기 '/', 검증 '/verify', 데이터셋 만들기 '/dataset', plus '/settings'). The production build is a static export that api.create_app mounts at '/' after all /api routes. All server calls go through the typed openapi-fetch client generated from web/openapi.json. Screens hold only presentation state and request ownership. Every decision is made by service functions behind the API.
