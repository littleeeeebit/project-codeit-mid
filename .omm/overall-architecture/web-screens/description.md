The Next.js app in `web/`, built by `npm run build` into `web/out`. `api.py` mounts it at `/` with `StaticFiles` after every API route. Pages: 질문하기 (`web/src/app/page.tsx` → `components/ask/ask-page.tsx`), 검증 (`app/verify/page.tsx` → `components/verify/*`), 데이터셋 만들기 (`app/dataset/page.tsx` → `components/dataset/*`) and 설정 (`app/settings/page.tsx`). Every call goes through the typed client in `web/src/lib/api.ts`, whose types come from `web/openapi.json` (`api-schema.d.ts`). That client sends `X-BidMate-Account`. On a 401 it navigates to `/api/auth/login`, and on a 409 with `X-BidMate-Account-Changed` it reloads the page. Reads are repeated through `usePoll` (`web/src/lib/use-poll.ts`): the budget every 2 s in `app-header.tsx`, each answer turn's `/api/requests/{id}` every 1 s until it reaches a terminal status, and verify and dataset overviews every 2–5 s while a job runs. `useAnswerStream` reads `/api/requests/{id}/stream` through `fetch` so the stream can be aborted.
