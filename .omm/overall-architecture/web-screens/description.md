The Next.js app in web/src has three pages: 질문하기 (src/app/page.tsx → AskPage), 검증 (src/app/verify) and 데이터셋 만들기 (src/app/dataset), plus a settings page (src/app/settings/page.tsx). The settings page reads `/api/budget` and changes the shared cap through `PUT /api/budget/limit`. All calls go to same-origin `/api/*`. The screens hold only ownership records (`request_id`, `generation_id`, `target`). They render an answer only while the server says it is attachable, and they never decide billing or execution state themselves.
