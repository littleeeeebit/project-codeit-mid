The Next.js app in `web/src` (pages `app/page.tsx` 질문하기, `app/verify/page.tsx` 검증, `app/dataset/page.tsx` 데이터셋 만들기, `app/settings/page.tsx` 설정) is built with `npm run build` into a static export that `api.py` mounts at `/`. In dev, `npm run dev` on :8510 forwards `/api/*` to `RFP_API_URL`. Screens are presentation only. Every call goes through the openapi-fetch client in `lib/api.ts`, typed from `web/openapi.json` / `lib/api-schema.d.ts`, which `tools/openapi.py` regenerates.
