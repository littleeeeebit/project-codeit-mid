A Next.js static export (`web/out`). The API process serves it, so a browser reaches the screens and `/api` on one origin and port. The pages are 질문하기 (`/`), 검증 (`/verify`), 데이터셋 만들기 (`/dataset`) and 설정 (`/settings`). The app header polls `/api/budget` and `/api/update/status`, and `sign-in.tsx` reads `/api/auth/me`. Every typed call goes through the `openapi-fetch` client in `lib/api.ts`, whose types are generated from `web/openapi.json` (`tools/openapi.py`). The one untyped call is the answer event stream, which uses raw `fetch`.
