Next.js pages, presentation only: `/` renders `AskPage` (`web/src/components/ask/ask-page.tsx`), plus `/verify`, `/dataset` and `/settings`. Every call goes through the `openapi-fetch` client in `web/src/lib/api.ts`, typed from `api-schema` (generated from `web/openapi.json` by `python tools/openapi.py`; `tests/test_api.py` fails when it is stale). A middleware adds `X-Member: encodeURIComponent(readMember())`, where `readMember` reads `localStorage['rfp-member']` and defaults to `owner` (`web/src/lib/member.ts`). Ownership actions pass `memberHeaders(name)` explicitly, using the name captured at submit time. `usePoll` (`web/src/lib/use-poll.ts`) keys each poll on what it watches and drops in-flight results for a stale key, so a late answer never lands on a screen that has moved on. Build mode: `next.config.ts` emits a static export (`output: 'export'`) served by FastAPI. Dev mode rewrites `/api/:path*` to `RFP_API_URL` (default `http://127.0.0.1:8511`).
