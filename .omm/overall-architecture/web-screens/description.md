The consultant and verifier screens are a Next.js app under `web/src`, built as a static export into `web/out`, which the API serves itself. Pages: `app/page.tsx` (질문하기 ask, `components/ask/*`), `app/verify/page.tsx` (검증: traces, evaluation, judges, maintenance, experiments, fidelity), `app/dataset/page.tsx` (gold drafting and review) and `app/settings/page.tsx` (API key, model, budget). Every call goes through `lib/api.ts`, an `openapi-fetch` client typed from `api-schema.d.ts`, which is generated from the API's OpenAPI schema. Two middlewares are attached. `expired` sends a 401 to `/api/auth/login`. `sameAccount` adds `X-BidMate-Account` and reloads the page on a 409 that carries `X-BidMate-Account-Changed`. The answer stream (`lib/use-answer-stream.ts`) bypasses the client but sends the same header through `accountHeaders()`. Polling uses `lib/use-poll.ts`, which drops late responses for a key the screen has left.
