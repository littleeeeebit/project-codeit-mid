The Next.js app in `web/src`, built as a static export into `web/out` that the API serves itself. There are four pages: 질문하기 (`app/page.tsx` → `ask-page.tsx`), 검증 (`app/verify/page.tsx`), 데이터셋 만들기 (`app/dataset/page.tsx`) and 설정 (`app/settings/page.tsx`). Their types come from `web/src/lib/api-schema.d.ts`, which `tools/openapi.py` generates. The screens own no state beyond what they poll. Each paid answer is owned by a turn, identified by `request_id`, `generation_id` and `target`. A result renders only while the API says it is still `attachable`.
