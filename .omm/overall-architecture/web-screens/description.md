A static Next.js export (`web/out`) served by the same FastAPI process. It has three member pages (질문하기 at `web/src/app/page.tsx`, 검증 at `web/src/app/verify/page.tsx`, 데이터셋 만들기 at `web/src/app/dataset/page.tsx`) plus 설정 (`web/src/app/settings/page.tsx`). The header `web/src/components/app-header.tsx` polls `/api/budget` every 2 s and mounts `UpdateBanner`. Every call goes through the openapi-fetch client in `web/src/lib/api.ts`, which is typed from `web/openapi.json`. The answer stream is the exception: it uses raw fetch with the same account header.
