Next.js App Router screens. `src/app/page.tsx` is 질문하기 (`components/ask/ask-page.tsx`). `src/app/verify/page.tsx` is 검증 (`components/verify/*`: trace, evaluation, experiments, judges, maintenance, fidelity, gold, records). `src/app/dataset/page.tsx` is 데이터셋 만들기 (`components/dataset/draft.tsx`, `review.tsx`). `src/app/settings/page.tsx` holds the API key, model and shared limit. `lib/api.ts` creates an `openapi-fetch` client typed from the generated `lib/api-schema.d.ts`; its middleware adds `X-Member`, the percent-encoded name from `lib/member.ts`. Ownership actions (ask, cancel, abandon, poll, stream) pass the name captured at submit through `memberHeaders`, so renaming mid-request does not change ownership. `lib/use-poll.ts` polls request status every second until the status is terminal. `lib/use-answer-stream.ts` reads the SSE stream through `fetch` because EventSource cannot send the member header. The screens are presentation only: `tests/test_api.py` checks that `api.py` imports nothing from the package except `service`.
