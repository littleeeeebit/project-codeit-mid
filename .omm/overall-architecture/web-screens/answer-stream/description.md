`useAnswerStream` opens GET /api/requests/{id}/stream?generation_id with `fetch`, not the api client, adding `accountHeaders()` by hand, and parses SSE frames. A `data:` frame replaces the provisional text, and `data: null` withdraws it after cancellation or a lost generation. `event: done` calls `onDone`, which is the TurnView poll's reload, so the validated outcome is fetched at once. TurnView mounts it only for a live, attachable, paid-mode turn. An aborted or dropped stream is swallowed because the status poll still delivers the outcome.
