useAnswerStream opens GET /api/requests/{id}/stream?generation_id with fetch and an AbortController and parses SSE frames manually. A `data:` frame carries the unvalidated partial answer {summary, summary_evidence_ids, claims}. `data: null` withdraws the text after a cancellation or a lost generation. `event: done` calls the poll's reload so the validated outcome is fetched at once. A dropped stream is ignored because the poll still delivers the outcome. The stream runs only while the turn is live, not revoked, and not a free mode.
