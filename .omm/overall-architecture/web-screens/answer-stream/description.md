Reads `GET /api/requests/{id}/stream?generation_id=…` with `fetch` and a `TextDecoderStream`, so the stream can be aborted. Each `data:` event replaces the provisional `{summary, claims}`, and `data: null` withdraws it. `event: done` calls the turn's `status.reload` so that the validated outcome is fetched at once. When the stream drops, its errors are swallowed and the 1 s status poll still delivers the outcome. Events that arrive after the turn's key changed are ignored.
