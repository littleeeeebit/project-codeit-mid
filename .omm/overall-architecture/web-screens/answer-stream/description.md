`useAnswerStream` uses fetch to read `/api/requests/{id}/stream?generation_id=...`, so the stream can be aborted. It splits server-sent events on blank lines. A `data:` event replaces the provisional `{summary, claims}` (`null` withdraws it). `event: done` calls `onDone`, which reloads the status poll so the validated outcome replaces the provisional text. Errors are swallowed on purpose, because the status poll still delivers the outcome.
