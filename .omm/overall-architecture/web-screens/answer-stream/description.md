`useAnswerStream` reads `GET /api/requests/{id}/stream?generation_id=` through `fetch`, not `EventSource`, because it must send the `X-Member` header. Each `data:` event replaces the provisional `{summary, claims}` parsed by `generation.partial_answer`. `data: null` withdraws the text after a cancellation or a lost generation. `event: done` calls `status.reload()` so the validated result replaces the stream at once. Errors are swallowed because the status poll still delivers the outcome.
