`useAnswerStream` opens `GET /api/requests/{id}/stream?generation_id=` with `fetch` (so it can be aborted) and parses the SSE frames by hand. A `data:` frame carries the unvalidated partial answer (summary, claims). `data: null` withdraws the text after a cancellation or a lost generation. `event: done` calls `onDone`, which triggers the status poll to fetch the validated outcome. It is used only for live, attachable, paid turns. Stream errors are swallowed because the status poll still delivers the outcome.
