`useAnswerStream` reads `GET /api/requests/{id}/stream?generation_id` through `fetch` plus a `TextDecoderStream`, because `EventSource` cannot send the `X-Member` header. Each `data:` event replaces the provisional `{summary, summary_evidence_ids, claims}`. `data: null` withdraws the text (cancellation or a lost generation). `event: done` triggers the caller's `onDone` (the status poll's `reload`). Stream errors are swallowed on purpose: the status poll still delivers the outcome. Free modes (`metadata`, `inventory`) never open a stream.
