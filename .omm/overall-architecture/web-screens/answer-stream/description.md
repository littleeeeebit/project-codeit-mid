`useAnswerStream` opens `GET /api/requests/{id}/stream?generation_id` with fetch (not EventSource), so it can be aborted, and sends `accountHeaders()`. Each `data:` event replaces the provisional `Streamed {summary, summary_evidence_ids, claims}`. `data: null` withdraws it after cancellation or a lost generation. `event: done` triggers `status.reload()`. Stream errors are swallowed because the status poll still delivers the outcome. It is used only for live, non-revoked, paid modes (not metadata or inventory).
