`useAnswerStream` reads `GET /api/requests/{id}/stream?generation_id=` through `fetch` with the submitting member's header, because `EventSource` cannot set headers. It parses `data:` events into the provisional `Streamed` answer: `null` withdraws the text. On `event: done` it calls `onDone` (the poll's `reload`), so the validated outcome replaces the streamed text. Leaving the turn aborts the stream. If the stream drops, the error is swallowed and the status poll still delivers the outcome.
