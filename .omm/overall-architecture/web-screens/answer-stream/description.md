`useAnswerStream` reads `GET /api/requests/{id}/stream?generation_id=` with `fetch`, because EventSource cannot send `X-Member`. It splits the body on blank lines. Each `data:` payload is the provisional answer from `generation.partial_answer`: summary, summary evidence IDs and claims. `data: null` withdraws the text after cancellation or loss of the generation. `event: done` calls `onDone`, which is `status.reload`, so the validated outcome is fetched at once. Stream errors are swallowed on purpose, because the status poll still delivers the outcome. The `Provisional` component shows this text as '작성 중 · 검증 전', and its citation markers cannot be opened.
