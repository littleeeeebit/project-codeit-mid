`useAnswerStream` in web/src/lib/use-answer-stream.ts opens `GET /api/requests/{id}/stream?generation_id=...` with fetch and an AbortController, and parses SSE frames by hand. A `data:` frame replaces the provisional text. `data: null` withdraws it (cancellation or lost generation). `event: done` calls `onDone`, which reloads the status poll to fetch the validated outcome. Stream errors are swallowed on purpose: the status poll still delivers the result, and the streamed text is never treated as validated.
