settings/page.tsx stores a member's own OpenAI key and answer model (`PUT /api/settings/api-key`, `PUT /api/settings/model`) and can change the shared cumulative limit (`PUT /api/budget/limit`). app-header.tsx reads `/api/budget`. sign-in.tsx reads `/api/auth/me` and posts `/api/auth/logout`. update-banner.tsx polls `/api/update/status` and posts `/api/update`, which writes the marker file that the root updater watches.
