`usePoll(key, load, everyMs, done)` is read-only polling keyed by what is watched (`request_id/generation_id`). It runs every 1000 ms until `done`, which here is a status other than queued or running. When the key changes, results still in flight for the old key are dropped. A failed re-poll keeps the data last shown for the same key. A failure under a new key never inherits the old key's data (commit 5bfcd5d). `reload()` re-polls at once; the stream's `onDone` calls it.
