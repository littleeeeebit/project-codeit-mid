Polls GET /api/verify/maintenance every 2000 ms while a run is live. It shows each step's status, ingest progress (current file and elapsed time from `detail.progress`) and the final status. 유지보수 실행 POSTs /api/verify/maintenance/start. 취소 POSTs /api/verify/maintenance/cancel with the run_id on screen, so a late or repeated click can never stop a successor run. The button is disabled while `cancelling` is true.
