`usePoll(key, load, everyMs, done)` is read-only polling keyed by `request_id/generation_id`. Results that arrive for an old key are dropped, so a late answer never lands on a screen that has moved on. `TurnView` polls `GET /api/requests/{id}?generation_id&target` every 1000 ms until the view's status leaves `queued`/`running`. `reload()` is called when the SSE stream reports `done`, so the validated outcome arrives immediately.
