Polls `GET /api/documents` (`service.find_documents` → `search_projects`) with query, institution, amount and closing-date filters. Documents that can be asked about sort first. Each `Document` carries `indexed`, `review_status`, `unavailable_reason`, metadata `conflicts` and `filter_undecided`. Selecting a document calls `AskPage.toggle`, which first calls `release()` to abandon the current conversation.
