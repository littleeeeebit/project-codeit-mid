The 검증 screens (`components/verify/*`). They call `/api/verify/overview`, `/fidelity`, `/ingestion` and `/traces` on load. Retrieval traces run with `POST /api/verify/traces`, and a paid answer from a frozen trace with `POST /traces/{id}/generate`. Experiment tables come from `GET /experiments`, and a picked row is activated with `POST /experiments/activate`. Maintenance uses `GET /maintenance` plus `POST /maintenance/start` and `/cancel`. Answer evaluation is `/evaluation/plan` then `/start`, judges are `/judges/plan` then `/start`, and the page also covers gold second review and verification history. Every paid action is a plan (free estimate) followed by a start that names the estimate.
