The verifier workspace (web/src/components/verify/*). On load it reads `/api/verify/overview`, `/api/verify/fidelity`, `/api/verify/ingestion` and `/api/verify/traces`. trace.tsx runs a free retrieval trace (`POST /api/verify/traces`) and can generate a paid answer from that frozen run (`POST /api/verify/traces/{run_id}/generate`), then polls `/api/requests/{id}`. experiments.tsx shows the comparison tables (`GET /api/verify/experiments`) and activates a row (`POST /api/verify/experiments/activate`). evaluation.tsx and judges.tsx plan, then start paid background runs with a consented estimate. maintenance.tsx starts the maintenance sequence. fidelity.tsx confirms HWP fidelity. gold.tsx records second reviews.
