검증 tabs, one file each under `web/src/components/verify/`. The overview loads `/api/verify/overview`, `/fidelity`, `/ingestion` and `/traces`. `trace.tsx` runs a frozen retrieval-only trace (`POST /api/verify/traces`), compares two runs (`GET /api/verify/compare`), and generates a paid answer from a run (`POST /traces/{run_id}/generate`), then polls `/api/requests/{id}`. `evaluation.tsx` plans and starts the development answer evaluation. `judges.tsx` plans, starts and reads the Luna/Jev judge comparison. `experiments.tsx` lists the comparison tables and POSTs `/api/verify/experiments/activate`. `fidelity.tsx` confirms an HWP fidelity check. `gold.tsx` handles second reviews. `records.tsx` reads the history and all members' requests.
