The 검증 tabs poll `/api/verify/overview`, `/fidelity`, `/ingestion` and `/traces`. Other tabs start background work: the trace tab (`POST /api/verify/traces` for a frozen retrieval-only run, then `/generate` for one idempotent paid answer per run), evaluation (`/evaluation/plan` → `/start`), judges (`/judges/plan` → `/start`), maintenance (`/maintenance/start`) and experiments (`/experiments` tables, `/experiments/activate`). Every start endpoint returns a run ID, and the tab then polls status.
