`PUT /api/settings/api-key` sends {api_key, model}. `service.set_api_key` checks the key with a free `models.retrieve` call, then creates a fresh `secrets.token_urlsafe(32)` session. The route stores only that session handle in the httponly, SameSite=strict cookie `bidmate_key_session`. `PUT /api/settings/model` changes the browser's answer model. `PUT /api/budget/limit` changes the shared cap through `budget.set_limit`.
