설정 reads `/api/settings/api-key` and `/api/budget`. `PUT /api/settings/api-key` sends `{api_key, model}`. The server checks the key, creates a new random session, and sets the `bidmate_key_session` cookie (httponly, samesite strict). The key itself stays only in process memory. `PUT /api/settings/model` changes this browser's answer model for requests it starts afterwards. `PUT /api/budget/limit` changes the shared cumulative cap and requires a reason.
