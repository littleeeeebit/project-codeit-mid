Reads and sets the browser's own OpenAI key and answer model (`/api/settings/api-key`, `/api/settings/model`) and the shared cumulative cap (`PUT /api/budget/limit`, which needs a reason). Setting a key returns the httponly, samesite=strict cookie `bidmate_key_session`. The cookie carries an opaque session handle, never the key. `app-header.tsx` also reads `/api/budget` for the cap warnings.
