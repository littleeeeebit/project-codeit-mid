`lib/api.ts` creates the openapi-fetch client with two middlewares. `expired` redirects any non-auth 401 to `/api/auth/login`. `sameAccount` adds `X-BidMate-Account` (the account bound by `bindAccount`) to every request and reloads the page on a 409 carrying `X-BidMate-Account-Changed: 1`. That pairs with the server's `_Session` check, so a tab never acts for an account it does not show. `errorText` surfaces the service's Korean `detail`.
