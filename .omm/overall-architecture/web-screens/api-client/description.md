`api` = createClient<paths> with two middlewares. `expired` sends a 401 (outside /api/auth/) to /api/auth/login. `sameAccount` adds `X-BidMate-Account` (set by `bindAccount` after /api/auth/me) to every request and reloads the page on a 409 that carries `X-BidMate-Account-Changed: 1`. That pairs with the server's `_Session` check, so a tab never acts for an account it does not show. `errorText` displays the service's Korean `detail` string.
