`web/src/lib/api.ts` creates the `openapi-fetch` client with two middlewares. `expired` handles a 401 on any non-auth route by replacing the location with `/api/auth/login`, which starts the hub sign-in. `sameAccount` adds `X-BidMate-Account` (the account the screen loaded as, set by `bindAccount` after `GET /api/auth/me`) to every request. When the server answers 409 with `X-BidMate-Account-Changed: 1`, it reloads the page, so no form or result from the old account survives under a different tab's sign-in. `errorText` shows the service's Korean `detail` message.
