createClient<paths> with two middlewares. `expired` redirects to /api/auth/login on any 401 outside /api/auth/. `sameAccount` adds X-BidMate-Account (set by bindAccount after /api/auth/me) to every request and reloads the page on a 409 carrying X-BidMate-Account-Changed. Tabs share one cookie, so this keeps a screen from acting for an account it does not show. errorText surfaces the server's `detail` string.
