`createClient<paths>({ baseUrl: "" })` sends same-origin requests to the serving process. A middleware adds `X-Member: encodeURIComponent(readMember())` to any call that does not already carry it. `memberHeaders(name)` pins the member who submitted a request, so that polls, cancels and abandons stay attributed to that person even if the header name field changes later. `errorText` shows the service's Korean `detail` (a `ServiceError` becomes 400 and an `AuthError` becomes 403 in `api.py`). `originalHref` builds `/api/originals/{doc_id}/{source_hash}` for downloads.
