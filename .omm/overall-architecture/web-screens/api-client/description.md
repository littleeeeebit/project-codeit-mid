`api.ts` builds one openapi-fetch client with two middlewares. `expired` replaces the window location with /api/auth/login on any 401 outside /api/auth/. `sameAccount` sets `X-BidMate-Account` (the URL-encoded member name) on every request, and reloads the page on a 409 that carries `X-BidMate-Account-Changed`. That way, a sign-in in another tab never lets this screen act for an account it does not show. `errorText` surfaces the service's Korean `detail`, and `originalHref` builds /api/originals/{doc_id}/{source_hash}.
