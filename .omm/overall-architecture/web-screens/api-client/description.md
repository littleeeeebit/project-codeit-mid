web/src/lib/api.ts builds one `openapi-fetch` client with two middlewares. `expired` sends the browser to `/api/auth/login` on any 401 outside /api/auth/. `sameAccount` attaches `X-BidMate-Account` (set by `bindAccount`) to every request and reloads the page on a 409 that carries `X-BidMate-Account-Changed: 1`. This stops a tab from acting for a different account after another tab signs in, because tabs share one session cookie.
