`openapi-fetch` client with two middlewares. `expired` reacts to a 401 outside `/api/auth/` by replacing the location with `/api/auth/login`, which starts the hub sign-in. `sameAccount` adds the `X-BidMate-Account` header (the account the screen loaded as, set by `bindAccount`) to every request, and reloads the page on a 409 that carries `X-BidMate-Account-Changed: 1`. Together these keep a tab from acting for an account it does not show after another tab signs in as someone else.
