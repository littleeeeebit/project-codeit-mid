An openapi-fetch client over the generated schema. Every call carries the session cookie and, after `bindAccount`, `X-BidMate-Account` (the URL-encoded account the screen loaded as). A 401 outside `/api/auth/` sends the browser to sign in again. A 409 with `X-BidMate-Account-Changed: 1` reloads the page, because another tab signed in as a different member. `originalHref` builds `/api/originals/{doc_id}/{source_hash}` download links.
