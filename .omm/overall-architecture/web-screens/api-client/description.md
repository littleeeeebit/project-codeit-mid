`web/src/lib/api.ts` creates the client with two middlewares. `expired` handles a 401 by sending the browser to `/api/auth/login`. `sameAccount` stamps the account the screen loaded as onto each request and reloads on an account-changed 409. `errorText` displays the service's Korean `detail` string. Calls that bypass the client (the SSE stream and the update wait loop) add `accountHeaders()` by hand.
