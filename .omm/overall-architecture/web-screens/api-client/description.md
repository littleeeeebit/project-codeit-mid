`web/src/lib/api.ts` creates the `openapi-fetch` client with `baseUrl: ""`. In development, `/api/*` is forwarded to `RFP_API_URL` (default `127.0.0.1:8511`); in production the API serves the export on the same origin. The `member` middleware adds `X-Member` unless the caller already set one (`memberHeaders(name)`). `errorText` shows the service's Korean `detail` string from 400/403 responses.
