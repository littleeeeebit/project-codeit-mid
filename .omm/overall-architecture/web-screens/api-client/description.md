web/src/lib/api.ts builds an `openapi-fetch` client typed by web/src/lib/api-schema.d.ts. The README says the types are regenerated from the API with `python tools/openapi.py`, and tests/test_api.py fails while the schema is stale. A middleware adds `X-Member: encodeURIComponent(readMember())` to every request without one. `memberHeaders(name)` pins the name captured at submission, so cancel, abandon and poll calls keep attributing to the submitting member even if the header field changes. `errorText` shows the service's Korean `detail` for 400/403 refusals.
