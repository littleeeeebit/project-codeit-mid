The 데이터셋 만들기 screen (`components/dataset/draft.tsx`, `review.tsx`) has two parts. Drafting picks documents and elements (`/api/drafting/documents`, `/elements`), builds slots, gets a priced plan (`/api/drafting/plan`), starts a run with the consented maximum (`/api/drafting/start`) and submits valid drafts to the queue (`/api/drafting/runs/{id}/submit`). Review shows `GET /api/gold/{candidate_id}` next to its source passages and posts `/decide` with a mandatory note.
