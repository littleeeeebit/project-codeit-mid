Drafting and review queue. draft.tsx lists development documents and elements, validates slots (POST /api/drafting/slots), gets a free maximum-cost estimate (POST /api/drafting/plan), starts a consented run (POST /api/drafting/start, then service.start_drafting) and submits valid drafts (POST /api/drafting/runs/{id}/submit, then gold.submit). review.tsx loads a candidate with its source spans and posts approve/reject decisions to /api/gold/{id}/decide. The page lists /api/gold/pending and /api/drafting/runs.
