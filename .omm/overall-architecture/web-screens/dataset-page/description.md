The 데이터셋 만들기 page. Drafting picks development documents and elements (`/api/drafting/documents`, `/elements`), builds slots (`/slots`), prices them (`/plan`), and starts a gpt-6-luna run within a consented maximum (`/start`). It then sends the valid drafts to the queue with `/runs/{id}/submit`. Review uses `GET /api/gold/pending`, `GET /api/gold/{id}` and `POST /api/gold/{id}/decide` (a note is required, and the drafting requester cannot approve).
