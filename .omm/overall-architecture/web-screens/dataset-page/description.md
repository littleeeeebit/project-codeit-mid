The dataset page polls `GET /api/gold/pending` and `GET /api/drafting/runs`. Drafting (`draft.tsx`) lists development-family documents (`GET /api/drafting/documents`) and their elements (`/elements?contains=`). Each question slot is validated server-side with `POST /api/drafting/slots`. The slots are priced with `POST /api/drafting/plan` (free) and started with `POST /api/drafting/start` carrying `consented_max_micro_usd`. Valid drafts from a finished run go to review with `POST /api/drafting/runs/{run_id}/submit`. Review (`review.tsx`) opens a candidate with `GET /api/gold/{candidate_id}`. It decides with `POST /api/gold/{candidate_id}/decide`, sending `expected_sha` (the row version shown), a required note, reject categories, `original_inspected` and `disputed`.
