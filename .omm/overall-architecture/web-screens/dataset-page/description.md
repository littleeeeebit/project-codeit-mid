The 데이터셋 만들기 page. `draft.tsx` lists development documents and elements, builds slots (`POST /api/drafting/slots`), prices them (`/plan`), starts a paid drafting run with a consented maximum (`/start`), and submits finished valid drafts to review (`/runs/{id}/submit`). `review.tsx` shows one pending candidate next to its source spans and posts approve or reject with a required note (`/api/gold/{id}/decide`).
