`useConversation` holds the turns of one conversation. `postAsk` sends `POST /api/ask` with the scope (`doc_id`, `source_hash`), the question, the mode (single, compare, corpus, metadata or inventory) and `previous_request_id` (the last turn). It keeps the returned `Owned` record. Leaving the conversation (new documents, a new scope or 새 대화) or unmounting calls `release()`, which sends `POST /api/requests/{id}/abandon` with `keepalive`. A POST still in flight is marked invalid and abandoned as soon as it returns. `TurnView` polls each turn, streams the latest live paid turn, and offers cancel (`POST /api/requests/{id}/cancel`). It renders `view.result` only when the request finished and `attachable` is true. The first citation opens in the evidence pane (`GET /api/requests/{id}/evidence/{evidence_id}`).
