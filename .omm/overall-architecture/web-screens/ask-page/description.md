`AskPage` keeps the conversation as `turns` and holds the latest turn's ownership in `owner`. `submit` posts `/api/ask` with the scope pairs `(doc_id, source_hash)`, the mode, the question and `previous_request_id = last.request_id`. A follow-up continues the server-side conversation. Input is disabled while the latest turn is unfinished (`busy`). Changing the selected documents or scope, pressing 새 대화, or unmounting calls `release()`. That invalidates any POST still in flight and calls `/api/requests/{id}/abandon` with `keepalive`. The server cancels only a still-queued request; a running one continues and settles. For paid modes the follow-up button reads '이어서 질문 · 유료 2회', because a follow-up pays for the rewrite and then for the answer.
