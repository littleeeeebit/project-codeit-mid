`AskPage` holds the selected documents (zero to two), the scope toggle (selected or all documents), the mode and the question. Modes: `single`, `compare` and `corpus` are paid; `metadata` and `inventory` are free. On submit it calls `POST /api/ask` with `{scope, question, mode}` and the `X-Member` header captured at submit time. It keeps the returned `Owned` record `{request_id, generation_id, target}` as the one request it owns. Any context change (document toggle, scope, mode, question edit, unmount) calls `release()`. That drops ownership and sends `POST /api/requests/{request_id}/abandon` with `keepalive: true`; the server cancels the request only while it is still queued. `OwnedAnswer` polls `GET /api/requests/{request_id}?generation_id&target` every second until the status leaves queued or running. It shows the reserved maximum cost while the request runs, and offers `POST /api/requests/{request_id}/cancel`. The answer renders only when the response says `attachable`. Otherwise the request stays in `History` (`GET /api/requests?limit=20`). Evidence opens through `GET /api/requests/{request_id}/evidence/{evidence_id}` (`answer-parts.tsx`). Originals download through `originalHref` → `GET /api/originals/{doc_id}/{source_hash}`. `DocumentSearch` calls `GET /api/documents` with the query and filters.
