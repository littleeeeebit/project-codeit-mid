Owns at most one request. Submit POSTs /api/ask with the scope ([] for 'all documents'), the question and a mode (single/compare/corpus/metadata/inventory), then stores {request_id, generation_id, target, member}. usePoll polls GET /api/requests/{id}?generation_id&target every 1 s until the status leaves queued/running. Changing the selection, scope, mode or question calls release(). release() invalidates any in-flight POST and calls POST /abandon with keepalive, which cancels only a still-queued request. The answer renders only when the server returns attachable=true (service.may_attach). Otherwise it is shown only under 내 최근 요청 (GET /api/requests).
