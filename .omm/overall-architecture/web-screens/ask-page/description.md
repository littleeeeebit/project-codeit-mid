Owns at most one request. `submit` POSTs `/api/ask` with scope (`[]` for all documents), question and mode (`single`, `compare`, `corpus`, `metadata`, `inventory`) and keeps the returned `Owned` record `{request_id, generation_id, target}` plus the submitting member. `usePoll` reads `GET /api/requests/{id}?generation_id&target` every 1000 ms until the status leaves `queued`/`running`. An answer renders only when the server says `attachable` (`service.may_attach`: same request, generation and target, and not cancelled). Changing the selection, submitting again or unmounting calls `release()`, which POSTs `/abandon` with `keepalive`. The server cancels only a still-queued request, so a running paid call finishes and settles but stays history. A Cancel button POSTs `/cancel`. 내 최근 요청 reads `GET /api/requests`. Evidence opens through `GET /api/requests/{id}/evidence/{evidence_id}` (`answer-parts.tsx`), and document search uses `GET /api/documents` (`document-search.tsx`).
