`ask-page.tsx` sends `api.POST("/api/ask")` with the scope (`{doc_id, source_hash}` pairs), the question, the mode (single, compare, corpus, metadata or inventory) and `previous_request_id` for a follow-up. It keeps the returned `Owned` record (`request_id`, `generation_id`, `target`). Each turn polls `GET /api/requests/{id}` and follows the SSE stream while it runs. Cancel calls `POST /api/requests/{id}/cancel`. When the user leaves a conversation, the latest turn gets `POST /api/requests/{id}/abandon`, which cancels it only while it is still queued (`service.abandon_request`). The history panel lists `GET /api/requests`.
