Ask conversation. `postAsk` POSTs /api/ask with scope (doc_id, source_hash pairs), question, mode and previous_request_id, and keeps the returned `Owned` {request_id, generation_id, target} as a Turn. `TurnView` polls GET /api/requests/{id}?generation_id&target every 1000 ms until the status leaves queued/running. It renders the validated `result` only when the server says `attachable` (service.may_attach). The Cancel button POSTs /api/requests/{id}/cancel. Leaving a conversation calls /abandon with keepalive, which cancels the request only if it is still queued. The evidence pane fetches /api/requests/{id}/evidence/{evidence_id} (answer-parts.tsx).
