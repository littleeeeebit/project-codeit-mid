`AskPage` keeps a conversation of turns. `submit` POSTs `/api/ask` with `{scope, question, mode, previous_request_id}`. The returned `Owned` record (`request_id`, `generation_id`, `target`) is the screen's ownership token for that turn. If the component unmounted mid-submit, the screen calls `/abandon`, which cancels the request only while it is still queued. Each `TurnView` polls `GET /api/requests/{id}?generation_id&target` every second through `usePoll` until a terminal status. It renders `view.result` only when the server returns `attachable` (`service.may_attach`). While the request runs and is not revoked, it follows the SSE stream and shows provisional text. The cancel button POSTs `/cancel`.
