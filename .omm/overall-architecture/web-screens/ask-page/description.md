`AskPage` holds the conversation as a list of `Turn`s. On submit it POSTs `/api/ask` with `{scope:[{doc_id,source_hash}], question, mode, previous_request_id: last turn's request_id}` and keeps the returned `Owned` record `{request_id, generation_id, target}` plus the member name. Several actions call `release()`, which abandons the latest owned request (`POST /api/requests/{id}/abandon`, `keepalive`): changing the documents, switching scope, pressing 새 대화, or unmounting. Abandon cancels only while the request is still queued. Each `TurnView` polls its own request with its own `generation_id` and `target` and renders an answer only when the server says `attachable`. While the request runs, it shows the streamed provisional text. Citation numbers open `EvidenceDetail` (`answer-parts.tsx`), which calls `GET /api/requests/{id}/evidence/{evidence_id}`. The paid button reads `유료 1회`, or `유료 2회` for a follow-up because the rewrite is a separate paid call. The input stays disabled until the latest turn reaches a terminal status. `DocumentSearch` lists `/api/documents`, and `History` lists `/api/requests`.
