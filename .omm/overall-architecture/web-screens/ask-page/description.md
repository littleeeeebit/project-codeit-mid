The 질문하기 conversation screen. It submits with `api.POST("/api/ask")` and receives an `Owned` record {request_id, generation_id, target}. It then polls `GET /api/requests/{request_id}?generation_id&target` and renders the outcome only when the server returns `attachable`. It cancels with `POST /api/requests/{id}/cancel`, and when the screen moves on it calls `POST /api/requests/{id}/abandon`, which cancels only a still-queued request. History comes from `GET /api/requests`. Evidence markers open `/api/requests/{id}/evidence/{evidence_id}`.
