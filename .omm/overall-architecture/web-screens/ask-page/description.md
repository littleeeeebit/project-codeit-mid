`AskPage` keeps exactly one owned request: `{request_id, generation_id, target, member}`, the member name captured at submit. Submitting calls `POST /api/ask`. Any change of selection, mode, scope or question calls `release()`, which posts `/api/requests/{id}/abandon` with `keepalive`. If the request is still queued, that cancels it. A POST that returns after the context has already changed is abandoned straight away. `OwnedAnswer` renders the result only when the server says `attachable`. Otherwise the answer stays under 내 최근 요청 (`GET /api/requests`). `DocumentSearch` uses `GET /api/documents`, and evidence opens through `GET /api/requests/{id}/evidence/{eid}`.
