질문하기. `postAsk` POSTs `/api/ask` with `{scope:[{doc_id, source_hash}], question, mode, previous_request_id}` and keeps the returned `Owned {request_id, generation_id, target}` per turn (`useConversation`). Each `TurnView` polls its own request with `generation_id` and `target`. It renders the validated `view.result` only when the server says `attachable` (`service.may_attach`). Otherwise the outcome stays in 내 최근 요청 (`GET /api/requests`). Cancel POSTs `/cancel`. Leaving a conversation POSTs `/abandon` with `keepalive: true`, which cancels only a still-queued request. Citation markers open `/api/requests/{id}/evidence/{evidence_id}` in the evidence pane. 원문 파일 받기 links `/api/originals/{doc_id}/{source_hash}`.
