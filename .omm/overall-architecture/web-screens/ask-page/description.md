Holds the conversation as a list of Turn objects: the Owned record {request_id, generation_id, target} plus the question, mode and docs. postAsk sends POST /api/ask with scope [{doc_id, source_hash}], question, mode and previous_request_id; the previous ID chains the conversation. Each TurnView polls only its own request. It renders the validated answer only when the server reports `attachable`; otherwise it shows a history note. Leaving a turn calls POST /api/requests/{id}/abandon with keepalive, which cancels only a still-queued request. The cancel button calls POST /api/requests/{id}/cancel and then reloads the poll.
