The conversation screen. `postAsk` sends `POST /api/ask` with the selected `(doc_id, source_hash)` pairs, the question, the mode (`single`, `compare`, `corpus`, `metadata` or `inventory`) and `previous_request_id`. It keeps the returned `Owned` record (`request_id`, `generation_id`, `target`). Each `TurnView` polls `GET /api/requests/{id}?generation_id&target` every second until the status leaves `queued` or `running`. It renders the result only when the server says `attachable`, and otherwise shows the turn as history. Leaving a conversation calls `POST /api/requests/{id}/abandon` with `keepalive`, which cancels only a request that is still queued. Cancel calls `POST /api/requests/{id}/cancel`. Citations open the evidence pane through `GET /api/requests/{id}/evidence/{evidence_id}` (`answer-parts.tsx`). Document search uses `GET /api/documents` (`document-search.tsx`).
