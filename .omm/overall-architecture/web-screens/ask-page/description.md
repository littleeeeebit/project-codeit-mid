Holds the conversation (`turns`), the scope (selected documents or all documents) and the mode: `single`, `compare`, `corpus`, `metadata` or `inventory`. `submit` posts `/api/ask` with `previous_request_id` set to the last turn's request, so a follow-up continues the same scope. It stores the returned `Owned` record ({request_id, generation_id, target}) together with the member name captured at submit time. Each `TurnView` polls `GET /api/requests/{id}` every second with its own generation and target, and renders `view.result` only when the server says `attachable`. Leaving the conversation (new documents, new scope, 새 대화, or unmount) calls `POST /abandon` with `keepalive`. That cancels the request only if it is still queued.
