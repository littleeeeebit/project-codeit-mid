The Ask (질문하기) conversation. `document-search.tsx` lists documents from GET /api/documents with institution, amount and closing-date filters. `useConversation.ask` posts each turn through `postAsk` (POST /api/ask with scope, question, mode and `previous_request_id` set to the last turn's request_id), appends a `Turn`, and keeps the latest `Owned` in a ref. Leaving the conversation (new scope, a new conversation or unmount) calls POST /api/requests/{id}/abandon with `keepalive`. If the initial POST has not returned yet, it is abandoned as soon as it does. The composer stays busy while the last turn is queued or running. Each `TurnView` polls GET /api/requests/{id}?generation_id&target every second until the status is terminal. For paid modes it also follows the SSE stream. It renders `result` only when `attachable`, cancels through POST /api/requests/{id}/cancel, and opens citations through GET /api/requests/{id}/evidence/{evidence_id} (answer-parts.tsx).
