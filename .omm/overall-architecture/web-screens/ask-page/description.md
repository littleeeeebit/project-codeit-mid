The conversation screen (ask-page.tsx with document-search.tsx, answer-view.tsx and answer-parts.tsx). `GET /api/documents` lists searchable projects. `POST /api/ask` sends scope, question, mode and `previous_request_id` and receives an `Owned` record {request_id, generation_id, target}. The screen polls `GET /api/requests/{id}?generation_id&target` via `usePoll`, and renders the validated outcome only when the server returns `attachable` (`service.may_attach`). Otherwise the turn stays in history. The cancel button calls `POST /api/requests/{id}/cancel`. Leaving a conversation calls `POST /api/requests/{id}/abandon`, which cancels only a still-queued request. Citation markers open `GET /api/requests/{id}/evidence/{evidence_id}`, and originals download from `/api/originals/{doc_id}/{source_hash}`.
