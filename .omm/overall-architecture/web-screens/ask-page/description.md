`useConversation` keeps the turns. Each turn is the ownership record `{request_id, generation_id, target}` returned by `POST /api/ask`, and every turn after the first sends the previous `request_id` as `previous_request_id`. Input is blocked while the latest turn is queued or running. Leaving the conversation (new scope, 새 대화, unmount) calls `release()`, which sends `POST /api/requests/{id}/abandon` with `keepalive`. A POST still in flight is invalidated and abandoned when it returns. Each turn polls `GET /api/requests/{id}?generation_id&target` with `usePoll`. The answer renders only while `attachable` is true (`service.may_attach`). Otherwise it is shown as revoked. `POST /cancel` cancels the turn, `GET /api/requests/{id}/evidence/{eid}` (answer-parts.tsx) fills the evidence pane, and `GET /api/requests` lists history. Document search uses `GET /api/documents`.
