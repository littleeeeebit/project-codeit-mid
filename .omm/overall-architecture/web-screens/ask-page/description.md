Sending a turn calls `POST /api/ask` with the scope, question, mode and `previous_request_id`, and keeps the returned `Owned {request_id, generation_id, target}`. Each `TurnView` polls `GET /api/requests/{id}?generation_id&target` every 1000 ms through `usePoll` until the status leaves queued or running. While the request is live and still attachable, the turn shows `useAnswerStream` text as provisional. It renders `view.result` only when the server says `attachable` (`service.may_attach`). Cancel calls `POST /api/requests/{id}/cancel`. Leaving a conversation calls `/abandon`, which cancels the latest turn only while it is still queued. Citation markers open evidence through `GET /api/requests/{id}/evidence/{evidence_id}` (`answer-parts.tsx`).
