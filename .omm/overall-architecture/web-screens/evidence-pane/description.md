`EvidenceDetail` calls `GET /api/requests/{request_id}/evidence/{evidence_id}` → `service.open_evidence`. The view is built only from the request's persisted evidence map: the exact quote, the neighbouring elements, the location, and warnings (`source_version_changed`, `extraction_revised`, `source_unreviewed`, `ocr_text`). The original-file link goes to `/api/originals/{doc_id}/{source_hash}`. The server serves it only when the recorded path sits in the managed `files/` directory and the bytes still hash to `source_hash`.
