`EvidenceDetail` in answer-parts.tsx calls `GET /api/requests/{request_id}/evidence/{evidence_id}` (`service.open_evidence`). The server builds the citation from the request's persisted evidence map: the exact quote, neighbouring elements in source order, location, review status and warnings (`source_version_changed`, `extraction_revised`, `ocr_text`, unreviewed source). The original file link goes to `/api/originals/{doc_id}/{source_hash}`. That route serves only managed files whose bytes still hash to `source_hash`.
