The 검증 page (verify-page.tsx) loads `/api/verify/overview`, `/fidelity`, `/ingestion` and `/traces`. trace.tsx creates frozen retrieval-only verifier runs (`POST /api/verify/traces` → `service.verifier_trace`, free). It can request one paid answer from such a run (`/traces/{run_id}/generate` → `generate_from_run`, idempotency key `vgen-<run_id>`) and compares two runs. experiments.tsx shows the comparison-matrix tables and posts `/api/verify/experiments/activate` with the person's name and note. evaluation.tsx, judges.tsx and maintenance.tsx plan and start background jobs with a consented estimate. gold.tsx records second reviews, and records.tsx lists history and all members' requests.
