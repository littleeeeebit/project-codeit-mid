`generation.py` is the only SDK call site. `OpenAITransport.chat` makes a Chat Completions call with a strict JSON-schema `response_format` (`AnswerPayload`), `reasoning_effort` and `max_completion_tokens`. `embed` makes an embeddings call with explicit dimensions. Both call `_check_owner()` first: if gateway ownership was lost, the result is `ProviderError(pre_execution=True)`. 4xx errors are classified as pre-execution (the reservation is released). Timeouts, connection loss and 5xx are not, so the attempt becomes `unknown`. `FakeTransport` echoes the first evidence unit per document and returns deterministic bigram vectors. It is used for `provider: fake`, checks and load tests. `tracing.py` wraps requests and drafting runs in Langfuse spans; it is observability only. `mask_otel_spans`/`redact` mask secrets on export, and a missing or failing Langfuse never changes an answer or the ledger.
