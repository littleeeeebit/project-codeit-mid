generation.py is the only SDK call site for chat. `OpenAITransport.chat` (generation.py:217) checks gateway ownership, then calls Chat Completions with strict JSON-schema output, `reasoning_effort`, `max_completion_tokens` and `max_retries=0`. With `on_delta` it streams and `_drain` accumulates content, calling `on_delta(content)` and reading usage from the last chunk. 4xx rejections become pre-execution `ProviderError`s, so the reservation is released. Timeouts, connection loss, 5xx and stream failures are not pre-execution, so the attempt becomes unknown. `embed` serves `metered_embed`. `FakeTransport` (provider `fake`) answers by echoing the first evidence and never builds a real SDK client. `build_messages` and `build_rewrite_messages` assemble prompts (PROMPT_VERSION `grounded-answer-12`, REWRITE_PROMPT_VERSION `standalone-query-1`), and `count_request_tokens` counts with tiktoken o200k_base plus per-message, schema and margin overhead.
