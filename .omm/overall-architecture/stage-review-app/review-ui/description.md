The Next.js static app in `review/src`. It lists runs and shows each stage's view: `retriever-view.tsx`, `chunking-view.tsx`, `generation-view.tsx` (answers per question, citations, rejected claims, validation failures, cost and latency with denominators) and `ocr-view.tsx` (image, text per candidate, character diff). `decision-panel.tsx` collects one chosen candidate or none, a reason per rejected candidate, and notes.
