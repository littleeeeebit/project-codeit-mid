Each run lives in `<data>/review/runs/<stage>-<UTC stamp>-<hex6>/`: `run.json` (refs with full commits, input and worker hashes, scorer fingerprint, host and state), `inputs/`, `candidates/<id>[.estimate|.paid|.config].json`, `estimate.json`, `view.json`, plus `docs/` for chunking and `images/` for OCR. `review/server.py` exports a run as a zip including `annotations.jsonl`, leaving out notes whose suggestion approval never committed, and imports it after checking `RUN_ID`, the schema and the notes.
