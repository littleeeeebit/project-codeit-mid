`stage-review run traffic` opens one read-only session (`default_transaction_read_only=on`) to the database named by `--source-dsn-env`, which is codeit's database through the tunnel. It freezes finished 질문하기 requests since `--since` into `inputs/requests.jsonl.gz`. Member ids become HMAC pseudonyms under a key kept in `.runtime/review/traffic/`, and an exit gate refuses to write any file in which a known member id survives. Requests are grouped by mode, outcome, validation failure and document, and one representative is sampled per group with a recorded seed. Nothing is written to the serving database.
