A coding agent delivers a retriever or chunking change as a git ref. `cli stage-review run <stage> --base <ref> --cand <ref>…` runs every ref on identical frozen inputs and writes one run folder. `review/server.py` (standard library only) serves the `review/` Next.js export on a free loopback port, shows runs and records the person's decision as Markdown and JSON for the agent to read. The runner and the app never activate, build or pay.
