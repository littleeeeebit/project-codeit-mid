This is an offline loop for comparing a coding agent's branches. The CLI runner (`cli stage-review run <stage>`) runs a baseline ref and candidate refs on identical frozen inputs. The standard-library server `review/server.py` shows the runs and records the person's decision. It is launched by `review.cmd` or `review.command`, listens on its own loopback port and serves the export in `review/out`. The server never runs a pipeline, loads a model or pays.
