`review.cmd`/`review.command` → `review/server.py`. `ensure_build` runs `npm ci` when `package-lock.json` changed and `npm run build` when the app source digest changed. That digest skips `node_modules`, `out`, `.next` and `__pycache__`. The server binds `127.0.0.1` on a free port, overriding `server_bind` so it does not reverse-resolve the address, and opens the browser. `_local()` accepts only a loopback Host header (a DNS-rebinding guard), and for writes only a same-origin or absent Origin. Routes: `GET /api/runs`, `/api/runs/{id}`, `/docs/{n}`, `/export` (zip) and `/decision`; `POST /api/import` (zip with exactly one run folder named like a run ID, no path traversal, never replacing an existing run, extracted through a temp dir and renamed into place); `POST /api/runs/{id}/decision`.
