`review/server.py` is a standard-library `ThreadingHTTPServer` on 127.0.0.1. It rebuilds `review/out` only when `source_digest` of `review/` changes. It serves run views and accepts zip imports up to 2 GiB. It writes decision files (`review-decision-1`) to `.runtime/review/decisions/<run-id>.md` and `.json`, and copies a short prompt that points the agent at the file. `data_dir()` resolves `RFP_DATA_DIR` from the environment or `.env`, defaulting to `.runtime`.
