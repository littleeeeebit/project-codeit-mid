`review/server.py` is a `ThreadingHTTPServer` bound to `127.0.0.1` on a free port and launched by `review.cmd` / `review.command`. On start it rebuilds `review/out` when the `review/` source digest changed. `_local()` accepts only a loopback Host and, for writes, same-origin requests. GET routes: `/api/runs`, `/api/runs/{id}` (view), `/docs/{n}`, `/images/{n}.png`, `/export`, `/annotations`, `/failure-types`, `/decision`, `/api/taxonomy`, `/api/taxonomy/progress`, `/api/taxonomy/suggestions/{type}`. POST routes: `/api/import`, `/api/runs/{id}/decision` (`write_decision`, which writes `.runtime/review/decisions/<run>.md|.json` and copies an agent prompt), `/api/runs/{id}/annotations` (`add_annotation`, author from `git config user.name`), `/api/taxonomy/export|decide|suggest-export`, and `/api/taxonomy/suggestions/decide`. `ReviewInputError` maps to 400.
