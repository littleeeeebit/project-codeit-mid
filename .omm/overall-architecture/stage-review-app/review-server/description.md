`review/server.py` is a stdlib HTTP server bound to `127.0.0.1` on a free port, launched by `review.cmd` or `review.command`. Its first start runs `npm ci` and `npm run build` in `review/` unless the source digest is unchanged. `_local` rejects non-loopback Host headers (DNS rebinding) and cross-origin writes. GET routes: `/api/runs`, `/api/runs/{id}`, `docs/{n}`, `images/{n}.png`, `export` and `decision`. POST routes: `/api/import` (zip) and `/api/runs/{id}/decision`. Static files come from the review export.
