Layout of `<data>/review/runs/<run-id>/`: `run.json` (schema `review-run-1`, refs with full commits, input and worker hashes, scorer fingerprint, runner host, per-candidate host and packages), `inputs/` (`activation.json`, `questions.json`, `rows.json`, `documents.json`, or `documents.json.gz` for chunking), `candidates/<id>.json` with `.config.json`, `worker.py`, `view.json`, and `docs/<n>.json` for chunking. Folders move between machines as zip files, for example to run GPU comparisons on a GPU host and view them elsewhere.
