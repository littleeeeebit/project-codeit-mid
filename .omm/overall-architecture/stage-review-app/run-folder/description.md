`run_folder(settings, run_id)` resolves `<data>/review/runs/<run-id>/`. It contains `run.json` (full commits, input and worker hashes, packages and the host per candidate), `inputs/`, raw `candidates/<id>.json` and `view.json`; chunking runs add `docs/<n>.json`. Run ids match `^(retriever|chunking|generation|ocr|traffic)-<stamp>-<hex>$`. A folder can be exported and imported as a zip, so GPU runs can be viewed on another machine.
