`evaluation/error_analysis.py` (standard library only) owns the file store under `<data>/review`. The span notes, edits, deletes and reviewed marks go to append-only `annotations/<run>.jsonl`. Taxonomy files are `exports/`, `proposals/`, `history.jsonl` and `versions/v<N>.json`. `annotation_state` folds the records and hides AI notes whose suggestion approval is not yet committed in history. `_fold` derives the accepted and pending types from history and proposals. `propose` (CLI) refuses a type without a Korean one-line name, a one-sentence definition, or existing unassigned notes. `decide` records accept, rename, merge, split and reject. `progress`, `run_counts` and `release_summary` compute counts over human-reviewed answers only. `write_lock` takes an OS file lock plus a thread lock around every read-check-write.
