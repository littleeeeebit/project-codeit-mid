The runner copies `stage_review_worker.py` into the run folder and runs that same copy for every candidate: `python -I -B worker.py <worktree> <stage> <inputs> <config> <output>`, with cwd set to the worktree. The environment strips `OPENAI_`, `GEMINI_`, `GOOGLE_API_`, `LANGFUSE_`, `TYPESAFE_` and `HF_TOKEN` variables, sets offline Hugging Face flags, and sets `PGOPTIONS=-c default_transaction_read_only=on`. The worker imports `rfp_assistant` from `<worktree>/src` and refuses to run if the package resolves outside the worktree. Retriever runs `retrieval.retrieve` for every frozen question side, with cached query vectors or uncached local embeddings that are never written back. Chunking runs `build_chunks` or `build_profile` per frozen document. Output carries status, host (CUDA and GPU), packages and elapsed time. A timeout of 3600 s or a missing output file fails the candidate.
