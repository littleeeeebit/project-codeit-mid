`stage_review.run(stage, base, cands)` resolves the refs (`.` means the working tree), freezes inputs under `inputs/` (or copies them with `--inputs-from`), and copies the worker script into the run folder. For each ref it runs `git worktree add --detach`, reads an optional `review-variant.json`, builds the candidate config, and refuses with a reason any GPU candidate on a host without CUDA. It runs the worker and always removes the worktree afterwards. Retriever and chunking runs are scored at once (`score_retriever` / `score_chunking`) into `view.json`. Generation and OCR runs stop with `state = needs_approval`. `on_ledger` wraps `reprice`, `resume` and `rescore` in the lifecycle of a ledger database that may differ from the runner's own, for example codeit's through a tunnel.
