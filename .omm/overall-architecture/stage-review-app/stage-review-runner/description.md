`stage_review.run` resolves each ref to a full commit (`.` means the working tree), creates `<data>/review/runs/<stage>-<UTC>-<hex6>/`, and either freezes inputs or copies them from `--inputs-from`. For each candidate it reads the committed `review-variant.json` (`read_variant`, with type-checked keys) and builds `candidate_config`: the frozen activation with the variant applied, refusing unknown keys, unregistered models, or a dense mode without a ready vector set. A candidate that needs a local GPU model on a host without CUDA is marked `refused`. Errors mark a candidate `failed` without stopping the others, and each worktree is removed in `finally`.
