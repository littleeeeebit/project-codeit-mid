`execute` starts `python -I -B worker.py <worktree> <stage> <inputs> <config> <output> <mode>` with every `OPENAI_`, `GEMINI_`, `LANGFUSE_` and similar secret stripped from the environment, with offline Hugging Face, and with a 3600 s timeout. Retriever, chunking and the OCR estimate run with `PGOPTIONS=-c default_transaction_read_only=on`. Only `mode=paid` receives a key, from `paid.approved_env` of an approved estimate. A worker that exits without output fails with its stderr tail. One failed candidate never discards the others.
