Each ref runs as `sys.executable -I -B stage_review_worker.py <worktree> <stage> <inputs> <config>`, with `WORKER_TIMEOUT_S` of 3600, using that ref's own package. Retriever and chunking workers get a read-only database session. A query vector comes from the cache or a local model, never from a paid call. `_SECRETS` lists the environment prefixes withheld from workers (OPENAI_, GEMINI_, GOOGLE_API_, LANGFUSE_, TYPESAFE_, HF_TOKEN). A ref may commit `review-variant.json` to override the frozen activation for the comparison only. A candidate that needs CUDA on a host without it is refused and kept with its reason.
