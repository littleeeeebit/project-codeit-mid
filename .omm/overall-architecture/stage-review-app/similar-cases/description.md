`suggest_export(type)` writes `taxonomy/suggest-exports/<id>/` containing `type.json` (definition, approved spans, rejected spans with reasons, waiting spans), `answers.jsonl` (every stored generation answer, reviewed or not) and `prompt.md`, and returns a prompt for the agent. `suggest` (CLI) admits a `failure-type-suggestions-1` file only for an accepted type, with spans verbatim in the stored field (or a `start` offset when the text occurs more than once), no extra keys, no overlap with already-filed cases, no repeat of a pending or rejected span, and one-line reasons. It writes `taxonomy/suggestions/<batch>.json`. `decide_suggestion` with approve appends an `ai_suggested` note to the run's annotations first, then the history record that commits it, reusing an orphan note on retry. Reject keeps the reason for the next bundle. Neither changes the taxonomy version.
