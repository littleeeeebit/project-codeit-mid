`evaluation/error_analysis.py` uses only the standard library. It keeps append-only span notes and reviewed marks in `annotations/<run-id>.jsonl` (`review-annotation-1`), with offsets verified against the stored answer text. It accepts failure-type proposals that the coding agent groups (`error-analysis propose`) and records the person's accept, rename, merge, split and reject decisions in `taxonomy/history.jsonl` and `versions/`. `similar_cases.py` validates further cases suggested by the agent. Writes under `review/` take an OS file lock (`write_lock`). The counts appear in `release-report` as a section that never changes a pass line.
