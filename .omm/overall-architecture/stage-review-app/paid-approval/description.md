`paid.estimate` prices each candidate's recorded per-call token bounds at the ledger's current rates. `approve` records the person's name and refuses an estimate that expired (24 h) or no longer fits the envelope. `resume` requires approval, `recheck`s the inputs, worker, rate card, refs and remaining budget, and refuses a ref that moved or a working tree that changed since pricing. It then runs each unfinished candidate with key prefix `<run>:<candidate>:…` so the ledger can tell what was already billed. The run ends `complete` or stays `stopped` (resumable). `reprice` re-prices what is left; `rescore` re-scores stored outputs without calls.
