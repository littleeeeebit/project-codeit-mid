`stage_review.run(stage, base, cands)` resolves each ref to a full commit; `.` is the working tree with a hash of its changes. It freezes inputs (`freeze`, or `--inputs-from` an earlier run) and copies `stage_review_worker.py` into the run folder. For each ref it checks out a worktree, reads an optional committed `review-variant.json`, builds the candidate config, and refuses GPU-needing candidates on a host without CUDA. It executes the worker and always removes the worktree. Retriever and chunking runs are scored at once into `view.json`. Generation and OCR runs stop with `state: needs_approval`. `on_ledger` runs reprice, resume and rescore inside a ledger database lifecycle (optionally codeit's, via `--ledger-dsn-env`).
