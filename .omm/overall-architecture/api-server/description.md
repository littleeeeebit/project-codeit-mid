src/rfp_assistant/api.py `create_app` builds the FastAPI app. On lifespan start it opens `service.app_resources()` (a singleton `Resources(settings, recover=True)`), wires `res.update_fence` to the `UpdateWatch`, and starts the GitHub poller. On stop it closes the resources. Routes are thin: each one resolves `Res` and `Member` dependencies and calls one service function. `ServiceError` maps to 400; the other shell errors (e.g. `AuthError`) map to 403.
