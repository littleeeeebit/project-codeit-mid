`_verify_routes` and `_dataset_routes` expose the verifier tooling: retrieval traces (`run_trace`, `generate_from_run_id`), the answer evaluation plan/start, judge plan/start/results, maintenance status/start, the experiments matrix with `activate_experiment`, the HWP fidelity list, rendered pages and confirmation, ingestion rows, corrections, history, and the gold drafting/review queue. Starts publish a run and launch a background thread through `_start_job` or the maintenance job. These functions were identified by name and signature; only the start paths were read in detail.
