`auth.Login.from_env` picks one of three modes. JupyterHub OAuth: hub URL, client ID/secret, redirect URI and an allowlist. A fixed local member: `BIDMATE_LOCAL_MEMBER`, used on a member's PC. Or a `problem` that closes the whole API. Having both the local member and hub settings is refused. `/api/auth/login` redirects to the hub with a state cookie. It first moves to the registered host when reached through a tunnel. `/api/auth/callback` checks the state, exchanges the code (`Hub.username`), enforces the allowlist and issues an in-memory session token.
