Routes: `/api/documents` → `find_documents`; `POST /api/ask` → `service.ask`, which always uses today as `as_of`; `/api/requests[/{id}]` → `list_requests` / `request_status` + `may_attach`; `/api/requests/{id}/stream` → an SSE generator that calls `service.answer_progress` every 0.15 s and emits `data:` with the partial answer (or `null` when revoked), then `event: done`; `/cancel`, `/abandon`, `/export`, `/evidence/{evidence_id}` → `open_evidence`; `/api/originals/{doc_id}/{source_hash}` → `original_download`. Account routes cover `/api/budget`, the budget limit, the API key, the model and the update status.
