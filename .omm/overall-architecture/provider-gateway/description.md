src/rfp_assistant/generation.py is the only SDK call site. OpenAITransport.chat uses Chat Completions with strict json_schema output (AnswerPayload), reasoning_effort and max_completion_tokens. OpenAITransport.embed uses the embeddings endpoint with explicit dimensions. Both call _check_owner (GatewayOwner.check) first, so a lost lock becomes a pre-execution ProviderError. 4xx-class SDK errors become ProviderError(pre_execution=True), which releases the reservation. Timeouts, connection errors and 5xx become pre_execution=False, which marks the attempt unknown. build_messages keeps instructions in the system prompt and puts question, documents and evidence as JSON data. count_request_tokens uses o200k_base plus framing and margin. validate_answer rejects refusals, truncation, schema errors, unknown or cross-document evidence IDs, quote mismatches, uncited claims, unlisted absence claims, claimed source absence, and a missing comparison side. FakeTransport is a deterministic test seam that never touches the network.
