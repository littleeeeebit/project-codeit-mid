`generation.py` is the only runtime SDK call site. `OpenAITransport.chat` calls Chat Completions (`gpt-6-luna`, strict `json_schema` from `AnswerPayload`, `reasoning_effort`, `max_completion_tokens`, no streaming). Authentication, permission, bad-request, not-found, rate-limit and unprocessable errors raise `ProviderError(pre_execution=True)`. Any other `OpenAIError` raises `pre_execution=False`, meaning it may have executed. Usage is mapped to prompt, completion, cached, cache-write and reasoning tokens. `owner_check` (`GatewayOwner.check` on PostgreSQL) runs before every call; lost ownership raises a pre-execution error. `build_messages` keeps instructions in `SYSTEM_PROMPT` (`PROMPT_VERSION='grounded-answer-4'`) and sends question, metadata and evidence as JSON data. `count_request_tokens` uses o200k_base plus per-message framing, the schema and a margin. `validate_answer` turns refusal, truncation, schema errors, unknown or cross-document evidence IDs, quote mismatches against the index, claimed source absence and a missing comparison side into `TechnicalError`. `FakeTransport` echoes the first evidence unit per document and generates hashed bigram embeddings for keyless tests.
