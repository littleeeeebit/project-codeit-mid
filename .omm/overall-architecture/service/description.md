src/rfp_assistant/service/service.py is the authenticated orchestration layer. Resources._initialize runs these steps in order: require an imported database, init_schema, budget.ensure_budget_row, take gateway ownership with recovery (recover_requests and budget.recover), then build FakeTransport or OpenAITransport. index(), dense() and reranker() load lazily what active_serving() names. active_serving reads the active_run and active_index rows from app_settings. It falls back to the kiwi_bm25 default when the run was measured under another corpus-routing rule or names an embedding model this code cannot run. Public functions such as ask, request_status, cancel_request, open_evidence, run_trace, start_drafting, gold_decide, start_maintenance and activate_experiment all call _authorize. Every signed-in member holds every capability (auth.visitor). Background work (drafting, answer evaluation, judges, maintenance) runs as threads added to Resources._jobs, and close() joins them.
