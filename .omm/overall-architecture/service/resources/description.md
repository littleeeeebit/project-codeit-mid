`Resources.__init__` enters `store.database_lifecycle`, then `_initialize` runs `require_imported_database`, `init_schema` and `budget.ensure_budget_row`. With `recover=True`, `_own` either borrows this process's live owner or takes `postgres.gateway_lock`; a lock already held raises `GatewayLockError`. It then runs `recover_requests` and `budget.recover`. The transport is `FakeTransport` for provider 'fake', `OpenAITransport` when OPENAI_API_KEY is readable, and otherwise none, with `provider_note = NO_API_KEY`. Handles are loaded lazily under `_index_lock`. `index()` reloads `KeywordIndex` whenever `active_index` changes. `dense()` verifies a vector set once per version; a refusal is remembered in `_dense_failed` and `stage_errors['dense']`, so retrieval falls back visibly without retrying every question. `reranker()` reloads when the model, revision, max length, concurrency or precision changes, freeing the GPU first. `retire_inactive` unloads GPU models that serving no longer uses. `set_api_key` stores one client per key session, in memory only. `close()` marks the owner closed under `_runner_lock`, shuts the runner down, joins jobs until `shutdown_wait_seconds`, runs recovery again if any thread is still alive, closes the transport and tracing, and releases the lock. It is registered with `threading._register_atexit`, so it runs before the executor's own join.
