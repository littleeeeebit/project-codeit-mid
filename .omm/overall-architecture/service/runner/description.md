_create() inserts a request snapshot under UNIQUE(member_id, idempotency_key) and rejects reuse with a different input hash. submit_answer() acquires a nonblocking admission slot only for a new paid request, persists queued state and submits its ID with a copied ContextVars context. run_queued() atomically claims queued-to-running unless cancelled, reconstructs AnswerRequest and Principal from request_json, then calls _execute(). Admission overflow causes no paid call.
