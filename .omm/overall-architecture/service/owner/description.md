`postgres.GatewayOwner` holds `pg_try_advisory_lock(GATEWAY_LOCK)` on one dedicated autocommit connection. `check()` confirms through pg_locks that the lock is still granted and that validation is still ready. If either fails it marks the owner `lost` and refuses all further dispatch; it never reconnects. `borrow_owner` lets several `Resources` objects in one process share the lock with a reference count, and `release()` closes the connection when the last user leaves.
