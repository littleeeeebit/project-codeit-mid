`RFP_DATA_DIR` (`.runtime/`) holds content-addressed or append-only artifacts written atomically (`write_text_atomic`, `write_jsonl_atomic`): `extracted/<hash>/<fp>/elements.jsonl`, `indexes/<version>/` (chunks, tokens, requirements, scope-terms, manifest), `runs/<run_id>/`, `compare/{tables,cells,estimates}`, `datasets/dev.jsonl`, `sealed/test.jsonl`, `drafts/`, `reviews/printed/<hash16>.pdf`, `ocr/`, `maintenance/{state.json,reports}` and `archive/` cold dumps. Database rows reference these by path and sha256, and loads re-verify the hashes.
