`GatewayOwner` holds a dedicated connection with `pg_try_advisory_lock(GATEWAY_LOCK)`. `gateway_lock` takes it, `borrow_owner` lets a second `Resources` in the same process (e.g. `PinnedResources`) share it with reference counting, and `require_owner`/`owner_guard` let `budget.reserve` and `mark_dispatching` refuse when ownership was lost. `OpenAITransport._check_owner` re-checks before every provider call.
