`storage/postgres.py` (Target, Connection, `open_db`, `tx`, `require_imported_database`, `GatewayOwner`) and `storage/store.py` (`init_schema`, app settings, atomic file writes). Records include `requests` (status, cancel_requested, request_json snapshot, trace_json, result_json), `attempts` (ledger states), `budget_settings`, `adjustments`, `database_control.paid_admission`, migration validation markers, audit events, documents, extractions and indexes, embedding sets and the app settings `active_run`/`active_index`. Startup refuses a database without a validated import, unchanged artifact hashes or the pinned server versions. Run artifacts, comparison tables and keyword index payload files live under `RFP_DATA_DIR`.
