`postgres.py` wraps psycopg pools: one per DSN, reference-counted through `lifecycle`, with `lock_timeout` 5 s and `statement_timeout` 60 s, and pgvector registered on each connection. `store.py` holds the schema: sources, documents, extractions, elements, indexes, chunks, requirements, reviews, fidelity_checks, app_settings (`active_run`, `active_index`), requests, attempts, adjustments, budget_settings, gold_candidates, gold_reviews, metadata_resolutions, corrections, verifier_runs, activations and audit_events. `vector_store.py` adds embedding_payloads, embedding_sets and embedding_set_rows. `GatewayOwner` holds `pg_try_advisory_lock(GATEWAY_LOCK)` on a dedicated connection; `owner_guard` checks inside every admission and dispatch transaction that this backend still holds it. `host_path` maps recorded absolute paths through `RFP_PATH_MAP`, so a database dumped on Windows can serve on the Linux VM.
