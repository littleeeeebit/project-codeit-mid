`storage/postgres.py` is the SQL dialect boundary. `Target(dsn_env='RFP_DATABASE_DSN')` names the database. `lifecycle` creates one bounded `ConnectionPool` per target (max 8 connections, autocommit, lock_timeout 5 s, statement_timeout 60 s, pgvector registered, server and extension versions enforced). `open_db` checks out a connection only inside an owned lifecycle. `bind_sql` translates qmark SQL and refuses SQLite constructs. `tx(immediate=True)` serializes writers by locking row 1 of `application_mutex`, and `read_snapshot` provides repeatable-read, read-only views. `storage/store.py` holds the schema: sources, extractions, requests, attempts, institution_types, activations and more. File artifacts (index directories, extraction files, OCR cache, run folders, maintenance state) live under `RFP_DATA_DIR` (`.runtime`), and `migration_validation.references_json` pins them by hash, which `require_imported_database` re-checks at startup. `host_path` maps recorded absolute paths with `RFP_PATH_MAP` when a dump is restored on another host.
