src/rfp_assistant/storage. postgres.py provides `Target`, the pooled `open_db`, `tx` (with the `application_mutex` row lock when immediate), `read_snapshot` (REPEATABLE READ, READ ONLY), `init_schema` (applies store.SCHEMA plus the vector_store and models external schemas under an advisory schema lock, and creates `application_mutex` and `database_control`), `require_imported_database`, and the gateway owner. store.py defines the tables: sources, fidelity_checks, documents, extractions, elements, indexes, chunks, requirements, reviews, app_settings (holding `active_run` and `active_index`), requests, attempts, adjustments, budget_settings, gold_candidates, extraction_inputs, metadata_resolutions, embedding_estimates, audit_events, corrections, verifier_runs, gold_reviews, eval_estimates and activations. It also provides the atomic file writers (`write_jsonl_atomic`, `write_text_atomic`) and `ProcessLock`. postgres_backup.py and maintenance.py implement backup, staged restore-check (a scratch database `rfp_mrestore_<uuid>`) and the maintenance sequence. hwp_loader.py, despite sitting under storage, is the `HwpHwpxLoader` adapter that ingestion uses when pyhwp fails.
