All persistent state lives in one PostgreSQL database named by `RFP_DATABASE_DSN`: documents, sources, extractions, elements, indexes, chunks, requirements, the pgvector `embedding_payloads`/`embedding_sets`/`embedding_set_rows`, requests, verifier_runs, attempts, adjustments, budget_settings, activations, gold_candidates, audit and app settings (`active_index`, `active_run`). `postgres.open_db` gives pooled connections that refuse any server other than 18.6 and pgvector other than 0.8.6. `tx(conn, immediate=True)` takes `SELECT … FROM application_mutex WHERE id = 1 FOR UPDATE`, which serializes every admission, idempotency and state write. `init_schema` takes a schema advisory lock and only moves the schema forward. Large artifacts are files under `RFP_DATA_DIR` (`.runtime`): extraction `elements.jsonl`, index directories, run folders, OCR caches, prints, drafts and the review runs. The DB records their paths and hashes, and `require_imported_database` re-verifies the referenced hashes at every startup.
