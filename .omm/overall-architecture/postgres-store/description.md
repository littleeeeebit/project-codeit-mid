src/rfp_assistant/storage/postgres.py and store.py. open_db wraps pooled psycopg connections with a sqlite-style API (bind_sql, Row). tx(conn, immediate=True) serializes writers with SELECT ... FOR UPDATE on the single application_mutex row. init_schema applies the store.py schema (sources, documents, extractions, elements, indexes, chunks, requirements, reviews, app_settings, requests, attempts, adjustments, budget_settings, gold_candidates, audit_events, verifier_runs, activations and more), the vector_store schema and the external Gemini ledger, under an advisory schema lock. It refuses a database whose schema is newer than the code. require_imported_database refuses startup without a complete migration_import, a passing migration_validation and unchanged referenced artifact hashes. Backups and restore-check live in postgres_backup.py and evaluation/release.py.
