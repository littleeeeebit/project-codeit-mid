`import_manifest` reads `data_list.csv` from `RFP_SOURCE_DIR` (`read_manifest_csv`, `normalize_row` with typed dates and amounts plus flags), hashes each original (`sha256_file`) and records one `documents` row per CSV association and one `sources` row per unique byte content. Byte-identical associations share an extraction but keep their own metadata and scope. `identity_report` and `resolve-metadata` later record canonical values with a rationale, which search, filters and the index's frozen scope terms then use.
