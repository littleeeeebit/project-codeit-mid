`step_fidelity` checks only HWP extractions with no current verdict. `step_keyword` builds or reuses an index with the served index's profile and review scope, with `activate=False`. `step_embedding` embeds the rebuilt index's uncached chunks with the activated embedding model through `compare.ensure_dense`: free for a local model, stopped with `NeedsApproval` and a priced estimate for a paid one. It is skipped when serving is keyword-only.
