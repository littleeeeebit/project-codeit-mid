`ParseWorker` is the parse callable passed to `ingestion.ingest`. It spawns one child process (`multiprocessing` spawn context, never forking the server's threads), which is reused across files and restarted after a kill. The child only parses (`_parse_source`) and returns results or pickled exceptions over a pipe, while every database write stays in the parent. The parent polls every 0.2 s. Past `parse_timeout_seconds` (default 120 s) it kills the child's whole process tree (`taskkill /F /T` on Windows, `killpg` elsewhere) and raises `ParseTimedOut`, so the file keeps its previous extraction and is retried next run. A cancel or a closing service kills it at once with `Stopped`.
