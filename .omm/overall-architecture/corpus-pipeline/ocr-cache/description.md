ocr.run takes a ProcessLock on .runtime/ocr/run.lock. For each parsed source it collects regions (HWP embedded pictures via hwp_regions, PDF raster images via regions). It reuses any finished read of the same picture digest. Otherwise it reads locally with PaddleOCR-VL (LocalOCR); when fallback_reasons flag the read (loop, low confidence, length far from the ink estimate), RemoteReader re-reads it with gpt-5-mini. That path calls budget.reserve with stage ocr:<region> and purpose ocr, then mark_dispatching and settle. Rows are checkpointed to .runtime/ocr/<hash>/<version>.jsonl after every region. An unknown billing or overrun raises OcrStop and ends the run. Ingest later merges the cache as image_text elements.
