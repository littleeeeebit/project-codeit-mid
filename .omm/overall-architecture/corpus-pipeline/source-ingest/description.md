`ingest_source` re-parses only when `input_key` changed (original, parser revision, native print, OCR cache or converter). HWP goes through `hwp5proc` (`parse_hwp`); if that fails and a Hancom print exists, it reads the printed PDF's text layer. PDF goes through PyMuPDF. OCR `image_text` regions are merged by `ocr.merge`. A failed parse quarantines the source (`parse_status='quarantined'`, `review_status='needs_recovery'`). `assign_revision` binds the extraction ID to the actual output: identical output keeps its revision and review, while different output creates a new revision beside the old one and resets review to `unreviewed`. Old artifacts and elements stay for pinned gold rows and issued citations. One crashing file is recorded as `error`, and `ingest` continues.
