`_parse_source` handles HWP by running the `hwp5proc` converter to XML and walking it (`parse_hwp`/`walk_hwp`). When pyhwp fails, it parses the original with `HwpHwpxLoader` (`load_hwp_hwpx`) instead, records a `pyhwp_failed` warning and uses the `hwp_loader` fingerprint; only a loader failure quarantines the source. PDFs go through PyMuPDF (`parse_pdf`). A quarantined source gets `parse_status='quarantined'`, `review_status='needs_recovery'` and a `reason_code`. `ingest` continues past per-file crashes, records them as `error`, and the CLI exits 1.
