`_parse_source` calls `parse_hwp` or `parse_pdf`. `parse_hwp` walks pyhwp `hwp5proc` XML through `run_hwp_converter`. When pyhwp fails it falls back to `HwpHwpxLoader` in `storage/hwp_loader.py` with warning `pyhwp_failed`, and only a loader failure quarantines the source. `parse_pdf` uses PyMuPDF. The result is elements, warnings, a reason code and a parser fingerprint. A new extraction revision is created only when the output actually changes. Old artifacts stay in place for pinned gold rows and issued citations. A crashing file is recorded as `error` and the run continues, with exit code 1 from the CLI.
