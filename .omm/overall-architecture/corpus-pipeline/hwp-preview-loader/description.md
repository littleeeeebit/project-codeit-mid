`load_hwp_hwpx(original)` lives on this branch. It accepts only `.hwp` and `.hwpx` and requires the file to exist. It imports `langchain_hwp_hwpx.HwpHwpxLoader` and `hwp_hwpx_parser`, so a missing dependency propagates as an environment error. It runs the loader in elements mode with tables, notes, memos and hyperlinks, raising on invalid or encrypted input. A loader exception gives `hwp_loader_failed`. A malformed result (not a list, non-string content, non-mapping metadata or non-string metadata keys) gives `hwp_loader_result_invalid` and discards every element. Non-empty items become `paragraph` elements at `loader/e<i>` with `order_basis: loader_grouped_elements` and `native_order_verified: false`. Empty output gives `hwp_empty_output`.
