`build_keyword_index` selects parsed sources by review policy (with `--include-unreviewed`, the unreviewed and `auto_flagged` sources too). It chunks each active extraction with `chunking.build_profile`, tokenizes with the Kiwi analyzer, and freezes `scope-terms.json`. The version is the hash of the config (chunker, profile, analyzer, IDF policy, extractions, metadata terms), so an identical build is reused. `activate=True` moves only `active_index`; once a run has been activated, only another activation changes what serves. `plan-embeddings` and `build-dense` then build the pgvector set for that index under a priced estimate.
