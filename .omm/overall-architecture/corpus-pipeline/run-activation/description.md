`evaluate-retrieval` and `compare` write frozen runs under `.runtime/runs/<run_id>/`. `activate_decision`, called from `activate-run` or from `POST /api/verify/experiments/activate` through `service.activate_experiment`, checks `decision_errors`: current evaluation policy, verified index and matrix, pinned embedding revision, and a valid finalist. In one transaction it then writes `app_settings.active_run` (`serving_config`) and `active_index`, and appends an `activations` row holding the previous configuration.
