`ingest_source` refuses an unknown source and an original whose bytes changed. A source with an owner-registered recovery artifact is reported as `recovered` and not reparsed. If `input_key` is unchanged and the artifact hash still matches, `_reused` returns the recorded outcome. Otherwise `_parse_source` runs. A failure reason sets `parse_status='quarantined'` and `review_status='needs_recovery'` with a `reason_code`. A success calls `assign_revision`, `diagnose` and `_record_input`, inserts the extraction and replaces its elements, then sets `parse_status='parsed'`. Review status resets to `unreviewed` whenever the extraction ID changes.
