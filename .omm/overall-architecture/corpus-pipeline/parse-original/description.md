`ingest_source` re-checks the original's SHA-256. It skips recovered sources, and reuses the prior extraction when `input_key` (bytes, parser, print, OCR cache, converter) is unchanged and the artifact hash still matches. HWP goes through `run_hwp_converter` (`hwp5proc` XML) and `walk_hwp`. When pyhwp fails but a Hancom print exists, the print's text layer is parsed instead and stays unreviewed. PDFs use `parse_pdf` (PyMuPDF). A parse failure sets the source `quarantined` with review `needs_recovery`. `ingest` keeps going after one crashing file and records it as `error`; `write_ingest_report` writes `.runtime/reports/ingest-*.json` with diagnostics.
