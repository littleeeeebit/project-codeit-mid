`parse_hwp` runs `hwp5proc` (`run_hwp_converter`; `RFP_HWP_CONVERTER` overrides the path) and walks the XML with `walk_hwp`, leaving picture markers where pyhwp met each BinData picture. `ocr.merge_hwp` replaces those markers with `image_text` elements from the OCR cache; a picture inside a table cell lands after its table. When pyhwp fails, `_parse_source` calls `load_hwp_hwpx` (src/rfp_assistant/storage/hwp_loader.py) with fingerprint `hwp_loader` and warning `pyhwp_failed`. That path has no picture positions, so no image text. Only a loader failure quarantines the source.
