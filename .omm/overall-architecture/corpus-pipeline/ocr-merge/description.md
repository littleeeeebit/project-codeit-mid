When a rendering exists (the Hancom-printed PDF `printed_pdf_path` for HWP, the original for PDF), `ocr.merge` inserts one `image_text` element per finished OCR region next to the print text around the image. It returns a fingerprint suffix that becomes part of the parser fingerprint. OCR itself (`ocr.run`, CLI `ocr`) reads raster regions with PaddleOCR-VL on the GPU, re-reads flagged regions with gemini-3.5-flash-lite under the $0.50 cap, and caches results under `.runtime/ocr/<hash>/`. OCR internals were read only at signature level.
