After a successful parse, `ocr.merge` inserts one `image_text` element for each finished OCR region cached under `.runtime/ocr/<hash>/`. Each goes next to the print text around its image, and a fingerprint suffix is appended so the revision changes. `ocr.run`, the CLI `ocr` command, produces those regions with PaddleOCR-VL on the GPU. It re-reads only flagged regions with Gemini 3.5 Flash-Lite, under `GEMINI_CAP_MICRO` ($0.50) tracked in `ocr/gemini-ledger.jsonl` behind a `ProcessLock`.
