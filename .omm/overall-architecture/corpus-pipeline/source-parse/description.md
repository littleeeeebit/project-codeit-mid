ingest() processes every unique source_hash once; one failing file is recorded as error and the run continues. ingest_source verifies the original's bytes still match source_hash and skips recovered sources. It reuses the prior outcome when input_key (original, parser revision, print, OCR cache, converter) is unchanged and the artifact hash still matches. Otherwise _parse_source runs. For HWP: hwp5proc XML -> walk_hwp with picture markers -> ocr.merge_hwp. For PDF: parse_pdf (PyMuPDF tables and blocks in reading order) -> ocr.merge. A non-empty reason quarantines the source (parse_status quarantined, review_status needs_recovery) and records the input.
