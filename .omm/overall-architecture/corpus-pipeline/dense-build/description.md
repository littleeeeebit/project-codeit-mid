`plan_embeddings` counts the unique payloads not yet cached and stores a priced estimate bound to the index, model, dimensions, rates and batches (valid 24 h). `build_dense` refuses a stale or over-envelope estimate, reserves and settles each batch in the `embedding` envelope, and publishes the set only after every row verifies (`vector_store.publish` → `PgDenseIndex.load(require_ready=False)` → state `ready`). Local registry models (`build_local_dense`) embed on CUDA only. Gemini has its own cap and ledger. `compare --matrix embedding` drives these per model.
