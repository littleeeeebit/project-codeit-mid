`plan-embeddings` writes a 24-hour estimate bound to index, model, dims, payloads, rates and batches. `build-dense` refuses a stale or over-envelope estimate, reserves and settles each batch in the `embedding` envelope, refuses while any embedding attempt is `unknown`, and publishes the set (`vector_store.publish`) only after every row is verified. Local GPU models (`build_local_dense`) and Gemini (`build_gemini_dense`) fill their own sets.
