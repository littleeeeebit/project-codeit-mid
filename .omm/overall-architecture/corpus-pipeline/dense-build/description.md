Each compared embedding model (`models.EMBEDDINGS`, revision- and prefix-pinned) has its own vector set over the same chunk payloads. Local models embed on the GPU for free. An OpenAI or Gemini corpus build first writes a priced estimate (`plan-embeddings`, 24 h, bound to index, model, dims, payloads and rates), runs only after approval, reserves and settles per bounded batch in the `embedding` envelope, and refuses while any embedding attempt is unknown. `publish_dense` registers the set only after every row is verified.
