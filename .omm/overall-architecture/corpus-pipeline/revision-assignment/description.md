`ingest_source` skips work when `extraction_inputs.input_key` is unchanged and the artifact hash still matches (`_reused`). Otherwise `assign_revision` derives the extraction ID from `source_hash` and the fingerprint. If that ID already exists with different output, it creates a content-addressed revision beside it, so traces, gold rows and citations pinned to the old elements stay valid. It writes `elements.jsonl` atomically, replaces the extraction's `elements` rows and sets `sources.active_extraction_id`. A new revision resets `review_status` to `unreviewed`. `diagnose` adds advisory flags (short output, no tables, blank pages, replacement characters) that never mark a source reviewed.
