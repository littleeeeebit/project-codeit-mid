`assign_revision` derives the base ID `sha256(source_hash:fp)[:24]`. If a stored artifact under that ID differs from the new output, it uses a content-addressed ID instead, so the old artifact and elements stay in place for pinned gold rows, traces and citations. It writes `elements.jsonl` atomically only when the content changed. `finalize_elements` assigns `element_id`, `source_order` and `search_text`.
