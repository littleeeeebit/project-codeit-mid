`fidelity.verify_source` refuses unparsed, non-HWP and recovered (`RECOVERED`) sources. It prints the original through Hancom Viewer to PDF when no print exists (`print_hwp`; Windows default printer 'Microsoft Print to PDF', 20–30 s per document). It then compares extraction elements with `rendered_pages(pdf)` both ways (6-character shingles, exact 3+ digit runs) and upserts `fidelity_checks(extraction_id, method=FIDELITY_VERSION)` with verdict, metrics and findings. `sources.review_status` becomes `auto_verified` or `auto_flagged` unless a human status is already recorded. The 검증 원문 대조 tab shows findings and page PNGs (`rendered_page_png`). `confirm_fidelity` records `sample_checked` through `record_review`.
