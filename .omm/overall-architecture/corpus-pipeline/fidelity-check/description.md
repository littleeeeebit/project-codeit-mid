`fidelity run` has Hancom Viewer print each HWP to PDF as an independent witness. It compares 6-character shingles both ways and runs of 3+ digits exactly, then records `auto_verified` or `auto_flagged` with element, cell and page findings in `fidelity_checks`. A human `sample_checked`/`reviewed` status is never overwritten by an automatic one. Maintenance runs it only for HWP extractions that have no verdict for the current `FIDELITY_VERSION`.
