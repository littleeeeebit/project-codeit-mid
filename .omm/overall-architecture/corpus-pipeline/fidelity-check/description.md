`fidelity.verify_source` has Hancom Viewer print the HWP to PDF and answers the save dialog itself; this needs Windows and the 'Microsoft Print to PDF' default printer. `compare` matches the extraction against the print's text layer both ways (6-character shingles, ruled table cells, exact runs of 3 or more digits). The source becomes `auto_verified` or `auto_flagged`, with the element, cell and page of every difference. A human status (`sample_checked`, set via `/api/verify/fidelity/{hash}/confirm` or `review record`) is never overwritten.
