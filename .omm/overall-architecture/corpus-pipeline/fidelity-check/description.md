`fidelity.verify_source` prints the HWP through Hancom Viewer to PDF (`print_hwp`, which drives the save dialog; the default printer must be Microsoft Print to PDF). It compares the PDF text layer with the extraction both ways, using 6-character shingles and exact digit runs, and stores a `fidelity_checks` row. It then sets `sources.review_status` to `auto_verified` or `auto_flagged` unless a human status is already present. The verify screen lists the findings, and `service.confirm_fidelity` records a person's confirmation. OCR text is skipped by the comparison.
