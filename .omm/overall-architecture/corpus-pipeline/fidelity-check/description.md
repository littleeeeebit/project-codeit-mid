For each parsed HWP, Hancom Viewer prints the original to PDF as an independent witness (Windows default printer "Microsoft Print to PDF"). Extraction and rendering are then compared both ways with 6-character shingles, plus an exact match for runs of three or more digits. The verdict is `auto_verified` or `auto_flagged`, with the element, cell and page of each difference. An automatic verdict never overwrites a human review status. `build-keyword --reviewed-only` admits only `auto_verified`, `sample_checked` and `reviewed` sources; the operating index (`--include-unreviewed`) also admits `unreviewed` and `auto_flagged` sources and labels them.
