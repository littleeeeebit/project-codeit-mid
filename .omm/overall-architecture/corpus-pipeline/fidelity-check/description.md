`fidelity.verify_source` compares an HWP extraction with Hancom Viewer's own printed PDF in both directions: 6-character shingles, plus exact runs of 3 or more digits. It writes `auto_verified` or `auto_flagged` to `fidelity_checks` with the exact element, cell and page of each difference. A human review status is never overwritten. The check needs Windows with Hancom and 'Microsoft Print to PDF' as the default printer. Maintenance checks only extractions that have no verdict under the current `FIDELITY_VERSION`.
