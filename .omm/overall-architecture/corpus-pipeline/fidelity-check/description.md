Per the README and the CLI `fidelity run`, Hancom Viewer prints each HWP to PDF, and that independent text layer is compared both ways with the extraction: 6-character shingles, plus exact runs of 3 or more digits. The verdict `auto_verified` or `auto_flagged` lists the elements, cells and pages that differ. A human `sample_checked` status, recorded through `/api/verify/fidelity/{hash}/confirm`, is never overwritten by an automatic one. This analysis did not trace `fidelity.py` internals.
