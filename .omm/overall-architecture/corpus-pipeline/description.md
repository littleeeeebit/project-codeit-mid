Turns the 100 CSV associations and their HWP/PDF originals into reviewed extractions and immutable indexes. It runs from the CLI (`manifest`, `ingest`, `ocr`, `fidelity run`, `build-keyword`, `plan-embeddings` / `build-dense`) or as one `maintain` sequence: backup → restore check → ingest → HWP fidelity → keyword → embedding → regression → report. Every step reuses unchanged inputs, so a rerun with nothing changed makes no provider call. Nothing here changes what serves.
