`compare.run_matrix` (CLI `compare --matrix lexical|chunking|embedding|reranker`, or a custom JSON) varies one declared axis per row and holds the serving run's other limits fixed. Each row is scored on three populations: dev inside its own document, dev across the corpus, and the needle set across the corpus. Finished cells are cached under `.runtime/compare/cells/`. Every row is written as an activatable run under `.runtime/runs/<run_id>/`. An uncached paid corpus build stops as a `needs_approval` row with a priced estimate until `compare --approve`. Tables go to `.runtime/compare/tables/<matrix>.json|md` and are shown by `/api/verify/experiments`.
