`ingest_source` calls `ocr.merge(settings, source_hash, raw, rendering)`, which places cached OCR text as `image_text` elements next to the surrounding print text and adds a fingerprint suffix. The OCR itself (`cli ocr`: PaddleOCR-VL on the GPU, with Gemini 3.5 Flash-Lite only for regions that fail the fallback test, under its own $0.50 cap in `.runtime/ocr/gemini-ledger.jsonl`) is described from the README and was not traced in code.
