`build_keyword_index` chunks the extractions (`retrieval/chunking.py`, structural profile by default, fixed-size profiles for comparison only). It writes a versioned index directory with a manifest and `scope-terms.json`, records it in the database, and makes it `active_index` only when `activate=True`. `--include-unreviewed` builds the operating index, which keeps unreviewed and auto_flagged sources and labels them. `--reviewed-only` builds the stricter index.
