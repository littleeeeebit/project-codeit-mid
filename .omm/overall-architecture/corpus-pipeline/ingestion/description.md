`import_manifest` reads `data_list.csv` (100 associations) into `documents`/`sources`. Byte-identical files share one source. `ingest` parses each unique original once through `ingest_source`, which first checks the original's sha256 and returns a recorded recovery or the reused result when `input_key` (bytes, parser revision, print, OCR cache, converter) is unchanged. `_parse_source` walks HWP through `hwp5proc` XML (`walk_hwp`) and merges OCR text at picture markers. When pyhwp fails it falls back to `HwpHwpxLoader` (`pyhwp_failed`). PDF goes through `parse_pdf`, also with OCR merged. A reason code quarantines the source (`needs_recovery`). `assign_revision` ties the extraction ID to the actual output: identical output keeps its revision and review, while different output gets a new revision and leaves the old artifact and elements in place for pinned gold and citations. A new revision resets review to `unreviewed`. A crashing file is recorded as `error`, the run continues, and the exit code is 1.
