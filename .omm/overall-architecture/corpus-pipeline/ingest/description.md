`ingest_source` refuses if the original's bytes no longer match the hash. It returns `recovered` for owner-registered recovery artifacts. It reuses the recorded outcome when `input_key` (original, parser revision, print, OCR cache, converter) is unchanged and the artifact hash still matches. Otherwise `_parse_source` runs: pyhwp's XML walk (`parse_hwp` via `hwp5proc`) plus `ocr.merge_hwp`, or PyMuPDF `parse_pdf` plus `ocr.merge`. `assign_revision` binds the extraction ID to the actual output. In one transaction it stores the elements, sets the active extraction, and resets review to `unreviewed` when the revision changed. A parse failure sets `quarantined` / `needs_recovery` with the reason. Diagnostics go to `.runtime/reports/ingest-*.json`.
