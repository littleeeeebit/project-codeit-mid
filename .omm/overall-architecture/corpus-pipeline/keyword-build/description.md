`build_keyword_index` selects parsed sources by review policy (the operating index includes `unreviewed`/`auto_flagged`, labeled; `--reviewed-only` builds the strict one). It chunks each active extraction with the chosen profile, tokenizes with Kiwi, and freezes title and institution terms. The version is the sha256 of the config, so identical inputs reuse an existing ready index. Files (`chunks.jsonl`, `tokens.jsonl`, `requirements.jsonl`, `scope-terms.json`, `manifest.json` with file hashes) are written to a temp directory and renamed into `.runtime/indexes/<version>/`. Rows in `indexes`/`chunks`/`requirements` are replaced in one transaction. `KeywordIndex.load` re-verifies the manifest and every file hash before serving.
