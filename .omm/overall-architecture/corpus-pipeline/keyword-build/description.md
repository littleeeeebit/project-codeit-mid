build_keyword_index selects parsed sources by review policy (reviewed-only, or including unreviewed and auto_flagged with --include-unreviewed). It chunks each active extraction with chunking.build_profile (structural or fixed profiles) and tokenizes with Kiwi. version is the hash of the config (chunker, analyzer, IDF policy, extractions, metadata-term snapshot). Files are written to a temp directory renamed to .runtime/indexes/<version>/, then one transaction replaces the indexes, chunks and requirements rows. With activate, it also sets app_settings active_index; maintenance builds without activating.
