`retrieval.build_keyword_index(profile, include_unreviewed)` selects parsed sources by review status, freezes `metadata_term_snapshot` (title/institution terms), chunks each active extraction with `chunking.build_profile` (structural by default; fixed-256/512/800 profiles for comparison), and tokenizes with Kiwi. It writes `chunks.jsonl`, `tokens.jsonl`, `requirements.jsonl`, `scope-terms.json` and `manifest.json` atomically to `.runtime/indexes/<version>`, where the version is a hash of the config. It then inserts the `indexes`, `chunks` and `requirements` rows. A ready version is reused. `activate=True` moves `active_index` only, and only on the default path before any run activation.
