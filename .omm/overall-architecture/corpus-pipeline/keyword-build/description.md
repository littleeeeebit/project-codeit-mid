`build_keyword_index` admits parsed sources by review status: `--reviewed-only` takes auto_verified, sample_checked and reviewed; the operating index adds unreviewed and auto_flagged, labelled. It snapshots each document's title and institution terms, chunks every active extraction with `chunking.build_profile` (structural or a fixed baseline profile) and tokenizes with Kiwi. The index directory is written atomically and the rows replaced in one transaction. `activate=True` moves `active_index`; once a run is activated, only another activation changes serving.
