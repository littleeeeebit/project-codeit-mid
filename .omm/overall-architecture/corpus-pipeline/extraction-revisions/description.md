`ingest_source` verifies the original's bytes still hash to the source hash and skips sources with an owner-registered recovery artifact. It reuses the recorded outcome when `input_key` (original, parser revision, native print, OCR cache, converter) is unchanged, unless `--force`. Otherwise it parses. A failure reason sets `parse_status='quarantined'`, `review_status='needs_recovery'` and `reason_code`. A success goes through `assign_revision`: the extraction ID is bound to the actual output, so a different output under the same fingerprint gets a content-derived ID beside the old one, and the old artifact and elements stay. Elements are written to `.runtime/extracted/<hash>/<fp>/elements.jsonl` and to the `elements` table. `sources` then gets `parse_status='parsed'`, the new `active_extraction_id`, and `review_status` reset to `unreviewed` whenever the extraction ID changed. `ingest` continues past a crashing file (status `error`, traceback kept). The CLI exits 1 and maintenance's `step_ingest` raises `StepFailed`.
