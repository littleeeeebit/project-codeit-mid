`ingest_source` skips a source whose `input_key` (original, parser revision, native print, OCR cache, converter) is unchanged and whose artifact hash still matches (`_reused`). It also skips a source with an owner recovery. Otherwise it parses. On failure, `sources` becomes `quarantined` / `needs_recovery` with a reason. On success, `assign_revision` binds the extraction ID to the actual output: identical output keeps its ID and review, and different output under the same fingerprint gets a content-hashed ID beside the old one, so pinned gold rows and citations stay valid. Elements are rewritten per extraction, `sources.active_extraction_id` moves, and review resets to `unreviewed` for a new revision. `ingest` continues past a crashing file, recording `error`, and the CLI exits 1. `write_ingest_report` writes `reports/ingest-*.json` with diagnostics.
