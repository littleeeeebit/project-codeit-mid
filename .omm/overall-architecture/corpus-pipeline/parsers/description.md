`ingest_source` refuses an original whose bytes changed, and returns the recorded outcome when `input_key` (original, parser revision, OCR cache, print, converter) is unchanged. `_parse_source` handles HWP with `parse_hwp` (the pyhwp `hwp5proc` XML walker). When pyhwp fails it falls back to `load_hwp_hwpx` (`storage/hwp_loader.py`) with the `hwp_loader` fingerprint and a `pyhwp_failed` warning. PDF goes through `parse_pdf` (PyMuPDF). A failure sets `sources.parse_status = 'quarantined'` with a `reason_code`. A crash in one file is recorded as `error` while the run continues. Diagnostics such as `short_output` and `no_tables` go to `.runtime/reports/ingest-*.json` and never mark a source reviewed.
