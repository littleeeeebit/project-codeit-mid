`parse_hwp` runs `hwp5proc` (`run_hwp_converter`, resolved from the env or `RFP_HWP_CONVERTER`) and walks the XML (`walk_hwp`, tables via `render_table`, equations). If pyhwp fails but a Hancom print exists, the print's text layer is used (`recovered_from_native_print`). `parse_pdf` uses PyMuPDF. A failure quarantines the source (`parse_status = quarantined`, `review_status = needs_recovery`, `reason_code`).
