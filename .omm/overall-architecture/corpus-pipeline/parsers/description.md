`parse_hwp` runs `hwp5proc` (`run_hwp_converter`, resolved from the env or `RFP_HWP_CONVERTER`) and walks the XML (`walk_hwp`, tables via `render_table`, equations). If pyhwp fails, `load_hwp_hwpx` (`HwpHwpxLoader`) parses the original instead (location format `hwp_loader`, its own parser fingerprint, warning `pyhwp_failed`); the Hancom print is never a text source, only the fidelity witness. `parse_pdf` uses PyMuPDF. A failure (for HWP, the loader's) quarantines the source (`parse_status = quarantined`, `review_status = needs_recovery`, `reason_code`).
