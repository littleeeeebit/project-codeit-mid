`assign_revision` derives `extraction_id` from source hash and parser fingerprint. When the stored artifact under that ID holds different output, it creates a content-addressed revision beside the old one, so the old elements stay valid for pinned gold rows, traces and citations. In one transaction, `ingest_source` then writes `extraction_inputs`, `extractions`, the `elements` rows and the source's `active_extraction_id`. A new revision resets `review_status` to `unreviewed`.
