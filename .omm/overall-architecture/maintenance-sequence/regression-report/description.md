`step_regression` runs `compare.regression`: K1 and the serving configuration over the served and the rebuilt index, using cached cells. A row needing approval raises `NeedsApproval`, and any incomplete row fails the step. Questions whose pinned evidence a re-parse replaced appear as `needs_evidence_review`, which makes the run `unverified`. The `report` step adds `compare.golden_counts`. `report_md` writes the markdown summary.
