`compare` runs the named matrices (`compare.MATRICES`: lexical, chunking, embedding, reranker) or a JSON spec. Only the declared axis varies, against the serving base (`serving_base`), on three populations: dev on its own document, dev over the corpus, and the needle set. Cached cells, vectors and reranker scores are reused. An uncached paid corpus build stops as a `needs_approval` row with a priced estimate until `compare --approve`. Tables go to `.runtime/compare/tables/<matrix>.{json,md}`; 검증 → 실험 비교 reads them via `service.experiments`. `compare.regression` is the maintenance regression table.
