`plan-run` prices every remaining attempt. `run_answers` answers each finalist's rows through `service.answer` on a `PinnedResources` (the finalist's retrieval configuration pinned) with idempotency key `<run>:<finalist>:<question>:<attempt_no>`. `_answer_row` never resends a key whose call may have been billed. It retries only refused, interrupted or pre-execution-released attempts. The first `budget_blocked`, new `unknown_billing` or error stops every worker before its next row; rerunning resumes the unfinished rows.
