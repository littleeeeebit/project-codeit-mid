`activate_decision` is reached from `activate-run` (a decision file or `--decided-by`) or from `service.activate_experiment` (the 실험 비교 button, with name and note). It runs `decision_errors` (the index and matrix verify, the run uses the current policy, a non-OpenAI embedding matches its pinned revision). Then, in one transaction, it sets `active_run` and `active_index` and appends to `activations` with the previous configuration. Serving picks it up on the next `res.serving()` read; `retire_inactive` unloads GPU models that are no longer used.
