`evaluate-retrieval` runs K0/K1/D/H(/HR) over independently reviewed dev rows and writes `.runtime/runs/<run_id>/` (`config.json`, `traces.jsonl`, `scores.json`, `report.md`). Metrics are graded against source spans (hit@k, recall, nDCG@5, MRR, packed coverage, qualifier losses, Wilson intervals). A configuration that already has scores is reused. Runs from an older `EVAL_VERSION`, a refused index, or a changed population cannot be activated.
