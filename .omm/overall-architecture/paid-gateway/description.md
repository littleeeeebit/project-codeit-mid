Every paid provider call goes through one path: reserve the maximum cost, mark the attempt dispatching under the request's stop check, call the provider with no SDK retries, then settle, release or mark unknown. For chat this is `service._metered_chat`. For query and corpus embeddings it is `dense.metered_embed` and `dense.query_vector`, which use the same ledger with `embedding` and `gold_eval` purposes (observed in the signatures and in the README). Ledger state lives in `attempts`, `adjustments` and `budget_settings`.
