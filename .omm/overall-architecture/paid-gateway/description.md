Every provider call that costs money goes through `gateway/budget.py` (the ledger) and `gateway/generation.py` (the only OpenAI SDK call site), under the database-wide `GatewayOwner` lock from `storage/postgres.py`. A reservation prices every input token at the cache-write rate plus the full output allowance (`max_cost`). It is checked against the shared cap and against the purpose envelope (`embedding`, `gold_eval`, `interactive`, `judge_eval`). Langfuse tracing in `gateway/tracing.py` only observes; it never gates a call.
