The only path to a paid provider. The ledger lives in PostgreSQL (`attempts`, `adjustments`, `budget_settings`, `external_attempts` for Gemini). `_metered_chat` in service.py and `metered_embed` in dense.py drive the same sequence: `reserve` the maximum cost, `mark_dispatching` with the request's stop guard in the same transaction, call the transport, then `settle` usage, `release` when the call provably never executed, or `mark_unknown`. Nothing is ever retried automatically. Langfuse tracing (`gateway/tracing.py`) observes calls but is never read by admission or settlement.
