Every paid call, whether answer, rewrite, OpenAI query embedding, drafting or a stage-review worker's answer, follows the same protocol. First, atomic reservation of the maximum cost. Second, a durable `dispatching` marker in the same transaction as the request's stop check. Third, the provider call with SDK retries disabled. Finally, settlement from reported usage, or release when the call provably never executed, or `unknown` otherwise. `service._metered_chat` and `_call_and_settle` implement this for chat calls.
