`gateway/` is the only path to paid providers. `budget.py` is the atomic ledger: `attempts`, `budget_settings`, `adjustments` and `external_attempts`. `generation.py` holds the only OpenAI SDK call site, plus prompts, the token counting and answer validation. `tracing.py` is optional Langfuse observability. The Gemini side ledger lives in `retrieval/models.py`.
