Every paid provider call uses a durable reservation ledger in the PostgreSQL `attempts` table, run under the database-wide gateway lock. `budget.reserve` admits atomically against `budget_settings` and `database_control`. `budget.mark_dispatching` writes a durable marker before the network call, in the same transaction as the request's stop check. Afterwards the attempt settles exactly once from reported usage, is released when execution provably did not happen, or stays `unknown` until the owner reconciles it. SDK retries are disabled (`max_retries=0`).
