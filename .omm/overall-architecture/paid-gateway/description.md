Every paid call — answer generation, query rewrite, query embedding, OCR fallback, drafting, judges, answer evaluation — follows the same contract. `budget.reserve` admits the worst-case cost atomically. `budget.mark_dispatching` records the dispatch durably under a stop guard. The transport makes the call. Then exactly one of settle, release (only on confirmed pre-execution rejection) or mark_unknown records the outcome. Nothing retries automatically: SDK retries are disabled (`max_retries=0`).
