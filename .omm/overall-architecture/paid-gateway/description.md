Every paid provider call (answer generation, follow-up rewrite, query or corpus embedding, drafting, judges) follows one protocol. Reserve the maximum cost atomically. Mark the attempt dispatching in the same transaction as the request's stop check. Call the provider with SDK retries disabled. Then settle from the reported usage, release when the provider rejected the call before execution, or mark the attempt unknown. Nothing retries automatically. Langfuse observes the calls but never feeds admission or settlement.
