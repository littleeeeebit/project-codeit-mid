One shared ledger for every paid call. The `budget.py` docstring defines the state machine: reserved → dispatching → settled; dispatching → unknown → settled or reconciled; reconciled → settled; reserved → released; dispatching → released only on a confirmed pre-execution rejection. Purposes draw on envelopes, as sixteenths of the cap: embedding 1, gold_eval 3, interactive 12, judge_eval 0. `generation.py` is the only SDK call site.
