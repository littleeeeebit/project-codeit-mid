Every paid provider call goes through the ledger in budget.py and the transport in generation.py. Admission is one transaction. It checks gateway ownership, `paid_enabled`, PostgreSQL `database_control.paid_admission`, the frozen flag, a known rate for the model, the purpose envelope, and the shared cap minus spent and pending, then inserts a `reserved` attempt at the maximum cost. Dispatch is a second transaction that re-checks the request's stop reason, ownership, paid admission and the absence of any `unknown` attempt before moving to `dispatching`. The response settles exactly once at the actual usage. An error proven to be pre-execution releases the attempt; any other error leaves it `unknown`.
