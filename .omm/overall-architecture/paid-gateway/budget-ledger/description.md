`reserve` runs one transaction under the application mutex: owner guard, `paid_enabled`, `paid_admission`, `frozen_reason`, a known rate, a known envelope purpose, `ceiling_micro_usd`, cap minus (spent + pending), and envelope headroom. It inserts an `attempts` row in state `reserved`, or returns `admitted: false` with a reason; database errors return `ledger_unavailable`. `mark_dispatching(guard)` moves `reserved` -> `dispatching`. It instead releases with `stopped_before_dispatch:<reason>` and raises `DispatchRefused` when the request's guard refuses, ownership is lost, admission is closed, or any `unknown` attempt exists. `settle` happens once and is idempotent on `settled`. Settling a `reconciled` attempt adds a negative late-settlement adjustment, and settling above the reservation sets `frozen_reason`, stopping all new paid work. `release`, `mark_unknown`, `add_adjustment` (idempotent by `correction_key`), `reconcile` (closed, non-overlapping intervals; covered unknown attempts become `reconciled`) and `recover` complete the state machine. `recover` also resolves the Gemini `external_attempts`. Envelope shares: embedding 1, gold_eval 3, interactive 12, judge_eval 0 (`ENVELOPE_SHARES`).
