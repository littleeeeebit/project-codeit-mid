`budget.reserve` runs one `tx(immediate=True)`. It checks `owner_guard`, `budget_settings.paid_enabled`, `database_control.paid_admission` and `frozen_reason`, then the model rate, the purpose envelope (`ENVELOPE_SHARES`: interactive, gold_eval, embedding, judge_eval), the consented ceiling, the cap minus spent minus pending, and the envelope remainder. It then inserts an `attempts` row in state `reserved`, priced at `max_cost` (every input token at the cache-write rate) and tagged with the `BILLING_SCOPE` contextvar. Database errors fail closed as `ledger_unavailable`. `settle` computes `micro_cost` from uncached, cached, cache-write and output tokens exactly once. A settlement above the reservation sets `frozen_reason`, which stops all new paid work. `reconcile`, `add_adjustment`, `set_limit` and `configure` are owner actions that write `adjustments`, `budget_settings` and `audit_events`. `recover` turns `dispatching` into `unknown` and `reserved` into `released`, for OpenAI and for `external_attempts` (Gemini).
