`reserve` does atomic admission in one transaction. It checks owner (`require_owner`, `owner_guard`), `paid_enabled`, `database_control.paid_admission`, `frozen_reason`, the model rate, the purpose envelope and the consented `ceiling_micro_usd`, then requires `cap - spent - pending >= max_cost` and envelope room. It inserts an attempt `reserved` with `price_json` (rates, rate_version, billing_scope from the `BILLING_SCOPE` contextvar). Database errors return `ledger_unavailable` (fail closed). `mark_dispatching(guard)` runs the request's `_stop_reason` in the same transaction. It refuses (and releases) on cancel/interrupt, lost ownership, maintenance, or any `unknown` attempt in the database; otherwise reserved → dispatching. `settle` is exactly once, computes the cost from reported usage, writes a negative late-settlement adjustment for a `reconciled` attempt, and sets `frozen_reason` when the cost exceeds the reservation. `recover` (startup or unclean close) moves dispatching → unknown and reserved → released, for both OpenAI and external attempts.
