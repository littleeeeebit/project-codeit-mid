gateway/budget.py works on the `attempts`, `adjustments` and `budget_settings` tables, always inside `tx(conn, immediate=True)`, which locks the single `application_mutex` row. `reserve` prices every input token at the cache-write rate (`max_cost`) and stores the rate snapshot and `billing_scope` (the key's OpenAI project) in `price_json`. `settle` is idempotent per attempt; if the settled cost exceeds the reservation it sets `frozen_reason`, which stops all new paid work until an owner inspects it. Owner-only operations, through the CLI: `configure`, `set_paid_enabled`, `add_adjustment`, `reconcile` (interval-based, project-scoped, never across billing scopes) and `set_limit`, which is also reachable from the 설정 page via PUT /api/budget/limit. `snapshot` feeds the header's 2-second budget poll.
