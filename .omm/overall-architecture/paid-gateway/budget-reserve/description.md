`budget.reserve` runs inside one `tx(immediate=True)`. It checks, in order: gateway ownership (`owner_guard`), `paid_enabled`, `database_control.paid_admission`, `frozen_reason`, a known rate for the model, a known purpose envelope, the consented ceiling, the remaining cap (`cap - spent - pending`) and the remaining envelope. It then inserts an attempt in state `reserved` whose `price_json` records the rates, the rate version and the browser's billing scope. The cost is the maximum, with every input token priced at the cache-write rate. Database operational errors fail closed as `ledger_unavailable`.
