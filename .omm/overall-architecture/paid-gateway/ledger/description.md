`budget.reserve` runs in one immediate transaction. It checks `owner_guard`, `paid_enabled`, `database_control.paid_admission`, `frozen_reason`, a known rate and purpose envelope, the consented ceiling (`above_consented_maximum`), cap minus spent minus pending (`cap_exhausted`) and the envelope remainder, then inserts an `attempts` row in `reserved` with the price snapshot and `billing_scope`. `mark_dispatching` runs the request's stop guard and the unknown-billing check in the same transaction and moves `reserved` to `dispatching`; on refusal it moves `reserved` to `released` and raises `DispatchRefused`. `settle` computes the cost from usage exactly once and freezes the ledger (`frozen_reason`) if the cost exceeded the reservation. `release`, `mark_unknown`, `recover` and `reconcile` complete the attempt state machine (see `state-transitions/attempt-states`).
