`Tracing.from_settings` builds a Langfuse client only when all three `LANGFUSE_*` values are present. `tracing.run` opens the root trace `answer-question` (trace ID seeded by the request ID; user, environment and release are set from `origin()`), and `tracing.step` opens the retriever, assemble, generation and guardrail spans. Text is masked for secret-shaped values on export. Every Langfuse call is wrapped in `_guard` / `_observe`: a failure logs a warning and changes neither answers nor the ledger.
