`Tracing.from_settings` builds a Langfuse client only when all three LANGFUSE_* values exist, and any construction error turns tracing off. `tracing.run` opens one trace per request, with an id derived from the request_id. `tracing.step` records spans for retrieval, evidence assembly, the rewrite and generation calls (with usage and ledger cost), and validation. The trace also carries the scores `citation_valid`, `insufficient_evidence` and `evidence_tokens`. `_guard` and `_observe` swallow every tracing exception, and a client-side mask redacts secret-shaped values.
