`tracing.run` opens one Langfuse trace per executed request in `_execute`. The trace ID is derived from the request ID. `tracing.step` spans cover `retrieve-evidence`, `assemble-evidence`, `rewrite-question`, `generate-answer` (with usage and ledger cost) and `validate-answer`. Free deterministic scores are recorded: `citation_valid`, `insufficient_evidence` and `evidence_tokens`. Tracing is enabled only when all three `LANGFUSE_*` variables are present. `mask` and `redact` hide secret-shaped values.
