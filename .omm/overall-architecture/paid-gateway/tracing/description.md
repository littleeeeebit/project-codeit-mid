`tracing.Tracing.from_settings` builds a Langfuse client on a private TracerProvider only when the provider is openai and all three `LANGFUSE_*` values exist. `tracing.run` opens one root observation per request, and `tracing.step` nests `retrieve-evidence`, `assemble-evidence`, `rewrite-question`/`generate-answer` (as_type generation, with usage and the ledger cost) and `validate-answer` (guardrail) under it. Deterministic scores are recorded as `citation_valid`, `insufficient_evidence` and `evidence_tokens`. Every SDK call is wrapped in `_guard`/`_observe`, so a tracing failure never reaches the traced work, and admission and settlement never read traces. `mask_otel_spans` redacts secret-shaped values. Outside a run (verifier traces, evaluation), steps record nothing.
