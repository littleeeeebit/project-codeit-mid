`tracing.run` opens one trace per executed request, with its ID seeded from the request ID. `tracing.step` wraps `retrieve-evidence`, `assemble-evidence`, `rewrite-question`, `generate-answer` and `validate-answer`, and `score_trace` records `citation_valid`, `insufficient_evidence` and `evidence_tokens`. It is created only alongside an `OpenAITransport` (`Tracing.from_settings`), and only when all three `LANGFUSE_*` values are present. Tracing is closed after the workers finish, so finished traces are flushed.
