`tracing.Tracing.from_settings` creates a Langfuse client only when all three `LANGFUSE_*` values exist. The trace ID comes from the request ID. Spans are `rewrite-question`, `retrieve-evidence`, `assemble-evidence`, `generate-answer` and `validate-answer`, with scores `citation_valid`, `insufficient_evidence` and `evidence_tokens`. Tracing is observability only: admission and settlement never read it, and a failing Langfuse changes neither answers nor the ledger (README).
