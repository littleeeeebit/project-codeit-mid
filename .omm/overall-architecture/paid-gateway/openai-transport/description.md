`generation.OpenAITransport` keeps one client per member key session (`set_key`). Replaced clients stay open until `close()`. An optional default client from the `OPENAI_API_KEY` environment variable serves contexts that have no session key. `chat()` uses Chat Completions with strict JSON-schema `response_format`, `reasoning_effort` and `max_completion_tokens`. With `on_delta` it streams (`include_usage`), and `_drain` accumulates the content and calls `on_delta(content)` on every delta. 4xx errors are classified as pre-execution; timeouts, connection loss and 5xx are not. `FakeTransport` stands in for it under `provider: fake` (tests, load-check).
