Holds one OpenAI client per key session (set_key) plus an optional server-environment default. Each call picks the client for the current KEY_SESSION contextvar, so a request pays with the key of the member who submitted it. No client raises ProviderError(NO_API_KEY, pre_execution=True). chat() streams with include_usage when on_delta is given and accumulates content into the callback. 4xx SDK errors are pre-execution; timeouts, connection loss, 5xx and mid-stream errors are not. embed() handles embedding calls. _check_owner runs before each call. FakeTransport stands in when provider='fake' and never builds an SDK client.
