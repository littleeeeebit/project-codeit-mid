`OpenAITransport` holds per-key-session clients (`set_key(session, key)`) selected by the `KEY_SESSION` contextvar that `bind_request` sets. `chat` uses Chat Completions with strict JSON schema output and `reasoning_effort`, streaming deltas to `on_delta`. It also provides `embed` for query and corpus vectors. Errors become `ProviderError(pre_execution=...)`, which tells the ledger whether to release the attempt or mark it unknown.
