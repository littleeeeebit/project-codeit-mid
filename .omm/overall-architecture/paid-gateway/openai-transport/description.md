`generation.OpenAITransport` keeps one SDK client per member key session (`set_key`, replaced clients retired until close) plus an optional environment default for the CLI. `_client` picks the client for `KEY_SESSION`. With no client it raises `ProviderError(pre_execution=True)` before any network call. `chat` streams with `include_usage` when `on_delta` is given; `_drain` reads the stream into content, refusal, finish reason, usage and response ID. Exceptions are classified: auth, permission, bad request, not found, rate limit and 422 count as pre-execution, while timeouts, connection loss and 5xx count as possibly executed. `_check_owner` calls the gateway owner's `check` before each call. `FakeTransport` (`provider=fake`) never builds an SDK client and backs `check`, `load-check` and fixture servers.
