`OpenAITransport` builds `openai.OpenAI(max_retries=0, timeout=request_timeout_seconds)`. `chat` calls Chat Completions with strict JSON-schema `response_format`, `max_completion_tokens` (4,000 by default per README) and `reasoning_effort` (low). Authentication, permission, bad-request, not-found, rate-limit and unprocessable errors raise `ProviderError(pre_execution=True)`; every other `OpenAIError` (timeouts, 5xx, connection loss) raises `pre_execution=False`. Usage maps to `prompt_tokens`, `completion_tokens`, `cached_tokens`, `cache_write_tokens` and `reasoning_tokens`. `embed` handles embeddings the same way. `FakeTransport` (provider `fake`) echoes the first evidence and fakes embeddings without network access or a key.
