`OpenAITransport` creates clients with `max_retries=0` and a finite timeout. Each `set_key(session, key)` makes a new client for that session, and a replaced client is kept until `close()` so calls in flight finish on it. `_client` picks the session of `KEY_SESSION` or the default environment key. With neither it raises a pre-execution `ProviderError(NO_API_KEY)`. `chat` streams with `include_usage` when `on_delta` is given, and `_drain` accumulates content and calls `on_delta(content)`. 4xx errors (auth, permission, bad request, not found, rate limit, unprocessable) are pre-execution; timeouts, connection loss, 5xx and any failure mid-stream are not. `embed` sorts vectors by index. `FakeTransport` (provider `fake`) echoes the first evidence for checks.
