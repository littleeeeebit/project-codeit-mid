`OpenAITransport` keeps one `openai.OpenAI(max_retries=0, timeout)` client per key session (`set_key`), selected by the `KEY_SESSION` contextvar, and falls back to the server env key. `chat` streams with `include_usage` when `on_delta` is given, and `_drain` concatenates deltas into `res.partials`. 4xx-class errors raise `ProviderError(pre_execution=True)`, so the caller releases the reservation. Timeouts, connection loss and 5xx raise `pre_execution=False`, so the caller marks the attempt unknown. Errors after a stream started are never pre-execution. `_check_owner` refuses before execution if gateway ownership was lost. `FakeTransport` (`provider: fake`) echoes evidence for checks and never builds an SDK client.
