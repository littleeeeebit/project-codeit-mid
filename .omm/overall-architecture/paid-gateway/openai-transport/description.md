OpenAITransport keeps one OpenAI client per browser session (set_key from the 설정 page) plus an optional server-environment default. `_client` picks the client of the KEY_SESSION contextvar. With no client it raises ProviderError(NO_API_KEY, pre_execution=True), so nothing is charged. chat() uses strict JSON response_format, max_completion_tokens and reasoning_effort, and streams with include_usage when on_delta is given (`_drain` accumulates content and calls on_delta). 4xx errors are pre_execution; timeouts, 5xx and mid-stream errors are not. check_api_key does a free models.retrieve and records the `openai-project` header as the billing scope.
