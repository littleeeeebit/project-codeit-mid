`OpenAITransport` makes SDK calls with `max_retries=0` and a finite timeout. It picks the client for the current `KEY_SESSION` or falls back to the env key. With no key it raises `ProviderError(pre_execution=True)` and nothing is charged. `chat` uses Chat Completions with strict JSON schema output and `reasoning_effort`. With `on_delta` it streams (`include_usage`) and pushes the accumulated text to `res.partials[request_id]`. 4xx errors are pre-execution, while timeouts, 5xx and stream failures are possibly executed. `_check_owner` runs before each call. `FakeTransport` stands in for `provider: fake` (checks and tests) and never builds an SDK client.
