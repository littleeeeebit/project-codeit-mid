`OpenAITransport` holds one SDK client per member key session, plus an optional default from the server environment, all with `max_retries=0` and a finite timeout. `chat` picks the client of the current `KEY_SESSION`; with none it raises `ProviderError(NO_API_KEY, pre_execution=True)`. It calls Chat Completions with strict JSON-schema output and `reasoning_effort`. With `on_delta` it streams and reads usage from the last chunk (`include_usage`). 4xx errors (authentication, permission, bad request, not found, rate limit, unprocessable) are pre-execution. Timeouts, connection loss, 5xx and stream failures are not. `_check_owner` refuses before execution when the gateway lock was lost. `FakeTransport` replaces it for `provider: fake`.
