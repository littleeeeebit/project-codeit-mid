`OpenAITransport` keeps one SDK client per browser session (`set_key`), plus an optional default client from the server environment. Clients are built with `max_retries=0` and a finite timeout. `_client` picks the client of the `KEY_SESSION` context variable and raises a pre-execution `ProviderError` when there is none. `chat` streams with `include_usage` when `on_delta` is given. 4xx errors are classified as pre-execution. Timeouts, 5xx errors and stream failures are not. `_check_owner` calls `GatewayOwner.check` before every chat or embed. `FakeTransport` replaces it for `provider: fake` and never builds an SDK client.
