`OpenAITransport` keeps one OpenAI client per member key session (`set_key`). The server-environment key serves only a context with no session key. `chat` uses Chat Completions with strict `response_format`, `max_completion_tokens` and `reasoning_effort`. When `on_delta` is set it streams with `include_usage`, and `_drain` hands each content delta to the callback; `service._generate` writes those into `res.partials`. Authentication, permission, bad-request, not-found, rate-limit and 422 errors raise `ProviderError(pre_execution=True)`. Timeouts, connection loss, 5xx and any failure mid-stream raise `pre_execution=False`. An authentication error keeps only its type name, because the message quotes part of the key. `embed` follows the same rules.
