Owner-only CLI actions (unresolved, settle, reconcile, adjust, paid, audit, each with --actor and a reason). reconcile records the provider total minus local settled cost for a closed, non-overlapping interval and scope, and moves the explicitly covered unknown attempts to reconciled. It refuses an interval holding unscoped server-key attempts unless include or exclude is stated. add_adjustment is append-only and idempotent by correction_key. set_limit backs the Settings page cap control while preserving spending and reservations.
