The owner CLI commands `unresolved`, `settle`, `reconcile` and `adjust` run through `Resources(dispatch=False)` beside the live server. `budget.reconcile` imports a closed interval's provider total for one billing scope and moves explicitly covered `unknown` attempts dispatched in that interval to `reconciled`. It records `provider_total − local settled` as an adjustment and refuses overlapping intervals, attempts billed to another scope, or unscoped attempts without an explicit include/exclude. While any PostgreSQL attempt is `unknown`, every new dispatch is refused.
