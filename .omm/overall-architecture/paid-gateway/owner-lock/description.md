`postgres.GatewayOwner` opens a dedicated connection outside the pool and takes `pg_try_advisory_lock(GATEWAY_LOCK)`. If another process holds it, the result is `LockHeld` → `GatewayLockError`. `check()` verifies through `pg_locks` that the lock is still granted and that recovery and validation are ready. If not, it marks the owner lost permanently. Several `Resources` in one process share the owner through `borrow_owner`, and the lock is released when the last user calls `release()`. `require_owner` runs before admission, `owner_guard` runs inside the admission and dispatch transactions, and `_check_owner` runs in the transport right before the network call.
