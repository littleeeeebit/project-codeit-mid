`tracing.run` opens one root per executed request (`answer-question`, trace ID from `create_trace_id(seed=request_id)`) and per drafting run. `tracing.step` nests `retrieve-evidence`, `assemble-evidence`, `rewrite-question`/`generate-answer` (with usage and ledger cost through `usage_and_cost`) and `validate-answer`. Scores: `citation_valid`, `insufficient_evidence`, `evidence_tokens`. Outside a run, steps record nothing, so verifier traces and evaluation runs are not traced. It is enabled only when all three `LANGFUSE_*` variables are present.
