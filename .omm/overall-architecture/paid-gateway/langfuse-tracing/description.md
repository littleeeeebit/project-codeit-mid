src/rfp_assistant/tracing.py wraps the Langfuse SDK. `run` opens one trace per executed request, with the trace ID derived from the request ID. `step` adds spans: `retrieve-evidence`, `assemble-evidence`, `rewrite-question`, `generate-answer` (model, parameters, usage and ledger cost through `usage_and_cost`) and `validate-answer`. Scores `citation_valid`, `insufficient_evidence` and `evidence_tokens` come from existing checks. Exported text is masked for secret-shaped values. Tracing is observability only: guarded calls never change admission, settlement or answers, and missing `LANGFUSE_*` variables create no client.
