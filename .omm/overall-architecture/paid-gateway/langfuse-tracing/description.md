`Tracing.from_settings` is created with the OpenAI transport when the `LANGFUSE_*` credentials are present. One trace per `/api/ask` request: `tracing.run('answer-question', seed=request_id)`, with user = member, environment server or local, and release `<branch>@<commit>`. Steps are `retrieve-evidence`, `assemble-evidence`, `rewrite-question` or `generate-answer` (generation spans with usage and ledger cost) and `validate-answer` (guardrail). Free scores: `citation_valid`, `insufficient_evidence`, `evidence_tokens`. `mask_otel_spans` redacts secret-shaped values on export. Payloads are built lazily, and every SDK call is guarded, so a down Langfuse never changes an answer or the ledger.
