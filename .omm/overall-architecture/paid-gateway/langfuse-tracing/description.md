`tracing.Tracing.from_settings` creates a Langfuse client only when all three `LANGFUSE_*` values exist. `tracing.run` opens one trace per executed request, with the trace ID derived from the request ID (`create_trace_id(seed=request_id)`). `tracing.step` nests the spans retrieve-evidence, assemble-evidence, rewrite-question, generate-answer (with usage and ledger cost from `usage_and_cost`) and validate-answer. The scores `citation_valid`, `insufficient_evidence` and `evidence_tokens` come from deterministic checks. `mask_otel_spans` redacts secret-shaped values on export.
