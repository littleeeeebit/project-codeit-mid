tracing.run opens one trace per executed request (trace ID derived from request_id) and per drafting run; tracing.step wraps the assemble-evidence, retrieve-evidence, generate-answer/rewrite-question and validate-answer spans. The scores citation_valid, insufficient_evidence and evidence_tokens come from existing deterministic checks. It is observability only: admission and settlement never read it, and a missing LANGFUSE_* variable disables it.
