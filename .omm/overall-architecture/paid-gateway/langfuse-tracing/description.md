`tracing.Tracing.from_settings` builds a client only for `provider=openai` with all three `LANGFUSE_*` values, on its own `TracerProvider`. It refuses a second owner of the same public key in one process. `origin()` tags each trace with environment (`server` when `BIDMATE_HUB_URL` is set, else `local`), release `<branch>@<short commit>`, and on local hosts the user `BIDMATE_LOCAL_MEMBER`. `tracing.run` opens the root observation with `trace_id = create_trace_id(seed)`: the request ID for `/api/ask`, a fresh UUID for each drafting run. `tracing.step` opens children only inside a run on the same context. Each `Step.update` builder runs inside `_guard`, and `mask_otel_spans` redacts secret-shaped strings on export. The scores `citation_valid`, `insufficient_evidence` and `evidence_tokens` come from existing checks.
