`tracing.Tracing.from_settings` is created with the OpenAI transport when all three `LANGFUSE_*` credentials exist. `tracing.run` opens a root trace per executed request, with the trace ID derived from the request ID. `tracing.step` spans cover retrieve-evidence, assemble-evidence, rewrite-question, generate-answer and validate-answer. Scores `citation_valid`, `insufficient_evidence` and `evidence_tokens` come from the existing deterministic checks. Payloads are built lazily, and `redact`/`mask_otel_spans` mask secret-shaped strings on export. Every SDK call is guarded, so a stopped or failing Langfuse changes neither answers nor the ledger. Embeddings, ingestion, OCR and evaluation runs are not traced.
