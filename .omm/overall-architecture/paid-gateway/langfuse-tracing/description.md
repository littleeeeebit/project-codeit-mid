Optional observability. `Tracing.from_settings` is built together with the OpenAI transport when the three `LANGFUSE_*` variables are present. `tracing.run(..., seed=request_id)` opens one trace per answer request, and `tracing.step` spans record retrieve-evidence, assemble-evidence, rewrite-question, generate-answer (with usage and ledger cost) and validate-answer. The trace also gets the deterministic scores `citation_valid`, `insufficient_evidence` and `evidence_tokens`.
