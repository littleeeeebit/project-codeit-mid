`budget.reserve` runs in one `tx(immediate=True)` transaction. It refuses with a reason when: the gateway owner is lost (`owner_guard`), `paid_enabled` is off, `database_control.paid_admission` is closed (postgresql_maintenance), the ledger is `frozen_reason`, the model has no rate (`unknown_rate`), the purpose is unknown, the amount exceeds a consented ceiling, the cap minus spent minus pending is short (`cap_exhausted`), or the purpose envelope is short (`envelope_exhausted`). The amount is `max_cost`: every input token at the cache-write rate plus the maximum output. Otherwise it inserts an `attempts` row in state `reserved`. Its `price_json` holds the rates, the rate version and the member's `billing_scope`. Database errors fail closed (`ledger_unavailable`). Envelopes: interactive, gold_eval, embedding, judge_eval and ocr (`ENVELOPE_SHARES`).
