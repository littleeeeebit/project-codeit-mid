Budget administration is owner CLI only, with `--actor` and a reason: `unresolved`, `settle` (`settle_from_evidence`), `reconcile` (closed interval, per provider project scope, covered unknown attempts become `reconciled`, no overlapping intervals), `adjust` (append-only, idempotent by correction key), `paid` (sets `paid_enabled` and PostgreSQL paid admission together), `audit`, `configure-budget` and `set-envelopes`. Each writes `audit_events`.
