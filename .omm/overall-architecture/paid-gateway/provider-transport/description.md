`OpenAITransport` wraps `openai.OpenAI(max_retries=0, timeout=request_timeout_seconds)`. `chat` calls `chat.completions.create(..., response_format, max_completion_tokens, reasoning_effort, stream=False)`. `embed` calls `embeddings.create(dimensions=…, encoding_format='float')`. Both call `_check_owner()` first, and lost ownership raises `ProviderError(pre_execution=True)`. 4xx errors (authentication, permission, bad request, not found, rate limit, unprocessable) raise `pre_execution=True`; timeouts, connection loss and 5xx raise `pre_execution=False`. Usage maps to prompt, completion, cached, cache_write and reasoning tokens. `FakeTransport` is the keyless test seam: it echoes the first evidence unit per document, makes deterministic bigram-hash embeddings and has an optional delay for race checks.
