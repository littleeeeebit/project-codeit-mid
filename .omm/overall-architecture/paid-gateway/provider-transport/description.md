`OpenAITransport` runs Chat Completions with strict structured output (`answer_json_schema` / `rewrite_json_schema`), `reasoning_effort` low and `max_completion_tokens` (4,000 for answers, 1,500 for rewrites). It streams deltas to `on_delta`. The key is chosen per call from the KEY_SESSION contextvar; a missing key gives NO_API_KEY. `check_api_key` is a free metadata read used by 설정. `FakeTransport` echoes evidence for tests and `load-check` and never builds an SDK client. A `ProviderError.pre_execution` flag tells settlement the call provably never ran.
