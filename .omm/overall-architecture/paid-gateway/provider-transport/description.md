`generation.OpenAITransport` keeps one OpenAI client per browser session (`KEY_SESSION`) plus an optional server-environment default, each with `max_retries=0` and a finite timeout. `chat` uses Chat Completions with strict `response_format`, `max_completion_tokens` and `reasoning_effort`. With `on_delta` it streams (`stream_options.include_usage`) and `_drain` forwards the accumulated content to `res.partials`. 4xx rejections are treated as pre-execution; timeouts, connection loss, 5xx and mid-stream errors are not. `FakeTransport` (provider `fake`) never builds an SDK client and is used by `check`, `load-check` and the fixture server.
