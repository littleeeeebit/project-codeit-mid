`generation.OpenAITransport.chat` calls `_check_owner` (lost ownership raises a pre-execution `ProviderError`), then `chat.completions.create` with strict `response_format`, `max_completion_tokens` and `reasoning_effort`. When `on_delta` is given it requests `stream=True` with `include_usage` and `_drain` accumulates content. The error class decides billing: 4xx (`AuthenticationError`, `BadRequestError`, `RateLimitError`, …) count as pre-execution, while timeouts, connection loss, 5xx and mid-stream errors are not, because the model may have run. `FakeTransport` serves `provider: fake` checks and never builds an SDK client.
