`generation.OpenAITransport` keeps one OpenAI client per member key session (`set_key`) plus an optional server-environment default. `_client` picks the client for `KEY_SESSION.get()` and raises a pre-execution `ProviderError(NO_API_KEY)` when it has none. `chat` uses Chat Completions with strict `response_format`, `reasoning_effort` and `max_completion_tokens`, and streams with `include_usage` when `on_delta` is set. `_drain` accumulates deltas; a failure mid-stream is never pre-execution. 4xx SDK errors are pre-execution and anything else is not. `embed` follows the same rules. `_check_owner` turns a lost gateway lock into a pre-execution refusal. `FakeTransport` replaces it for `provider: fake`.
