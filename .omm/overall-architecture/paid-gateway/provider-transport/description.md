`OpenAITransport.chat` calls Chat Completions with strict `response_format`, `max_completion_tokens` and `reasoning_effort`. When `on_delta` is given it streams with `include_usage`, and `_drain` accumulates content and calls `on_delta(content)` on every chunk. 4xx errors (authentication, permission, bad request, not found, rate limit, unprocessable) raise `ProviderError(pre_execution=True)`. Other `OpenAIError`s, including any failure after a stream started, raise `pre_execution=False`. `embed` follows the same mapping. `FakeTransport` echoes the first evidence or joins the last question and never builds an SDK client.
