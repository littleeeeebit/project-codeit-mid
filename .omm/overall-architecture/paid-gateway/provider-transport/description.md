`OpenAITransport` keeps one `openai.OpenAI(max_retries=0, timeout)` client per browser session (`set_key`) plus an optional server-environment default. `_client` picks the client for `KEY_SESSION` and raises a pre-execution `ProviderError(NO_API_KEY)` when there is none. `chat` maps 4xx errors to pre-execution failures and timeouts, connection loss and 5xx to possibly executed ones. With `on_delta`, it streams with `include_usage`, and `_drain` treats any failure after the stream started as executed. `check_api_key` reads model metadata for free and returns the `openai-project` header as the billing scope; a legacy key falls back to a key digest. `FakeTransport` never touches the network and streams three deltas. It is used by `provider: fake`, `check` and `load-check`.
