`OpenAITransport.chat` calls Chat Completions with strict `json_schema`, `max_completion_tokens` and `reasoning_effort`. With `on_delta` it streams with `stream_options.include_usage` and `_drain` accumulates content, calling `on_delta(full_content)` after each delta. Usage arrives in the last chunk. Authentication, permission, bad-request, not-found, rate-limit and unprocessable errors are pre-execution. Timeouts, connection errors, 5xx and any error mid-stream are not. `FakeTransport` (`provider: "fake"`) never builds a client: it echoes the first evidence unit per document, joins the last question for rewrites, emits three deltas and can be delayed to expose races.
