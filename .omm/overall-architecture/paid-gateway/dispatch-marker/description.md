`mark_dispatching(db, attempt_id, guard)` runs the caller's guard in the same transaction; for requests that is `_dispatch_guard` → `_stop_reason`, which returns cancelled or interrupted. It also checks the gateway owner, PostgreSQL paid admission, and whether any attempt is `unknown`. On any refusal the reservation becomes `released` with `stopped_before_dispatch:<reason>` and `DispatchRefused` is raised, so nothing is sent. Otherwise the attempt becomes `dispatching` with `dispatched_at`, a durable marker written before the network call.
