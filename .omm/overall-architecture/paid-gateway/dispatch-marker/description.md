`budget.mark_dispatching(attempt, guard)` runs the request's `_stop_reason` (cancelled, interrupted, closing), `owner_guard`, the `paid_admission` check, and a global check that no attempt is `unknown`, all in one transaction. On any refusal it releases the reservation as `stopped_before_dispatch:<reason>` and raises `DispatchRefused`. Otherwise it sets `dispatching` with `dispatched_at`. Because the stop check and the marker are one transaction, no shutdown or cancel can slip between them.
