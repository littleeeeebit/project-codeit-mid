`generation.validate_answer` parses the strict JSON schema payload (`answer_json_schema`). It checks that every claim, summary and conflict cites known evidence IDs belonging to the claim's document, and that quotes match the stored chunk bodies. For compare it also requires each represented document. It raises `TechnicalError` with codes such as `unknown_evidence_id`, `evidence_quote_mismatch` and `claim_without_evidence`; `service._validated` maps these to `citation_valid=0`. `partial_answer` parses incomplete streamed JSON for the provisional view.
