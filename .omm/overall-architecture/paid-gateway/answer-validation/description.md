`build_messages` keeps the trusted `SYSTEM_PROMPT` (`PROMPT_VERSION` `grounded-answer-10`) separate from a JSON user message carrying the question, as-of date, document briefs, retrieval limitations, allowed evidence IDs per document and evidence texts. `count_request_tokens` (o200k_base, plus 4 per message, the schema and `framing_margin_tokens`) sizes the reservation. `validate_answer` rejects refusals, truncation (`finish_reason == 'length'`), schema-invalid content, unknown evidence IDs, evidence from another document, quotes differing from the stored index text (`_stored_quote`), uncited claims or conflicts, `source_absence_verified` (top-k misses cannot prove absence), `answered` without claims, and a comparison missing a side. Absence claims whose text matches a listed missing field are silently dropped. The `citation_valid` Langfuse score comes from this step.
