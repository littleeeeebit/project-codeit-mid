`generation.validate_answer(response, evidence, allowed_doc_ids, stored_quotes, required_doc_ids)` parses the strict JSON-schema output (`answer_json_schema`). It rejects unknown evidence IDs, evidence outside the scope, quotes that no longer match the stored chunk, claims, conflicts or summaries without evidence, and, in compare mode, an answer that drops a selected side. Errors whose names start with a `CITATION_ERRORS` code also score `citation_valid` 0. `validate_rewrite` checks the follow-up rewrite against `question_max_characters`. `partial_answer(content)` parses the incomplete streamed JSON into `{summary, summary_evidence_ids, claims}` for the provisional view.
