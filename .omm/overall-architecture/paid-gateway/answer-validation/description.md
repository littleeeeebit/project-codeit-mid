`validate_answer(response, evidence, allowed_doc_ids, stored_quotes, required_doc_ids)` rejects unknown evidence IDs, scope mismatches, quote mismatches against the stored element text (`_stored_quote`), and claims, conflicts or summaries without evidence. In compare mode it requires both sides. Failure becomes `technical_error` with the cost already recorded, and the trace scores `citation_valid` 0 or 1.
