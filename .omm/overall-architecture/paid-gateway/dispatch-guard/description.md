`budget.mark_dispatching(attempt_id, guard)` runs the request's `_stop_reason` (cancelled, interrupted, or service closing), `owner_guard`, the paid-admission flag and the check for unknown attempts in the same transaction that moves `reserved → dispatching`. If any of them refuses, the attempt becomes `released` with `stopped_before_dispatch:<reason>` and `DispatchRefused` is raised, so a shutdown or cancel can never slip between the check and the network call.
