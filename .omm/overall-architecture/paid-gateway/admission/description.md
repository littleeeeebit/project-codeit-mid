`budget.reserve` runs in one `tx(immediate=True)`, which serializes on the `application_mutex` row. It refuses, in order: ownership failure; `paid_disabled`; `postgresql_maintenance` (`database_control.paid_admission` false); `frozen` (a previous overrun); `unknown_rate`; `unknown_purpose`; `above_consented_maximum`; `cap_exhausted` (cap − spent − pending < max cost); `envelope_exhausted` (per-purpose envelope: interactive, embedding, gold_eval, judge_eval). Otherwise it inserts a `reserved` attempt with `max_cost` (every input token priced at the cache-write rate) and a `price_json` holding the rates, rate_version and the browser key's `billing_scope`. Database errors fail closed as `ledger_unavailable`.
