`budget.reserve` calls `require_owner`, then opens one immediate transaction. In order, it refuses on `owner_guard` (`gateway_ownership_lost`, `postgresql_recovery_or_validation`), `paid_disabled`, `postgresql_maintenance`, `frozen`, `unknown_rate`, `unknown_purpose` (envelope), `above_consented_maximum`, `cap_exhausted` (cap minus spent minus pending) and `envelope_exhausted`. If none applies it inserts an `attempts` row with state `reserved`, the rates, the `rate_version` and an optional `billing_scope`. Database errors return `ledger_unavailable`, so admission fails closed.
