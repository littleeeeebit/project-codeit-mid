`budget.reserve` runs in one `tx(immediate=True)` transaction. It checks the owner guard, `paid_enabled`, `database_control.paid_admission` (`postgresql_maintenance`), `frozen_reason`, the model's rate (`unknown_rate`) and the envelope's existence. It computes `max_cost`, which prices every input token at the cache-write rate. It checks an optional consented `ceiling_micro_usd`, the cap minus spent and pending, and the envelope's own remainder. On success it inserts a `reserved` attempt whose `price_json` carries the rates, `rate_version` and the bound `BILLING_SCOPE`. Database errors return `ledger_unavailable` (fail closed).
