`budget.reserve` is one transaction under the global `application_mutex` row lock. In order, it refuses on: ownership, `paid_enabled`, `database_control.paid_admission` (`paid on` sets both), `frozen_reason`, unknown model rate, unknown purpose, a consented ceiling (`above_consented_maximum`, used by frozen verifier runs), the cap minus spent minus pending (`cap_exhausted`), and the envelope remainder. On success it inserts an `attempts` row in state `reserved`, whose `price_json` records the rates, the rate version and the member's `BILLING_SCOPE`. A database error returns `ledger_unavailable` (fail closed). The caller maps refusals to `budget_blocked`, with search and evidence browsing still free.
