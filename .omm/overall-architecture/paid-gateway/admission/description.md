budget.reserve(request_id, member_id, stage, purpose, model, input_tokens, max_output_tokens, ceiling) runs in one tx(immediate) transaction. It checks owner_guard, paid_enabled, database_control.paid_admission, frozen_reason, the model's rate, purpose envelope existence, an optional consented ceiling (`above_consented_maximum`), the cap (cap − spent − pending) and the envelope's remaining room. It then inserts an `attempts` row in state `reserved` with max_cost (every input token priced at the cache-write rate) and price_json, including BILLING_SCOPE (the browser key's OpenAI project). Database errors fail closed as `ledger_unavailable`.
