`budget.reserve(...)` runs in one `tx(immediate=True)` under the application mutex. It checks ownership, `paid_enabled`, `database_control.paid_admission`, `frozen_reason`, a known rate for the model, a known envelope (purpose), and the optional `ceiling_micro_usd` (a consented maximum, which yields `above_consented_maximum`). It then checks that the cap minus spent minus pending covers the amount (`cap_exhausted`) and that the envelope does too (`envelope_exhausted`). When all pass it inserts an `attempts` row in state `reserved` with the rates snapshot. Database errors fail closed as `ledger_unavailable`. `max_cost` prices every input token at the cache-write rate.
