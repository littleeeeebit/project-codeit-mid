The owner budget commands (`unresolved`, `settle`, `reconcile`, `adjust`, `paid on|off`, `audit`, `configure-budget`, `set-limit`, `set-envelopes`) construct `service.Resources(settings, dispatch=False)`, a ledger-only owner with no transport and no lock, so they run beside the serving app. `budget.reconcile` moves `unknown → reconciled` against provider totals; a later real usage can still settle a reconciled attempt, which inserts a negative `late-settlement:` adjustment. `set_paid_enabled(True)` refuses while any attempt is `unknown`. By contrast, paid maintenance commands (`build-dense`, `run-answers`, …) use `_paid_resources` = `Resources(settings)` and refuse while the UI owns the gateway.
