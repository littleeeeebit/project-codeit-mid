`tracing.Tracing.from_settings` is created with the OpenAI transport when the `LANGFUSE_*` keys exist. `service._execute` opens a root trace per request (`tracing.run`, trace ID seeded by `request_id`). Steps `retrieve-evidence`, `assemble-evidence`, `rewrite-question`/`generate-answer` and `validate-answer` add spans and the scores `citation_valid`, `insufficient_evidence` and `evidence_tokens`. User, environment (`server`/`local`) and release (`<branch>@<commit>`) are set per README. The internals of `tracing.py` were not read.
