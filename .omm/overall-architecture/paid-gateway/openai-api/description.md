The external OpenAI API. Chat Completions use a strict JSON schema (`answer_json_schema`, `rewrite_json_schema`). The default model is gpt-6-luna with reasoning_effort low; the output cap is 4,000 tokens for answers and 1,500 for rewrites. Embeddings are requested with explicit dimensions. When a member enters a key, `check_api_key` makes a free model-metadata read and records the key's billing project.
