`set_api_key` (설정 page → `PUT /api/settings/api-key`) validates the key against the chosen model and creates a new random key session. It stores the client in `OpenAITransport._sessions`, records `{set_by, model, billing_scope}` in `Resources.key_sources`, and points `member_keys[member]` at the session. `bind_request` sets the contextvars `KEY_SESSION`, `REQUEST_MODEL` and `budget.BILLING_SCOPE` per HTTP request. A request already running therefore keeps its key, model and billing project even if the member changes them, and `reserve` writes the billing scope into `price_json` for later reconciliation by project. The server-environment key, if any, serves only contexts with no session key.
