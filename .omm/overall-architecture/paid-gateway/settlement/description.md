`budget.settle` is idempotent per attempt. It prices the reported prompt, cached, completion and cache-write tokens with the rates stored on the attempt. If the attempt was already `reconciled`, it adds a negative `late-settlement:` adjustment. If the cost exceeds the reservation, it sets `budget_settings.frozen_reason`, which stops all new paid work until inspected. `release` and `mark_unknown` are guarded state transitions. The owner CLI's `reconcile` resolves `unknown` attempts against a dated provider total, per billing scope, over non-overlapping intervals.
