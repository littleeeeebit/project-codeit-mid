`settle` is idempotent per attempt: a duplicate returns the stored cost. It prices the reported prompt, cached, cache-write and completion tokens from the attempt's own `price_json` rates. Settling a `reconciled` attempt appends a compensating `late-settlement:` adjustment. A cost above the reservation sets `budget_settings.frozen_reason`, so admission refuses everything until inspected. `release` applies only to `reserved` attempts (or `dispatching` with `confirmed_pre_execution`). `mark_unknown` applies only to `dispatching`. Owner-only `reconcile` closes an interval for one billing scope, records provider total minus local settled cost, and moves the explicitly covered unknown attempts to `reconciled`.
