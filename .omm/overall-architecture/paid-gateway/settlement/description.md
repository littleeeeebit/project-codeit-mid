After the call: usage present → `budget.settle` computes cost from uncached, cached and cache-write prompt tokens and completion tokens using the frozen rates. It is exactly-once; a repeat returns `duplicate`. A cost above the reservation sets `budget_settings.frozen_reason`, which stops all new paid work until inspected. Usage absent → `mark_unknown('provider returned no usage')`. Pre-execution error → `release(confirmed_pre_execution=True)`. Any other error, or a failed settlement write → `mark_unknown`. `_finish` derives the request's `billing_state` from its attempts with precedence unknown > pending > reconciled > settled > released.
