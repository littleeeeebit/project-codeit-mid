`budget.settle` runs exactly once per attempt, from `dispatching`, `unknown` or `reconciled`. It computes `micro_cost` from uncached, cached, cache-write and output tokens. Settling an attempt that was already reconciled inserts a negative `late-settlement` adjustment. A cost above the reservation sets `budget_settings.frozen_reason`, which blocks all new admission until an owner inspects it. `release` (from reserved, or from dispatching when confirmed pre-execution) and `mark_unknown` (from dispatching) are guarded `_transition`s. Owner CLI `reconcile` moves unknown attempts to `reconciled` against a dated provider interval.
