`settle(attempt, usage, response_id)` is idempotent. It computes `micro_cost` from prompt, cached, cache-write and completion tokens using the rates frozen on the attempt. If the attempt was already `reconciled`, it also writes a `late-settlement:` negative adjustment. If the cost exceeds the reservation, it sets `budget_settings.frozen_reason`, which stops all new paid work until an owner inspects it. `release` is allowed from `reserved`, or from `dispatching` only with `confirmed_pre_execution`. `mark_unknown` is allowed only from `dispatching`. Every change bumps the ledger revision (`_bump`).
