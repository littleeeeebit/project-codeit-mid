`budget.reserve` works in one `tx(immediate=True)` transaction. It checks `require_owner` and `owner_guard`, then `paid_enabled`, `database_control.paid_admission`, `frozen_reason`, a known rate for the model, a known purpose envelope, the optional consented ceiling, cap minus spent minus pending against `max_cost`, and envelope headroom. It then inserts an `attempts` row in state `reserved` with a price snapshot and the bound `BILLING_SCOPE`. Any operational database error fails closed with reason `ledger_unavailable` and no DSN in the message.
