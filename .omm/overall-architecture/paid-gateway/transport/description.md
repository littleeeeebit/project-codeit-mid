`OpenAITransport.chat` calls `chat.completions.create` with strict `response_format`, `max_completion_tokens` and `reasoning_effort`. When `on_delta` is given it streams with `include_usage`. A 4xx such as authentication, bad request or rate limit raises `ProviderError(pre_execution=True)`, and the caller releases the reservation. Timeouts, connection loss, 5xx and errors mid-stream raise `pre_execution=False`, and the caller marks the attempt unknown. `embed` serves paid query and corpus embeddings in the same way. `check_api_key` and `check_model` are free metadata reads that run when a key is entered.
