`OpenAITransport` holds per-key-session clients (`set_key(session, key)`). The session comes from the `KEY_SESSION` contextvar bound by `_Session`, so each member pays with their own key and the model and billing project in force when the request began. `chat(..., on_delta=...)` streams content to `res.partials`. A `ProviderError` with `pre_execution` releases the reservation; any other failure marks it unknown. `FakeTransport` answers deterministically for tests and `provider: fake`. `check_api_key` does a free metadata read when a key is entered.
