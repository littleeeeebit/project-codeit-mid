`OpenAITransport` creates one client per member key session, plus an optional default key from `OPENAI_API_KEY` for the CLI or a personal machine, always with `max_retries=0` and a finite timeout. `chat` uses Chat Completions with strict `response_format`, `reasoning_effort` and `max_completion_tokens`. When `on_delta` is given it streams with `include_usage`, and `_drain` pushes the accumulated text to `res.partials[request_id]`. A 4xx error raises `ProviderError(pre_execution=True)`. A timeout, connection loss, 5xx or mid-stream failure raises `pre_execution=False`. `FakeTransport` replaces it under `provider: fake` and never builds an SDK client.
