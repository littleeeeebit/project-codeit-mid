`generation.OpenAITransport.chat` sends Chat Completions with a strict JSON schema, `reasoning_effort`, `max_completion_tokens` and streaming deltas to `on_delta`. Before each call it checks the owner (`owner_check`). It uses the key of the bound `KEY_SESSION`. `ProviderError.pre_execution` distinguishes failures that provably never ran. `FakeTransport` echoes evidence for tests and `check` runs.
