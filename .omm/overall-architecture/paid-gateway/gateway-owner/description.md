`postgres.GatewayOwner` opens a dedicated autocommit connection, checks the server version, and takes `pg_try_advisory_lock(GATEWAY_LOCK)`. If another process holds it, `LockHeld` becomes `GatewayLockError` (the CLI paid commands refuse while the UI runs). `check()` verifies the lock is still granted and that recovery and validation are ready; a lost session sets `lost=True` permanently. `owner_guard(conn)` repeats the check inside every admission and dispatch transaction. `borrow_owner` counts users, so several `Resources` in one process (for example `PinnedResources` for evaluation) share one lock, which is released with the last user.
