`GatewayOwner` opens a dedicated connection outside the pool and takes `pg_try_advisory_lock(GATEWAY_LOCK)`. If the lock is held, it raises `LockHeld`, which the service turns into `GatewayLockError`. `check()` confirms the lock is still granted and that recovery and validation are ready. On any failure it sets `lost` permanently and never reconnects, so a restart is needed and unknown billing must be reconciled. A user count lets several `Resources` in one process share the owner. The last `release()` closes the session, which drops the lock.
