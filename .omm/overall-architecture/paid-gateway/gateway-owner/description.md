`postgres.GatewayOwner` opens a dedicated psycopg connection and takes `pg_try_advisory_lock(GATEWAY_LOCK)`. A second process gets `LockHeld` → `GatewayLockError`. `check()` verifies via `pg_locks` that the lock is still granted and that recovery and validation are ready; a loss sets `lost` permanently, and it never reconnects. Another `Resources` in the same process borrows the owner (`borrow_owner`, user count), and the last `release()` closes the session. `OpenAITransport._check_owner` runs `check()` before each call and turns a failure into a pre-execution `ProviderError`.
