`GatewayOwner` opens a dedicated autocommit psycopg connection and takes `pg_try_advisory_lock(GATEWAY_LOCK)`. Several `Resources` in one process share it through `borrow_owner` and a user count; the last `release()` closes the session and so frees the lock. `check()` verifies through `pg_locks` that the lock is still granted and that recovery and validation are ready. On any psycopg error it marks itself lost and never reconnects. `owner_guard(conn)` repeats the check inside admission and dispatch transactions.
