`GatewayOwner` holds `pg_try_advisory_lock(GATEWAY_LOCK)` on a dedicated connection for the process lifetime; another holder raises `LockHeld`. `borrow_owner` shares it within one process with a reference count, and the last `release()` closes the session. `check()` and `owner_guard(conn)` verify the lock is still granted (pg_locks), that recovery is not blocked and that validation is ready; otherwise dispatch is refused with `gateway_ownership_lost` or `postgresql_recovery_or_validation`. It never reconnects after loss.
