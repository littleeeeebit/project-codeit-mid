`GatewayOwner` opens a dedicated autocommit psycopg connection and takes `pg_try_advisory_lock(GATEWAY_LOCK)`, raising `LockHeld` when another process owns it. `check()` (passed to `OpenAITransport` as `owner_check`) confirms the lock is still granted and that recovery and validation are ready. Once the lock is lost, the owner never reconnects and every further dispatch is refused. `borrow_owner` lets a second `Resources` in the same process share the lock with reference counting, and the last `release()` closes the session.
