`GatewayOwner` holds `pg_try_advisory_lock(GATEWAY_LOCK)` on a dedicated connection for the process lifetime. `borrow_owner` lets other `Resources` in the same process share it, for example answer evaluation's `PinnedResources`. `check()` verifies three things: the lock is still granted, recovery is complete, and validation is ready. A loss sets `lost` permanently (it never reconnects); from then on `owner_guard` returns `gateway_ownership_lost` at admission and at dispatch.
