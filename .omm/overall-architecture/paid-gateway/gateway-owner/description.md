GatewayOwner opens a dedicated autocommit psycopg connection, checks the server version, and takes pg_try_advisory_lock(GATEWAY_LOCK). It is registered per target; Resources instances in one process share it through borrow_owner and reference counting. check() confirms the lock is still granted in pg_locks and that recovery and validation are ready. Any loss sets `lost` permanently: it never reconnects, and a restart must reconcile unknown billing.
