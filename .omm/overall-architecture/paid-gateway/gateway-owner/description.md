`postgres.GatewayOwner` holds `pg_try_advisory_lock(GATEWAY_LOCK)` on one dedicated connection until shutdown, so only one process per database can dispatch paid calls. `check()` confirms through `pg_locks` that the lock is still granted and that recovery and validation are ready. Losing the lock marks the owner lost permanently, and it never reconnects. `borrow_owner` lets several `Resources` objects in one process share the lock, counting users. `owner_guard(conn)` repeats the ownership check inside the admission and dispatch transactions.
