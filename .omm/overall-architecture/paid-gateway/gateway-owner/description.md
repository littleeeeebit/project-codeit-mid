`GatewayOwner` keeps one dedicated psycopg connection holding `pg_try_advisory_lock(GATEWAY_LOCK)`. `check()` confirms the lock is still granted in `pg_locks` and that recovery and validation are ready; a lost lock is permanent, because it never reconnects. `borrow_owner` lets several `Resources` in one process share it, with a use count, and `release()` closes the connection with the last user. `OpenAITransport._check_owner` calls `check()` before every SDK call and turns a failure into a pre-execution `ProviderError`.
