`postgres.GatewayOwner` opens one dedicated autocommit connection and takes `pg_try_advisory_lock(GATEWAY_LOCK)`. `check()` verifies through `pg_locks` that the session still holds it and that recovery/validation are ready. Losing it sets `lost=True` permanently, with no reconnect. `owner_guard(conn)` repeats the check inside ledger transactions. Several `Resources` in one process share the owner via `borrow_owner` (reference-counted `users`), and the last `release()` closes the session, which frees the lock. Acquisition triggers restart recovery (`recover_requests` + `budget.recover`).
