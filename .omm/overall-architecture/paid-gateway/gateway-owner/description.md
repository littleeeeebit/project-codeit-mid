`postgres.GatewayOwner` holds `pg_try_advisory_lock(GATEWAY_LOCK)` on a dedicated autocommit connection until shutdown. Several `Resources` in one process share it through `borrow_owner` (reference-counted `users`). `check()` confirms the lock is still granted and that recovery and validation are ready. A connection error marks it `lost` for good, and it never reconnects. `owner_guard(conn)` repeats the check inside the admission and dispatch transactions and returns `gateway_ownership_lost` or `postgresql_recovery_or_validation`. `OpenAITransport._check_owner` runs `check()` before every chat or embedding call and converts a failure into a pre-execution `ProviderError`.
