`GatewayOwner` opens a dedicated autocommit connection and takes `pg_try_advisory_lock(GATEWAY_LOCK)`; if the lock is held it raises `LockHeld`, which `Resources._own` turns into `GatewayLockError`. `check()` (called by `OpenAITransport._check_owner` and `require_owner`) confirms the lock is still granted and that recovery and validation are ready, and marks the owner permanently `lost` on any failure. `owner_guard(conn)` repeats the check inside the admission and dispatch transactions. `borrow_owner` shares one owner among several `Resources` of a process with a user count; the last `release()` closes the session.
