GatewayOwner holds pg_try_advisory_lock(GATEWAY_LOCK) on a dedicated autocommit psycopg connection for the process lifetime. Resources in one process share it through borrow_owner with a user count, and the last release closes the session. check() verifies through pg_locks that the lock is still granted and that recovery and validation are ready. A loss marks the owner lost permanently with no reconnect. OpenAITransport._check_owner calls it before every chat or embed call and converts a failure into a pre-execution ProviderError.
