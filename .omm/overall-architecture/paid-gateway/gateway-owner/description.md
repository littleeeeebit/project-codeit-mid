`postgres.GatewayOwner` holds `pg_try_advisory_lock(GATEWAY_LOCK)` on one dedicated autocommit connection for the process lifetime. A held lock raises `LockHeld`, which surfaces as `GatewayLockError('another process already owns the paid gateway')`. Several `Resources` in one process share the owner through `borrow_owner`, which counts users; the last `release()` closes the connection and so frees the lock. `check()` verifies the lock is still granted and that recovery and validation are ready; after any loss it sets `lost` and never reconnects. `owner_guard(conn)` repeats the check inside admission and dispatch transactions using the owner's backend PID.
