`evaluation.activate_run` is reached from `activate-run`, a decision file, or the 검색 구성 비교 activate action (`service.activate_experiment`). It checks `run_errors`, which covers completeness, the current `EVAL_VERSION`, artifact readiness and the corpus-route record. In one transaction it then sets `app_settings.active_run` (mode, index, dense version, embedding, limits, reranker) and `active_index`, and appends a row to `activations` with the previous configuration. At request time, `service.active_serving` reads the stored activation again. It falls back to the `kiwi_bm25` default when the run's `corpus_route` differs from `corpus_route_record()` or its embedding model is unknown, and drops a reranker that was promoted under an older evaluation policy.
