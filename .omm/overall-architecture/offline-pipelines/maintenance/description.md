`maintenance.run` runs `STEPS` in order and writes `.runtime/maintenance/state.json` before and after each step. Steps: `backup` (reused when table digests and artifacts are unchanged), `restore_check` (into a scratch `rfp_mrestore_<uuid>` database, dropped afterwards), `ingest`, `fidelity`, `keyword` (`activate=False`), `embedding` (raises `NeedsApproval` with a priced estimate for a paid model), `regression` (`compare.regression`), then `report`. The first failure stops the sequence. If a re-parse orphaned pinned gold evidence, the run ends `unverified`. The report records `serving.unchanged` and the provider-call count.
