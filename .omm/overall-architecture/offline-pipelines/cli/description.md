`cli.py:main` dispatches about 60 subcommands, among them init, manifest, ingest, fidelity, ocr, build-keyword, plan-embeddings, build-dense, evaluate-retrieval, compare, activate-run, gold, freeze-release, run-answers, backup, restore-check, release-report and maintain. The budget-administration commands (`reconcile`, `unresolved`, `settle`, `adjust`, `paid`, `audit`, `configure-budget`) open `service.Resources(settings, dispatch=False)` so they can run beside the live server without taking the gateway lock. Paid CLI runs such as `build-dense`, `run-answers` and `run-judges` need the gateway, so the UI has to be stopped first.
