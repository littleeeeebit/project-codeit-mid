`fidelity.verify_source` prints the HWP through Hancom Viewer to Microsoft Print to PDF, answering the save dialog by Win32 automation (`print_hwp`). It extracts the print's text layer, compares in both directions with 6-character shingles plus exact digit runs (`compare`), upserts `fidelity_checks` and sets `review_status` to `auto_verified` or `auto_flagged`, but never over a human status (`HUMAN_STATUSES`). Recovered sources are refused, because their text layer is the extraction itself.
