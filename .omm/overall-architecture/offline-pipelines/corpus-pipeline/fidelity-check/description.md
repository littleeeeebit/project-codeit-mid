`verify_source` prints the HWP through Hancom Viewer (`print_hwp`; Microsoft Print to PDF answers the save dialog), compares both ways (6-character shingles, exact runs of digits), and upserts `fidelity_checks`. It sets `sources.review_status` to `auto_verified` or `auto_flagged` unless a human status (`HUMAN_STATUSES`) is already present. Sources recovered from the print are refused because no independent witness remains. The 검증 screen's `confirm_fidelity` records `sample_checked`.
