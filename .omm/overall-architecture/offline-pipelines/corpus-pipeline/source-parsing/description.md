`ingest_source` re-hashes the original (refusing changed bytes) and skips owner-recovered sources and unchanged inputs. HWP goes through `parse_hwp` (the `hwp5proc` XML from pyhwp walked by `walk_hwp`); when pyhwp fails but a Hancom print exists, the print's PDF text layer is used (`recovered_from_native_print`). PDF goes through `parse_pdf` (PyMuPDF). A failure sets `sources.parse_status = 'quarantined'`, `review_status = 'needs_recovery'` and a reason code. `ingest` catches each source's exception, records it as `error` and continues (the CLI exits 1).
