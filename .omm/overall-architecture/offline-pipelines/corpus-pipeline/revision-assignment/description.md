`assign_revision` derives the extraction ID from `source_hash:fingerprint`. When the stored artifact's content differs under the same fingerprint, it creates a content-hashed revision beside the old one and leaves the old artifact and element rows for pinned gold rows and citations. `ingest_source` then records the input key, inserts the extraction and elements, and moves `sources.active_extraction_id`. A new revision resets `review_status` to `unreviewed`. Diagnostics (`short_output`, `no_tables`, `thin_tail` and others) go to `.runtime/reports/ingest-*.json`.
