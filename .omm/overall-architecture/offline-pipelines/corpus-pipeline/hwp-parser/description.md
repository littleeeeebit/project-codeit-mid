`parse_hwp` runs `hwp5proc` (`RFP_HWP_CONVERTER`) to XML and walks it (`walk_hwp`) into paragraph, table and cell elements with picture markers, after which `ocr.merge_hwp` inserts `image_text` at those markers. When pyhwp fails, `_parse_source` falls back to `storage/hwp_loader.load_hwp_hwpx`. That path uses its own `hwp_loader` fingerprint and a `pyhwp_failed` warning, and gives no picture positions, so no OCR text. Only a loader failure quarantines the source.
