From originals to indexed chunks. `manifest` imports `data_list.csv` associations with hashes and conflicts. `ingest` parses each unique original once, reusing work when `input_key` (original, parser revision, native print, OCR cache, converter) is unchanged. `fidelity run` compares HWP extractions with Hancom-printed PDFs. `ocr` reads image regions. `build-keyword` builds the operating index.
