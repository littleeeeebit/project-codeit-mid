`import_manifest` reads `data_list.csv` (`read_manifest_csv`, `normalize_row` with typed dates and amounts), hashes each original, and upserts `sources` by SHA-256 and `documents` by filename. Duplicates and conflicts are reported (`manifest_report`). `ingest` then calls `ingest_source` once per unique hash. A source whose bytes changed raises `original bytes changed`, and one crashing file is recorded as `error` while the run continues (the CLI exits 1).
