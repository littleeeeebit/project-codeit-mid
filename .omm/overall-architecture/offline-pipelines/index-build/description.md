`build-keyword` builds immutable Kiwi BM25 indexes per chunk profile; only the structural profile serves, and the fixed-* profiles are for comparison. `plan-embeddings` stores a priced estimate that expires after 24 h. `build-dense` refuses a stale or over-envelope estimate, and refuses while any embedding billing is unknown. It reserves and settles each batch in the `embedding` envelope, and publishes the pgvector set only after every row verifies (`vector_store.publish`). `build_local_dense` builds the sets of local GPU models for free.
