The owner CLI (`python -m rfp_assistant.cli …`) builds and changes everything that serves. Every command except `check`, `load-check` and `restore-check` runs against the validated `RFP_DATABASE_DSN`. Nothing runs on a schedule, and only `activate-run` (or the 실험 비교 activate button) changes what serves. `maintenance.run` chains backup, ingest, fidelity, keyword, embedding and regression steps. The CLI and the 검증 → 유지보수 button both reach it.
