`python -m rfp_assistant.cli <command>` (on the VM, `tools/bidmate-cli.sh`, which loads `/etc/bidmate/server.env` and runs as `bidmate`). These commands produce what the server reads: `manifest`/`ingest`/`ocr`/`fidelity` (extractions), `build-keyword` (immutable keyword indexes), `plan-embeddings`/`build-dense` and `compare` (embedding sets and comparison tables), `evaluate-retrieval`/`compare-runs` (frozen runs), `activate-run` (serving switch), gold commands, phase-4 `freeze-*`/`run-answers`/`release-report`, `backup`/`restore-check`, and `maintain`. See the `data-flow` and `maintenance-sequence` perspectives for the order. `check`/`load-check` use temporary databases on `RFP_POSTGRES_TEST_DSN`; `restore-check` uses `RFP_RESTORE_DATABASE_DSN`.
