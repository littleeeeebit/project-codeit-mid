Batch pipelines that turn the original HWP and PDF corpus into serving artifacts, and that decide what serves. They run from the owner CLI. Maintenance, development answer evaluation, judge runs, drafting and activation can also start from the screens, inside the serving process. The code follows the plan's operating rule: pipelines run every variant and record comparison tables, and only a person's activation (CLI `activate-run` or the experiments activate action) changes what serves.
