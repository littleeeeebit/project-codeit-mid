`retrieval.build_keyword_index` chunks every eligible source's active extraction with a profile (`chunking.build_profile`: structural by default, or fixed-256/512/800). Eligibility is reviewed-only by default; `--include-unreviewed` adds unreviewed and auto_flagged sources. It tokenizes with Kiwi, freezes `scope-terms.json`, writes a temporary directory that is renamed into `indexes/<version>`, and replaces the index's rows in one transaction. With `activate` it moves only `active_index`, which serves only when no run is activated. `dense.plan_embeddings` then `build_dense` (paid, against a 24-hour estimate in the `embedding` envelope), or `build_local_dense` (GPU), fills `embedding_payloads` and publishes a verified `embedding_sets` version (`vector_store.publish`).
