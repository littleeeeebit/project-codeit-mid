`Runner.row_key` hashes the row, index, populations and every effective limit (`limits_identity`, embedding identity, reranker identity) into a cell key. `cached` returns `.runtime/compare/cells/<key>.json` unless the cell failed (failures are retried) or its run directory lost `scores.json`. Corpus and query vectors and `rerank_scores` (`CachedReranker`) are also reused, so a rerun computes only what is missing.
