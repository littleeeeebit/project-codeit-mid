`compare.run_matrix` expands one declared axis (lexical, chunking, embedding, reranker, or a custom JSON) over the serving base. It scores every row on three populations (the dev set in its own document, the dev set over the corpus, the needle set). Finished cells are cached and every row is written as an activatable run under `runs/`. The output is `compare/tables/<matrix>.json` and `.md`, which the 실험 비교 view reads through `service.experiments`. Uncached paid corpus embeddings become `needs_approval` rows until `compare --approve`. `evaluate-retrieval`, `trial-reranker` and `compare-runs` are the older per-run equivalents.
