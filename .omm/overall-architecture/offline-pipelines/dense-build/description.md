`plan_embeddings` counts unique payload tokens and prices the misses without calling the provider. `build_dense` refuses a stale estimate, then sends bounded batches through `metered_embed`, which reserves, dispatches and settles each one in the `embedding` envelope. It refuses to run while any embedding attempt is unknown. `build_local_dense` embeds on the GPU for registry models (`models.EMBEDDINGS`). `vector_store.publish` writes `embedding_sets` and `embedding_set_rows` in state `building`, re-verifies every vector checksum and its row-to-chunk mapping through `PgDenseIndex.load`, and only then flips the set to `ready`.
