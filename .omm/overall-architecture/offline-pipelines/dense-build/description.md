`plan_embeddings` prices the unique uncached payloads (`cl100k_base`) and stores an estimate valid for 24 h. `build_dense` refuses a stale estimate or one outside its envelope, reserves and settles each batch in the `embedding` envelope, and refuses to run while any embedding attempt is unknown. `build_local_dense` and `build_gemini_dense` cover the other backends. `vector_store.publish` inserts the set as `building`, verifies it with `PgDenseIndex.load`, then marks it `ready`.
