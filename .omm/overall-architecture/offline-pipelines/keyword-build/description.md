`retrieval.build_keyword_index` selects parsed sources by review policy: `--reviewed-only`, or `--include-unreviewed` for the operating index. It freezes each document's title and institution terms (`metadata_term_snapshot`), chunks with `chunking.build_profile`, and tokenizes with Kiwi. The version is a hash of the configuration (chunker, analyzer, IDF policy, extractions, metadata-terms hash). Files are written into a temporary directory and renamed into `.runtime/indexes/<version>/` (chunks, tokens, requirements, scope-terms, manifest). `_record_index` then writes the `indexes`, `chunks` and `requirements` rows in one transaction and, before any run has been activated, may move `active_index`.
