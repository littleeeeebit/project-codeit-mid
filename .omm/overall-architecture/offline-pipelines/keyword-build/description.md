`build_keyword_index` selects parsed sources by review policy (`--reviewed-only`, or the operating index with unreviewed and auto_flagged sources). It chunks each active extraction with `chunking.build_profile` (structural, or a fixed baseline) and tokenizes with the shared Kiwi `Analyzer`. It freezes each document's name terms and derives the version as a hash of chunker, profile, analyzer, IDF policy, review scope, extractions and metadata terms. It writes the files atomically and inserts the `indexes`/`chunks`/`requirements` rows. `activate=True` moves only `active_index`, and once a run has been activated, only activation changes what serves.
