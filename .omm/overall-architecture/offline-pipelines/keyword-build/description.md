`build_keyword_index` selects parsed sources by review policy (`--include-unreviewed` adds `unreviewed` and `auto_flagged`), chunks them by profile (`chunking.build_profile`), tokenizes with Kiwi, and freezes `scope-terms.json`. The version is a hash of the config, which makes a rebuild with the same inputs a no-op. It writes files to a temp directory, renames it, then inserts the `indexes`, `chunks` and `requirements` rows in one transaction. `activate=True` moves `active_index` only on the phase-1 default path.
