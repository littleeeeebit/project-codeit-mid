`plan_embeddings` counts unique payloads, subtracts verified cache hits and stores a 24-hour estimate bound to index, model, dimensions, rates and batch limits. `build_dense` refuses a stale or over-envelope estimate. It reserves and settles each batch in the `embedding` envelope and refuses while any embedding attempt is unknown. It publishes the matrix only after every row is verified. Local models (`build_local_dense`, models.py) run only on CUDA with a VRAM-capped allocator. Gemini builds use their own ledger.
