`import_manifest` reads `data_list.csv`, hashes each original, and groups byte-identical associations. `ingest_source` reuses the prior extraction when `input_key` (original, parser revision, native print, OCR cache, converter) and the artifact hash are unchanged. Otherwise it parses HWP with `hwp5proc` (`parse_hwp`), falling back to the Hancom print's PDF text layer, or parses PDF with PyMuPDF. It merges OCR `image_text` elements and binds the extraction revision to the actual output (`assign_revision`); a different output gets a new ID beside the old one. It writes `.runtime/extracted/<hash>/<fp>/elements.jsonl` plus `elements` rows. A new revision resets review to `unreviewed`. A failure quarantines the source with a `reason_code`.
