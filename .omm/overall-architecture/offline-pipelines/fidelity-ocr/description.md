`fidelity run` has Hancom Viewer print each HWP to PDF, then compares extraction and print in both directions, using 6-character shingles and exact runs of 3+ digits. It records `fidelity_checks` and sets review_status to auto_verified or auto_flagged; it never overwrites a human status. `ocr` reads raster regions with PaddleOCR-VL on the GPU and re-reads flagged regions with Gemini, under Gemini's own $0.50 cap; the next ingest merges the text. Both steps need the Windows host with Hancom printing or CUDA (README).
