`evaluation.activate_decision` (from the CLI `activate-run` or the route `/api/verify/experiments/activate`) loads the run, validates it with `decision_errors` (index and matrix verify, current `EVAL_VERSION`, pinned embedding revision and prefixes), and in one transaction sets `active_run` and `active_index` and appends to `activations`. The next request's `active_serving` reads it. `Resources.index()` and `dense()` reload when the version differs, and `retire_inactive` unloads GPU models that are no longer used.
