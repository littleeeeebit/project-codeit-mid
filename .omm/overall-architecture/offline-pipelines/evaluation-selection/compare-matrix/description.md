`compare --matrix lexical|chunking|embedding|reranker` (`compare.MATRICES`) runs every row of a declared axis matrix on the same three populations. It reuses cached indexes, vectors, rerank scores and finished cells. A paid row stops as `needs_approval` with a priced estimate until `compare --approve`. It writes `.runtime/compare/tables/<matrix>.json` and `.md`, which `service.experiments` serves to the experiments tab with the serving row marked.
