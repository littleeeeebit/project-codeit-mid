`drafting._generate` opens a trace `draft-gold-questions` (fresh UUID seed, member who started it). It refuses while any `gold_drafting` attempt is reserved, dispatching or unknown, and requires an absolute output directory that does not exist yet. It creates a job request row and drafts five slots per call (`_draft_call`): reserve in `gold_eval` with the remaining consented ceiling, `mark_dispatching` with the service guard, `transport.chat` (`reasoning_effort=none`), then settle. `_accept_drafts` validates each draft with `GoldChecker` and the drafting rules into `candidates.jsonl` and `invalid.json`. Any refusal, truncation or overrun stops the run, and nothing is approved. From the web, `service.start_drafting` lends the server's transport and tracer; from the CLI, `drafting.generate` takes the gateway lock itself.
