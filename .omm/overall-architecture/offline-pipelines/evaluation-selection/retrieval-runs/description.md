`evaluate-retrieval` freezes runs (K0, K1, D, H, HR) by dataset hash, evaluated population, index manifest, analyzer, dense version and limits under `.runtime/runs/<run_id>/` (`config.json`, `traces.jsonl`, `scores.json`, `report.md`). Scoring is against source spans (hit@k, nDCG@5, packed completeness, critical failures, latency, Wilson intervals). Only independently reviewed development rows are scored, and the sealed split is refused.
