`stage_review.run` resolves the refs to full commits, freezes the inputs into the run folder (`freeze`: serving activation, index, vectors, dev and needle questions, or the elements of indexed documents), writes `run.json` before any pricing, and runs each candidate. Afterwards one scorer grades every candidate (`score_retriever`, `score_chunking`, `_score_paid`). `rescore` re-reads stored outputs and the ledger without making calls.
