`execute` runs `python -I -B stage_review_worker.py <worktree> <stage> <inputs> <config> <output> <mode>` with the worktree as the working directory and a timeout. Free stages get a read-only database session and no API keys, and a query vector comes only from cache or a local model. For paid stages, the worker builds its own `service.Resources`, which takes the gateway lock on the shared ledger.
