`review/server.py` uses only the standard library and serves `review/out`, the static Next.js export (built on first start or when `review/` changed), on a free `127.0.0.1` port. It reads run folders under `<data>/review/runs`, imports and exports run zips (at most 2 GB), and never runs a pipeline, loads a model or pays. It is launched by `review.cmd` or `review.command` (`RFP_REVIEW_PYTHON` overrides the interpreter).
