`service.active_serving(settings)` is the single reader of `app_settings.active_run` / `active_index`. With no activation, the keyword default `kiwi_bm25` serves on the active index. It falls back to the default when the run's corpus route differs, serves `kiwi_bm25` without dense when the embedding model is not in `ALLOWED_EMBEDDING_MODELS`, and drops the reranker (keeping hybrid) when an HR run carries a superseded `eval_version`. `describe_serving` produces the single report wording.
