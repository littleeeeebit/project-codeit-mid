`plan_embeddings` counts unique payloads with `cl100k_base`, subtracts verified cache hits and stores a 24-hour estimate bound to index, model, dims, payload set, rates and batches. `build_dense` refuses a stale or over-envelope estimate, reserves and settles each batch in the `embedding` envelope, and refuses while any embedding attempt is unknown. `build_local_dense` runs pinned local models on CUDA only (`models.EMBEDDINGS`; no CPU fallback; VRAM capped at dedicated free memory minus 512 MB; batch halved on OOM). `publish_dense` -> `vector_store.publish` inserts the `embedding_sets` row as `building` with its rows, verifies it through `PgDenseIndex.load(require_ready=False)`, then flips it to `ready`.
