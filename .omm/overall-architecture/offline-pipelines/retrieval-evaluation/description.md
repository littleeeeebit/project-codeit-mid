`evaluate-retrieval` writes frozen, retrieval-only runs under `.runtime/runs/<run_id>/`. Each run is bound to the dataset hash, the evaluated population, the index manifest, the analyzer, the dense version and the limits. Runs are scored against source spans: hit@k, nDCG@5, packed completeness, critical failures and Wilson intervals. `trial-reranker`, `compare --matrix` (lexical, chunking, embedding, reranker) and `compare-runs` write the comparison tables the experiments screen reads. Paid rows stop as `needs_approval` estimates.
