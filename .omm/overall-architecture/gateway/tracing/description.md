tracing.run opens one Langfuse trace per executed request, with the trace ID seeded by request_id. Its steps are retrieve-evidence, assemble-evidence, rewrite-question, generate-answer and validate-answer. It records three scores: citation_valid, insufficient_evidence and evidence_tokens. mask and redact remove secret-shaped strings before export. If any LANGFUSE_* variable is missing, no client is created. SDK failures are caught and never change an answer or the ledger.
