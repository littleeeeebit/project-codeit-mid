`generation.validate_answer` parses the strict structured payload and applies `status_problem`. Every claim must name an allowed document, cite at least one evidence id, and cite only known ids from its own document; in a comparison, an inference may cite both sides as long as it cites its own. Each cited quote must equal the stored quote from the serving index (`service._stored_quote`). Conflicts need evidence. A `source_absence_verified` missing field is refused, because top-k misses cannot establish absence. `answered` requires claims and summary evidence, and a comparison must cover both sides. Inline [E1] markers are stripped from the text. A failure raises `TechnicalError`, which becomes `technical_error` with the cost kept and no retry. Citation errors score `citation_valid` 0.
