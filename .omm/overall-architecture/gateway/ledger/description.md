`budget.reserve` runs inside `tx(immediate=True)`. It checks, in order: `owner_guard`, `paid_enabled`, `database_control.paid_admission`, `frozen_reason`, the model's rate, the purpose envelope, the consented ceiling, the cap minus spent minus pending, and the envelope balance. If all pass, it inserts an `attempts` row in state `reserved` with a `price_json` snapshot of the rates, the rate version and the billing scope. An operational database error fails closed as `ledger_unavailable`. `mark_dispatching` runs the request guard, the owner check, the paid-admission check and a check for any attempt in state 'unknown', all in one transaction; a refusal releases the reservation as `stopped_before_dispatch:<reason>`. `settle` computes cost from prompt, cached, completion and cache-write tokens; a cost above the reservation sets `budget_settings.frozen_reason`. `recover` runs at startup and on an unclean close. The owner CLI commands `unresolved`, `settle`, `reconcile`, `adjust` and `paid` resolve the rest.
