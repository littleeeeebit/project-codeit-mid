gateway/budget.py. reserve() works in one transaction that holds the app mutex. It checks owner_guard, paid_enabled, database_control.paid_admission, frozen_reason, a known rate for the model, the purpose envelope, the consented ceiling, and the cap minus spent minus pending. Then it inserts an attempts row in state reserved. A refusal returns one reason: paid_disabled, postgresql_maintenance, frozen, unknown_rate, unknown_purpose, above_consented_maximum, cap_exhausted, envelope_exhausted or ledger_unavailable. mark_dispatching runs the request's guard in the same transaction. On a refusal it releases the reservation and raises DispatchRefused. settle() prices the reported usage exactly once. If the cost is higher than the reservation, it sets budget_settings.frozen_reason.
