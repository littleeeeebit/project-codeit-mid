OpenAITransport sets max_retries=0 and a finite timeout. It keeps one client per key session, chosen by the KEY_SESSION context variable that service.bind_request sets for each request. The environment key is used only by contexts that have no session key. chat() streams with include_usage when on_delta is passed, and _drain sends the growing content to Resources.partials. A 4xx raises ProviderError(pre_execution=True). Any other OpenAIError raises pre_execution=False. FakeTransport stands in when provider is 'fake'.
