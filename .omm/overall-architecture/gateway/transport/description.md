`generation.OpenAITransport` builds one `openai.OpenAI(max_retries=0, timeout=request_timeout_seconds)` client per key session. `KEY_SESSION` picks the member's client; without one it falls back to the server environment key; with neither it raises `ProviderError(NO_API_KEY, pre_execution=True)`. Authentication, permission, bad-request, not-found, rate-limit and unprocessable errors count as before execution. Timeouts, connection loss, 5xx and errors during a stream count as possibly executed. Streaming uses `stream_options.include_usage`, and `_drain` calls `on_delta` with the accumulated content. `_check_owner` calls `GatewayOwner.check` before every call. `FakeTransport` stands in for provider 'fake'; it never builds an SDK client.
