src/rfp_assistant/cli.py defines argparse subcommands, including init, manifest, ingest, fidelity, ocr, build-keyword, plan-embeddings, build-dense, evaluate-retrieval, compare, activate-run, maintain, gold, run-answers, backup, restore-check, release-report, configure-budget, paid, reconcile, settle, adjust and audit. Budget administration is CLI-only and each command takes --actor and a reason. The web side can change only the shared cap, through PUT /api/budget/limit. Every command except check, load-check and restore-check runs against RFP_DATABASE_DSN.
