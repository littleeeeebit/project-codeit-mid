`python -m rfp_assistant.cli` (`main`) parses one subcommand. `restore-check` uses `RFP_RESTORE_DATABASE_DSN`; `check` and `load-check` create isolated databases on `RFP_POSTGRES_TEST_DSN` with the fake provider. Every other command enters `store.database_lifecycle`, calls `require_imported_database` (except `init`) and `init_schema` (except `budget-report`), then dispatches through `COMMANDS`. Corpus commands call `corpus/ingestion.py`, `ocr.py` and `fidelity.py` directly. `build-keyword` calls `build_keyword_index` and moves `active_index` only while no `active_run` exists. Paid maintenance commands go through `_paid_resources` -> `service.Resources(settings)`, which takes the gateway lock and so refuses while the UI holds it. Budget administration (`unresolved`, `settle`, `reconcile`, `adjust`, `paid`, `audit`) uses `Resources(settings, dispatch=False)`, a ledger-only owner that can run beside the serving app.
