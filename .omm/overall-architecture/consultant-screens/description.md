The Next.js app in web/ is built as a static export into web/out and mounted last by `create_app`, so `/api/*` stays the API's. Screens are typed from web/openapi.json (web/src/lib/api-schema.d.ts, regenerated by tools/openapi.py). The Ask screen (web/src/components/ask/ask-page.tsx) is the main consumer. It POSTs `/api/ask` with scope, question, mode and `previous_request_id`, and keeps the returned `{request_id, generation_id, target}` ownership record. It polls `GET /api/requests/{id}?generation_id&target` through `usePoll` and renders the validated result only when the server says `attachable` (`service.may_attach`). While a paid turn runs, it follows `/api/requests/{id}/stream` with `useAnswerStream`. Turns are cancelled with `/cancel`. Leaving a conversation calls `/abandon`, which cancels only a still-queued request. Every call sends the `X-BidMate-Account` header (`accountHeaders`), and a 409 reloads the page. The Verify, Dataset and Settings pages call `/api/verify/*`, `/api/drafting/*`, `/api/gold/*`, `/api/settings/*` and `/api/budget`. Those pages were matched by route name; their calls were not traced one by one.
