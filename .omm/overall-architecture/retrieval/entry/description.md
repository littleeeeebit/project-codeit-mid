service.retrieve takes the question, the scope (DocRefs or all_documents), request_id, allow_paid, optional limits and an optional verifier mode. Limits can only go down: _narrow_limits caps each value at the serving value. It calls res.retire_inactive(cfg) to unload GPU models that no longer serve. dense.query_vector is paid only when allow_paid and request_id are set. A cache miss on a free path returns no vector, and the mode then falls back. After retrieval it appends these limitations: index_outdated:, activated_run_stale:corpus_route, and <stage>_unavailable taken from Resources.stage_errors. With no index it raises ServiceError.
