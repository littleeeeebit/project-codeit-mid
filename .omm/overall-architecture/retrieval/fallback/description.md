A dense mode drops to kiwi_bm25 when the matrix is missing, was built on another index version, the query vector is missing or the vector has the wrong dimensions. The reason is recorded, for example 'hybrid->kiwi_bm25:query_vector_unavailable'. hybrid_rerank without a loaded reranker drops to hybrid. Every fallback goes into RetrievalResult.fallback and the trace, so none is silent.
