retrieval/retrieval.py retrieve() is the one ranking path shared by serving, verifier traces and evaluation runs. The caller, service.retrieve, resolves the scope and loads the active KeywordIndex. It applies the activated run's recorded settings (Resources.run_settings), so serving reproduces what was measured. For dense modes it gets a query vector from dense.query_vector. Everything runs inside the tracing step 'retrieve-evidence'. Modes: whitespace_bm25 (K0), kiwi_bm25 (K1), dense, hybrid and hybrid_rerank.
