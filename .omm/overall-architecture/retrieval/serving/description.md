`service.active_serving` reads the app settings `active_run` (JSON written by `evaluation.activate_decision`) and `active_index`. With no run it serves the keyword default (`kiwi_bm25`). A run measured under another `corpus_route_record()` is not served; the keyword default serves instead, with `fallback_reason=activated_corpus_route_requires_rerun`. An embedding model outside ALLOWED_EMBEDDING_MODELS degrades to kiwi_bm25. A `hybrid_rerank` run from an older EVAL_VERSION keeps hybrid retrieval but drops the reranker. `describe_serving` gives the one wording that reports use.
