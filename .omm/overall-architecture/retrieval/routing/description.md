When the scope has more than two documents (the all-documents scope), route_corpus narrows it to the projects the question names. It uses the scope-terms.json frozen into the index and records the limitation corpus_routed:. scope_rows turns the scope into allowed chunk rows. The limitations scope_not_indexed: and index_includes_unreviewed_sources are recorded too. Each run stores corpus_route_record(), and active_serving refuses to serve a run measured under a different routing rule.
