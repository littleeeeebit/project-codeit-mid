`_candidates` lists every channel's ranked candidates. Hybrid modes fuse the lexical and dense ids with `fuse` (weighted RRF with a protected BM25 head, per the serving limits). `hybrid_rerank` calls `_rerank`: it keeps up to `rerank_protect` leading BM25 rows in place and reranks the pool below them down to `depth` with `LocalReranker`. An inference error serves the hybrid order with `fallback=hybrid_rerank->hybrid:reranker_error`. `_available_mode` reports a missing matrix, query vector or reranker before scoring starts, as a mode fallback.
