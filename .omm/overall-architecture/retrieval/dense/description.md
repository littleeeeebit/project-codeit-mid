`PgDenseIndex.search(query, allowed, k)` searches the pgvector set for the activated dense version, filtered to the allowed rows. The query vector comes from `dense.query_vector`. It is first looked up in a cache keyed by normalized text, model and dimensions. On a miss, a local model embeds it on the GPU for free. An OpenAI model pays only when `allow_paid` is set and there is a request_id, through `metered_embed`, which reserves and settles in the same ledger. Gemini uses its own cap. Free retrieval never pays: a miss returns `paid_query_embedding_not_allowed`, and the mode falls back to kiwi_bm25. In hybrid mode with no lexical or exact match, dense results are not used (`no_lexical_match:dense_not_used`), because nearest neighbours always exist and would otherwise be arbitrary passages.
