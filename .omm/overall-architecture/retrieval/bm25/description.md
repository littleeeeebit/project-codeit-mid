`_lexical_matches`: K0 uses `WhitespaceAnalyzer`, and K1 uses the Kiwi analyzer whose tokens are persisted in the index. For K1, `scope_redundant_terms` drops terms that cannot discriminate inside the scope, plus the selected project's restated name when one or two documents are selected. Codes, digits and negations are never dropped, and the dropped terms are recorded as `scope_redundant_terms:`. `rank_lexical` scores only the allowed rows, up to `channel_top_k`. `_name_only` detects hybrid questions that only name a project. For those it skips the lexical channel and ranks the named documents' rows by dense similarity (`name_only_question:dense_within_named_documents`).
