`src/rfp_assistant/api.py`. `_routes` covers ask, requests, stream, cancel, abandon, evidence, originals, budget and settings. `_verify_routes` covers traces, evaluation, judges, maintenance, experiments/activate, fidelity, corrections and history. `_dataset_routes` covers drafting and the gold queue; it is registered after `/api/gold/recent` so `/api/gold/{candidate_id}` does not shadow it. Pydantic `_Read` models mirror the service dataclasses read-only. `service.ServiceError` maps to 400, and `auth.AuthError` (`SHELL_ERRORS`) maps to 403. The `_KeySession` ASGI middleware reads the `bidmate_key_session` cookie and calls `service.bind_request`, which binds the contextvars `KEY_SESSION`, `REQUEST_MODEL` and `BILLING_SCOPE` for the whole HTTP request. Work it submits copies that context, so a background answer pays with the key, model and billing scope its browser had at submit time. `PUT /api/settings/api-key` sets that cookie as httponly and samesite=strict. The value is an opaque session handle, not the key.
