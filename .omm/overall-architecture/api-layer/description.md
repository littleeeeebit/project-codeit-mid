`src/rfp_assistant/api.py` builds the FastAPI app. The `lifespan` handler opens the process's single `Resources` (`service.app_resources()` → `get_resources(load_settings())` with `recover=True`). It then wires `res.update_fence = app.state.update.fenced`, starts the update watch's GitHub poller, and on shutdown stops the poller and closes the resources. `ServiceError` maps to 400 and `AuthError` to 403. Route groups: `_auth_routes`, `_routes` (ask, requests, budget, settings, update, originals), `_verify_routes` and `_dataset_routes`. The dataset routes are registered after `/api/gold/recent` so that `/api/gold/{candidate_id}` does not shadow it.
