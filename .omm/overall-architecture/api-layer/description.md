src/rfp_assistant/api.py. The ASGI middleware `_Session` runs for every `/api/` path. It refuses cross-origin non-GET requests (403), refuses all calls when `Login.problem` is set (503), and lets the three `SIGN_IN` routes through. For everything else it resolves the `bidmate_session` cookie to a hub username (401 if none), compares `X-BidMate-Account` with that username (409 on mismatch), and requires the header on state-changing calls (428). It then stores the member in `scope.state` and calls `service.bind_request` to pin the member's key session, answer model and billing scope in contextvars for the request and for any work it starts. Route groups: `_auth_routes` (login/callback/logout/me), `_routes` (info, budget, settings, documents, ask, requests, stream, cancel, abandon, export, evidence, originals), `_verify_routes` (/api/verify/*, /api/gold second-review/recent) and `_dataset_routes` (/api/drafting/*, /api/gold/*). `ServiceError` maps to 400, and `auth.AuthError` (in `SHELL_ERRORS`) maps to 403. Pydantic `_Read` models mirror the service dataclasses without changing them.
