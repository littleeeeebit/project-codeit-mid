`auth.Login` (`service/auth.py`) is configured from the environment (`Login.from_env`). `/api/auth/login` sets a 10-minute state cookie on `/api/auth/` and redirects to the hub's authorize URL. A visit through another host is first moved to the registered redirect host. `/api/auth/callback` compares the state with `secrets.compare_digest`, then `Login.sign_in(code)` exchanges the code with the hub server-side, reads the hub user, checks `BIDMATE_ALLOWED_USERS` and creates an in-memory 12-hour session token (`SESSION_SECONDS`). `/api/auth/logout` drops the token. Sessions are not persisted, so every restart, including an update, signs everyone out.
