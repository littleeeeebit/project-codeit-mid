Thin route functions translate pydantic shapes to service calls. Examples: `POST /api/ask` → `service.ask`; `GET /api/requests/{id}` → `service.request_status` plus `service.may_attach`; `POST /cancel` → `cancel_request`; `GET /api/documents` → `find_documents`; `PUT /api/settings/api-key` → `set_api_key`; `GET /api/originals/{doc_id}/{source_hash}` → `original_download`; the `/api/verify/*` routes → `verifier_trace`, `experiments`, `activate_experiment`, `start_maintenance` and others; the `/api/drafting/*` and `/api/gold/*` routes → drafting and gold functions. Read-only mirrors (`_Read` models with `from_attributes`) type the service's dataclass results without changing them.
