`GET /api/requests/{id}/stream` first calls `service.answer_progress`, which raises before the stream opens if the caller may not see the request. A synchronous generator then re-reads `answer_progress` every 0.15 s. It emits `data: <partial>` whenever the unvalidated partial changes, or `data: null` when cancellation or a lost generation revokes it, and ends with `event: done` once the request leaves queued/running. The partial comes from `res.partials[request_id]`, written by `_paid_answer`'s `on_delta` callback and cleared in `_finish`.
