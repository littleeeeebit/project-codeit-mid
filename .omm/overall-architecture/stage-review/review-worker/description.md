execute() starts `python -I -B worker.py` (a copy of stage_review_worker.py frozen into the run folder) with every OPENAI_/GEMINI_/LANGFUSE_/HF_TOKEN variable stripped and HF offline flags set. Retriever, chunking and OCR estimate runs get PGOPTIONS default_transaction_read_only=on. The generation worker in paid mode builds service.Resources (the gateway owner) and answers each row through answers._answer_row with idempotency keys <run>:<candidate>:<question>:<n>. It skips questions already finished, reports lost answers (settled in the ledger but never stored) without paying again, and stops on blocked or unknown_billing. capped_reservations temporarily replaces budget.reserve so every reservation's ceiling is what the approval has left after committed spend.
