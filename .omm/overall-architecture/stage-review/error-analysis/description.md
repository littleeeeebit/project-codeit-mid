`evaluation/error_analysis.py` folds the append-only stores under `<data>/review`: `annotations/<run>.jsonl` (`live_notes`, `reviewed_answers`), `taxonomy/proposals/*.json`, `taxonomy/history.jsonl` (the commit log) and `taxonomy/versions/v<N>.json` (snapshots). `export` writes the unassigned live notes and a `prompt.md` into `taxonomy/exports/<export-id>/`. `propose` validates the agent's `failure-taxonomy-proposal-1` file: only `name`/`definition`/`notes` keys, a Korean one-line name, a one-sentence definition, existing live notes not held by another type, and no duplicate name. `decide` applies accept, rename, merge, split or reject: it writes the version snapshot first, then appends to history, so a failed snapshot commits nothing. `progress`, `run_counts` and `release_summary` count answers with a type over answers a person reviewed.
