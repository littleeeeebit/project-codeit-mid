`execute` runs `python -I -B worker.py <worktree> <stage> <inputs> <config> <output> <mode>` with `cwd=worktree`, a 3600 s timeout, and an environment stripped of `OPENAI_`, `GEMINI_`, `GOOGLE_API_`, `LANGFUSE_`, `HF_TOKEN` and similar, with HF and transformers offline. The worker imports the candidate's own `rfp_assistant` package. Retriever and chunking (and the OCR estimate) get a read-only PostgreSQL session. In paid mode, `generation` builds a real `service.Resources` (taking or borrowing the gateway lock) and a `PinnedResources` with the frozen activation. Inside `capped_reservations` it calls `answers._answer_row` per row, skipping rows already finished and marking rows `lost` when the ledger shows them billed with no stored result. It stops on `blocked` or `unknown_billing`.
