One scorer grades all candidates. score_retriever covers nDCG@5 on dev and needle top-5 hits; score_chunking covers chunk sizes and kept table titles. For paid stages, _score_paid first reads ledger_spend per candidate, then score_generation (pass rate, required claims, supported vs rejected claims, validation failures, cost, latency with replayed rows unmeasured) or score_ocr (character diff against the baseline, flagged, re-read and unreadable counts). The result is written to view.json and run.json. rescore re-reads stored outputs without any call.
