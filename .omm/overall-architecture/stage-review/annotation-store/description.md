Span notes live in `.runtime/review/annotations/<run-id>.jsonl` (`review-annotation-1`), one append-only record per note, edit, deletion, reviewed mark or sample addition. The server refuses offsets that do not select the exact stored text. Failure types are grouped by the coding agent from an exported bundle (`error-analysis export` → `proposal.json` → `propose`). The person accepts, renames, merges, splits or rejects each type, appended to `taxonomy/history.jsonl` with versions in `taxonomy/versions/`. Similar-case suggestions (`suggest`) are approved one by one as `ai_suggested` notes. They never mark answers reviewed and never enter the rate. Every write takes an OS file lock.
