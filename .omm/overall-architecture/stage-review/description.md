Compares a baseline git ref with candidate refs for one stage (retriever, chunking, generation or ocr) on identical frozen inputs. Each ref runs in its own git worktree and a fresh isolated Python process. The run folder lives under .runtime/review/runs/<run-id>/ (run.json, inputs/, candidates/, view.json). The review app only displays runs and writes decisions. Retriever and chunking are free and read-only; generation and OCR stop at a priced estimate until a person approves.
