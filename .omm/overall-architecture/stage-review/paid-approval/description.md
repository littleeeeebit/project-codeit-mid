The estimate pass records each item's token bounds. estimate() prices what is left at the ledger's current rates (subtracting what the ledger shows was already billed under the candidate's key prefix) and writes estimate.json; run.json moves to needs_approval and the app does not list the run yet. approve() records approved_by in the estimate and the audit log, refusing an estimate that is expired (24 h) or no longer fits the envelope. resume() calls require_approved and recheck (inputs, worker hash, rates, refs and remaining budget unchanged) before any worktree. approved_env() is the only path by which a worker receives the key. Never-dispatched reservations count as available, because the next pass's recovery releases them.
