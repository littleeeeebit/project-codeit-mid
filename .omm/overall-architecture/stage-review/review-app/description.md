review/server.py is a stdlib ThreadingHTTPServer bound to 127.0.0.1 on a free port. It accepts only a loopback Host, and writes only from a same-origin page. It builds review/ (npm ci / npm run build) only when the lockfile or sources changed. GET /api/runs lists runs that have view.json. GET /api/runs/<id> returns the view, docs/<n>.json or images/<n>.png. Export and POST /api/import move zipped run folders between hosts; an import is validated by check_run and never replaces an existing run. The Next.js views live in review/src/components/*-view.tsx.
