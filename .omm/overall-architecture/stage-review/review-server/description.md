`review/server.py` runs `Handler` on a `ThreadingHTTPServer`. `_guard` admits only a loopback Host with the server's own port and, for writes, a same-origin page (or no Origin); other requests get 403. GET routes: `/api/runs`, `/api/runs/<id>` (view.json), `/docs/<n>`, `/images/<n>.png`, `/export`, `/annotations` (`annotation_state`), `/failure-types` (`ea.run_counts`), `/decision`, `/api/taxonomy`, `/api/taxonomy/progress?last=N`. POST routes: `/api/import`, `/api/runs/<id>/decision` (`write_decision` writes `.md` first, then `.json`, under `write_lock`, and returns the agent prompt), `/api/runs/<id>/annotations` (`add_annotation` validates offsets against the stored answer text through `field_text`, refuses duplicate IDs, and records the author from `git config user.name`), `/api/taxonomy/export`, `/api/taxonomy/decide`. `ensure_build` runs `npm ci` and `npm run build` only when the lockfile or sources changed.
