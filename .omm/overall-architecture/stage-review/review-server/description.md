`Handler` serves `review/out` and a small JSON API: `GET /api/runs`, `/api/runs/<id>` (view.json), docs, images, export zip, annotations, failure-types and decision, plus `/api/taxonomy`, progress and suggestions. `POST /api/import`, `/runs/<id>/decision`, `/runs/<id>/annotations`, `/taxonomy/export|decide|suggest-export|suggestions/decide`. `_local()` accepts only a loopback `Host` with this port (no DNS rebinding) and same-origin writes. Note authors come from `git config user.name`.
