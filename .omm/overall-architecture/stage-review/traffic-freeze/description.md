`traffic_review.run` opens one session with `default_transaction_read_only=on` to the database named by `--source-dsn-env`. It reads finished 질문하기 requests since `--since`: the idempotency key is a UUID generation ID with no verifier run, so evaluation, stage-review and sealed requests are excluded. It joins their `request_listings` and freezes request, result and trace JSON into `inputs/requests.jsonl.gz`. Member IDs become HMAC pseudonyms under a key that never leaves `.runtime/review/traffic/`. An exit gate refuses any written file in which a known member ID survives. Sampling is one representative per rule group (validation failures first), then proportional extra picks with a recorded seed.
