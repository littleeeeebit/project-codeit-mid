`execute` runs `python -I -B worker.py <worktree> <stage> …` in the worktree with a 3,600 s timeout. The environment is stripped of `OPENAI_`/`GEMINI_`/`LANGFUSE_`/HF token variables, offline Hugging Face is forced, and `PGOPTIONS=-c default_transaction_read_only=on` is set for retriever, chunking and OCR estimate. A failed or timed-out worker stays in the run with its reason. In paid mode the worker builds its own `Resources` as gateway owner and answers through `answers.PinnedResources` (`gold_eval`), so the codeit `bidmate.service` must be stopped for `resume`, because it holds the lock.
