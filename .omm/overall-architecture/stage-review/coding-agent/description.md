The agent is outside the runtime. It reads `review/decisions/<run-id>.md|json` (chosen candidate, rejection reasons, notes, and a 'Next step' that says to merge the code but never `review-variant.json`, and to reproduce configuration with `compare` + `activate-run`). It also reads the exported note bundle and writes `proposal.json`, which it submits with `python -m rfp_assistant.cli error-analysis propose --file ...`. The app copies a one-line prompt pointing at these files.
