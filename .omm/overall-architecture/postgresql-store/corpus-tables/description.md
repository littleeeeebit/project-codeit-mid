`sources` hold one row per original hash, with parse and review status and the active extraction. `documents` are CSV associations with `active_source_hash`. `extractions` record artifact path and parser fingerprint. `elements` keep source-order text, search text, location and table. `extraction_inputs` is the reuse key per source. `indexes` hold version, manifest path, manifest hash, config and state. `chunks` and `requirements` are per index version. The rest are `metadata_resolutions`, `reviews`, `fidelity_checks`, `gold_candidates`/`gold_reviews`, and `embedding_estimates`/`eval_estimates`.
