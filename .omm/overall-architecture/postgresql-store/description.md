src/rfp_assistant/postgres.py provides a bounded psycopg ConnectionPool per Target. lifecycle() probes the server version and pgvector 0.8.6 and is reference-counted. open_db() refuses to open without an owner. tx() runs a transaction, and immediate=True adds SELECT … FOR UPDATE on application_mutex. read_snapshot is REPEATABLE READ, READ ONLY. Ledger: attempts, adjustments, budget_settings, embedding_estimates, eval_estimates. Gold: gold_candidates, gold_reviews. Vectors (vector_store.SCHEMA): embedding_payloads, embedding_sets, embedding_set_rows.
