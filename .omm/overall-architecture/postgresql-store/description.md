`postgres.py` and `store.py` own the database. `lifecycle()` creates one bounded `ConnectionPool` per DSN, reference-counted per owner, after a probe that refuses any server other than PostgreSQL 18.6 and any pgvector other than 0.8.6. `open_db()` refuses to work without an owner. `tx(immediate=True)` takes `SELECT ... FROM application_mutex FOR UPDATE`, a single global write mutex that serializes idempotency, admission and ledger writes. `GatewayOwner` holds `pg_try_advisory_lock(GATEWAY_LOCK)` on a dedicated connection until the last user releases it, and `check()` re-verifies the lock and the validation state before every provider call. `require_imported_database` refuses startup without `migration_import.state='complete'`, a passing `migration_validation`, unchanged referenced artifact hashes, and a verified `bidmate_recovery` fence. The schema (`store.SCHEMA`, version 6) holds sources/documents/extractions/elements/indexes/chunks/requirements, requests/attempts/adjustments/budget_settings, the gold tables, verifier_runs, activations and audit_events; `vector_store.SCHEMA` adds the embedding tables.
