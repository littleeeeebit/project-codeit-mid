`storage/postgres.py` and `storage/store.py`. `lifecycle()` creates one bounded `psycopg_pool.ConnectionPool` per `Target` (8 connections, 5 s timeouts). It refuses servers other than PostgreSQL 18.6 and pgvector other than 0.8.6, and sets `lock_timeout` to 5 s and `statement_timeout` to 60 s. `bind_sql` translates qmark SQL and rejects SQLite dialect. `tx(immediate=True)` serializes writers by taking `SELECT … FROM application_mutex FOR UPDATE`. Tables from `store.SCHEMA`: sources, documents, extractions, elements, indexes, chunks, requirements, reviews, app_settings, requests, attempts, adjustments, budget_settings, gold_candidates, extraction_inputs, metadata_resolutions, embedding_estimates, audit_events, corrections, verifier_runs, gold_reviews, eval_estimates and activations. Added to these are the `vector_store.SCHEMA` tables (embedding_payloads, embedding_sets, embedding_set_rows) and the control tables (`database_control`, `migration_import`, `migration_validation`). Index payloads, extraction element files and run folders are files whose hashes the rows record. `host_path` remaps recorded Windows paths through `RFP_PATH_MAP`.
