All records live in one PostgreSQL 18.6 database (`bidmate_app`, DSN from `RFP_DATABASE_DSN` in the process environment). The schema is `store.SCHEMA`, applied by `postgres.init_schema` with `INTEGER`→`BIGINT` and `TEXT COLLATE "C"` rewrites, plus `vector_store.SCHEMA` and `models.EXTERNAL_SCHEMA`. Code calls `open_db`/`tx` with sqlite-style `?` placeholders, which `bind_sql` rewrites.
