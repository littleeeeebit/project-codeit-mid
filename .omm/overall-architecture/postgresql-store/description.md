PostgreSQL 18.6 with pgvector 0.8.6, reached through `postgres.py`. `lifecycle(target)` opens one bounded `psycopg_pool.ConnectionPool` per DSN. It is reference-counted, refuses a DSN change while owned, and each connection is configured by `_configure` (server version check, `lock_timeout 5s`, `statement_timeout 60s`, pgvector version check, `register_vector`). `open_db` checks out a pooled connection and refuses when no lifecycle owner exists. `tx(immediate=True)` serializes every write through `application_mutex FOR UPDATE`. `read_snapshot` gives a repeatable-read read-only view. Tables (`store.py` SCHEMA plus `vector_store.SCHEMA`): sources, documents, extractions, elements, fidelity_checks, reviews, indexes, chunks, requirements, app_settings (`active_index`, `active_run`, `ledger_revision`), requests, attempts, adjustments, budget_settings, audit_events, corrections, verifier_runs, gold_candidates, gold_reviews, metadata_resolutions, extraction_inputs, embedding_estimates, eval_estimates, activations, embedding_payloads, embedding_sets, embedding_set_rows, database_control, schema_migrations, migration_import and migration_validation.
