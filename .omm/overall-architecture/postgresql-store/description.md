`postgres.py` pins PostgreSQL 18.6 (`SERVER_VERSION` 180006) and pgvector 0.8.6. Every pooled connection runs `_configure` (lock_timeout 5s, statement_timeout 60s, `register_vector`). `open_db` requires an entered `lifecycle`; there is no implicit pool. `bind_sql` adapts the `?` placeholders that `store.py` SQL uses. Tables (from `store.SCHEMA`, `vector_store.SCHEMA`, `models.EXTERNAL_SCHEMA`) cover sources, documents, extractions, chunks/requirements per index version, indexes, app_settings (`active_run`, `active_index`), requests, attempts, adjustments, budget_settings, audit_events, gold_candidates, activations, embedding_payloads/sets/set_rows, external_attempts, and `database_control.paid_admission`. Index files (`chunks.jsonl`, `tokens.jsonl`, `scope-terms.json`, manifest) and extraction artifacts stay on disk under `RFP_DATA_DIR` (`.runtime`), hash-referenced from the database.
