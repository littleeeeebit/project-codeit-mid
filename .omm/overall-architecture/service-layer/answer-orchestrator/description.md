`_execute` opens one Langfuse root trace per request (`tracing.run('answer-question', seed=request_id)`) and dispatches by mode. `metadata` → `_metadata_answer`: typed CSV facts with known, unknown, conflict, zero_review or resolved state, free. `inventory` → `_inventory_answer`: every coded requirement row for the extraction, from the `requirements` table, free. Paid modes → `_paid_answer`. Every exit goes through `done()` → `_finish`, which reads the request's attempts from the ledger, derives `billing_state` (precedence unknown > pending > reconciled > settled > released) and writes `status`, `trace_json` and `result_json` in one transaction. A request already marked interrupted or cancelled keeps that status. `_trace_outcome` adds the free scores `insufficient_evidence` and `evidence_tokens`; `citation_valid` is scored inside validation. The full paid path is in request-lifecycle.
