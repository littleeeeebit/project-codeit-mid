Resources.__init__ enters store.database_lifecycle, runs postgres.require_imported_database (refuses a database without a validated import or with changed artifact hashes), init_schema and budget.ensure_budget_row. With recover=True it takes postgres.gateway_lock and runs recover_requests plus budget.recover. The transport is generation.FakeTransport when provider='fake', OpenAITransport when OPENAI_API_KEY is readable, otherwise none (provider_note = NO_API_KEY). set_api_key, called from the 설정 page, can create an OpenAITransport later. index() reloads KeywordIndex when app_settings active_index changes. dense() loads and verifies PgDenseIndex once per version and remembers a failed verification so retrieval falls back visibly. reranker() reloads the local model when its key changes. run_settings() overlays the activated run's recorded limits and embedding on Settings. close() rejects new work, shuts the runner down, joins jobs within shutdown_wait_seconds, recovers if jobs are still alive, closes the transport and tracing, and releases the gateway owner. close() is registered through threading._register_atexit so a SIGINT stop closes before executor workers are joined.
