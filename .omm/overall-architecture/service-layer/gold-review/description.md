`submit_drafts` refuses runs that are not completed, have no valid rows or were already submitted. It runs `evaluation.assign_families`, then `gold.submit` inserts `gold_candidates` rows (`pending`) under batch `<draft run id>`, drafted by `drafting.DRAFTER`. `gold_decide` requires a note. It refuses approval by whoever started the drafting run (from `request.json`), and `gold.decide` refuses approval by the drafter or the drafting model, a stale `expected_sha`, a second decision, or a gold-2 approval without `original_inspected`. Approval rewrites `.runtime/datasets/<dataset>.jsonl` from the database. Rejection writes a rejection wiki page. `candidate_review` assembles the cited spans inside their element text (`candidate_spans`), the PDF pages and the CSV metadata.
