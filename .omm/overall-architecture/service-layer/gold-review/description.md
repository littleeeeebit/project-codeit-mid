Review queue for drafted questions (`src/rfp_assistant/gold.py`). `submit_drafts` refuses runs that are incomplete, empty or already submitted, then calls `evaluation.assign_families` and `gold.submit(candidates.jsonl, run_id, 'dev', drafting.DRAFTER)`. `gold_decide` -> `gold.decide`: only `pending` rows; `expected_sha` must equal the stored `row_sha256`; the drafter, or the drafting model, cannot approve; gold-2 approval requires `original_inspected`; rejection needs categories (and a note for `other`). In the same transaction, an approval rewrites the dataset JSONL (`dataset_path`) with `write_jsonl_atomic`, and a rejection renders a rejection-wiki page. `gold_second_review` records agree/disagree on approved gold rows. Sealed datasets are refused outside the owner's CLI (`_sealed_refusal`).
