Three paid jobs, each a daemon thread on this process's gateway and appended to `res._jobs`. `start_drafting` reprices with `plan_drafting`, refuses when the maximum exceeds the consented amount or does not fit, takes `_DRAFT_LOCK` and `_runner_lock`, writes `request.json` into a `draft-YYYYMMDD-xxxxxx` run directory, and runs `drafting._generate(..., guard=lambda conn: 'interrupted' if res._closed else None, tracer=res.tracing)`. Its output is `output/candidates.jsonl`, `receipt.json` and `invalid.json`; a failure writes `error.txt` or `interrupted.txt`. `start_answer_evaluation` (estimate action `answer-finalists` only) calls `answers.begin_answers` and then `answers.run_answers` in the thread. `start_judges` calls `judges.begin` and then `judges.run(closing=lambda: res._closed)`. Both take `_EVAL_LOCK` and `_refuse_closed_or_busy`. Status is read back from run directories (`drafting_runs`, `judge_overview`); a crash leaves `last-error.txt`.
