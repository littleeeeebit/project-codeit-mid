Three kinds of paid job run on daemon threads registered in `res._jobs`, so `close()` joins them. Drafting: `start_drafting` reprices with `plan_drafting` and refuses if the price exceeds the consented maximum or `fits` is false. It writes `.runtime/drafts/<run_id>/request.json` and runs `drafting._generate` (five slots per call, `gold_eval` envelope, guard returning `interrupted` once the service closes). Development answer evaluation: `start_answer_evaluation` → `answers.begin_answers` publishes `config.json` before returning, then `answers.run_answers` runs `service.answer` through `PinnedResources` (the finalist's recorded serving config, `paid_purpose='gold_eval'`). Judges: `start_judges` → `judges.begin` and `judges.run` (`judge_eval` envelope). Failures are written to `last-error.txt`, `error.txt` or `interrupted.txt` in the run directory, and finished rows stay. Rerunning resumes.
