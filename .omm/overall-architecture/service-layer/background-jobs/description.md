start_drafting (drafting._generate, gold_eval envelope), start_answer_evaluation (answers.run_answers with PinnedResources charging gold_eval), start_judges (judges.run) and start_maintenance (maintenance.run). Each publishes its run (a file under RFP_DATA_DIR) before returning, then starts a daemon thread under contextvars.copy_context(), registered in res._jobs so close() joins it. Module-level dicts _DRAFT_JOBS, _EVAL_JOBS, _JUDGE_JOBS and _MAINTENANCE_JOB allow one run of each kind at a time; evaluation and judges also exclude each other via _EVAL_LOCK and _refuse_closed_or_busy. A failure is written to last-error.txt / error.txt / interrupted.txt. Finished settled calls stay settled, and rerunning resumes.
