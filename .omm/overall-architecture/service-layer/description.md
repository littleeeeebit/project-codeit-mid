`service.py` holds the authenticated public functions, process resource ownership and request orchestration. Each public function first calls `_authorize(principal, capabilities...)`. That only states which role it serves: the UI visitor holds every capability, and the CLI and tests pass narrower principals. The module also keeps process-global registries for paid background jobs (`_EVAL_JOBS`, `_JUDGE_JOBS`, `_DRAFT_JOBS`) and the in-process executor.
