RequestRunner wraps a ThreadPoolExecutor(request_workers=6) and a BoundedSemaphore(request_admission=12). submit_answer calls try_admit inside _create's transaction (the before_insert hook), so only a new idempotency key consumes a slot. A full queue raises ServiceError before any paid work. submit() runs _run under contextvars.copy_context(), so the browser's key session, model and billing scope travel with the work. shutdown() stops accepting, waits, cancels futures and marks queued (and, if workers are still pending, running) requests `interrupted` in one transaction.
