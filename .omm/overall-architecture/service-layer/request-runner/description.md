`RequestRunner` (service.py:340) is a ThreadPoolExecutor with `request_workers` threads (6) and a BoundedSemaphore of `request_admission` slots (12). `submit_answer` takes a slot inside the `_create` transaction (`before_insert=admit`), so a full queue is refused before the row exists and before anything is paid. Each task runs `run_queued(request_id)` inside `contextvars.copy_context()`, so the worker pays with the browser key, model and billing scope bound when the HTTP request arrived. `shutdown()` stops accepting work, waits, cancels futures that have not started, and in one transaction marks queued and still-running persisted requests `interrupted`. A worker still inside a provider call keeps its attempt `dispatching`; that attempt settles if the call returns, or becomes unknown after a restart.
