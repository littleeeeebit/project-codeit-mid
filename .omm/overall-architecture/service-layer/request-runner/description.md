`RequestRunner` is a `ThreadPoolExecutor(max_workers=request_workers=6)` plus a `BoundedSemaphore(request_admission=12)`. `submit_answer` acquires a slot with `try_admit()` inside `_create`'s insert transaction (the `before_insert` hook), so a duplicate idempotency key never uses a slot. It then submits only the request ID. `_run` calls `service.run_queued` and always releases the slot. `shutdown(wait)` stops accepting, waits up to `shutdown_wait_seconds`, cancels unstarted futures, marks queued requests `interrupted`, and marks running ones `interrupted` only if some future is still pending.
