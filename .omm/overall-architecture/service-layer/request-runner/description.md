`RequestRunner` wraps a `ThreadPoolExecutor(request_workers)` (default 6) and a `BoundedSemaphore(request_admission)` (default 12, validated within workers..48). `try_admit` is non-blocking and runs inside the `_create` transaction, only for a new idempotency key. `_run` executes `run_queued(res, request_id)` and always releases the slot. Workers receive only request IDs and rebuild the principal from the persisted `request_json` snapshot. `shutdown(wait)` stops accepting, waits for futures, cancels pending ones, and in one immediate transaction marks every `queued` row `interrupted`. It marks `running` rows `interrupted` only if some futures are still pending.
