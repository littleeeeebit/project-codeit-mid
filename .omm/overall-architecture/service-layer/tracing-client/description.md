`tracing.Tracing.from_settings` builds one Langfuse client on its own TracerProvider, only for provider `openai` with all three LANGFUSE_* values set. `tracing.run` opens a root observation whose trace ID is `create_trace_id(seed=request_id)`. `tracing.step` nests retrieve-evidence, assemble-evidence, rewrite-question/generate-answer and validate-answer. Free deterministic scores are `citation_valid`, `insufficient_evidence` and `evidence_tokens`. Every SDK call goes through `_guard`, so tracing never raises into the traced work, and `mask_otel_spans` redacts secret-shaped values on export. Admission, reservation and settlement never read tracing.
