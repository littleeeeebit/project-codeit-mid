open_evidence reads the evidence map from the request's result_json, never from model output. It adds neighbouring elements from the loaded index or the preserved extraction artifact (_ordered_elements) and warnings: source_version_changed, extraction_revised, source review status and ocr_text. original_download accepts only a UUID doc_id and a 64-hex source_hash pair that matches the document's active source. It requires the path to sit directly in settings.files_dir and the file's SHA-256 to equal source_hash before returning the bytes.
