`open_evidence` reads the evidence unit only from the request's persisted `result_json.evidence` map, so the model never supplies a URL, path or page. It returns the stored quote, neighbouring elements from the loaded index or the preserved extraction artifact (`load_elements`), and the location. It adds warnings: `source_version_changed`, `extraction_revised`, `source_unreviewed`/`auto_flagged`/`needs_recovery`, and `ocr_text` for `image_ocr` locations. `get_request` limits access to the requesting member, or any principal with `verifier`, which every UI visitor has.
