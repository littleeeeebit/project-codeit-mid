verifier_trace runs retrieval only, never paying for a query vector, under a versioned verifier_config. It prices the prompt and inserts a row into `verifier_runs` with config_json, trace_json (retrieval, as_of, estimate, serving snapshot, stage errors) and scope. generate_from_run submits a paid AnswerRequest with idempotency key `vgen-{run_id}` and verifier_run_id. _frozen_run_for then makes _paid_answer reuse the frozen evidence (_frozen_prep) without retrieving again, and passes the frozen estimate as the reservation ceiling. run_generation_block withholds the button when the model has no rate or the serving config changed.
