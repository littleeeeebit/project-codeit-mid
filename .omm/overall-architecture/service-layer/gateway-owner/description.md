`postgres.GatewayOwner` (postgres.py:298) opens a dedicated autocommit connection and holds `pg_try_advisory_lock(GATEWAY_LOCK)` until shutdown. If another process holds it, `LockHeld` is raised, which becomes `GatewayLockError`: a CLI paid command refuses while the UI runs. Several Resources in one process share it through `borrow_owner` and a user count. `check()` confirms that the lock is still granted and that recovery and validation are ready; it is called by `OpenAITransport._check_owner` before every provider call and by `require_owner`/`owner_guard` inside `budget.reserve` and `mark_dispatching`. Once ownership is lost it never reconnects: further dispatch is refused until a restart, which recovers in-flight attempts as unknown.
