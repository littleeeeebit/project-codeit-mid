`api.py` defines Pydantic read-only mirrors of the service dataclasses (`_Read` with `from_attributes`) and three route groups: `_routes` (ask, requests, budget, settings, documents, originals), `_verify_routes` and `_dataset_routes`. Order matters: `_dataset_routes` registers last so that `/api/gold/{candidate_id}` does not shadow `/api/gold/recent`. The ASGI middleware `_KeySession` reads the cookie on every HTTP request and calls `service.bind_request`, which sets the contextvars `KEY_SESSION`, `REQUEST_MODEL` and `budget.BILLING_SCOPE`. All work the request starts inherits them, because the runner and job threads submit through `contextvars.copy_context().run`. The lifespan creates `service.app_resources()` (`get_resources(load_settings())` with `recover=True`) and closes it on shutdown.
