create_app() builds the FastAPI app. Its lifespan calls service.app_resources() (one shared Resources with recover=True) and closes it on stop. Routes are registered in three groups: _routes (ask, requests, evidence, originals, budget), _verify_routes and _dataset_routes. Dataset routes come last so /api/gold/{candidate_id} does not shadow /api/gold/recent. Each route converts Pydantic input to one service call. service.ServiceError maps to 400 and auth.AuthError to 403. _member() turns X-Member into service.visitor(name). /api/originals streams bytes only after service.original_download re-hashes the managed file.
