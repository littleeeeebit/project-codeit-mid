`api.create_app` builds the FastAPI app. Its lifespan opens the process's single `service.Resources` (`service.app_resources()` → `get_resources(load_settings())` with `recover=True`), wires `res.update_fence` to `UpdateWatch.fenced`, starts the update poller, and closes everything on stop. `ServiceError` maps to 400 and `AuthError` to 403. Route groups are registered before the static mount, so `/api/*` always reaches the API. Response models in api.py are read-only pydantic mirrors of service dataclasses (`from_attributes=True`). They type the screens and never change service output.
