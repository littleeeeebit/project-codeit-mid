`create_app()` in `src/rfp_assistant/api.py`. The lifespan opens `service.app_resources()`, which calls `get_resources(load_settings())` and creates `Resources(recover=True)`. Shutdown calls `Resources.close()`. The ASGI middleware `_Session` gates every `/api/*` path in this order: cross-origin writes get 403, a missing login configuration gets 503, and the sign-in routes pass through. Without a session it answers 401. A mismatched account header gets 409, and a write without the header gets 428. It then calls `service.bind_request` to fix the member's key session, model and billing scope in contextvars for the request and every thread it starts. Route groups: `_account_routes` (info, budget, budget limit, API key, model), `_ask_routes` (documents, `POST /api/ask`, request list and status, SSE stream), `_request_routes` (cancel, abandon, export, evidence, original download), `_verify_routes` (traces, evaluation, operations, review) and `_dataset_routes` (drafting and gold). `ServiceError` maps to 400 and the `SHELL_ERRORS`, such as `AuthError`, map to 403. Pydantic models (`Answer`, `RequestView`, `Evidence`, …) are read-only mirrors of the service dataclasses.
