`auth.Login`. `/api/auth/login` redirects to the hub's `/hub/api/oauth2/authorize`, with a state cookie scoped to `/api/auth/`. If the visit came through another host (for example an SSH tunnel), it first moves to the registered redirect host. `/api/auth/callback` compares the state with `secrets.compare_digest`, exchanges the code, reads `/hub/api/user` and accepts only `BIDMATE_ALLOWED_USERS`. It then sets an HttpOnly, SameSite=Lax session cookie on path `/api/`, so the cookie never reaches the hub's notebook servers on the same host. Sessions last 12 h, in memory. `BIDMATE_LOCAL_MEMBER` skips sign-in for one local developer, and `Login.from_env` refuses it next to hub settings.
