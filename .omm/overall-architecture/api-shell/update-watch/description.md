`update.UpdateWatch` records the running commit (`build_head`) and polls the public GitHub repository every 300 s for main's head. `POST /api/update` raises `watch.accepting` under `res._runner_lock`, then refuses if `open_paid_work` sees queued or running requests, admitted slots, live job threads, or open or unknown ledger attempts. Otherwise it writes the marker file `BIDMATE_UPDATE_REQUEST` and an audit row. A root systemd path unit runs `tools/infra/update.sh`, which fast-forwards, rebuilds, restarts and rolls back on failure. This module only reads that script's `result.json`. `fenced()` (accepting, or a result still `running`) is checked at every paid admission.
