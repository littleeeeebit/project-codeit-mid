The `_Session` ASGI middleware applies to `/api/*` only. It refuses a state-changing request whose `Origin` is not this host (or the dev origins when `BIDMATE_LOCAL_MEMBER` is set) with 403. It answers 503 when login is misconfigured. Except for `/api/auth/login|callback|logout`, it resolves the `bidmate_session` cookie to a member (401 otherwise). It answers 409 when `X-BidMate-Account` names another account, and 428 when a write names no account. It then calls `service.bind_request(res, member)`, which sets the contextvars `KEY_SESSION`, `REQUEST_MODEL` and `BILLING_SCOPE` from that member's current key session for the whole request. Work started from the request (the executor via `contextvars.copy_context().run`, background jobs) inherits those values, so it pays with the key, model and billing project the member had when it began.
