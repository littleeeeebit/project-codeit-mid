`retrieval.retrieve` collects exact requirement-code hits (`CODE_RE`), which stay ahead of every ranker. For an all-documents scope it narrows to named projects through `route_corpus`, using IDF-weighted title and institution terms and at most `ROUTE_MAX` documents. `scope_redundant_terms` drops non-discriminating query terms and restated project names; it never drops codes, digits or negations, and only drops when a kept term still matches. `rank_lexical` then scores admitted rows with BM25 (K1) or the whitespace analyzer (K0). A name-only question in hybrid modes skips lexical ranking and ranks the named documents by dense search alone (`name_only_question:dense_within_named_documents`). Every decision is appended to `limitations`.
