`scope_redundant_terms` drops query terms that appear in more than half of the scope's chunks, plus the selected project's own name terms when restated (one or two selected documents only). Codes, digits and negations are protected. Terms are dropped only if a kept term still matches something in the scope. `rank_lexical` scores only the allowed rows with BM25 and returns rows with positive score, ties broken by chunk ID. A name-only question in hybrid mode ('○○ 사업은 어떤 사업이야?') clears the lexical channel and ranks the named documents by meaning (`name_only_question:dense_within_named_documents`).
