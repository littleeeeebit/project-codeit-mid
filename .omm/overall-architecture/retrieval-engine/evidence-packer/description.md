The packer walks `ranking` (exact matches first) and admits each chunk as an `EvidenceUnit(E1..En)` holding doc, source hash, extraction, chunk, element ids, quote (`chunk.body`), location and token count. A chunk is skipped with a reason when it carries another requirement code, the unit limit (`evidence_max_units`) is reached, it duplicates a span already picked, or the token budget is used up (the first unit may use `evidence_max_tokens`; later units use `evidence_target_tokens`). Linked sibling pieces of a split element are pulled in nearest-first, up to `LINKED_EXTRA_UNITS`; a piece left out is recorded as `linked_evidence_missing:`. Out-of-scope rows are excluded defensively (`outside_scope`).
