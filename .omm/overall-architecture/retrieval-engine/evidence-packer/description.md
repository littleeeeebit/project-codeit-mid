Walks `ranking` and admits chunks under these limits: `evidence_max_units`, no overlapping spans (`duplicate_span`), and a token budget (`evidence_max_tokens` for the first unit, `evidence_target_tokens` after). Each admitted chunk pulls in up to `LINKED_EXTRA_UNITS` (2) sibling pieces of a split element, nearest first; a sibling left out is reported as `linked_evidence_missing:`. Each unit becomes `EvidenceUnit(evidence_id=f"E{n}", doc_id, source_hash, extraction_id, chunk_id, element_ids, quote, location, token_count)`. These IDs are the only citations the answer validator accepts.
