The ranking is walked into `EvidenceUnit`s `E1..En`, admitting each chunk unless it carries another requirement code, the unit limit (`evidence_max_units`, 10) is reached, its span duplicates an admitted one, or it exceeds the token budget (`evidence_max_tokens` for the first unit, `evidence_target_tokens` after). Linked sibling pieces of a split element are pulled in nearest first (`LINKED_EXTRA_UNITS`), and a missing piece is reported as `linked_evidence_missing`. The function returns a `RetrievalResult` with candidates, exclusions, timings and limitations.
