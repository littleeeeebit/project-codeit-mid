`retrieval.retrieve(settings, index, analyzer, question, scope, mode, dense, query_vector, reranker, rerank_depth)` scores only rows of the scope's active extractions, then packs evidence units. Modes: K0 `whitespace_bm25`, K1 `kiwi_bm25`, D `dense`, H `hybrid`, HR `hybrid_rerank`. A dense mode whose matrix, base index, query vector or dimensions are missing falls back to kiwi_bm25 and records it in `fallback`. `service.retrieve` picks the activated mode through `res.serving()`, fetches or pays for the query vector, appends `index_outdated:` and `*_unavailable` limitations, and records a Langfuse `retrieve-evidence` step.
