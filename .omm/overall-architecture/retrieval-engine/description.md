`retrieval.retrieve(settings, index, analyzer, question, scope, mode=..., dense=..., query_vector=..., reranker=...)` is the pure retrieval function. `service.retrieve` wraps it: it resolves scope pairs (DocRef plus the extraction the loaded index serves), obtains a query vector (`dense.query_vector`: cached, local GPU, or paid through the ledger only when `allow_paid`), wraps the call in a `retrieve-evidence` tracing step, and appends `index_outdated:` / `activated_run_stale:` / `<stage>_unavailable` limitations. Modes are K0 `whitespace_bm25`, K1 `kiwi_bm25`, D `dense`, H `hybrid` and HR `hybrid_rerank`. A missing dense matrix, a matrix mismatch, a missing query vector or a missing reranker falls back visibly through `RetrievalResult.fallback`.
