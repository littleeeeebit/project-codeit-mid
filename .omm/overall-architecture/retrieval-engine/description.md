`service.retrieve` resolves the scope: (DocRef, extraction) pairs, or `corpus_scope` for all documents. It reads `res.serving()`, takes `run_settings` overrides from the activated run, gets a cached or paid query vector for dense modes from `dense.query_vector`, and calls `retrieval.retrieve`. The engine returns a `RetrievalResult` with candidates per channel, the packed `EvidenceUnit`s, excluded chunks with reasons, limitations, timings and the fallback reason. Any unavailable stage degrades visibly: dense to `kiwi_bm25`, rerank to hybrid.
