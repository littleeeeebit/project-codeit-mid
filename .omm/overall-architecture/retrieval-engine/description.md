`retrieval.retrieve(settings, index, analyzer, question, scope, mode, dense, query_vector, reranker, ...)` is a function over a loaded `KeywordIndex` plus optional pgvector and reranker handles. `service.retrieve` sets up the call: it resolves the scope (or `corpus_scope` for all documents), picks the mode and narrows limits from the serving configuration, gets the query vector, and wraps the call in a `retrieve-evidence` trace step. The modes are whitespace_bm25 (K0), kiwi_bm25 (K1), dense (D), hybrid (H) and hybrid_rerank (HR). The result is a `RetrievalResult` with ranked candidates per channel, packed `EvidenceUnit`s (E1..En), exclusions with reasons, limitations and per-stage timings.
