`retrieval/retrieval.py` is the pure retrieval function `retrieve(settings, index, analyzer, question, scope, mode, dense, query_vector, reranker, ...)`. `service.retrieve` feeds it from `Resources`: active index, run settings, dense matrix, query vector, reranker. Modes: `whitespace_bm25` (K0), `kiwi_bm25` (K1), `dense`, `hybrid`, `hybrid_rerank`. Serving currently uses the activated hybrid row: the BM25 top 6 are kept in order, the rest is weighted RRF k=60, 50 candidates per channel, and 10 evidence units.
