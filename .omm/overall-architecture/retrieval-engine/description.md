The service wrapper `service.retrieve` resolves scope, the loaded index and the activated configuration (`res.serving()` → `active_serving`). It applies run-specific settings (`run_settings`: embedding model and dims, depths, RRF constant, evidence limits, reranker precision and length) and obtains a query vector when the mode is dense. It then calls `retrieval.retrieve` inside a `retrieve-evidence` span. Limitations such as `index_outdated:*`, `activated_run_stale:corpus_route`, `dense_unavailable` and `reranker_unavailable` are appended rather than failing the request.
