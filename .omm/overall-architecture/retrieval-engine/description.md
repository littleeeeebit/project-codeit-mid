Retrieval is free unless a paid request needs an uncached OpenAI query embedding. `service.retrieve` resolves the scope and loads the active `KeywordIndex`. It applies the activated configuration (`active_serving`, `run_settings`), may fetch a query vector (`dense.query_vector`), and calls `retrieval.retrieve`. That returns a `RetrievalResult` with ranked candidates per channel, packed `EvidenceUnit`s (E1..En), excluded chunks with reasons, limitations, timings and any fallback. Per the README, the current serving run `H-0fffb2a6ec` is hybrid keyword-first fusion over exact pgvector search: BM25 head 6, RRF k 60, 50 candidates per channel and 10 evidence units.
