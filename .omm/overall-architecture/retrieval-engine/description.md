src/rfp_assistant/retrieval.py `retrieve()` runs scoped retrieval over an immutable KeywordIndex, plus the verified pgvector set (vector_store.PgDenseIndex) and an optional local reranker that service.Resources supplies. Modes: whitespace_bm25 (K0), kiwi_bm25 (K1), dense, hybrid, hybrid_rerank. The live serving run H-0fffb2a6ec (per README) is hybrid with keyword_first fusion, 50 candidates per channel and 10 evidence units. Any unavailable stage falls back and records the reason in `fallback` and `limitations`.
