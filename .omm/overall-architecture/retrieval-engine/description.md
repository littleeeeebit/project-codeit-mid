`service.retrieve` resolves the scope: selected documents through `_resolve_scope`, or every indexed source through `corpus_scope` when all documents are searched. It loads the activated index and settings and, in dense modes, obtains a query vector. It then calls `retrieval.retrieve`, wrapped in a `retrieve-evidence` trace step. The function serves modes K0 `whitespace_bm25`, K1 `kiwi_bm25`, D `dense`, H `hybrid` and HR `hybrid_rerank`. It falls back visibly (`fallback`, `limitations`) whenever the dense matrix, query vector or reranker is unavailable. The result is a `RetrievalResult` holding candidates per channel, the final ranking, packed `EvidenceUnit`s with stable `E<n>` IDs, exclusions with reasons, stage timings and limitations.
