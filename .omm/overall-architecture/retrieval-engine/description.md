`service.retrieve` resolves the scope (or the whole corpus), applies `res.run_settings(cfg)` so the activated run's limits and embedding override the process configuration, gets a query vector when the mode is dense, and calls `retrieval.retrieve`. The modes are `whitespace_bm25` (K0), `kiwi_bm25` (K1), `dense` (D), `hybrid` (H) and `hybrid_rerank` (HR). A missing dense set, query vector or reranker makes the mode fall back, and the reason is recorded in `fallback`. The serving row noted in the README is H: keyword-first fusion over exact pgvector search, 50 candidates per channel and 10 evidence units.
