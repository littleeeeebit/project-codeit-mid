`service.retrieve` resolves the scope (`_resolve_scope` refuses a stale `source_hash`, and the corpus scope uses `corpus_scope`), reads `res.serving()`, calls `retire_inactive`, applies `run_settings` and optional narrowing `limits`, obtains a query vector when the mode is dense, and calls `retrieval.retrieve` inside the Langfuse step `retrieve-evidence`. Modes are K0 `whitespace_bm25`, K1 `kiwi_bm25`, D `dense`, H `hybrid` and HR `hybrid_rerank`. A dense mode missing its matrix, query vector or reranker falls back to K1 (or H) and records that in `fallback`. The result is a `RetrievalResult` with candidates per channel, the ranking, packed `EvidenceUnit`s, excluded rows with reasons, limitations and per-stage timings. Serving (README, run `H-0fffb2a6ec`) is hybrid keyword-first fusion over exact pgvector search: the BM25 top 6 kept, RRF k 60, 50 candidates per channel, 10 evidence units.
