Scoped retrieval over immutable keyword indexes and pgvector sets. `service.retrieve` resolves the scope to `(DocRef, active_extraction_id)` pairs (or every indexed source for corpus mode), loads the activated config, may obtain a query vector, and calls `retrieval.retrieve`. That function routes a named-project question to that project's documents, finds exact code matches, ranks Kiwi BM25 (K1) or whitespace BM25 (K0), adds dense neighbours only when there is some lexical match, fuses (`keyword_first:60:1.0:6` on the serving row), optionally reranks, and packs evidence units within the token limits. A mode whose matrix, vector or reranker is unavailable falls back and records the reason in `fallback` and `limitations`.
