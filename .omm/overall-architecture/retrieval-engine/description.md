`retrieval/retrieval.py` implements the modes K0 (`whitespace_bm25`), K1 (`kiwi_bm25`), D (`dense`), H (`hybrid`) and HR (`hybrid_rerank`) over an immutable `KeywordIndex`. `dense.py` and `vector_store.py` provide query vectors and pgvector search, and `models.py` pins the embedding and reranker registry and the local GPU runners. `service.retrieve` is the serving wrapper. It reads `active_serving`, retires unused GPU models, builds run settings from the activated run's limits, obtains a query vector (from cache, from a local model, or paid only when `allow_paid`), calls `retrieval.retrieve` inside the `retrieve-evidence` trace step, and appends limitations such as `index_outdated:` and `dense_unavailable`.
