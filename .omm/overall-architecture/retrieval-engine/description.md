`service.retrieve` resolves scope, loads the active `KeywordIndex`, reads `active_serving` (the activated run or the `kiwi_bm25` default), calls `retire_inactive` to unload GPU models the activation no longer uses, and applies `run_settings`. For dense modes it fetches a query vector. It then calls `retrieval.retrieve(...)` inside a traced `retrieve-evidence` step. The result lists the limitations that reach the trace and the prompt: `index_outdated`, `activated_run_stale:corpus_route` and `<stage>_unavailable`.
