`service.retrieve` resolves the scope, the active index and the serving config, optionally obtains a query vector, then calls `retrieval.retrieve` (src/rfp_assistant/retrieval/retrieval.py) inside a `retrieve-evidence` trace step. Modes are K0 whitespace_bm25, K1 kiwi_bm25, D dense, H hybrid and HR hybrid_rerank. A missing matrix, query vector or reranker falls back explicitly and is recorded in `fallback`/`limitations`.
