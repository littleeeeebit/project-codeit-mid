`retrieval.retrieve(settings, index, analyzer, question, scope, mode, dense, query_vector, reranker, ...)` scores only rows of the scoped extractions. Modes are K0 `whitespace_bm25`, K1 `kiwi_bm25`, D `dense`, H `hybrid` and HR `hybrid_rerank`. If a needed stage is unavailable, the mode degrades visibly and the reason is recorded in `fallback` (`hybrid->kiwi_bm25:query_vector_unavailable`, `hybrid_rerank->hybrid:reranker_unavailable`). `service.retrieve` supplies the loaded index, the dense index (verified once per version), and a query vector from `dense.query_vector`. A paid OpenAI query embedding happens only when `allow_paid` is set, which is true for paid answer requests only. `service.retrieve` also appends limitations: `index_outdated`, `activated_run_stale` and `*_unavailable`.
