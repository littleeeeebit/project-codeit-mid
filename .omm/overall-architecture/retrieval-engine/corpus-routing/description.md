`_routed_scope` handles the all-documents scope (more than 2 pairs). `route_corpus` narrows it to the documents whose frozen title terms the question names and records `corpus_routed:`. `_name_only` detects a question that only names a project in hybrid modes; the lexical channel is then cleared and `_named_rows` ranks the named documents by meaning. `_exact_matches` puts rows whose `requirement_key` equals a code in the question (`CODE_RE`) first, and records `code_not_found`/`code_ambiguous`.
