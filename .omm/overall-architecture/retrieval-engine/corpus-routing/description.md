`_routed_scope`: when the scope has more than two documents (the all-documents scope only), `route_corpus` narrows it to the documents the question names and records `corpus_routed:`. It also notes `index_includes_unreviewed_sources` and `scope_not_indexed:`. `_exact_matches` puts chunks whose `requirement_key` equals a code in the question ahead of every ranker. `_name_only` and `_named_rows` handle a question that only names a project, ranking that project's overview passages by meaning.
