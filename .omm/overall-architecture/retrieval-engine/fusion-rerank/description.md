`fuse` applies weighted RRF (`rrf_k`, `dense_weight`). With `fusion == keyword_first`, the leading `keyword_head` BM25 rows keep BM25 order and dense rows can never displace them, then the list is cut to `fused_top_k`. When a hybrid mode found no lexical match and no code, the dense channel is not used (`no_lexical_match:dense_not_used`). In `hybrid_rerank`, `LocalReranker.rerank` (`dense.py`) reorders the pool below an optional protected BM25 head. An inference exception falls back to the hybrid order and records `reranker_error` in `fallback`.
