`_candidates` builds each channel's candidates. `fuse` applies weighted RRF (`rrf_k`, `dense_weight`). With `fusion == keyword_first`, the leading `keyword_head` BM25 rows keep BM25 order and dense rows can never displace them. HR then runs `_rerank` with the local reranker over the fused depth, optionally protecting the head rows. A reranker inference error falls back to H and records the reason.
