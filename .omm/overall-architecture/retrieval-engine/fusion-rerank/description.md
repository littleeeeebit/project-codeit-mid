`fuse` computes weighted RRF (`rrf_fuse`, `1/(k+rank)`). With `fusion == keyword_first` it pins the first `keyword_head` BM25 rows in BM25 order and orders the rest by RRF, cut to `fused_top_k`. In HR mode, `_rerank` keeps the protected leading BM25 rows and reranks the pool below them down to `depth` with `dense.LocalReranker`. An inference exception serves the H order and records the fallback `hybrid_rerank->hybrid:reranker_error:…`.
