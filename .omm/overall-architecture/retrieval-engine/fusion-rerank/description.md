`_candidates` and `fuse` combine the lexical and dense rankings, using `rrf_fuse` with the activated run's fusion geometry. In `hybrid_rerank`, `_rerank` reorders up to `rerank_depth` rows that sit below `rerank_protect` leading BM25 rows, using the local reranker. On an inference error it falls back to hybrid and records it in `fallback`. This node was read from function signatures, the `retrieve` body and the README; `_candidates` and `fuse` were not traced line by line.
