`_candidates` records every channel's ranks. Hybrid fuses the lexical and dense IDs with `fuse` (weighted RRF, keyword-first head per the run's limits). `hybrid_rerank` reranks the rows below the protected BM25 head, down to `rerank_depth`, with the local reranker (`LocalReranker`, one-at-a-time model lock). An inference error serves the H order and records `hybrid_rerank->hybrid:reranker_error`. An HR activation from a superseded evaluation policy is served as plain hybrid (`active_serving`).
