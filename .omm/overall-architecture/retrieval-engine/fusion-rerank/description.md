`fuse` computes weighted RRF (`sum(weight / (rrf_k + rank))`). With `fusion=keyword_first`, the first `keyword_head` BM25 rows (6 in the serving row) keep BM25 order ahead of everything else, and the result is cut to `fused_top_k` (50). `_rerank` (HR only) reranks the pool below the protected BM25 head down to `depth` with the `LocalReranker`. An inference error serves the H order and records `hybrid_rerank->hybrid:reranker_error`. Exact code matches stay ahead of every ranker (`ranking = exact + ordered`).
