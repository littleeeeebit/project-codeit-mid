Hybrid modes fuse the lexical and dense id lists with `fuse()` (weighted RRF; the README records keyword-first fusion with a protected BM25 head of 6). `hybrid_rerank` reranks the pool below `rerank_protect` leading BM25 rows using the loaded `LocalReranker`. A reranker exception degrades to the hybrid order with the reason in `fallback`. If no lexical match exists in a hybrid mode, dense search is not used at all (`no_lexical_match:dense_not_used`).
