`_candidates` records every channel's ranks (exact, bm25/bm25_ws, dense, rrf). `fuse` applies weighted `rrf_fuse` (k, dense weight) and, with `fusion == keyword_first`, pins the leading `keyword_head` BM25 IDs in BM25 order before the fused rest, truncated to `fused_top_k`. In `hybrid_rerank`, `_rerank` keeps up to `rerank_protect` leading keyword rows and reranks the pool down to `depth`. An inference exception serves the H order with fallback `hybrid_rerank->hybrid:reranker_error:…`. A run activated under an older `EVAL_VERSION` is downgraded to hybrid by `active_serving`.
