`_pack_evidence` walks the ranking, with exact code matches first. It admits a chunk unless the chunk belongs to another requirement code, `evidence_max_units` is reached, its spans overlap an already picked chunk, or the token budget is exceeded. The first unit is limited by `evidence_max_tokens` and later units by `evidence_target_tokens`. After each admitted chunk it tries to add that chunk's `linked` split siblings, nearest first and at most `LINKED_EXTRA_UNITS`. A sibling left out is reported as `linked_evidence_missing:`. Units are numbered `E1…En`. Each carries the doc, source hash, extraction, chunk, element IDs, quote and location (page, table rows), which the answer validator and the evidence pane use.
