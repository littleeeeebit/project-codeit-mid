`_pack_evidence` walks the ranking in order. It skips duplicate spans and out-of-scope rows. When a code was asked, it rejects chunks carrying a different requirement code. It enforces `evidence_max_units` and the token budgets: `evidence_max_tokens` for the first unit and `evidence_target_tokens` afterwards. It then pulls up to `LINKED_EXTRA_UNITS` linked sibling pieces of a split element, nearest first. A sibling that does not fit is recorded as `linked_evidence_missing:<chunk>:<reason>`. Units carry `doc_id`, `source_hash`, `extraction_id`, `chunk_id`, `element_ids`, the quote and the location.
