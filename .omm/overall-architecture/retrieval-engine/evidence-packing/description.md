The ranking is walked in order with exact matches first. A chunk is admitted unless one of these applies: it carries another requirement code (`other_requirement_code`), the unit limit is reached (`evidence_max_units`), its span overlaps one already picked (`duplicate_span`), or the token budget is exceeded (`evidence_max_tokens` for the first unit, `evidence_target_tokens` after). Linked sibling pieces of a split element are added nearest first, up to `LINKED_EXTRA_UNITS = 2`; a sibling left out is reported as `linked_evidence_missing:`. Each unit carries `doc_id`, `source_hash`, `extraction_id`, `chunk_id`, `element_ids`, the chunk body as quote, location and token count.
