The final ranking is exact matches first, then the ordered list. `_pack_evidence` turns it into `EvidenceUnit`s (`E1…`) within the evidence unit and token limits (README: 4,800 tokens per document). It keeps linked pieces of split oversized elements or rows together, and records exclusions and `linked_evidence_missing`. The units carry `doc_id`, `chunk_id`, location and quote. The answer validator later checks every cited quote against the stored element text (`_stored_quote`).
