`service.active_serving` (service.py:399) reads the `active_run` and `active_index` app settings. With no run, it serves the keyword default (`settings.retrieval_mode`, fallback `kiwi_bm25`). A run whose `limits.corpus_route` differs from `retrieval.corpus_route_record()` serves the default and adds `fallback_reason=activated_corpus_route_requires_rerun`. An embedding model outside ALLOWED_EMBEDDING_MODELS is downgraded to kiwi_bm25. A `hybrid_rerank` run from an older EVAL_VERSION keeps hybrid retrieval but drops the reranker. `Resources.retire_inactive` unloads GPU embedders and rerankers that the current configuration no longer uses.
