`active_serving(settings)` reads the app settings `active_run` and `active_index`. With no run it returns the keyword default `kiwi_bm25`. It ignores an activated run whose `corpus_route` no longer matches `corpus_route_record()` (fallback_reason `activated_corpus_route_requires_rerun`) or whose embedding is not allowed, and drops the reranker for a hybrid_rerank run from an older `EVAL_VERSION`. `retrieve` also calls `res.retire_inactive(cfg)` to unload GPU models the active config no longer uses.
