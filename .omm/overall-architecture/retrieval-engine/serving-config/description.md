`active_serving` reads `app_settings.active_run` and `active_index`. With no activation it serves the keyword default (`retrieval_mode`, fallback `kiwi_bm25`). An activated run measured under a different corpus-routing rule (`corpus_route_record`) is not served; the result is flagged `activated_run_stale:corpus_route`. An embedding model this code cannot run is served as `kiwi_bm25`. An HR row from an older `EVAL_VERSION` is served as `hybrid` without the reranker. `Resources.run_settings` overrides the process settings with the run's recorded embedding model and dimensions, depths, RRF and evidence limits, and reranker length, precision and concurrency, so serving reproduces what was measured.
