`active_serving` reads `app_settings.active_run` (JSON written by activation) and `active_index`. With no activation it serves the keyword default (`kiwi_bm25`). If the run's recorded `limits.corpus_route` differs from `corpus_route_record()`, it falls back to the keyword default with `fallback_reason=activated_corpus_route_requires_rerun`, and the result carries `activated_run_stale:corpus_route`. An embedding model outside `ALLOWED_EMBEDDING_MODELS` drops to `kiwi_bm25`. A `hybrid_rerank` run from an older `EVAL_VERSION` serves `hybrid` without the reranker.
