`active_serving(settings)` reads `app_settings.active_run` and `active_index`. With no run, it returns the keyword default on `active_index`. It also falls back to the keyword default in three cases. If the run's `limits.corpus_route` differs from `corpus_route_record()`, it reports `fallback_reason=activated_corpus_route_requires_rerun`. If the activated embedding model is outside `ALLOWED_EMBEDDING_MODELS`, it serves `kiwi_bm25`. If a `hybrid_rerank` run carries an older `EVAL_VERSION`, it serves hybrid without the reranker. `Resources.run_settings` copies the run's limits, embedding model and dimensions, and reranker length, concurrency and precision over the process `Settings`, so serving reproduces what was measured.
