`active_serving(settings)` reads the `active_run` and `active_index` app_settings on every call. With no activation it serves the keyword default (`settings.retrieval_mode` = kiwi_bm25). It falls back to that default with `fallback_reason` when the run's recorded `limits.corpus_route` differs from `corpus_route_record()`, drops to kiwi_bm25 when the run's embedding model is not in `ALLOWED_EMBEDDING_MODELS`, and downgrades `hybrid_rerank` to `hybrid` when the run's `eval_version` is superseded. `Resources.run_settings` overrides the process settings with the run's embedding model and dimensions, its limits (channel_top_k, fused_top_k, evidence units and tokens) and its reranker parameters, so serving reproduces what was measured.
