`active_serving(settings)` reads the `active_run` and `active_index` app settings. With no run it returns the keyword default (`settings.retrieval_mode`, `fallback_mode kiwi_bm25`). It serves the default instead when the run's `limits.corpus_route` differs from `corpus_route_record()` (`activated_corpus_route_requires_rerun`). It drops dense retrieval when the embedding model is not allowed, and drops the reranker for an HR run from an older `EVAL_VERSION`. `Resources.run_settings(cfg)` overrides the process settings with the run's recorded limits, embedding model and dimensions, and reranker settings, so serving reproduces what was measured. `retire_inactive` unloads local GPU embedders and rerankers the activation no longer uses.
