`fuse` applies `rrf_fuse([lexical, dense], k=settings.rrf_k, weights=[1.0, dense_weight])`. With `fusion == "keyword_first"` it pins the first `keyword_head` BM25 rows in BM25 order, so a dense row can never displace a protected keyword match. It then truncates to `fused_top_k`. Candidates from every channel (`exact`, `bm25`, `dense`, `rrf`, `rerank`) are kept in `RetrievalResult.candidates` for traces.
