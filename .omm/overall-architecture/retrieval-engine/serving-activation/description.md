`service.active_serving` reads `app_settings.active_run` and `active_index`. With no activated run, it serves the keyword default. If the run's recorded `corpus_route` differs from `corpus_route_record()`, it falls back to the default with `fallback_reason=activated_corpus_route_requires_rerun`. An embedding model outside `ALLOWED_EMBEDDING_MODELS` drops to `kiwi_bm25`. An HR run from a superseded `EVAL_VERSION` keeps hybrid without the reranker. `Resources.run_settings` then overrides the process settings with the run's embedding model and dimensions, depths, RRF constant, evidence limits and reranker settings, so serving reproduces what was measured.
