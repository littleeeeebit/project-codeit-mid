`CODE_RE` extracts requirement codes such as SFR-001 from the question and matches them against each in-scope chunk's `requirement_key`, with `requirement_detail` chunks first. These rows go ahead of every ranker (`ranking = exact + ordered`). The packer also refuses chunks carrying a different code (`other_requirement_code`). Missing or ambiguous codes are reported as `code_not_found:` / `code_detail_unavailable:` / `code_ambiguous:`.
