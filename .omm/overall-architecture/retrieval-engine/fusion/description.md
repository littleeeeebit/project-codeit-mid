`_candidates` records every channel's ranks. For hybrid modes `fuse` runs `rrf_fuse` (`weight/(k+rank)`) with `rrf_k` and `dense_weight`. Under `fusion == "keyword_first"` it keeps the first `keyword_head` BM25 rows in BM25 order and orders the rest by RRF, cut to `fused_top_k`. The README records the serving row `H-5b2565f606` as keyword-first with k 60, dense weight 1.0, head 6, 50 candidates per channel and 10 evidence units.
