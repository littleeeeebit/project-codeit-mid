fuse() computes weighted RRF (rrf_fuse, sum of weight/(k+rank), ties by chunk ID). With fusion=keyword_first, the first keyword_head BM25 IDs stay ahead in BM25 order, so a dense row cannot displace a protected keyword match. The result is truncated to fused_top_k. hybrid_rerank optionally reorders the top `depth` with the local reranker. An inference error falls back to the hybrid order with the reason recorded.
