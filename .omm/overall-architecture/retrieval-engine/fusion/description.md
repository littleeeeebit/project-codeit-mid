`fuse` computes weighted RRF (`rrf_fuse`, k=`rrf_k`, weights [1.0, `dense_weight`]). In `keyword_first` mode the leading `keyword_head` BM25 IDs keep BM25 order and everything else follows by RRF, truncated to `fused_top_k`. When a hybrid mode has no lexical or exact match and the question is not name-only, dense is skipped (`no_lexical_match:dense_not_used`), because nearest neighbours alone are not evidence.
