`dense.query_vector` checks the pgvector cache by `payload_hash(normalized query, model, dims, "query")`. On a miss: a local model embeds on the GPU for free; Gemini is embedded under its own capped external ledger; OpenAI goes through `metered_embed`, which follows the same reserve → mark_dispatching(guard) → embed → settle/unknown path. The OpenAI miss is paid only when `allow_paid` is set and a request_id exists; otherwise the vector is `None` and the mode falls back to keyword. `_priced` adds the query-embedding estimate to the request's maximum when a miss would be paid.
