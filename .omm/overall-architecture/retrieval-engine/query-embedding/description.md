`dense.query_vector` looks up `payload_hash(normalized question, model, dims, 'query')` in the pgvector cache. On a miss, a local registry model embeds on the GPU for free. A Gemini model goes through its own ledger. OpenAI calls `metered_embed` (reserve → mark_dispatching with the request guard → `transport.embed` → settle, or unknown/release) only when `allow_paid` and a `request_id` are present; free retrieval otherwise returns no vector. A missing vector makes `_available_mode` fall back to K1.
