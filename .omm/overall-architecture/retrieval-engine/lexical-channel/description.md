`_exact_matches` puts requirement codes found by `CODE_RE` ahead of every ranker. `_lexical_matches` -> `rank_lexical` runs BM25 over the allowed rows only and returns only positive scores. Inside the scope, `scope_redundant_terms` drops terms that appear in more than half of the scope's chunks, plus restated title terms, but never codes, digits or negations. It drops anything only if a kept term still matches, and records what it dropped in the limitations. K0 uses `bm25_for(WhitespaceAnalyzer)`, which is built lazily for each loaded index.
