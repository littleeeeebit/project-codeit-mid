`_lexical_matches` → `scope_redundant_terms` drops non-protected query terms that appear in more than half of the scope's chunks, plus the selected project's own restated name terms (one or two selected documents only). It drops them only when a kept term still matches the scope. Codes, digits and negations are never dropped. `rank_lexical` scores BM25 over the allowed rows only and returns positive scores, tied by chunk ID. K0 uses a `WhitespaceAnalyzer` BM25 built lazily per loaded index (`bm25_for`).
