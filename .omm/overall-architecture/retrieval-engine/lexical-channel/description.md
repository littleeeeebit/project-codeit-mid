`_exact_matches` puts rows whose `requirement_key` equals a code in the question (`CODE_RE`) first, detail rows ahead of summary rows, and notes `code_not_found` or `code_ambiguous`. `_lexical_matches` runs BM25 (`rank_lexical`) with the Kiwi analyzer; K0 uses `WhitespaceAnalyzer`. Inside one or two selected documents, `scope_redundant_terms` drops terms that cannot discriminate there (non-positive scope-local IDF) or that restate the project's own name. Codes, digits and negations are never dropped.
