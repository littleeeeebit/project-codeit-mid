`build_keyword_index` selects parsed sources by review status (`--include-unreviewed` adds `unreviewed` and `auto_flagged`), freezes per-document title/institution terms (`scope-terms.json`), and derives a version from the config hash. It writes `chunks.jsonl`, `tokens.jsonl`, `requirements.jsonl` and `manifest.json` into a temp dir, then renames it to `.runtime/indexes/<version>`. In one transaction it records `indexes`, `chunks` and `requirements` rows, and with `activate` it updates `app_settings.active_index`. `KeywordIndex.load` is what `Resources.index()` serves. An index built under another analyzer is still served but marked `index_outdated:`.
