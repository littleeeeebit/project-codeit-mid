An immutable index per version: a hash of chunker fingerprint, profile, analyzer fingerprint, IDF policy, review scope, extraction IDs and frozen title/institution terms. It is built by `build_keyword_index` and loaded by `KeywordIndex.load` into `res._index` when `active_index` changes. `source_extraction` maps each original to the extraction this index holds, so a re-parse that moves `sources.active_extraction_id` does not change serving until a new run is activated. `index_compatibility` flags analyzer or policy drift as `index_outdated:`.
