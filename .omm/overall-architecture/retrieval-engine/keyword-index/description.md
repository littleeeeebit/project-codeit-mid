An immutable index directory `<data>/indexes/<version>/` holding `manifest.json`, `chunks.jsonl`, `tokens.jsonl`, `requirements.jsonl` and `scope-terms.json`. It is mirrored by `indexes`, `chunks` and `requirements` rows. `KeywordIndex.load` verifies the manifest hash against the DB row and every file hash against the manifest, checks that token rows match chunk rows, and loads the elements of each extraction. The version is `sha256(config)[:16]`, where the config covers the chunker fingerprint, profile, analyzer fingerprint, IDF policy, review scope, extraction IDs and the metadata-terms hash. `source_extraction` pins which extraction the index serves for each original, so a re-parse never changes served chunks before a new activation. `index_compatibility` appends `index_outdated:` to the limitations when the analyzer or query policy changed.
