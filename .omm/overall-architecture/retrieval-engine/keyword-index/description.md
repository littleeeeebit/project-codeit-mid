`KeywordIndex.load(settings, version)` reads the `indexes` row and refuses an index whose state is not `ready`. It verifies the SHA-256 of the manifest and of every file under `.runtime/indexes/<version>/`, and loads `chunks.jsonl` and `tokens.jsonl` (which must align) into `BM25Okapi`. It also loads the element rows of each extraction it holds, `scope-terms.json`, and `source_extraction`. Serving resolves an original through `source_extraction`, not through `sources.active_extraction_id`, so a re-parse never changes what serves until a new index is activated.
