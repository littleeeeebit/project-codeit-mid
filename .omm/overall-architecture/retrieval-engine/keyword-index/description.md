`KeywordIndex.load(settings, version)` reads the `indexes` row and verifies the `manifest.json` hash and every listed file hash. It loads `chunks.jsonl` and `tokens.jsonl` (the row order must match), builds `BM25Okapi` from the persisted Kiwi tokens, and loads each extraction's elements and `scope-terms.json`, the per-document title and institution terms frozen at build time. `source_extraction` maps source_hash → the extraction this index holds, so a re-parse does not change what serves until a new index is activated. `index_compatibility` flags an index built with another analyzer or query policy; it is still served but labeled `index_outdated:`.
