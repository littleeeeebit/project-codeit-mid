`KeywordIndex.load` verifies the `indexes` row's manifest hash and every listed file hash. It then reads chunks.jsonl and tokens.jsonl, rebuilds `BM25Okapi` from the persisted Kiwi tokens, loads the elements of each extraction, and reads `scope-terms.json` (title and institution terms frozen at build). `index_compatibility` flags an index built with another analyzer or query policy; it is still served, with `index_outdated:` in the limitations.
