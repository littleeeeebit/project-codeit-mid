`build_keyword_index` writes an immutable directory `.runtime/indexes/<version>/` containing `chunks.jsonl`, `tokens.jsonl`, `requirements.jsonl`, `scope-terms.json` and `manifest.json` with per-file SHA-256. It writes to a temp directory first and renames it into place, then inserts the `indexes`, `chunks` and `requirements` rows and optionally sets `active_index`, all in one transaction. The version is a hash of the chunker, profile, analyzer, IDF policy, review scope, extraction IDs and metadata-term snapshot, so an unchanged build is reused. `KeywordIndex.load` re-verifies the manifest hash and every file hash, and loads elements for every extraction. The `review_scope` value `includes_unreviewed` adds the `index_includes_unreviewed_sources` limitation to every result.
