KeywordIndex.load(settings, version) reads the immutable .runtime/indexes/<version>/ files (chunks, tokens, requirements, scope-terms.json, manifest). In retrieve: _routed_scope narrows the all-documents scope to the projects a question names (route_corpus). _exact_matches puts requirement-code rows first, detail rows ahead. _lexical_matches runs Kiwi BM25 after dropping scope-redundant terms; codes, digits and negations are never dropped. _name_only detects a question that only names a project and switches to dense ranking within the named documents.
