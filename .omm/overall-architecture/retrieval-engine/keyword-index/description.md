`KeywordIndex.load` reads the `indexes` row (state `ready`), verifies the manifest hash and every listed file hash (`chunks.jsonl`, `tokens.jsonl`, `requirements.jsonl`, `scope-terms.json`), checks that token rows match chunk rows, builds `BM25Okapi` from the persisted Kiwi tokens, and loads the elements of every extraction it holds. `source_extraction` maps each original to the extraction this index holds, so a re-parse that moved `sources.active_extraction_id` does not change what serves before an activation. `index_compatibility` flags an index built with another analyzer or without the metadata snapshot. It is still served, but every result carries `index_outdated:`.
