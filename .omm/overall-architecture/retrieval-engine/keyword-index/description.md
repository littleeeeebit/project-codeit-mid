`KeywordIndex.load(settings, version)` reads the `indexes` row, verifies the `manifest.json` hash and every file hash listed in it, then loads `chunks.jsonl`, `tokens.jsonl` and `scope-terms.json` from `.runtime/indexes/<version>/`. It rebuilds `BM25Okapi` from the persisted Kiwi tokens and loads the elements of each indexed extraction. `source_extraction` maps each original to the extraction this index holds, so a re-parse never changes what an issued index serves. `index_compatibility` flags an index built with another analyzer, and the result then carries `index_outdated:` limitations. `Analyzer` (Kiwi) is shared process-wide through `service.shared_analyzer`.
