`KeywordIndex.load` reads the `indexes` row and verifies the manifest hash and every listed file hash. It loads `chunks.jsonl` and `tokens.jsonl` (the token rows must align with the chunks) and builds `BM25Okapi`. It loads every extraction's elements for citation context, maps each source hash to its served extraction, and loads `scope-terms.json` (title and institution terms frozen at build time). `index_compatibility` flags an index built with a different analyzer or query policy as `index_outdated:`; the index still serves.
