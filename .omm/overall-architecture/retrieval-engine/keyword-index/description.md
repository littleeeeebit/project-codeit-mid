`KeywordIndex.load` (retrieval.py:270) reads the `indexes` row, verifies the manifest hash and every listed file hash, and loads chunks.jsonl and tokens.jsonl into a BM25Okapi. It also loads the elements of every indexed extraction and the source-to-extraction map, so serving resolves an original through the index rather than through `sources.active_extraction_id`, which a re-parse moves first. Inside `retrieve`, requirement codes (CODE_RE) produce exact matches that rank ahead of everything. `scope_redundant_terms` drops query terms present in more than half of the scope's chunks, plus restated project-name terms (only with one or two selected documents). It never drops codes, digits or negations, and drops nothing unless a kept term still matches. `rank_lexical` scores only rows inside the scope. A question that only names its documents (`name_only_question`) skips BM25 and ranks those documents' rows by meaning.
