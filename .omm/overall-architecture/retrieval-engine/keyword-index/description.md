`KeywordIndex.load` reads the `indexes` row, verifies the manifest SHA-256 and every listed file hash under `.runtime/indexes/<version>/` (chunks.jsonl, tokens.jsonl, requirements.jsonl, scope-terms.json), rebuilds `BM25Okapi` from the persisted Kiwi tokens, and loads the elements of every extraction it holds via `load_elements`. Paths go through `postgres.host_path`, which remaps through `RFP_PATH_MAP`. `source_extraction` pins which extraction serves each source, independent of `sources.active_extraction_id`. It is cached on `Resources._index` until the active version changes.
