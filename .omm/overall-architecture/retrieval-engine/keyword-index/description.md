`build_keyword_index` selects parsed sources by review status (`auto_verified`, `sample_checked`, `reviewed`; plus `unreviewed`/`auto_flagged` with `--include-unreviewed`). It chunks each extraction with `chunking.build_profile`, tokenizes with Kiwi `Analyzer`, and freezes per-document title and institution terms (`scope-terms.json`). It writes `chunks.jsonl`, `tokens.jsonl`, `requirements.jsonl` and `manifest.json` to a temp directory, then renames it to `.runtime/indexes/<version>`. `_record_index` replaces the `indexes`/`chunks`/`requirements` rows in one transaction and optionally sets `active_index`. The version is a hash of the config (chunker, analyzer, IDF policy, extractions, metadata terms), so a rebuild with unchanged inputs is reused. `KeywordIndex.load` is called from `Resources.index()`.
