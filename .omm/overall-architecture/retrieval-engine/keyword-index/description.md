`KeywordIndex.load(settings, version)` loads the index built by `build_keyword_index` (CLI `build-keyword`) from runtime files: the chunks with spans, `requirement_key`, `token_count` and linked siblings; `row_of`; `rows_by_extraction`; and `scope_terms` (each document's frozen title and institution terms from `scope-terms.json`). `res.index()` reloads it when `app_settings.active_index` changes. Chunking profiles come from `retrieval/chunking.py`.
