`KeywordIndex.load` verifies the `indexes` row (state `ready`), the manifest SHA and every listed file's SHA, then loads `chunks.jsonl`, `tokens.jsonl` and the extraction elements and builds `BM25Okapi`. `source_extraction` maps each original to the extraction this index holds, so a re-parse that has moved `sources.active_extraction_id` does not change what is served until another activation (`service._doc_rows` uses it). `rank_lexical` scores admitted rows only. A query with no shared token returns empty, never arbitrary zero-score rows. K0 builds an extra whitespace BM25 once per loaded index (`bm25_for`).
