`KeywordIndex.load` reads the `indexes` row and verifies `manifest.json` against its stored hash. It then verifies every listed file (`chunks.jsonl`, `tokens.jsonl`, `requirements.jsonl`, `scope-terms.json`), rebuilds `BM25Okapi` from the persisted Kiwi tokens and loads the elements of each extraction. `source_extraction` pins each original to the extraction the index was built over, so a re-parse does not change what serves until a new index is activated. `scope_terms` freezes each document's title and institution terms at build time.
