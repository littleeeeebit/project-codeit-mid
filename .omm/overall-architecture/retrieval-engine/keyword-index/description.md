`KeywordIndex.load(settings, version)` reads the immutable `.runtime/indexes/<version>/` directory: `chunks.jsonl`, `tokens.jsonl`, `requirements.jsonl`, `scope-terms.json` and `manifest.json`. These were written by `build_keyword_index` (atomic temp directory, then rename) with matching `indexes`, `chunks` and `requirements` rows. The version is a hash of the chunker, profile, analyzer, IDF policy, review scope, extraction IDs and the metadata-term snapshot. `index_compatibility` marks an index built with another analyzer or query policy as `index_outdated:`; it is still served.
