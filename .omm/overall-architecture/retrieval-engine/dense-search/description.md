`PgDenseIndex.load` verifies the identity of the `embedding_sets` row against its source index, the model, dimensions and policy, the row count and order, and each vector's checksum. `search` runs `EXACT_SQL` (cosine `<=>` over `embedding_set_rows` joined to `embedding_payloads`, filtered by `row_order = ANY(allowed)`, with ties broken by chunk ID) or, when the run chose `dense_search: hnsw`, the HNSW query with `hnsw.iterative_scan = strict_order`. Dense ranking is skipped when no lexical or exact match exists (`no_lexical_match:dense_not_used`).
