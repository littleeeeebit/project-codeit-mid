`dense.query_vector` hashes the normalized question with the model, dimensions and `query` kind, then looks it up in `embedding_payloads` (`vector_store.cache_get`, checksum-verified). On a miss, a local model embeds on the GPU for free. An API model is paid only when `allow_paid` and `request_id` are set: OpenAI goes through `metered_embed` (reserve, mark_dispatching with the request guard, `transport.embed`, settle or unknown) and Gemini through its own ledger (`gemini_embed`). The new vector is cached with `cache_put`. `PgDenseIndex.load` verifies that the set, its source index, its config identity and every row's checksum and extraction mapping match the keyword index. `search` runs `EXACT_SQL` (pgvector `<=>`, ties broken by chunk ID), or the HNSW query only when the run selected `dense_search: hnsw`.
