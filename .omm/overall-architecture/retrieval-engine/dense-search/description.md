`PgDenseIndex.search` returns the top-k cosine rows among the admitted scope rows of the activated embedding set. The query vector comes from `dense.query_vector`: first the `embedding_payloads` cache (keyed by normalized text, model, dims and policy). For a local model such as the serving BGE-m3-ko, a miss is embedded on the GPU for free and cached. For an API model it is paid through `metered_embed` only when `allow_paid` (a paid request), or through Gemini under its own cap. In hybrid modes dense is skipped when there is no lexical, exact or name-only match (`no_lexical_match:dense_not_used`), because nearest neighbours always exist and would be arbitrary.
