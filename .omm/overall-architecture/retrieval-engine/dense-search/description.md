`vector_store.PgDenseIndex.load` verifies the embedding set: its state, source-index manifest hash, homogeneous model/dimensions/policy, row order, and each vector's checksum and unit norm. `search(query, allowed, k, settings)` runs `EXACT_SQL` (cosine `<=>` over `embedding_set_rows` filtered by `row_order = ANY(allowed)`, ties broken by chunk ID) or, only when the run selected `dense_search: hnsw`, `HNSW_SQL` with a transaction-local strict-order iterative scan. A search that mixes models or dimensions is refused. Query vectors are cached in `embedding_payloads`, keyed by normalized text, model and dimensions.
