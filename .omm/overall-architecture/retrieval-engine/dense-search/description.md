PgDenseIndex.search runs EXACT_SQL (ORDER BY embedding <=> query, restricted to row_order = ANY(allowed)) unless the run's settings select `hnsw`. The query vector comes from dense.query_vector, called in service.retrieve. That function uses the cache table embedding_payloads first, then a local GPU model or the Gemini ledger, or an OpenAI metered_embed only when allow_paid and a request_id are given. Load verifies the model, dimensions, policy, checksums and the exact row order against the keyword index.
