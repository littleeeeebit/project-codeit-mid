DenseIndex.load verifies a vector set against its base keyword index version. A failure leaves dense unloaded, and retrieval falls back to kiwi_bm25 with dense_index_unavailable, dense_index_mismatch or query_vector_unavailable. query_vector caches by normalized text, model and dimensions. A local model embeds a miss on the GPU for free. An OpenAI miss is reserved and settled through budget.reserve (stage `embedding`) only when allow_paid. The hybrid modes skip dense when there is no lexical match (no_lexical_match:dense_not_used).
