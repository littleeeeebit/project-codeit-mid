`PgDenseIndex.load` verifies the embedding set: its `embedding_sets` row is `ready`, its rows are complete and ordered, it does not mix models, dimensions, policies or extractions, every vector checksum and unit norm holds, and the chunk order matches the keyword index exactly. `search` runs `EXACT_SQL` (cosine `<=>` restricted to `row_order = ANY(allowed)`), or HNSW with a strict-order iterative scan when the activated run selected `dense_search: hnsw`.
