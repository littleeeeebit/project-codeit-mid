`vector_store.PgDenseIndex` (aliased as dense.DenseIndex) loads one `embedding_sets` version. It verifies that the set, its source index and configuration agree, that every row maps in order to a chunk of the base keyword index, and that every vector has the right model, dimensions and policy, a valid checksum and unit norm. `search` (vector_store.py:203) runs EXACT_SQL (`ORDER BY embedding <=> ?`, ties broken by chunk_id) restricted to `row_order = ANY(allowed)`. When the activated run selected `dense_search: hnsw`, it runs HNSW_SQL with iterative strict-order scanning inside a transaction instead. A mixed model or dimension search is refused.
