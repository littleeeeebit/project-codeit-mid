`vector_store.PgDenseIndex`, aliased as `dense.DenseIndex`, searches verified pgvector sets, exact by default (README: HNSW missed recall@20 0.99). `dense.query_vector` looks up the query cache by normalized text, model and dimensions first. On a miss, a local model (the serving BGE-m3-ko) embeds on the GPU for free. An OpenAI model goes through `metered_embed` (reserve, mark_dispatching, transport.embed, settle) only when `allow_paid`. A Gemini model uses its own cap and ledger (`models.gemini_embed`, `external_attempts`). In hybrid modes, dense search is skipped when there is no lexical or exact match (`no_lexical_match:dense_not_used`).
