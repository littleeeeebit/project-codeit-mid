`dense.query_vector` looks up the cache by normalized query, model and dimensions. On a miss, a local model embeds on the GPU for free. An OpenAI miss is paid through `metered_embed` (reserve, `mark_dispatching` with the request's guard, embed, settle) only for paid requests (`allow_paid`). Gemini goes through its own capped ledger. `DenseIndex.load` verifies the pgvector set against the base index version. `DenseIndex.search` returns the top k admitted rows by cosine, using exact search or HNSW per the run's `dense_search`. In hybrid modes with no lexical or exact match, dense search is skipped (`no_lexical_match:dense_not_used`).
