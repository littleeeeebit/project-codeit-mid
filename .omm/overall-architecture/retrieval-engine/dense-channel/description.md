`service.retrieve` gets the query vector from `dense.query_vector`. That reads the pgvector cache by normalized text, model and dimensions (`embedding_payloads`). A local model embeds a miss on the GPU, which is free. An OpenAI miss is paid through `metered_embed` (reserve → dispatching → `transport.embed` → settle) only when `allow_paid` and a request ID are given, and Gemini goes under its own cap. A verifier trace never pays. `PgDenseIndex.load` verifies the set's identity, row order, model, dimension and policy homogeneity, every vector's checksum and unit norm, and that the chunk IDs equal the keyword index's rows. `search` runs `EXACT_SQL` (cosine with `<=>`, filtered by `row_order = ANY(allowed)`), or HNSW with a strict-order iterative scan only when the run selected `dense_search: hnsw`. In hybrid modes, dense ranking is skipped when there is no lexical or exact match (`no_lexical_match:dense_not_used`).
