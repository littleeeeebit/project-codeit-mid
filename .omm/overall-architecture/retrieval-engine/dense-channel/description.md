`dense.query_vector` checks the pgvector cache by `payload_hash(normalized question, model, dims, 'query')`. A miss on a local model (BGE-m3-ko) is embedded on the GPU for free (`models.local_embedder`). A miss on an API model is paid only with `allow_paid` and a request ID: OpenAI through `metered_embed` (ledger stage `embedding`), Gemini through `gemini_embed` under its own cap. `PgDenseIndex.search` runs `EXACT_SQL` (cosine `<=>` restricted to `row_order = ANY(allowed)`), or HNSW with an iterative strict-order scan only when the run selected `dense_search: hnsw`. In hybrid modes dense is skipped when there is no lexical or exact match (`no_lexical_match:dense_not_used`).
