`dense.query_vector` looks the normalized query up in `embedding_payloads` by payload hash (model, dimensions and policy must match). On a miss: a local model embeds on the GPU for free, while an OpenAI miss is paid through `metered_embed` (ledger, `request_id`, `_dispatch_guard`) only when `allow_paid` is set and a request ID exists, which is true for interactive paid answers. A Gemini miss uses its own ledger. `PgDenseIndex.search` then runs `EXACT_SQL` (cosine `<=>`, ties by chunk_id) or, only when the run chose `dense_search: hnsw`, `HNSW_SQL` with strict-order iterative scan. In hybrid modes the dense channel is skipped when there is no lexical match (`no_lexical_match:dense_not_used`). An unavailable matrix or vector falls back to `kiwi_bm25`, recorded in `fallback`.
