`dense_mod.query_vector` serves a cached query vector by text, model and dimensions. On a cache miss it pays through the gateway only when `allow_paid`, and then under the same `_dispatch_guard` stop check. `DenseIndex.search` scores allowed rows from the verified embedding set (`retrieval/vector_store.py`: tables `embedding_payloads`, `embedding_sets`, `embedding_set_rows`). Hybrid skips dense when there is no lexical or exact match (`no_lexical_match:dense_not_used`).
