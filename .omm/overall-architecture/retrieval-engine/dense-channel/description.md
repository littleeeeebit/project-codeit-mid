`dense.query_vector` hashes the normalized query by model, dimensions and kind and reads the pgvector cache. On a miss, a local model embeds on the GPU for free. A Gemini or OpenAI model embeds only when `allow_paid` and a request ID are given: OpenAI goes through `metered_embed`, which uses the same reserve, dispatch and settle cycle and the same `guard`, and Gemini goes through its own cap and ledger. Otherwise the result is `paid_query_embedding_not_allowed`. `PgDenseIndex.load` verifies the set's identity, row order, chunk mapping, model, dimensions, policy and every vector checksum. `search` runs `EXACT_SQL` (cosine `<=>`, ties broken by chunk ID) or, when the run chose `dense_search=hnsw`, `HNSW_SQL` with an iterative strict-order scan. Any unavailability falls back to `kiwi_bm25` with the reason in `fallback`.
