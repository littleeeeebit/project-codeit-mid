`dense.query_vector` looks up `payload_hash(text, model, dims, 'query')` in the pgvector cache. On a miss, a local model embeds on the GPU for free. An OpenAI miss is paid only when `allow_paid` and a `request_id` are present, through `metered_embed` (reserve with stage `embedding` -> `mark_dispatching(guard)` -> `transport.embed` -> settle or unknown); Gemini goes through its own capped ledger. `PgDenseIndex.load` verifies set, source and config identity, row order, and each vector's checksum. `search` runs `EXACT_SQL` (cosine over `embedding_set_rows` joined to `embedding_payloads`, filtered by `row_order = ANY(allowed)`), or HNSW with strict-order iterative scan only when the activated run chose `dense_search: hnsw`. In hybrid modes dense search is skipped when no lexical match exists (`no_lexical_match:dense_not_used`).
