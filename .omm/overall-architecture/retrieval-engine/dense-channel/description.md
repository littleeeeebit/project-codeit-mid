`res.dense()` loads and verifies the activated `DenseIndex` once per (dense_version, index version); a failure records `stage_errors['dense']`, and retrieval falls back to kiwi_bm25 with a reason. `dense.query_vector` returns a pgvector-cached vector (cache 'hit'), a local GPU model's vector, a Gemini vector, or a paid OpenAI embedding through budget.reserve / mark_dispatching / settle. The paid path is taken only when the caller passes `allow_paid`; otherwise the reason is `paid_query_embedding_not_allowed`. In hybrid modes, dense search is skipped when no lexical or exact match exists (`no_lexical_match:dense_not_used`).
