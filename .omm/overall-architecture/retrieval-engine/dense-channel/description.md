`DenseIndex.search(query_vector, allowed, k, settings)` scores the allowed rows against the activated vector set (pgvector via `retrieval/vector_store.py`; model registry in `retrieval/models.py`, with local GPU embedders). When the matrix, the query vector or the dimensions are missing or mismatched, `retrieve` falls back to `kiwi_bm25` and records `fallback`. In hybrid modes, dense is skipped when no lexical or exact match exists (`no_lexical_match:dense_not_used`).
