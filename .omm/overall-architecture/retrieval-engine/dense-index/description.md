On SQLite, `dense.DenseIndex.load` verifies the dense manifest, the file hashes, the base keyword manifest hash, float32 dtype, shape, finiteness, unit norms and row-for-row chunk order before use. `search` is a dot product restricted to admitted rows. On PostgreSQL, `vector_store.PgDenseIndex.load` performs the equivalent identity checks over `embedding_sets`, `embedding_set_rows` and `embedding_payloads` (checksums, model/dimension/policy homogeneity, extraction scope), and explicitly refuses NumPy as a serving fallback. Query vectors are cached by normalized text, model and dimensions (`cache_get`/`cache_put`: `.runtime/embedding-cache` files or `embedding_payloads` rows). A corrupt entry counts as a miss.
