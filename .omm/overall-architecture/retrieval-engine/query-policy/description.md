`Analyzer` (Kiwi, `ANALYZER_VERSION kiwi-bm25-2`) tokenizes an analysis copy of the text. `normalize_for_analysis` collapses letter-spaced headings and applies `SPACING_ALIASES`. Requirement codes are matched exactly (`CODE_RE`) and pinned ahead of every ranker, with `code_not_found` / `code_ambiguous` limitations. For an all-documents scope, `route_corpus` keeps up to `ROUTE_MAX` (4) documents whose frozen title/institution terms (`scope-terms.json`) the question restates, using greedy IDF weighting. `scope_redundant_terms` drops terms present in more than half the scope's chunks and the selected project's restated name, but never codes, digits or negations, and only when a kept term still matches. A question that only names a project (`name_only_question`) ranks the named documents by dense similarity alone. `index_compatibility` flags an index built under another analyzer or before the metadata snapshot.
