Used only for `hybrid_rerank`, through `Resources.reranker()`, which loads `dense.load_reranker` once per (model, revision, max_length, concurrency, precision) and frees the GPU first. It reranks the fused pool below `rerank_protect` leading BM25 rows, up to `rerank_depth`. An inference exception serves the H order and records `hybrid_rerank->hybrid:reranker_error:...`. Queue and inference milliseconds go into `timings_ms`.
