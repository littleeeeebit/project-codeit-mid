`active_serving(settings)` reads `app_settings.active_run` and `active_index`, which `evaluation.activate_run` writes. With no run, it serves the keyword default. A run measured under a different corpus-routing rule (`corpus_route_record`) is served as the keyword default with a `fallback_reason`. An embedding model outside `ALLOWED_EMBEDDING_MODELS` drops to kiwi_bm25. An HR run from an older `EVAL_VERSION` keeps hybrid retrieval but drops the reranker. Requests, maintenance and latency sampling all read the activation through this function, so none of them serves a run that activation would refuse.
