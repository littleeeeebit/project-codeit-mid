Reads app_settings active_run and active_index per call. Without an activation it serves the keyword default (settings.retrieval_mode with fallback kiwi_bm25). If the activated run's corpus_route differs from corpus_route_record(), it serves the default with fallback_reason activated_corpus_route_requires_rerun. An embedding model outside ALLOWED_EMBEDDING_MODELS falls back to kiwi_bm25. A hybrid_rerank activation from an older EVAL_VERSION is demoted to hybrid without a reranker.
