Used only in `hybrid_rerank`. `Resources.reranker` loads `dense.LocalReranker` through `load_reranker`, keyed by model, revision, max length, concurrency and precision. It frees the GPU before loading a different model. `retrieve` keeps up to `rerank_protect` leading rows that came from BM25 and reranks the pool below them, up to the rerank depth. If inference throws, the H order is served and the fallback is recorded (`hybrid_rerank->hybrid:reranker_error`).
