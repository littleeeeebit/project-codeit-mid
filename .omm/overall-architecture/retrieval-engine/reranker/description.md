Applies only in `hybrid_rerank`. `Resources.reranker()` loads `dense.LocalReranker` per (model, revision, max_length, concurrency, precision), freeing the previous model's GPU memory first. `rerank_protect` keeps the BM25 head in place and reranks the pool below it up to `rerank_depth`. Any inference exception serves the hybrid order with `fallback: hybrid_rerank->hybrid:reranker_error`. The README says the local reranker failed its gate, so the current serving run does not use it.
