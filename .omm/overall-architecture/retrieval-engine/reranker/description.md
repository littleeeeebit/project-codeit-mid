Applies only in `hybrid_rerank`. `Resources.reranker()` loads `dense.load_reranker` keyed by model, revision, max length, concurrency and precision, freeing the previous GPU model first. `retrieval.retrieve` protects the leading BM25 rows (`rerank_protect`) and reranks the pool down to `rerank_depth`. An inference error serves the H order with `fallback=hybrid_rerank->hybrid:reranker_error:...`. `reranker_max_concurrency` must stay 1 (README: parallel preprocessing crashed on the real GPU).
