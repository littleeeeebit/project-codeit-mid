`_rerank` keeps up to `rerank_protect` leading BM25 rows in place and reranks the rest of the pool down to `depth` with the `LocalReranker` from `dense.load_reranker`. An inference exception serves the H order with fallback `hybrid_rerank->hybrid:reranker_error`. `Resources.reranker()` reloads only when the model, revision, max length, concurrency or precision changes, and frees the GPU before it loads.
