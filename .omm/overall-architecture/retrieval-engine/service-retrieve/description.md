Resolves the scope or, for all_documents, uses corpus_scope. It loads the active index (raising 'no index' when absent), retires GPU models the activation no longer uses, and applies the run settings and narrowed limits. In a dense mode it checks that the DenseIndex model and dimensions match the run's; on a mismatch it records stage_errors and serves without dense. It then gets a query vector through dense.query_vector with allow_paid and the request's _dispatch_guard. The call is wrapped in a `retrieve-evidence` tracing step that holds ranked chunk texts, timings and candidates. It appends index_outdated:<reason> when the index's analyzer or query policy is stale, and activated_run_stale:corpus_route when the activation was measured under another routing rule.
