`dense.query_vector` looks up the cache keyed by normalized text, model and dimensions (`embedding_payloads`). On a miss it chooses by backend: a local GPU model embeds for free; OpenAI goes through `metered_embed` (reserve, dispatch, settle in the shared ledger) only when `allow_paid` and a request ID are present, which means a paid answer; Gemini goes through its own capped `external_attempts` ledger. A miss without permission returns no vector, and retrieval falls back to K1 with `query_vector_unavailable`.
