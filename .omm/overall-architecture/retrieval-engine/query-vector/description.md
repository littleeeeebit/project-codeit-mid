`dense.query_vector` caches by normalized text, model and dimensions (`vector_store.cache_get` / `cache_put`). A local model (BGE-m3-ko) embeds a miss on the GPU for free. An OpenAI miss is paid only for a paid request (`allow_paid` with a request ID), through `metered_embed` on the same ledger and dispatch guard. Gemini uses its own cap and its own `external_attempts` ledger. A miss that is not allowed returns no vector, and retrieval falls back to K1.
