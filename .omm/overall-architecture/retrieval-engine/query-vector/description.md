`dense.query_vector` (dense.py:218) hashes the normalized question with the model, dimensions and 'query' policy, and looks it up in `embedding_payloads` (`vector_store.cache_get`, checksum-verified). A local model embeds a miss on the GPU for free. An API miss is paid only when `allow_paid` is set and a `request_id` exists (paid answers; evaluation with --allow-paid-queries): OpenAI goes through `metered_embed` in the shared ledger with the request's dispatch guard, Gemini through `models.gemini_embed` under its own cap. Without permission it returns `paid_query_embedding_not_allowed`, and retrieval falls back to kiwi_bm25 with the reason recorded. `_priced` adds the query-embedding estimate to the answer reservation only when a miss would be paid.
