`dense.query_vector` first looks up the pgvector cache, keyed by normalized text, model, dimensions and kind `query` (`vector_store.cache_get`). On a miss, a local model embeds on the GPU for free. An OpenAI miss is paid through `metered_embed` (reserve, dispatch, settle on the shared ledger) and only when `allow_paid` and a `request_id` are both present. A Gemini miss goes through its own capped ledger. The query embedding runs under the request's `_dispatch_guard`, so a cancelled request does not dispatch it.
