In `Resources.__init__`, entering `database_lifecycle` opens the psycopg pool and `_initialize` then sets everything up. It requires a validated import, runs `init_schema` and `budget.ensure_budget_row`, and claims gateway ownership through `_own`. `_own` borrows this process's existing `GatewayOwner` or takes `postgres.gateway_lock`. When it takes a fresh lock, it runs `recover_requests` and `budget.recover`. The transport is `FakeTransport` for `provider: fake`, `OpenAITransport` when `OPENAI_API_KEY` exists, or none with `provider_note = NO_API_KEY` until a browser enters a key (`set_api_key` then builds an OpenAITransport). `index()` reloads `KeywordIndex` whenever `active_serving()["index_version"]` changes. `dense()` verifies a pgvector set once per version and caches a refusal in `_dense_failed`. `reranker()` reloads only when its key changes. `retire_inactive` unloads GPU models the activated configuration no longer uses. `close()` rejects new work, drains the runner within `shutdown_wait_seconds`, joins jobs, runs recovery again if threads survive, then closes the transport and tracing and releases the lock. The stop is registered both with `threading._register_atexit` and with atexit, so uvicorn's SIGINT/SIGTERM closes it while workers are still alive.
