`Resources.__init__` enters `database_lifecycle`. `_initialize` then calls `postgres.require_imported_database`, `init_schema` and `budget.ensure_budget_row`, and with `recover=True` claims the gateway lock (`_own`). Claiming the lock runs `recover_requests` (queued/running → interrupted) and `budget.recover` (dispatching → unknown, reserved → released); nothing is replayed. Transport selection: `FakeTransport` for `provider: fake`; otherwise `OpenAITransport` from `OPENAI_API_KEY` if present, else `provider_note = NO_API_KEY` until a member enters a key on 설정 (`set_api_key` → `transport.set_key(session, key)`; `member_keys` and `key_sources` live in memory only). The resources also lazily load the serving `KeywordIndex`, `DenseIndex` (verified once per version; a failure is recorded in `stage_errors` and dense is skipped) and the reranker, keyed on everything its inference depends on. `close()` sets `_closed`, shuts the runner down with `shutdown_wait_seconds`, joins jobs, re-runs recovery if threads are still alive, closes transport then tracing, and releases the owner. It is registered on both `threading._register_atexit` and `atexit`, so workers see the stop before the executor joins them.
