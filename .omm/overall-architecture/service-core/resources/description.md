`Resources` is the process-wide owner. On init it holds the database lifecycle, requires the validated import, runs `init_schema` and `ensure_budget_row`, and with `recover=True` takes the gateway lock (`postgres.gateway_lock`). Holding the lock means no older process can still dispatch, so it then runs `recover_requests` and `budget.recover`. It builds `FakeTransport` for `provider: fake`, else `OpenAITransport` when an env key exists. Otherwise the transport appears on the first member key. Under `_index_lock` it lazily loads and caches the active `KeywordIndex`, the `PgDenseIndex` (verified once per version, and a failure is remembered so serving falls back to keyword) and the reranker. `serving()` reads the activation from the database on every call through `active_serving`, and `run_settings()` overrides limits and embedding with what the activated run measured. `close()` refuses new work, waits `shutdown_wait_seconds` for the runner and jobs, recovers whatever is still alive, closes the transport and tracing, and releases the lock. It is registered on both threading's exit hook and atexit.
