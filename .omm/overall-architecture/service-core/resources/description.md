`Resources` is the process-wide owner, created once by `get_resources(load_settings())` from `app_resources()` in the API lifespan. `_initialize` does the following in order: `postgres.require_imported_database`, `init_schema`, `budget.ensure_budget_row`, then `_own()`. `_own()` either borrows this process's live `GatewayOwner` or takes `postgres.gateway_lock`; with `recover=True` it then runs `recover_requests` and `budget.recover`. After that it builds a `FakeTransport` (provider 'fake') or an `OpenAITransport` (only if `OPENAI_API_KEY` exists; otherwise `provider_note = NO_API_KEY` until a member enters a key). It lazily loads `KeywordIndex` and `PgDenseIndex` per active version, with a failed dense load cached in `_dense_failed`, and loads the reranker per config key. It keeps `member_keys`, `key_sources` and `partials` (streamed text) in memory. `close()` sets `_closed`, shuts the runner down, joins the job threads up to `shutdown_wait_seconds`, re-runs recovery if any thread is still alive, closes the transport and then tracing, and releases the lock. It is registered on `threading._register_atexit` so it runs before the executors are joined.
