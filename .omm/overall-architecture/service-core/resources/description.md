`Resources.__init__` enters `database_lifecycle`. `_initialize` then calls `require_imported_database`, `init_schema` and `budget.ensure_budget_row`. With `recover=True`, or whenever a transport exists, `_own` either borrows this process's `GatewayOwner` or takes a new one, and a new one runs `recover_requests` and `budget.recover`. The transport is a `FakeTransport` when `provider == "fake"`. Otherwise it is an `OpenAITransport` built from `OPENAI_API_KEY` or later from a member key (`set_api_key`), and tracing is created alongside it. `close()` stops new submissions, calls `RequestRunner.shutdown(shutdown_wait_seconds)`, and joins job threads until the deadline. If any thread is still alive it reruns the recoveries. It then closes the transport and tracing and releases the owner and pool. `close` is registered both with `threading._register_atexit` and with `atexit`, so it runs before the executor's own exit join.
