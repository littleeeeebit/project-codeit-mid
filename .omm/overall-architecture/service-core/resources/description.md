`Resources.__init__` enters `store.database_lifecycle` (a bounded psycopg pool) and calls `require_imported_database`, `init_schema` and `ensure_budget_row`. With `recover=True` it takes the gateway lock (`_own` → `postgres.gateway_lock`) and runs recovery: `recover_requests` marks queued and running requests `interrupted`, and `budget.recover` turns dispatching attempts into `unknown` and reserved ones into `released`. It then builds `OpenAITransport` (from the environment key if present, otherwise per-browser keys later) or `FakeTransport` when `provider=fake`. It lazily loads `KeywordIndex`, `PgDenseIndex` and the reranker for whatever `active_serving` names. `run_settings()` overrides the process settings with the activated run's limits and embedding, so serving reproduces what was measured. `close()` stops admission, waits `shutdown_wait_seconds` for the runner and jobs, recovers anything still unfinished, closes the transport, flushes tracing, and releases the lock.
