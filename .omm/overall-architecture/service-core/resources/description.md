`Resources.__init__` / `_initialize`. With `provider='fake'` it never builds a real SDK client. Otherwise it reads `OPENAI_API_KEY` for the server-environment key, or waits for a member key through `set_api_key`. Any transport implies gateway ownership (`_own`). `index()` reloads when `app_settings.active_index` changes. `dense()` verifies a pgvector set once per version and records `stage_errors['dense']` on failure, so retrieval falls back visibly. `retire_inactive` unloads GPU embedders or the reranker that the activated row no longer uses. `run_settings()` overlays the activated run's embedding, limits and reranker settings onto the process settings, so serving reproduces what was measured.
