`_metadata_answer` returns CSV facts from `metadata_facts` per selected document. Unknown fields become missing fields, and conflicting fields set the status to `conflicting_evidence`. `_inventory_answer` requires exactly one indexed document. It lists every row of the `requirements` table for that index version and extraction, in source order, as evidence `R1..Rn`, with a completeness declaration that depends on the review status. Both complete inline inside `submit_answer`: the row is created as `running` and finished before the HTTP response returns. They never reserve budget or call a provider.
