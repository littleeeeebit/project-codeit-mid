`metadata` mode (`_metadata_answer`) answers from typed CSV metadata and recorded resolutions (`metadata_facts`: known, unknown, conflict, zero_review or resolved). `inventory` mode (`_inventory_answer`, `requirement_inventory`) lists the structured requirement rows of the serving index's `requirements` table. `submit_answer` runs both inline, without the executor and without any ledger attempt. They still persist a request row and a trace, so they can be conversation turns.
