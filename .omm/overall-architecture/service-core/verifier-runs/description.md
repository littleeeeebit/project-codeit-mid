`verifier_trace` runs free retrieval for one or two documents in a verifier-chosen mode with narrowing limits (`verifier_config`, `_narrow_limits`). It prices the prompt and persists the configuration, retrieval, token count and estimate in `verifier_runs` under a `vr-…` ID. `generate_from_run` submits a paid answer with the idempotency key `vgen-<run_id>`, so repeated presses produce one request. In `_paid_answer`, `_frozen_run_for` checks that the question, scope, mode and as-of date still match and that `resolve_verifier_config` still describes the current serving state. `_frozen_prep` then prices the run's own evidence without retrieving again, and `ceiling=frozen.estimate_micro_usd` makes `budget.reserve` refuse anything above the estimate the person consented to (`above_consented_maximum`).
