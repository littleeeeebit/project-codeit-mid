`open_evidence(request_id, evidence_id)` reads the evidence unit from the request's persisted `result_json` evidence map, never from model output. It adds neighbouring elements from `_ordered_elements`: the loaded index, or the preserved extraction artifact when a newer index dropped that revision. It also adds warnings `source_version_changed`, `extraction_revised`, `source_unreviewed`/`auto_flagged`/`needs_recovery` and `ocr_text`. `original_download` accepts only UUID doc IDs and 64-hex hashes, resolves the recorded path, requires it to sit directly in `settings.files_dir`, and re-hashes the bytes before returning them.
