`RequestRunner` wraps a `ThreadPoolExecutor(max_workers=request_workers)` (6) and a `BoundedSemaphore(request_admission)` (12). `submit_answer` calls `try_admit()` inside the `_create` transaction (`before_insert`), so a full queue is refused before any row is written. Workers receive only a request ID, run it under a copy of the HTTP request's contextvars (key session, model, billing scope), and release the slot when they finish. `shutdown()` marks queued requests `interrupted`, and also marks running ones `interrupted` when they do not finish within the wait.
