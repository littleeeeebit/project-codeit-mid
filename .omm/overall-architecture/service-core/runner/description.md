`RequestRunner` is a `ThreadPoolExecutor(request_workers)` plus a `BoundedSemaphore(request_admission)`. Workers receive only the request ID. `_run` → `run_queued`, which claims `queued → running` exactly once (only if `cancel_requested = 0`), rebuilds the request and principal from `request_json`, and executes. `shutdown` stops intake, waits, cancels futures, and marks queued (and, if still pending, running) rows `interrupted`.
