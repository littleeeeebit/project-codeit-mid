`RequestRunner` is a `ThreadPoolExecutor` with `request_workers` threads (6 per the README) and a `BoundedSemaphore` of `request_admission` slots (12). Workers receive only request IDs. `_run` calls `run_queued`, which atomically moves the row from `queued` to `running` when `cancel_requested = 0`. It rebuilds the `AnswerRequest` and `Principal` from the persisted `request_json` and then calls `_execute`. `shutdown()` stops accepting, waits, and marks queued rows (and still-running rows if any future is pending) `interrupted`.
