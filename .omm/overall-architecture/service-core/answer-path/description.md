`_execute` opens the Langfuse root trace `answer-question` (seed = request_id). `_execute_traced` then dispatches by mode and converts `_Stop`, `ServiceError` and any exception into a stored outcome through `done()` and `_finish`, so a request never stays `running` after an error. The paid branch (`_paid_answer`) is detailed under request-lifecycle: unavailable documents are rejected; follow-ups are rewritten (`_rewrite`); `_prepare_paid` retrieves and prices (single, compare per side, or corpus); empty evidence ends as `insufficient_evidence` without a call; `_generate` streams through `_metered_chat`; `_validated` checks citations; `_finish` stores the result and billing state. `_checkpoint` runs before every new paid stage.
