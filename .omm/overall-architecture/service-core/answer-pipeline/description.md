`_execute` wraps each request in one Langfuse root trace (`tracing.run`, with the trace id derived from the request id) and calls `_execute_traced`. That function dispatches to `_metadata_answer` or `_inventory_answer` (free; these complete inline in `submit_answer`) or to `_paid_answer`. It converts `_Stop` into cancelled or interrupted, `ServiceError` into `clarification_required`/failed, and any other exception into `technical_error`/failed, so a request never stays `running`. Every exit goes through `_finish`, which takes the attempts and the billing rollup from the ledger, keeps an already cancelled or interrupted status, stores `trace_json`/`result_json`, and drops `res.partials[request_id]`. Details are under request-lifecycle/paid-answer-stages.
