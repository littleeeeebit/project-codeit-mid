_execute opens one Langfuse trace seeded by request_id and calls _execute_traced. That dispatches to _metadata_answer, _inventory_answer (free) or _paid_answer. Every exit goes through done(), which calls _finish: it reads the request's attempts to derive billing_state (precedence unknown > pending > reconciled > settled > released), keeps an externally set interrupted/cancelled status, and writes result_json and trace_json. _Stop maps to cancelled/interrupted, ServiceError to clarification_required with status failed, and any other exception to technical_error with status failed. A request is never left running. See request-lifecycle/paid-answer-pipeline for the paid stages.
