Paid and long work started from the 검증 and 데이터셋 screens runs on daemon threads that are registered in `res._jobs`, so `close()` joins them. `start_drafting` runs `drafting._generate` against the `gold_eval` envelope under the consented maximum. `start_answer_evaluation` runs `answers.run_answers`, `start_judges` runs `judges.run`, and `start_maintenance` runs `maintenance.run`. Each refuses to start while the service is closing, has no key, or already runs a job of the same kind (`_EVAL_LOCK`, `_DRAFT_LOCK`, `_MAINTENANCE_JOB`). Failures go to `last-error.txt` or `error.txt` in the run folder, and rerunning resumes. Drafted rows reach the gold queue only through `submit_drafts` → `gold.submit`, and `gold_decide` refuses approval by whoever requested the drafting run.
