`_execute` opens one Langfuse trace (`tracing.run('answer-question', seed=request_id)`) and calls `_execute_traced`, which routes `metadata`/`inventory` to free answers and every other mode to `_paid_answer`. `_paid_answer` resolves scope and returns `ingestion_unavailable` when every selected document is unparsed or unindexed. It then checkpoints (`_checkpoint` → `_stop_reason`). If `previous_request_id` is set, `_conversation` loads up to 6 earlier turns plus up to 8 cited evidence units, and `_rewrite` makes a paid standalone-question call. `_prepare_paid` calls `prepare_answer`/`_prepare_compare` (retrieve + `_priced` builds the messages, counts tokens and estimates the reservation). An empty evidence set returns `insufficient_evidence` with no model call. After another checkpoint, `_generate` streams into `res.partials[request_id]`, and `_validated` runs `generation.validate_answer` as the traced guardrail step. Every exit goes through `done` → `_finish`, which writes `status`, `trace_json` and `result_json` and derives `billing_state` from the request's attempts (precedence unknown > pending > reconciled > settled > released). `_finish` keeps `interrupted`/`cancelled` if they were set meanwhile and drops the partial.
