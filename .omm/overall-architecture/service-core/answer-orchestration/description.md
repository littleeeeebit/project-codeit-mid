`_execute` opens one Langfuse trace per request (`tracing.run(... seed=request_id)`) and `_execute_traced` dispatches by mode. `metadata` and `inventory` are free and run inline. `single`, `compare` and `corpus` go through `_paid_answer`. `compare` uses `_prepare_compare`: one scoped retrieval per document with the single-document limits, merged with renumbered evidence IDs and per-side coverage. `corpus` calls `prepare_answer(all_documents=True)`. `_priced` builds the messages (`generation.build_messages`), counts tokens exactly with o200k plus framing and margin, and estimates the reservation, adding the query-embedding price on a cache miss. Every exit path goes through `done()` → `_finish`, which takes the billing state from the ledger. `ServiceError` becomes `clarification_required`/failed and any other exception `technical_error`/failed, so a request never stays `running`.
