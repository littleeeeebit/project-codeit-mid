`Resources.partials` maps request_id to the raw streamed JSON text. `_paid_answer` passes `on_delta=streamed` to `_metered_chat`, and `OpenAITransport._drain` calls it with the accumulated content for every chunk. `answer_progress` returns `generation.partial_answer(content)` only while the request is `running`, not cancel-requested, and owned by the same `generation_id`. `_finish` pops the entry once the validated result is stored. Because it is in memory only, streamed text is lost on restart; the persisted result is authoritative.
