`active_serving(settings)` reads the `active_run` and `active_index` rows through `get_app_setting`. With no run it serves the keyword default (`settings.retrieval_mode`, falling back to `kiwi_bm25`). A run whose recorded `limits.corpus_route` differs from `corpus_route_record()` falls back to the default with `fallback_reason=activated_corpus_route_requires_rerun`. An unknown embedding model falls back to `kiwi_bm25`. A `hybrid_rerank` run from an older `EVAL_VERSION` loses its reranker. `Resources.run_settings` overlays the run's measured limits, embedding model and dimensions, and reranker settings onto the process settings. `index()`, `dense()` and `reranker()` load and verify once per version under `_index_lock`. A dense set that fails verification is cached as failed (`_dense_failed`) and noted in `stage_errors`. `retire_inactive` unloads GPU models that the activation no longer uses.
