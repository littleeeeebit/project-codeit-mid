`active_serving(settings)` reads `app_settings.active_run` and `active_index` on every call. Without an activation it returns the keyword default (`settings.retrieval_mode`, fallback `kiwi_bm25`). It also degrades a stored activation: a different `limits.corpus_route` than `retrieval.corpus_route_record()` → keyword default with `fallback_reason=activated_corpus_route_requires_rerun`; an embedding model outside `ALLOWED_EMBEDDING_MODELS` → `kiwi_bm25`; `hybrid_rerank` under a superseded `EVAL_VERSION` → `hybrid` without the reranker. `Resources.run_settings(cfg)` overrides the process settings with the activated run's limits, embedding model/dimensions and reranker length/concurrency/precision, so serving reproduces what was measured.
