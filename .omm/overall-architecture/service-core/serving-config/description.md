`active_serving(settings)` reads `app_settings.active_run` and `active_index` on every call; `retrieve`, `_config_snapshot` and the maintenance steps all call it. With no activation it returns the keyword default `kiwi_bm25`. It refuses a stored run when the corpus-routing rule changed (`fallback_reason: activated_corpus_route_requires_rerun`) or its embedding model is unknown. It downgrades `hybrid_rerank` from a superseded `EVAL_VERSION` to `hybrid`. `Resources.run_settings(cfg)` overlays the run's recorded limits, embedding model/dimensions and reranker settings onto the process settings, so serving reproduces what was measured.
