`active_serving(settings)` reads `app_setting active_run` and `active_index` on every call. With no activation, it serves the keyword default (`settings.retrieval_mode`, falling back to `kiwi_bm25`). An activated run is overridden in three cases. If its recorded `limits.corpus_route` differs from `retrieval.corpus_route_record()`, the default serves with `fallback_reason=activated_corpus_route_requires_rerun`. If its embedding model is outside `ALLOWED_EMBEDDING_MODELS`, it serves keyword only. If it is a `hybrid_rerank` run from an older `EVAL_VERSION`, hybrid serves without the reranker. `Resources.run_settings(cfg)` overlays the run's measured limits, embedding model/dims and reranker length/precision/concurrency on the process settings, so serving reproduces what was measured. `retire_inactive` unloads GPU embedders and rerankers that the active configuration no longer uses.
