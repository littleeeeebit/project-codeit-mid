`Resources.partials` is an in-memory dict, `request_id` → raw streamed JSON so far. The `streamed` callback in `_paid_answer` writes it. `_finish` removes it. `answer_progress` returns `generation.partial_answer(content)` only while the request is running, not cancel-requested and owned by the same `generation_id`. `partial_answer` parses incomplete JSON with pydantic_core `from_json(allow_partial=...)`. It takes evidence IDs only from finished strings, strips inline `[E1]` markers and drops 'absence' claims. Partials are not persisted; a restart loses them, and only the validated outcome survives.
