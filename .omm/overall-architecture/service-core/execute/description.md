`_execute` opens one Langfuse trace per request (`tracing.run`, seeded by the request ID). `_execute_traced` dispatches by mode and maps exceptions to outcomes: `_Stop` → cancelled/interrupted, `ServiceError` → `clarification_required` (failed), anything else → `technical_error` (failed). Every exit goes through `done` → `_finish`, which derives `billing_state` from the request's attempts (precedence unknown > pending > reconciled > settled > released). `_finish` keeps a status that is already cancelled or interrupted, turns a completed-but-cancel-requested run into cancelled, writes `trace_json` and `result_json`, and drops the streamed partial.
