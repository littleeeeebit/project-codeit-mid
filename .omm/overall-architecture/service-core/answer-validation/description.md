_validated loads the stored chunk body for each evidence unit (_stored_quote) and calls generation.validate_answer inside a `validate-answer` guardrail span. The payload must parse against the strict JSON schema. Every claim must stay in scope and cite evidence of its own document, except a comparison inference, which may cite both sides. Cited quotes must equal the stored text. Conflicts need evidence, and a `source_absence_verified` missing field is refused, because top-k misses cannot prove absence. An answered status needs claims and summary evidence, and a comparison must cover both sides. Inline E-ids are stripped from the text. On failure the trace scores citation_valid = 0 and the request ends technical_error/failed with cost recorded and no retry.
