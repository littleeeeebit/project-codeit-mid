`set_api_key` validates the key format and checks it against the chosen model with a free metadata call (`generation.check_api_key`, which also returns the billing project). It then creates a fresh `secrets.token_urlsafe` key session: `Resources.set_api_key` → `OpenAITransport.set_key(session, key)`, plus `key_sources[session]` and `member_keys[member]`. Requests already running keep the session, client, model and project they started with, and replaced clients are kept until `close()`. Only the audit row records who set a key; no file, row, log or trace holds the key itself. `OpenAITransport._client` picks the client for `KEY_SESSION`, falls back to the server-environment key, and otherwise raises `ProviderError(pre_execution=True)`, so the reservation is released without a charge.
