`_paid_answer` returns `ingestion_unavailable` when every scoped document is quarantined or unindexed. Before each paid stage it calls `_checkpoint`, which raises `_Stop` when the request is cancelled or interrupted. A follow-up is rewritten first (`_rewrite`, stage `query_rewrite`, 1,500-token cap). Retrieval then runs by mode: `prepare_answer` for single or corpus, `_prepare_compare` (one subquery per document at single-document limits) for compare, or `_frozen_prep` when a verifier run is being generated. The earlier answer's cited units (`CARRIED_EVIDENCE` = 8) are appended and renumbered. No evidence yields `insufficient_evidence`, with no paid answer call. Otherwise it calls `_metered_chat` with `on_delta` writing `res.partials[request_id]`, validates the output, and stores the result through `_finish`.
