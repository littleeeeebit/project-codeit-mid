`_paid_answer` handles the modes single, compare and corpus. It returns `ingestion_unavailable` when every selected document is unparsed or not indexed. It resolves a frozen verifier run (`_frozen_run_for`) and calls `_checkpoint` before each paid stage. For a follow-up it rewrites the question (`_rewrite`). It then prepares the prompt and estimate: `prepare_answer`, `_prepare_compare` (one subquery per document at single-document limits) or the corpus path with `all_documents=True`. With no evidence it returns `insufficient_evidence`. Otherwise it calls `_generate` → `_metered_chat`, then `_validated` → `generation.validate_answer`, and stores the result with `_finish`. Every exit path goes through `done()` → `_finish`, which records the ledger-derived billing state and `_trace_outcome`.
