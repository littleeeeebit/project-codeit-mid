`_paid_answer` runs these steps. Resolve the scope and refuse with `ingestion_unavailable` if no selected document is parsed and indexed. Run `_checkpoint` (stop if cancelled or interrupted). For a follow-up, `_rewrite` makes one paid `query_rewrite` call into a standalone question. `_prepare_paid` → `prepare_answer` retrieves (a dense query vector may be paid), appends the previous answer's cited evidence (`_with_carried`), builds messages and counts tokens (`_priced`). With no evidence it returns `insufficient_evidence` without a model call. Otherwise it runs a checkpoint, then `_generate` → `_metered_chat` with `on_delta` streaming into `res.partials`. Last comes `_validated` (`generation.validate_answer` against the allowed evidence IDs, documents and stored quotes, scored `citation_valid`). A validation failure stores `raw_output` (capped at 4,000 chars) in the trace and ends as `technical_error`; it is billed and never retried. Compare mode uses `_prepare_compare`. A frozen verifier run reuses the run's evidence without new retrieval and refuses to exceed its consented estimate.
