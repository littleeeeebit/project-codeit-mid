run_queued claims queued -> running only when cancel_requested = 0, then rebuilds AnswerRequest and Principal from request_json. _execute opens a Langfuse trace seeded by request_id. _paid_answer runs these steps: (1) resolve scope; if every document is unparsed or unindexed, the outcome is ingestion_unavailable. (2) _checkpoint. (3) For a follow-up, _rewrite makes a paid `query_rewrite` call (1,500 max output tokens) producing a standalone question; then another _checkpoint. (4) _prepare_paid: retrieve plus _priced (build_messages, count_request_tokens, budget.estimate); compare mode retrieves once per document at single-document limits (_prepare_compare); corpus mode searches all indexed sources. (5) No evidence means insufficient_evidence. (6) _checkpoint, then _generate streams into res.partials. (7) _validated. (8) done() -> _finish. Any ServiceError ends as clarification_required/failed; any other exception ends as technical_error/failed, so a row never stays running.
