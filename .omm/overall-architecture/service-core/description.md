`src/rfp_assistant/service.py` holds every behaviour the screens and the CLI use. One `Resources` object per data directory owns the process's state. `RequestRunner` executes paid questions in the background. `active_serving` decides which retrieval configuration answers questions. The answer pipeline (`_execute` → `_paid_answer`) turns a persisted request into a stored, validated outcome. Paid evaluation, judge, drafting and maintenance threads are registered so that shutdown can join them.
