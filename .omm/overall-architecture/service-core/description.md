`src/rfp_assistant/service/service.py` holds the behaviour behind every screen and CLI path. `Resources` is the process owner. `submit_answer` and `answer` persist and execute answer requests. `RequestRunner` is the bounded executor. `_execute` -> `_paid_answer` -> `_metered_chat` is the paid answer pipeline, and `active_serving` resolves what retrieval serves. Background verifier jobs (drafting, answer evaluation, judges, maintenance) run as daemon threads registered in `Resources._jobs`, so `close()` can join them.
