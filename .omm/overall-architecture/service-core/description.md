src/rfp_assistant/service/service.py is the single façade the API and CLI call. Public functions take `(res, principal, ...)` and call `_authorize`, which uses `auth.require_any` on capabilities. Signed-in members are built by `auth.visitor()` with every capability, so the capability checks only narrow in-process callers such as the CLI and tests. The module also owns orchestration: the answer pipeline, the bounded request executor, frozen verifier runs, the gold review entry points, and the background paid jobs (drafting, answer evaluation, judges, maintenance).
