`src/rfp_assistant/service/service.py` holds every public behavior the screens and CLI call, each beginning with `_authorize(res, principal, ...capabilities)` (`auth.require_any`). Every signed-in member holds every capability. It owns process lifetime (`Resources`), bounded request execution (`RequestRunner`), the answer pipeline (`submit_answer` → `run_queued` → `_execute` → `_paid_answer`), frozen verifier runs, paid background jobs (drafting, answer evaluation, judges, maintenance) and the update fence (`open_paid_work`, `request_update`).
