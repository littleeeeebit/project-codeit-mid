`service/service.py` holds the behaviour every screen and CLI command calls. Public functions take `(res, principal, ...)` and authorize with `_authorize`. Every signed-in member holds every capability, and only in-process callers pass narrower principals. The module owns request execution, serving-configuration resolution, evidence opening, budget administration, and the starting and supervising of background paid jobs. It delegates retrieval to `retrieval/`, paid calls to `gateway/`, corpus-wide metadata answers to `metadata_answers.py`, drafting to `drafting.py`, and answer evaluation to `answers.py`.
