`src/rfp_assistant/service.py` holds every public operation, the process-wide resources, and request orchestration. Every public function first calls `_authorize(principal, capability...)`. This states the role the function serves rather than authenticating anyone, since UI visitors hold every capability. Paid flows reach the provider only through `_metered_chat` (chat) or `dense.metered_embed` (query embeddings). Both use the same reserve → mark_dispatching(guard) → call → settle/release/unknown sequence.
