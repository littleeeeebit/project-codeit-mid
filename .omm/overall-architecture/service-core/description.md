src/rfp_assistant/service/service.py holds the behaviour both the API and the CLI call. `Resources` is the process owner. It refuses a database without a validated import (`postgres.require_imported_database`), initializes the schema and budget row, claims or borrows the gateway owner, recovers what a previous process left (`recover_requests`, `budget.recover`), builds an OpenAI or Fake transport, and lazily loads the active keyword index, dense matrix and reranker keyed by the activated configuration (`active_serving`). `close()` stops intake, waits `shutdown_wait_seconds` for the runner and jobs, marks leftovers interrupted, closes the transport and tracing, and releases the lock.
