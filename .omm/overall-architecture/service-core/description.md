`service/service.py` is the authenticated public surface plus request orchestration. `_authorize` → `auth.require_any` names the capability each function serves; every signed-in member holds every capability (`auth.visitor`). The module owns the process resources, the bounded request executor, the ask pipeline, background job threads (drafting, answer evaluation, judges, maintenance) and the update fence. `service/answers.py`, `service/drafting.py`, `service/ops.py` and `service/update.py` are its satellites.
