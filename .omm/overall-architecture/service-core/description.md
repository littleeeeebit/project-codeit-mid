`service/service.py` holds the behaviour both entry points call. `Resources` is the process-wide owner. It enters `database_lifecycle`, requires the validated import, runs `init_schema`, ensures the budget row, and takes the gateway owner (`_own` → `postgres.gateway_lock`, then `recover_requests` + `budget.recover`). It builds `FakeTransport` or `OpenAITransport` and lazily loads the active keyword index, the dense set and the reranker. `RequestRunner` is the bounded executor for paid modes (`single`, `compare`, `corpus`). Free modes (`metadata`, `inventory`) run inline in `submit_answer`.
