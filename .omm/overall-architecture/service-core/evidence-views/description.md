`request_status`/`list_requests` build `RequestView` from the row plus its attempts: reserved total over open states, settled total, `billing_state`, and the parsed `result`. `open_evidence` resolves an evidence ID only from the request's stored evidence map. It reads neighbouring elements through `_ordered_elements`, which falls back to the preserved extraction artifact when the active index no longer holds that revision. `original_download` accepts only UUID `doc_id` with 64-hex `source_hash`, a path inside `files_dir`, and matching bytes.
