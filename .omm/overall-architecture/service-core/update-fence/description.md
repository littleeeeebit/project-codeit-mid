`service/update.py`. `UpdateWatch` polls the GitHub API every 300 s for main's head versus `build_head()`, the commit read once at startup. `request_update` raises `watch.accepting` under `res._runner_lock`, refuses while `open_paid_work` reports active requests, admitted slots, live jobs, or open/unknown attempts, and then atomically writes the `BIDMATE_UPDATE_REQUEST` marker. Root systemd units (`bidmate-update.path`/`.service` → `tools/infra/update.sh`) fast-forward, rebuild, restart and roll back. This module only reads their `result.json`/`update.log`. `fenced()` (accepting or marker present or result `running`) is wired into `Resources.update_fence` in the lifespan, and every paid admission checks it through `_refuse_while_updating`.
