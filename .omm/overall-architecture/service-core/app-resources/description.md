`Resources.__init__` / `_initialize` own six things. (1) The pool lifecycle. (2) Gateway ownership: `_own` either borrows this process's live `GatewayOwner` or takes the lock and runs `recover_requests` plus `budget.recover`. (3) The transport: `FakeTransport` when `provider == "fake"`; `OpenAITransport` when a server-environment key exists or a browser key is first set; otherwise `provider_note = NO_API_KEY`. (4) The shared Kiwi `Analyzer`. (5) The lazily loaded `KeywordIndex`, `DenseIndex` and reranker, each reloaded only when the activated version changes. (6) `partials`, an in-memory dict of streamed text keyed by request_id. `Resources(dispatch=False)` is the ledger-only owner that CLI admin commands use beside the live server: no transport, no lock, and any paid stage is refused at admission. `close()` marks the service closed, shuts down the runner within `shutdown_wait_seconds`, and joins jobs. If any job is still alive it re-runs recovery. It then closes the transport and tracing and releases the lock. `close()` runs from the lifespan, from `threading._register_atexit` (so it fires before the executor's own join), and from `atexit`.
