`Resources.__init__` enters `store.database_lifecycle` and runs `require_imported_database`, `init_schema` and `budget.ensure_budget_row`. With `recover=True` it takes the gateway lock (`_own` → `postgres.gateway_lock`), or borrows it when another `Resources` in the same process already holds it. Taking the lock also runs recovery: `recover_requests` marks queued and running requests interrupted, and `budget.recover` moves dispatching attempts to unknown and releases reserved ones. Nothing is replayed. The transport is `FakeTransport` for `provider: fake`, an `OpenAITransport` when `OPENAI_API_KEY` is present, or none with `provider_note = NO_API_KEY`. `index()`, `dense()` and `reranker()` reload lazily whenever `active_serving()` names another version. A dense set that fails verification is remembered in `_dense_failed`, so it is not reloaded on every question. `close()` sets `_closed`, shuts down the runner, joins the jobs until `shutdown_wait_seconds`, runs recovery again if threads are still alive, then closes the transport, flushes tracing and releases the lock. It is registered with both `threading._register_atexit` and `atexit`, so it runs before the executor's own join.
