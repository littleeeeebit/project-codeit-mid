`auth.Login.from_env` reads the hub URL, OAuth client settings and `BIDMATE_ALLOWED_USERS`, or `BIDMATE_LOCAL_MEMBER` for one local developer. Per the API docstring, it refuses the local member next to hub settings. `sign_in` exchanges the code and reads `/hub/api/user`. `member(token)` resolves the in-memory session. `auth.visitor(name)` builds the `Principal` that every service function receives.
