`_paid_answer` runs these steps. (1) If every scoped document is unparsed or unindexed, it returns `ingestion_unavailable`. (2) `_frozen_run_for` resolves a frozen verifier run, which allows no new retrieval. (3) `_checkpoint` runs before every paid stage. (4) A follow-up is rewritten into a standalone query by `_rewrite`, a paid `query_rewrite` stage. (5) Corpus mode tries `metadata_answers.route` first. (6) `_prepare_paid` retrieves and prices: `prepare_answer`, or `_prepare_compare` with one subquery per document, then `_priced`, which builds messages with `generation.build_messages`, counts tokens and estimates cost. (7) With no evidence it returns `insufficient_evidence` and makes no generation call. (8) `_generate` streams deltas into `res.partials`. (9) `_validated` runs `generation.validate_answer` against the allowed evidence ids, the doc ids and the stored quotes, and a citation error scores `citation_valid=0`. If the model output fails validation, `raw_output` (up to 4000 characters) is stored in the trace and the request ends `technical_error`. The cost is recorded and there is no retry.
