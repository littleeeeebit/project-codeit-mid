`Resources.index()` reloads `KeywordIndex.load` whenever the active index version changes. `dense()` loads and verifies the dense index once per version. On a `DenseError` it records `stage_errors['dense']` and remembers the failure, so retrieval falls back to keyword search without retrying until a new activation or a restart. `reranker()` reloads only when the key (model, revision, max length, concurrency, precision) changes, and frees the GPU first. `retire_inactive(cfg)` unloads local embedders and the reranker that the activated configuration no longer uses. The Kiwi analyzer is a process singleton (`shared_analyzer`).
