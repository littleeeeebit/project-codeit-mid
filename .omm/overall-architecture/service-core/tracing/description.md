`tracing.run` opens one Langfuse trace per executed request, seeded with the request ID. `tracing.step` spans cover `retrieve-evidence`, `assemble-evidence`, `rewrite-question`, `generate-answer` and `validate-answer`. Free scores (`citation_valid`, `insufficient_evidence`, `evidence_tokens`) come from existing checks. Secrets are masked on export. Tracing turns off when any `LANGFUSE_*` credential is missing.
