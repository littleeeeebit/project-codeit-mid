One paid chat stage. budget.reserve takes the request_id, member_id, stage, purpose (`interactive` for Resources), model, input_tokens and max_output_tokens, plus the frozen-run ceiling when there is one. A refusal returns budget_blocked, or clarification_required for above_consented_maximum. paid_refusal() (no transport or no key) releases the reservation with provider_unavailable. budget.mark_dispatching runs with _dispatch_guard, so a cancelled or interrupted request is released in the same transaction and raises _Stop. _call_and_settle calls transport.chat inside a `generation` tracing step. A pre-execution ProviderError (4xx) releases the attempt; other errors, a missing usage block or a failed settle mark it unknown. A successful settle records usage and cost on the span. There is no automatic retry anywhere.
