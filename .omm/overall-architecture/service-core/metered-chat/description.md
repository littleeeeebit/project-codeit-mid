`_metered_chat` is the single paid chat path, used for stage `query_rewrite` (`REWRITE_MAX_OUTPUT_TOKENS = 1500`) and stage `generation` (`generation_max_output_tokens`, 4000 per the README). The sequence: `budget.reserve`, which refuses `above_consented_maximum` when a frozen run's ceiling is exceeded and `budget_blocked` for other refusals; `res.paid_refusal()`, which releases the reservation as `provider_unavailable` when no key exists; `budget.mark_dispatching(attempt, _dispatch_guard)`, where a guard refusal of `cancelled`/`interrupted` raises `_Stop` and a ledger refusal returns `budget_blocked`; then `transport.chat(...)` inside a tracing step. Outcomes: `ProviderError(pre_execution)` → `release(confirmed_pre_execution=True)`; other provider errors → `mark_unknown`; missing usage → `mark_unknown`; otherwise `settle`, and a failed settlement → `mark_unknown` plus a `technical_error`.
