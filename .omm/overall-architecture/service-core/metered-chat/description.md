The one chat-call path for a request. It runs `budget.reserve` with stage, purpose 'interactive', model, counted input tokens, max output tokens and an optional consented ceiling. A refusal maps to budget_blocked or clarification_required, and a missing key (`paid_refusal`) releases the reservation. It then runs `budget.mark_dispatching` with `_dispatch_guard`, so the request's cancel/interrupt check and the dispatching marker share one transaction. Finally `_call_and_settle` calls `transport.chat(..., on_delta)` inside a `generate-answer`/`rewrite-question` generation span and settles, releases or marks unknown. It never retries.
