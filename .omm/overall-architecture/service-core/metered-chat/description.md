`_metered_chat` calls `budget.reserve` for the maximum cost: input tokens priced at the cache-write rate plus `max_output_tokens`. A refusal maps to `budget_blocked`, or to `clarification_required` for `above_consented_maximum`. `res.paid_refusal()`, for example a missing key, releases the reservation. `budget.mark_dispatching` runs the request's stop check (`_dispatch_guard` -> `_stop_reason`) inside the same transaction. A cancel or interrupt raises `_Stop`, and any other refusal maps to `budget_blocked`. `_call_and_settle` then calls `transport.chat`. A `ProviderError` with `pre_execution` releases the reservation. Any other failure, or a response without usage, marks the attempt unknown. Usage is settled with `budget.settle`, and a failure to settle marks the attempt unknown as well.
