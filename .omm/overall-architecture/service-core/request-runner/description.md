`RequestRunner` is a ThreadPoolExecutor (`request_workers`) plus a BoundedSemaphore (`request_admission`). `try_admit` acquires a slot under `res._runner_lock` after `_refuse_while_updating`; a full queue makes `submit_answer` raise '요청이 많아…' before any row or payment exists. Workers receive only request IDs and run `run_queued` inside a copied context. `shutdown` stops accepting, waits, cancels pending futures, and marks queued rows interrupted, plus running rows if any future is still pending.
