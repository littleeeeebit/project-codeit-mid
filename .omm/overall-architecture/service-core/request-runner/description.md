`RequestRunner` is a ThreadPoolExecutor with `request_workers` threads (README: 6) plus a BoundedSemaphore of `request_admission` slots (12). `try_admit` runs inside `_create`'s insert transaction, and only for a new idempotency key. `submit` runs `run_queued` in `contextvars.copy_context()`, so the member's key session, model and billing scope travel with the work. `shutdown` stops accepting, waits, cancels futures that have not started, and marks queued requests `interrupted`. It also marks running requests `interrupted` when futures were still pending at the deadline.
