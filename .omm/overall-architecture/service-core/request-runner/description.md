`RequestRunner` runs a ThreadPoolExecutor with `request_workers` threads (6 per README) and a BoundedSemaphore of `request_admission` slots (12). `try_admit` checks `_refuse_while_updating` and takes a slot under `_runner_lock`, then increments `admitted`. `open_paid_work` reads that counter because it is counted before the queued row exists. `submit` schedules `run_queued(request_id)` inside a copied contextvars context, so the member's key session and model carry over. `release` frees the slot when the worker ends.
