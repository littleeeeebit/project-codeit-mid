ThreadPoolExecutor(max_workers=request_workers, 6 per README) plus BoundedSemaphore(request_admission, 12). Each submit runs contextvars.copy_context().run(self._run, id). The worker therefore inherits the submitting member's KEY_SESSION, REQUEST_MODEL and BILLING_SCOPE. _run calls run_queued and always releases the slot. shutdown() stops accepting, waits, cancels unstarted futures and marks queued (and, if any worker is still pending, running) rows as interrupted.
