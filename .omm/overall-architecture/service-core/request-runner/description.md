`RequestRunner` is a `ThreadPoolExecutor(max_workers=request_workers=6)` plus a `BoundedSemaphore(request_admission=12)`. `submit_answer` calls `try_admit()` inside the `_create` transaction (`before_insert`), so a full queue is refused before any row or paid work exists. Duplicate idempotency keys never consume a slot. `submit()` runs `run_queued` inside `contextvars.copy_context()`, so the member's key session and model carry into the worker. `shutdown()` stops accepting, waits, cancels unstarted futures, and marks queued rows `interrupted`; it marks running rows `interrupted` only if futures are still pending.
