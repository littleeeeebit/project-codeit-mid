`RequestRunner` wraps a `ThreadPoolExecutor(max_workers=request_workers)` and a `BoundedSemaphore(request_admission)` (README: 6 workers, 12 admitted). `try_admit` runs under `res._runner_lock` and first calls `_refuse_while_updating`. `submit` schedules `contextvars.copy_context().run(self._run, request_id)`, so the member's key session and model travel with the job. `_run` calls `run_queued` and always releases the slot. `shutdown` stops accepting, waits, cancels queued futures, and marks queued requests (and running ones if any future is still pending) `interrupted`.
