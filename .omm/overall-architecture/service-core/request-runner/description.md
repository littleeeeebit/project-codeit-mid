`RequestRunner` is a `ThreadPoolExecutor(max_workers=request_workers)` (6) behind a `BoundedSemaphore(request_admission)` (12). `try_admit` runs under `res._runner_lock`, first calling `_refuse_while_updating`, then taking a slot and incrementing `admitted`. `submit_answer` calls it from `_create(..., before_insert=admit)`, so only a new idempotency key consumes a slot and a full queue is refused with no paid call. `_run` wraps `run_queued` and always releases the slot. `shutdown` stops accepting, waits, cancels futures, and marks queued requests interrupted, and running ones too if any are still pending.
