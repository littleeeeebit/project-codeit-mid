`RequestRunner` combines a `ThreadPoolExecutor(request_workers)` with a `BoundedSemaphore(request_admission)`. `admitted` counts slots taken before the queued row exists, and `update.open_paid_work` reads it. `submit` runs `run_queued` inside `contextvars.copy_context()`. Workers receive only request ids and never touch UI state. `shutdown` stops accepting and waits up to `shutdown_wait_seconds`. It then cancels unstarted futures and marks queued requests `interrupted`, and also marks running ones `interrupted` if workers are still alive.
