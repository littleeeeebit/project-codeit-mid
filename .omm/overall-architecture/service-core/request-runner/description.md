RequestRunner wraps a ThreadPoolExecutor (request_workers, 6 per README) and a BoundedSemaphore of request_admission slots (12). submit_answer calls try_admit() inside _create's insert transaction only for a new idempotency key, so a full queue is refused before the row exists and before any paid work. Workers receive only request IDs. shutdown() stops accepting new work, waits, cancels unstarted futures, marks queued requests interrupted and also running ones if futures are still pending.
