`RequestRunner` wraps a `ThreadPoolExecutor(request_workers)` (6 workers) and a `BoundedSemaphore(request_admission)` (12 slots). `submit_answer` calls `try_admit` inside the `_create` transaction, before the row is inserted, and only for a new idempotency key. A duplicate key reuses the earlier request and takes no slot. A full queue raises `ServiceError` before any paid work. `_run` calls `run_queued`, then releases the slot. `shutdown` stops accepting work, waits, and marks queued requests interrupted. Running requests are also marked interrupted when a worker is still pending; its in-flight attempt stays `dispatching`, so it becomes unknown after a restart.
