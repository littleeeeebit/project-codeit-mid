`RequestRunner` is a `ThreadPoolExecutor(request_workers)` (6) plus a `BoundedSemaphore(request_admission)` (12). `try_admit` runs inside `_create`'s insert transaction (`before_insert`), so a full queue refuses before any row or paid work exists. `submit` schedules `contextvars.copy_context().run(self._run, request_id)`. Workers receive only request IDs and rebuild everything from the persisted `request_json` snapshot (`run_queued`). `shutdown` stops accepting and waits. It marks `queued` rows `interrupted`, and marks `running` rows `interrupted` only if futures are still pending.
