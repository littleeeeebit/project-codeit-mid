`RequestRunner` is a `ThreadPoolExecutor(request_workers)` plus a `BoundedSemaphore(request_admission)`. The README states 6 workers and 12 admitted requests. A slot is taken in `admit()`, inside the same transaction that inserts a new request. A duplicate idempotency key never takes a slot. A full queue is refused before any paid work. Workers receive only request IDs and call `run_queued`. `shutdown()` stops accepting, waits `shutdown_wait_seconds`, cancels unstarted futures and marks queued requests `interrupted`. Running requests are marked `interrupted` only when some futures did not finish.
