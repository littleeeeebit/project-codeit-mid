`RequestRunner` wraps a `ThreadPoolExecutor(max_workers=request_workers)` and a `BoundedSemaphore(request_admission)`. The README states 6 workers and 12 admitted requests. `try_admit` runs under `res._runner_lock` and first calls `_refuse_while_updating`, so an accepted update never races a new admission. `submit` schedules `run_queued` in a copied contextvars context, and `_run` releases the slot when the request finishes. `shutdown` stops accepting, waits, cancels unstarted futures, and marks queued rows (and running rows when workers are still pending) as interrupted.
