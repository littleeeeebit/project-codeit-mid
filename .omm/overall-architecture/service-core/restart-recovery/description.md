`Resources.close()` sets `_closed`, then `RequestRunner.shutdown(shutdown_wait_seconds)` waits a bounded time and marks rows interrupted: queued rows always, running rows only if futures are still pending. It then joins the jobs, and if any is still alive it runs `recover_requests` and `budget.recover`. Finally it closes the transport and tracing and releases the gateway owner. Close is registered through `threading._register_atexit` so it runs before the executor's own join. On the next start, `_own` runs `recover_requests` (queued and running → interrupted, never replayed) and `budget.recover` (dispatching → unknown, reserved → released).
