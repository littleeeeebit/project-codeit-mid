`generation.validate_answer` parses the strict `AnswerPayload` JSON schema (`grounded-answer-12` prompt). It rejects unknown evidence IDs, citations outside a claim's `doc_id`, quotes that do not match `_stored_quote` (the chunk body in the loaded index), uncited claims or summaries, and compare answers that drop a represented side. Any failure becomes a `technical_error` result with the raw output saved in the trace. The cost has already been recorded and nothing is retried. The deterministic Langfuse score `citation_valid` comes from this step.
