`Resources.__init__`/`_initialize` runs a fixed sequence. It requires a validated import (`postgres.require_imported_database`), applies `init_schema` and `budget.ensure_budget_row`, and claims the gateway with `_own` → `postgres.gateway_lock`; a second Resources in the same process borrows the owner instead. The transport is `FakeTransport` for provider `fake`, otherwise `OpenAITransport` built from `OPENAI_API_KEY` or a key a member enters later. It also loads the shared Kiwi analyzer. It lazily loads and caches the active `KeywordIndex`, `DenseIndex` and reranker per serving version and exposes `update_fence`, a callable the API replaces with `UpdateWatch.fenced`. `_runner_lock` serializes runner creation, paid admission, job registration, `set_api_key` and `close()`.
