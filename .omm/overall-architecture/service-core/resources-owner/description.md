service.Resources is the process-wide owner. On construction it enters store.database_lifecycle (the bounded psycopg pool), calls postgres.require_imported_database, init_schema and budget.ensure_budget_row, and builds the transport. provider='fake' selects FakeTransport. Otherwise, if OPENAI_API_KEY is set, it builds OpenAITransport with owner_check bound to the gateway owner. Any transport forces _own(), which either borrows this process's GatewayOwner or acquires the advisory lock and then runs recover_requests + budget.recover. index() reloads KeywordIndex when active_serving().index_version changes. dense() loads PgDenseIndex once per version and remembers a failed verification in stage_errors so retrieval falls back visibly. close() stops admission, waits up to shutdown_wait_seconds for runner futures and job threads, and re-runs recovery if threads are still alive. It then closes the transport, flushes tracing and releases the lock. close() is registered through threading._register_atexit so it runs before executor joins.
