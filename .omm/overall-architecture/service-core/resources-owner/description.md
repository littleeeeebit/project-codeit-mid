`Resources.__init__` enters `database_lifecycle`, requires a validated import, runs `init_schema` and `budget.ensure_budget_row`, and with `recover=True` calls `_own`. `_own` either borrows this process's existing `GatewayOwner` (`postgres.borrow_owner`) or takes the advisory lock (`postgres.gateway_lock`) and recovers conservatively: `recover_requests` marks queued and running requests interrupted, and `budget.recover` turns dispatching attempts unknown and releases reserved ones. Transport choice: `provider == "fake"` → `FakeTransport`. Otherwise an `OpenAITransport` on `OPENAI_API_KEY` when present, or no transport with `provider_note = NO_API_KEY` until a member enters a key (`set_api_key` creates the transport lazily). `index()`, `dense()` and `reranker()` load and cache by the activated version. `dense()` remembers a verification failure (`_dense_failed`) so retrieval falls back without retrying every request. `run_settings()` overrides the process settings with the activated run's embedding, limits and reranker parameters, so serving reproduces what was measured. `retire_inactive` unloads GPU models the activation no longer uses. Member keys live only in memory (`key_sources`, `member_keys`).
