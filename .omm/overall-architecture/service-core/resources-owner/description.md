`Resources.__init__` enters `store.database_lifecycle` (the bounded psycopg pool) and calls `postgres.require_imported_database`, which refuses to start without a validated import or with an open recovery fence. It then runs `init_schema` and `budget.ensure_budget_row`. Transport selection: `provider='fake'` builds a `FakeTransport`; otherwise `OPENAI_API_KEY` builds an `OpenAITransport` whose `owner_check` is the gateway lock's `check`, plus Langfuse `Tracing`. No key leaves `transport=None` and `provider_note`. `_own` takes `postgres.gateway_lock`, or borrows this process's existing owner. Only a fresh owner runs recovery (`recover_requests` + `budget.recover`). `dispatch=False` gives a ledger-only owner used by the budget admin CLI beside the serving app. It also caches the Kiwi analyzer (one per process), the `KeywordIndex` (reloaded when `active_index` changes), the `DenseIndex` (verified once per version; a failure is remembered in `_dense_failed` and reported in `stage_errors`) and the reranker (reloaded only when the model/revision/length/concurrency/precision key changes). `retire_inactive` frees GPU models the activated configuration no longer uses.
