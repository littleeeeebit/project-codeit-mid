`Resources.__init__` enters `database_lifecycle` (the bounded psycopg pool), then runs `require_imported_database`, `init_schema` and `ensure_budget_row`. With `recover=True`, or when a transport exists, `_own` borrows this process's `GatewayOwner` or acquires a new one. A newly acquired owner runs `recover_requests` and `budget.recover`: unfinished requests become interrupted, dispatching attempts become unknown and reserved attempts are released. Nothing is replayed. For `provider == 'fake'` it builds `FakeTransport`. Otherwise it builds an `OpenAITransport` from `OPENAI_API_KEY`, or leaves `provider_note = NO_API_KEY`. It loads lazily: `index()` follows `active_index`, `dense()` verifies the vector set once per version and remembers a refusal in `_dense_failed`, and `reranker()` reloads the model only when the inference key changes. `retire_inactive` frees GPU models that the activation no longer uses. `set_api_key` stores a member's key only in memory, in a new key session. `close()` stops the runner, joins jobs, closes the transport and tracing, and releases the gateway. A Resources built with `dispatch=False` is ledger-only, for CLI budget administration next to the serving app.
