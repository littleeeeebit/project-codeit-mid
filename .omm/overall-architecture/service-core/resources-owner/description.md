`Resources.__init__` enters `store.database_lifecycle`, a pooled PostgreSQL target, and `_initialize` then does the following. It requires a validated import, runs `init_schema` and `budget.ensure_budget_row`. It claims or borrows the gateway owner (`_own`, which also runs restart recovery). It builds `FakeTransport` when `provider == "fake"`, or `OpenAITransport` when `OPENAI_API_KEY` is readable. With no key, `provider_note` explains that paid generation is unavailable, and free search still works. It creates `Tracing` only alongside a real transport. It lazily loads and caches `KeywordIndex`, `DenseIndex` and the reranker per active version under `_index_lock`. `serving()` re-reads the activation (`active_serving`) on every call. `run_settings()` overrides embedding, limits and reranker settings with the values the activated run measured. `retire_inactive` unloads GPU models that the current activation no longer uses.
