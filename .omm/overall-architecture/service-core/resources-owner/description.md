`Resources.__init__`/`_initialize` claims the data directory. With `recover=True` (the served app via `get_resources`/`app_resources`), or whenever a transport exists, it takes the `GatewayOwner` advisory lock, or borrows the process's existing one through `postgres.borrow_owner`. A fresh owner marks queued and running requests `interrupted` and moves `dispatching` attempts to `unknown`; nothing is replayed. `index()` reloads `KeywordIndex` when `active_index` changes. `dense()` verifies a `PgDenseIndex` once per version and records a failure in `stage_errors['dense']`, so retrieval falls back visibly. `reranker()` reloads only when model, revision, length, concurrency or precision change, freeing the GPU first. `run_settings()` overlays the activated run's embedding, limits and reranker settings so serving reproduces what was measured. `close()` stops the runner, joins background jobs with a deadline, re-runs recovery if any thread is still alive, closes the transport and tracing, and releases the lock. It is registered both with `threading._register_atexit` and with `atexit`.
