`Resources.__init__` enters `store.database_lifecycle` (the pool), then `_initialize` runs `require_imported_database`, `init_schema` and `ensure_budget_row`. With `recover=True` it calls `_own`, which takes `postgres.gateway_lock` (or borrows this process's owner) and runs `recover_requests` plus `budget.recover`. The transport is chosen here: `FakeTransport` for `provider: fake`, `OpenAITransport` when `OPENAI_API_KEY` exists (personal machines; never on the shared VM), otherwise none, and `provider_note = NO_API_KEY` until a browser enters a key. It lazily loads `KeywordIndex`, `PgDenseIndex` and the reranker, each keyed by the active version. `close()` is registered through `threading._register_atexit`, so a SIGINT stop runs it before `concurrent.futures` joins the workers. It rejects new work, waits up to `shutdown_wait_seconds`, marks unfinished work interrupted, closes the transport and tracing, and releases the lock.
