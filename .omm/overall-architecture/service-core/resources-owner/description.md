`Resources.__init__` enters `database_lifecycle` and runs `_initialize`. That calls `require_imported_database`, `init_schema` and `budget.ensure_budget_row`. With `recover=True` it calls `_own` → `postgres.gateway_lock` (`pg_try_advisory_lock`), else raises `GatewayLockError`. Recovery then runs `recover_requests` (queued/running → interrupted) and `budget.recover` (dispatching → unknown, reserved → released). It then builds `FakeTransport` for `provider: fake`, or `OpenAITransport` from `OPENAI_API_KEY` with `owner_check`. Lazy accessors: `index()` reloads `KeywordIndex` when `active_serving().index_version` changes. `dense()` loads and verifies `PgDenseIndex` once per version and remembers a refusal in `_dense_failed` and `stage_errors['dense']`. `reranker()` reloads on a model/revision/length/concurrency/precision key and calls `free_gpu` first. `retire_inactive(cfg)` unloads GPU embedders and rerankers the activated config no longer uses. `run_settings(cfg)` overlays the activated run's limits, embedding model/dims and reranker settings over process `Settings`, so serving reproduces what was measured. `close()` stops admission, waits `shutdown_wait_seconds` for the runner and jobs, recovers if threads are still alive, closes transport and tracing, then releases the lock. It is registered on `threading._register_atexit`, so it runs before executor workers are joined.
