`Resources.__init__` enters the database lifecycle, requires a validated import, initializes the schema and budget row, and with `recover=True` calls `_own`. `_own` takes `postgres.gateway_lock` (`pg_try_advisory_lock(GATEWAY_LOCK)` on a dedicated connection) and runs `recover_requests` (queued and running requests become `interrupted`) and `budget.recover` (dispatching attempts become `unknown`, reserved ones `released`). Nothing is replayed. It builds `FakeTransport` for `provider=fake`, `OpenAITransport` when an env key exists, and otherwise records `NO_API_KEY` until a member enters a key. It lazily loads and caches `KeywordIndex`, the pgvector `DenseIndex` (a failed verification is remembered per version) and the reranker. GPU models no longer used by the active configuration are retired (`retire_inactive`). `close()` refuses new work, waits `shutdown_wait_seconds` for workers and jobs, re-runs recovery if a job is still alive, closes the transport, flushes tracing, and releases the lock. A ledger-only variant (`dispatch=False`) serves CLI budget administration beside the running server.
