Resources(settings, recover=True) enters the database lifecycle, calls require_imported_database, init_schema and ensure_budget_row, then claims the gateway (postgres.gateway_lock, or borrow_owner when another Resources in the process holds it). On first ownership it runs recovery: recover_requests marks queued/running rows interrupted, and budget.recover turns dispatching attempts unknown and releases reserved ones. Nothing is replayed. It builds FakeTransport when provider='fake'; otherwise it builds OpenAITransport from OPENAI_API_KEY or from the first key a member enters. It lazily loads the active KeywordIndex, DenseIndex and reranker keyed by the activation. close() rejects new work, shuts the runner down, joins jobs until shutdown_wait_seconds, re-runs recovery if a job is still alive, then closes the transport and tracing and releases the lock.
