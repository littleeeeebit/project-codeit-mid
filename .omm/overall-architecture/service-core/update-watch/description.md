`UpdateWatch` records the commit that started the process (`build_head`) and polls GitHub main. `POST /api/update` (`request_update`) only writes a marker file named by `BIDMATE_UPDATE_REQUEST`. Root-owned systemd units then run `tools/infra/update.sh`, which fast-forwards, rebuilds, restarts, health-checks and rolls back on failure. While an update is accepted, `Resources.update_fence()` returns true, and `_refuse_while_updating` makes `RequestRunner.try_admit` and every job start refuse new paid work. `open_paid_work` reports in-flight work to the banner.
