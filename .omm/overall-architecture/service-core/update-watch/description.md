`UpdateWatch` (src/rfp_assistant/service/update.py) records `service.build_head()` at startup and polls GitHub `littleeeeebit/project-codeit-mid` main every 300 s without a token. `request_update` sets `accepting` under `res._runner_lock`, calls `open_paid_work` (thread and slot counts, then queued and running rows, then the ledger snapshot), refuses if anything is open, and writes the marker file named by `BIDMATE_UPDATE_REQUEST`. `fenced()` (accepting, the marker present, or result.json saying `running`) is checked at every paid admission. The module never runs git or systemctl.
