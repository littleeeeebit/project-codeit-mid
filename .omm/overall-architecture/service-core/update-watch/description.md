`service/update.py` `UpdateWatch.from_env(build_head())` polls the public GitHub repository for main's head. `request_update` sets `watch.accepting` under `res._runner_lock`, refuses while `open_paid_work` reports queued or running requests, admitted slots, live jobs, or open or unknown attempts, then atomically writes the marker file (`BIDMATE_UPDATE_REQUEST`) and an audit row. Root-owned systemd units (`bidmate-update.path` and `.service`, `tools/infra/update.sh`) perform the fast-forward, rebuild, restart and rollback. This module only reads their `result.json`. `Resources.update_fence` blocks new paid admissions while an update may restart the process.
