start_drafting (gpt-6-luna drafts, gold_eval envelope, below a consented maximum), start_answer_evaluation, judge runs and start_maintenance each run in a daemon thread under copy_context. The thread is appended to res._jobs under _runner_lock with the closed and update-fence checks. close() joins them and runs recovery if one outlives the deadline. Their outputs go to run folders under .runtime and to gold_candidates rows, which go through the review queue.
