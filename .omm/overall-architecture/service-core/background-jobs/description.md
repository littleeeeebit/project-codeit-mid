Paid or long work started from 검증 and 데이터셋 runs on daemon threads started with `contextvars.copy_context().run` and appended to `res._jobs`, so `close()` joins them. `start_answer_evaluation` → `answers.run_answers` with `PinnedResources` (purpose `gold_eval`). `start_judges` → `judges.run`. `start_drafting` → `drafting._generate` with a `guard` that returns `interrupted` once `res._closed`. `start_maintenance` → `maintenance.run`. One evaluation or judge run at a time (`_EVAL_LOCK` + `_refuse_closed_or_busy`), one drafting run (`_DRAFT_LOCK`), and one maintenance sequence. Each start publishes its run record (config.json, request.json or state.json) before returning, so the next overview read lists it. Failures are written as `last-error.txt`/`error.txt` beside the run, and settled calls stay settled.
