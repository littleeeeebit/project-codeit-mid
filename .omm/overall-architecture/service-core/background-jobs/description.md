Paid jobs run on daemon threads started under `res._runner_lock`, appended to `res._jobs` (joined by `close()`), and each is published as a run before the start call returns. `start_drafting` runs `drafting._generate` with the consented maximum and the `gold_eval` envelope, writing to `.runtime/.../drafts/<run_id>/`. `start_answer_evaluation` runs `answers.run_answers` from a loaded estimate; only `answer-finalists` is allowed from the screen. `start_judges` runs `judges.run`. `start_maintenance` runs `maintenance.run` with `closing=lambda: res._closed`. Only one evaluation or judge run at a time is allowed (`_EVAL_LOCK`, `_refuse_closed_or_busy`), and likewise one drafting run and one maintenance run. A failure writes `last-error.txt` or `error.txt`; rerunning resumes.
