These jobs share the process's gateway owner and transport. `start_drafting` runs `drafting._generate` (consented maximum, `gold_eval`). `start_answer_evaluation` runs `answers.run_answers` through `PinnedResources`, which serves the finalist run's configuration. `start_judges` runs `judges.run`. `start_maintenance` runs `maintenance.run`. Each one publishes its run directory or state before returning the run ID, so the next poll lists it. `_EVAL_LOCK` with `_refuse_closed_or_busy` allows one evaluation or judge run at a time; maintenance and drafting each allow one at a time. Exceptions are written to `last-error.txt` or `error.txt`. A run that was cut off is reported as `interrupted` on the next status read.
