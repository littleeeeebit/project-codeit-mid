Long paid jobs started from the screens run on daemon threads registered in `res._jobs`. `start_drafting` (gpt-6-luna drafting via `drafting._generate`, charged to `gold_eval`, only one at a time via `_DRAFT_JOBS`), `start_answer_evaluation`, `start_judges` and `start_maintenance` each check `paid_refusal`, the update fence and `res._closed` under `_runner_lock`. Drafting writes `request.json`, then `output/candidates.jsonl`, `invalid.json` and `receipt.json` under the drafts directory, or `error.txt`/`interrupted.txt` on failure. `submit_drafts` hands a completed run's valid rows to `gold.submit` (the `dev` review queue). Each job's dispatch guard returns `interrupted` once `res._closed` is set.
