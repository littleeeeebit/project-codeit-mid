Paid long-running work that starts from the screens. `start_answer_evaluation` (answers.run_answers) and `start_judges` (judges.run) share `_EVAL_LOCK`, run one at a time, and use `_refuse_closed_or_busy` then `_start_job`. `start_drafting` (drafting._generate, gpt-6-luna, `gold_eval` envelope) runs under `_DRAFT_LOCK`. `start_maintenance` (maintenance.run over STEPS backup → restore_check → ingest → fidelity → keyword → embedding → regression → report) allows one per process. Each checks `_refuse_while_updating` under `_runner_lock` and appends its thread to `res._jobs`, so `close()` joins it and `open_paid_work` counts it. A job failure is written to `last-error.txt`, `error.txt` or `interrupted.txt` in its run directory, and rerunning resumes.
