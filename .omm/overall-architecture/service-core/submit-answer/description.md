`service.ask` creates a new `generation_id`, which doubles as the idempotency key, and calls `submit_answer(AnswerRequest)`. `_validate_request` checks the mode, length and scope rules (compare needs exactly two documents, corpus needs none). `_conversation` checks that every earlier turn belongs to this member, has finished and has the same scope. Free modes (metadata, inventory) go to `_create(..., "running")` and execute inline. Paid modes go to `_create(..., "queued", before_insert=admit)`. Inside the insert transaction, `runner.try_admit()` takes a `BoundedSemaphore(request_admission)` slot, and a full queue is refused with no paid call. A duplicate idempotency key with the same `input_hash` returns the earlier request; a different input under the same key is refused. If `runner.submit` fails, the slot is released and the row is marked failed (`_fail_unscheduled`).
