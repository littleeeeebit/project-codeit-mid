`lifecycle(target)` counts references to one `ConnectionPool` per target, identified by a hash of the DSN; a changed DSN is refused. On first creation it probes the server: `require_server` refuses any version other than 18.6. `_configure` sets `lock_timeout` 5 s and `statement_timeout` 60 s and requires pgvector 0.8.6. `open_db` refuses to create a pool implicitly, so a caller must already be inside `database_lifecycle`. Rows come back as dict-like `Row`.
