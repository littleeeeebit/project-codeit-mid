`postgres.lifecycle(target)` creates one reference-counted `psycopg_pool.ConnectionPool` per DSN after a probe connection passes `require_server` (server_version_num 180006). Each pooled connection is configured with `lock_timeout` 5s, `statement_timeout` 60s and a pgvector 0.8.6 check. `open_db` refuses to run without an owner (`database_lifecycle`) or when the DSN changes. Connections autocommit; `tx()` opens a transaction, and `read_snapshot` runs REPEATABLE READ, READ ONLY. `store.open_db`/`tx` are thin wrappers, and `bind_sql` translates `?` placeholders.
