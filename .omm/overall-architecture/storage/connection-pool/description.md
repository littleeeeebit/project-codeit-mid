`lifecycle(target)` first probes the server for version 180006 and pgvector 0.8.6, then opens a reference-counted `ConnectionPool`. `open_db` refuses to run without a lifecycle owner. `tx(conn, immediate=True)` opens a transaction and runs `SELECT ... FROM application_mutex WHERE id = 1 FOR UPDATE`, serializing every immediate write: requests, attempts, adjustments, gold decisions and activation.
