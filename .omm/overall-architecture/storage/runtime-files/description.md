`.runtime/` (or `RFP_DATA_DIR`) holds the extraction artifacts (`extracted/<hash>/<fp>/elements.jsonl`), keyword indexes, runs, compare cells and tables, datasets, sealed sets, drafting runs, maintenance state and reports, OCR caches and prints. Writes go through `write_text_atomic` and `write_jsonl_atomic`. Backups go to `RFP_BACKUP_DIR` or a `-backups` sibling, never inside the runtime.
