`require_imported_database` blocks startup of the app and of every CLI command except check, load-check and restore-check in three cases: when `bidmate_recovery.control` exists without a verified receipt, when `migration_import.state` is not 'complete' or `migration_validation` did not pass for the same snapshot, or when any referenced original, extraction or index manifest (and every file the manifest lists) is missing or its hash has changed (`references_valid`). A failed `record_validation` also sets `database_control.paid_admission = false`.
