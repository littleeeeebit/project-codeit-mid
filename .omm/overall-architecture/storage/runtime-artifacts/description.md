`write_text_atomic`, `write_bytes_atomic` and `write_jsonl_atomic` replace files atomically under `RFP_DATA_DIR`. That covers extraction artifacts (`extracted/<source_hash>/<fingerprint>/elements.jsonl`), keyword indexes (`indexes/<version>/`), run directories (`runs/<run_id>/`), comparison tables and cells (`compare/`), drafting runs, OCR caches and maintenance state and reports. `ProcessLock` guards file-based ledgers such as the Gemini OCR ledger.
