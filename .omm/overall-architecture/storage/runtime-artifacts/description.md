Content under `RFP_DATA_DIR` includes: `extracted/<source_hash>/<fingerprint>/elements.jsonl`, `indexes/<version>/` (manifest, chunks, tokens, scope terms), `runs/<run_id>/` (frozen retrieval runs), `compare/` (matrix tables, cells, estimates), `ocr/<hash>/`, `reviews/printed/` (Hancom prints), `review/` (stage-review runs, annotations, taxonomy, decisions), `maintenance/` and `archive/` (cold dumps). Writes use `write_text_atomic` / `write_jsonl_atomic`.
