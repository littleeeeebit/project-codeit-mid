`embedding_payloads` stores each vector once per payload hash, model, dimensions and policy, with a checksum. `embedding_sets` and `embedding_set_rows` map one set version to the chunk order of its source keyword index. `publish` writes a set, and `PgDenseIndex.load(require_ready=False)` verifies it before it is marked ready. `cache_get` / `cache_put` serve both corpus and query vectors.
