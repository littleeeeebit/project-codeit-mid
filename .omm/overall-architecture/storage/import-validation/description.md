`require_imported_database` refuses startup in three cases: `bidmate_recovery.control` exists and is not `verified` with a passed receipt; `migration_import` is not complete; or `migration_validation` does not match. It then rehashes every referenced original, extraction and index manifest, including each file the manifest lists, through `host_path`, which honours `RFP_PATH_MAP`. `record_validation(passed=False)` also closes `database_control.paid_admission`.
