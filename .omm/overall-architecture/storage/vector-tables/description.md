`embedding_payloads` caches every corpus and query vector by payload_hash, with model, dimensions, policy and a checksum. `embedding_sets` holds one row per dense version, tied to its source keyword index, in state building or ready. `embedding_set_rows` maps row_order to chunk_id to payload_hash, with a foreign key to `chunks`. An optional HNSW index per dimension is built by `build_hnsw`. The README records that exact search serves, because HNSW missed recall@20 0.99.
