`require_imported_database`, `GatewayOwner.check` and `owner_guard` read three things: `migration_import` must be complete, `migration_validation` must have passed with a matching snapshot, and `bidmate_recovery.control/receipt` must not show an incomplete recovery. `references_valid` re-hashes every recorded original, extraction artifact and index manifest, together with the files each manifest lists. A failed validation sets `database_control.paid_admission = false`.
