`storage/postgres.py` provides the connection target, pooled connections with version checks (PostgreSQL 18.6, pgvector 0.8.6), `require_imported_database` (the migration import and validation markers plus artifact hashes), the gateway owner and recovery fences. `storage/store.py` provides `open_db`, `tx(immediate=True)`, `init_schema`, `dumps`, atomic file writes and the app settings. Durable records: `documents`, `sources`, `extractions`, `elements`, `requests`, `attempts`, `adjustments`, `budget_settings`, `database_control`, `verifier_runs`, `gold_candidates`, `fidelity_checks`, `activations`, `audit_events` and vector sets. Immutable artifacts (extraction JSONL, index files, runs, compare tables, drafts, OCR cache, prints) live under `RFP_DATA_DIR`.
