PostgreSQL is the only database (`storage/postgres.py`, `storage/store.py`). It is reached through one psycopg pool per DSN (`lifecycle`/`open_db`) with autocommit connections, a 5 s lock timeout, a 60 s statement timeout, and a `Connection` wrapper that rewrites `?` placeholders. Large immutable artifacts live under `RFP_DATA_DIR` (`.runtime`) and are referenced from rows by absolute path and SHA-256: extraction element JSONL, keyword index files, run directories, datasets, drafts and maintenance reports. On Linux, `host_path` remaps recorded Windows paths through RFP_PATH_MAP.
