`storage/postgres.py` holds pooled psycopg connections, a translation from `?` placeholders to psycopg parameters (`bind_sql`), transactions, schema creation, the import and recovery gates and the gateway owner. `storage/store.py` re-exports these as `open_db`, `tx`, `init_schema` and `database_lifecycle`, and adds `app_settings` access and atomic file writes. `postgres_backup.py` and `maintenance.py` run the owner's backup, restore-check and maintenance sequence.
