`storage/store.py` declares the application schema (`SCHEMA_VERSION = 6`). `storage/postgres.py` provides connections (pooled, version-checked: server 18.6 and pgvector 0.8.6), `tx(conn, immediate)`, the schema advisory lock, the import-validation marker, recovery fences, and the gateway lock. `vector_store.py` adds the pgvector tables. Connections open per operation and no transaction spans a network inference. Large artifacts (element JSONL, index directories, OCR caches, runs, comparison tables, drafts) live under `RFP_DATA_DIR` (`.runtime`) and are bound to rows by path and SHA-256.
