PostgreSQL (`bidmate_app`, DSN only from `RFP_DATABASE_DSN` in the process environment) holds every record: corpus, indexes, requests, traces, ledger, audit, gold and activations. pgvector holds the vector sets (`vector_store.SCHEMA`). Large immutable artifacts live under `RFP_DATA_DIR` (`.runtime`); rows reference them by path and hash. `storage/store.py` holds the schema and atomic file writes (`write_text_atomic`, `write_jsonl_atomic`). `postgres.py` handles connections and version checks (server 180006, extension 0.8.6). `postgres_backup.py` and `maintenance.py` handle backup, restore-check and the maintenance sequence.
