review/server.py is a standard-library `ThreadingHTTPServer` bound to 127.0.0.1 on a free port, started by `review.cmd` / `review.command`. On start it rebuilds `review/out` with npm when the review sources' digest changed. It reads `RFP_DATA_DIR` (environment or `.env`) and serves the review screens plus a small JSON API over `<data>/review`. It imports `rfp_assistant.evaluation.error_analysis` and `similar_cases`, both standard library only, by putting `src/` on `sys.path`. It never runs a pipeline, loads a model or pays.
