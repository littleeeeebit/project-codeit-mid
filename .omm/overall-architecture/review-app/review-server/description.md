`Handler._get` serves run lists, `view.json`, chunking docs, OCR images, zip export, annotation state (with `rereview` flags), per-run failure-type counts, saved decisions, taxonomy state and progress, and suggestion queues. `Handler._post` handles imports, decisions (`write_decision`), notes (`add_annotation` with `git config user.name` as author), and taxonomy export, decide, suggest-export and suggestion decide. Bad input → 400 (`ReviewInputError`), missing → 404.
