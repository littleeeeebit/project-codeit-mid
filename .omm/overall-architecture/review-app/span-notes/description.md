`annotations/<run-id>.jsonl` (`review-annotation-1`) is append-only: notes, edits, deletions, reviewed marks and hand-added `sample` records for traffic runs. The server refuses a note whose code-point offsets do not select the stored text of that answer field (`field_text`), and refuses duplicate IDs. `error_analysis.SOURCES` labels generation-run notes `gold` and traffic-run notes `traffic`.
