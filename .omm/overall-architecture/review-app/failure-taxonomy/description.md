`error-analysis export` (or the copy-prompt button) bundles notes that belong to no type for the coding agent. `error-analysis propose --file` admits a type only with a Korean one-line name, a one-sentence definition and existing unassigned notes. The person accepts, renames, merges, splits or rejects each type in the app (`ea.decide`). Decisions append to `taxonomy/history.jsonl`, and each change to the accepted set writes `taxonomy/versions/v<N>.json`. Progress counts answers with a note of a type over reviewed answers.
