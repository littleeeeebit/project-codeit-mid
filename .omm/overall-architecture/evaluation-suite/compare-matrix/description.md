`compare --matrix lexical|chunking|embedding|reranker` (`compare.MATRICES`) runs every declared variant on the same three populations and writes `.runtime/compare/tables/<matrix>.json`/`.md`, with each row also written as an activatable run. Cells, vectors and reranker scores are cached, so a rerun makes no provider call. Uncached paid corpus builds stop as `needs_approval` rows until `compare --approve` runs. `service.experiments` reads the tables for 검증 → 실험 비교 and marks the serving row; `experiment_questions` lists one row's failed questions. `compare.regression` supplies maintenance's regression table. The internals of compare.py were not read beyond these callers.
