`answers.plan_run` prices every remaining row (`price_row` uses `service.prepare_answer` and `_prepare_compare` with `allow_paid=False`) into a stored estimate. `begin_answers` publishes the run. `run_answers` executes each row through `service.answer(PinnedResources(...))`, which serves the finalist's recorded configuration and charges `gold_eval`. Resuming skips finished rows and rows with inconclusive billing (`_conclusive`). `score_record` and `aggregate_answers` compute Wilson-bounded rates. `export_review_sheet` and `import_reviews` handle the blind human verdicts; there is no paid judge in scoring. `plan_latency` and `latency_run` sample concurrent answers the same way.
