`evaluate-retrieval` freezes a run per mode under `runs/<run_id>/` (config.json, traces.jsonl, scores.json, report.md). The run is bound to the dataset hash, the evaluated population, the index manifest, analyzer, dense version, limits and `EVAL_VERSION`. Metrics are graded against source spans (hit@k, nDCG@5, MRR, packed coverage, critical failures, latency, Wilson intervals). `trial-reranker` scores the frozen H pool. Paid query embeddings require `--allow-paid-queries` and are charged to `gold_eval`.
