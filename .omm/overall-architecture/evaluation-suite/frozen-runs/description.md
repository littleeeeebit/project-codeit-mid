`evaluate-retrieval` writes `.runtime/runs/<run_id>/` (`config.json`, `traces.jsonl`, `scores.json`, `report.md`), frozen by dataset hash, evaluated population, index manifest, analyzer, dense version and limits under `EVAL_VERSION`. `load_run` reads them back. `run_errors` and `decision_errors` refuse a stale policy, a changed population, an incompatible index or a mismatched embedding revision. Those details come from the README and the function names; the scoring internals were not read.
