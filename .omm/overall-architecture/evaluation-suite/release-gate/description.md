`freeze-release` (sealed.py) records the release candidate's hashes and frozen dev and test manifests. The sealed test set then runs once, and any later run is labelled a post-test regression. `release-report` (release.py) decides `ready`, `limited` or `blocked` from recorded state. `backup` and `restore-check` (postgres_backup.py) take and verify custom-format dumps; a restore leaves paid admission off.
