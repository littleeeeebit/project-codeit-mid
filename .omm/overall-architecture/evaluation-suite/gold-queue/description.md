`gold_candidates` rows move pending → approved/rejected via `gold.decide`, with a required note, an `expected_sha` row hash and reject categories. Approved development rows are rendered to `.runtime/datasets/dev.jsonl`. Rejected rows go to the rejection wiki and await an inferred reason (`gold infer`). Approved rows marked `disputed` need `second_review`. `service.gold_decide` additionally refuses approval by whoever started the drafting run (`_drafting_meta(...).requested_by`). The web queue lists development candidates only; sealed `test` candidates are owner-CLI only.
