`evaluation.activate_decision`, called from the 실험 비교 activate route via `service.activate_experiment` or from CLI `activate-run`, loads the run, refuses on `decision_errors` (index and matrix verify, current policy, pinned embedding revision and prefixes), and then in one transaction sets the app settings `active_run` (serving config with `activated_at`) and `active_index`, and inserts an `activations` row with the previous value. The next `Resources.index()`/`dense()`/`reranker()` call reloads to match, and `retire_inactive` frees GPU models no longer used.
