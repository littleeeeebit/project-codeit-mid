PostgreSQL is reached through storage/postgres.py (a psycopg wrapper that rewrites ? placeholders and enforces the server and pgvector versions) and storage/store.py, whose SCHEMA defines sources, extractions, elements, chunks, indexes, requirements, app_settings, requests, attempts, adjustments, gold_candidates, activations and more. store.tx(immediate=True) runs SELECT ... FOR UPDATE on the single application_mutex row. database_control.paid_admission gates paid work. Large artifacts are files written atomically (write_jsonl_atomic, write_text_atomic) and referenced from rows by path and hash (extractions.artifact_path, indexes.manifest_path and manifest_hash). postgres_backup.py writes verified dumps and runs restore checks into an isolated database with paid admission off.
