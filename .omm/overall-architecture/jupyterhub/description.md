External identity provider: the team's JupyterHub on codeit:8000, where BidMate is registered as the OAuth service `bidmate`. `auth.Hub.authorize_url` builds `/hub/api/oauth2/authorize`. `auth.Hub.username` POSTs the code to `/hub/api/oauth2/token` from the server (`BIDMATE_HUB_API_URL`, defaulting to `BIDMATE_HUB_URL`), then GETs `/hub/api/user` with the bearer token. BidMate never sees a password and keeps no user table. A hub user who is not in `BIDMATE_ALLOWED_USERS` gets `LoginError(403)`, and network or JSON failures become `LoginError(502)`.
