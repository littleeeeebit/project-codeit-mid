`postgres.lifecycle`/`store.database_lifecycle` registers one pool per `Target`. `open_db` refuses when no lifecycle owns the pool or when the DSN hash changed. Every connection requires server 18.6, and pooled connections also require pgvector 0.8.6 (per README). `read_snapshot` gives a repeatable-read, read-only view. Stage-review workers get `PGOPTIONS=-c default_transaction_read_only=on` for the retriever, chunking and OCR-estimate passes.
