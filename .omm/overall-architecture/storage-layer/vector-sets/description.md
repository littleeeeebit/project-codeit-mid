`embedding_payloads` stores verified vectors keyed by payload hash, with model, dimensions, policy, checksum and provenance. They are shared by corpus chunks and cached queries. `embedding_sets` and `embedding_set_rows` map one keyword index's row order to payloads for one model. `publish` marks a set `ready` only after every row is verified. `build_hnsw` is offline maintenance, never run at startup.
