One PostgreSQL application database (`bidmate_app`, via `RFP_DATABASE_DSN`) holds documents, sources, extractions, elements, chunks, indexes, embedding sets and payloads, requests, attempts, adjustments, budget settings, audit events, gold candidates, activations and app settings (`active_run`, `active_index`). Large artifacts live under `RFP_DATA_DIR` (default `.runtime/`): extracted `elements.jsonl`, index directories, runs, compare tables, OCR caches, review run folders and annotations. The database records their hashes.
