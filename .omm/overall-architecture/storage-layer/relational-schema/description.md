`store.init_schema` applies the application schema plus `vector_store.SCHEMA` and `models.EXTERNAL_SCHEMA` under an advisory transaction lock, and refuses a schema newer than the code (`schema_migrations`). It also creates the `application_mutex` and `database_control` rows. `get_app_setting`/`set_app_setting` hold the serving pointers. `store.py` itself was only seen through these call sites.
