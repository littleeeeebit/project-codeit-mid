Tracing.from_settings builds a Langfuse client only when provider is openai and all three LANGFUSE_* values exist. It uses its own TracerProvider and a secret-masking export hook. tracing.run opens one root observation per executed request, with the trace ID derived from request_id. tracing.step nests retrieve-evidence, assemble-evidence, generate-answer (usage and ledger cost) and validate-answer. Free scores are citation_valid, insufficient_evidence and evidence_tokens. Every SDK call is wrapped by _guard and _observe, so a stopped or failing Langfuse never changes answers or the ledger. Drafting runs also receive res.tracing.
