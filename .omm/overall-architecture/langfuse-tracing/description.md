`tracing.Tracing.from_settings` creates a Langfuse client only when all three of `LANGFUSE_HOST`, `LANGFUSE_PUBLIC_KEY` and `LANGFUSE_SECRET_KEY` resolve (process environment, then `.env`). `Resources` creates it together with a real `OpenAITransport`, never for an injected or fake transport. `tracing.run(..., seed=request_id)` opens one root per executed `/api/ask` request, and drafting runs get their own root. `tracing.step` records nested observations only inside a run on the same thread, so verifier traces and evaluation runs are not traced. Steps: `retrieve-evidence` (ranked chunks with text), `assemble-evidence` (packed evidence, prompt tokens), `generate-answer` (model, usage, ledger cost) and `validate-answer`. Payloads are built lazily, and every SDK call is guarded. `mask_otel_spans` is the single export gate: it redacts secret-shaped strings recursively through JSON and fails closed to `[REDACTED]`. `Resources.close` flushes after the workers finish.
