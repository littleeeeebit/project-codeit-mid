`tracing.Tracing.from_settings` creates a Langfuse client only when all three `LANGFUSE_*` values exist, and swallows client errors. `service._execute` opens one trace per executed request (`tracing.run('answer-question', seed=request_id)`; trace ID = `create_trace_id(seed=request_id)`). Spans cover `retrieve-evidence`, `assemble-evidence`, `rewrite-question`/`generate-answer` (generation, with usage and ledger cost) and `validate-answer`. Free scores `citation_valid`, `insufficient_evidence` and `evidence_tokens` are attached. `mask_otel_spans` redacts secret-shaped values. `_guard` makes every tracing call best-effort, so admission, reservation and settlement never read it. Drafting runs are traced too (`tracer=res.tracing`).
