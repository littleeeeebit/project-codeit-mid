src/rfp_assistant/tracing.py. Tracing.from_settings is created with the OpenAI transport when LANGFUSE_* credentials exist. service._execute opens `answer-question` (trace ID seeded from request_id) with child steps rewrite-question, retrieve-evidence, assemble-evidence, generate-answer and validate-answer. It scores citation_valid, insufficient_evidence and evidence_tokens. Drafting runs get their own trace. Payloads are lazy lambdas; mask_otel_spans redacts secret-shaped strings on export. Every SDK call is guarded, so a stopped Langfuse changes neither answers nor the ledger.
