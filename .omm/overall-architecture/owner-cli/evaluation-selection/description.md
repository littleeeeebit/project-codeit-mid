`evaluation.py` validates gold datasets, runs frozen retrieval runs (`.runtime/runs/<run_id>/config.json, traces.jsonl, scores.json, report.md`, bound to dataset hash, evaluated population, index manifest, analyzer, dense version and limits) and scores them against source spans (hit@k, nDCG@5, MRR, packed coverage, Wilson intervals). `activate_decision` (from `activate-run`, a decision file, or the 실험 비교 view through `service.activate_experiment`) runs `decision_errors` and `run_errors`. Then, in one immediate transaction, it sets `active_run` to `serving_config(...)`, sets `active_index`, and appends an `activations` row holding the previous configuration.
