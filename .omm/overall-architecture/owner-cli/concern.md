`Resources._initialize` takes gateway ownership only when it builds a transport. With provider 'openai' and no OPENAI_API_KEY (the shared host has none), `Resources(settings)` from `cli maintain` takes no advisory lock. It could then run beside the server and its own maintenance thread, writing ingest results and indexes concurrently. This comes from reading the code, not a runtime test; the `_paid_resources` docstring promises a refusal.
