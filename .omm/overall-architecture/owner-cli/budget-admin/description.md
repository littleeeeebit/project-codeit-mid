Owner-only commands `configure-budget`, `paid on|off` (`set_paid_enabled` sets the ledger switch and `database_control.paid_admission` together), `set-envelopes`, `unresolved`, `settle` (`settle_from_evidence`), `reconcile`, `adjust` (`add_adjustment`, idempotent per `correction_key`) and `audit`. Each needs `--actor` and a reason and writes an audit row. The 설정 page can only change the shared cap (`PUT /api/budget/limit` → `budget.set_limit`), keeping spent and pending amounts intact.
