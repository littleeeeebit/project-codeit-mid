`fidelity run` prints each HWP through Hancom Viewer to PDF (Microsoft Print to PDF) as an independent witness and compares it both ways with 6-character shingles and exact digit runs. It sets `auto_verified` or `auto_flagged` with element, cell and page findings, and never overwrites a human review status. The internals were not read; this follows the README and `ingestion.printed_pdf_path`/`render_pages`.
