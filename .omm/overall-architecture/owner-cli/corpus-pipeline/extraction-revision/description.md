`assign_revision` binds the extraction ID to the actual output. The same fingerprint with identical elements keeps its ID; different output gets a content-addressed ID beside the old one, whose artifact and element rows stay for pinned gold rows and citations. `ingest_source` then writes `extractions`, replaces `elements` (`_store_elements`), records `extraction_inputs` with diagnostics (`diagnose`) and sets `sources.active_extraction_id`. Review status is reset to `unreviewed` unless the active extraction is unchanged. A source that `recover-source` replaced with an owner-approved conversion is not reparsed.
