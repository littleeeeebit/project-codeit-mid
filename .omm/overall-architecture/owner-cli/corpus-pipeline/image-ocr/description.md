`cli ocr` runs PaddleOCR-VL locally on GPU over embedded HWP pictures (BinData; WMF/EMF rendered on Windows) and PDF raster images, caching results per region under `.runtime/ocr/<hash>/`. Regions that fail the fallback test (loop, low mean probability, length far from the ink estimate) are re-read by gpt-5-mini through the gateway, from the `ocr` envelope (which starts empty). On the next `ingest`, `ocr.merge_hwp`/`ocr.merge` insert `image_text` elements and append an OCR suffix to the parser fingerprint, so OCR changes create a new extraction revision.
