`python -m rfp_assistant.cli <command>`, with about 50 subcommands registered via `add_parser`. Corpus: `init`, `manifest`, `ingest` (→ `ingestion.ingest`), `fidelity`, `ocr`, `review`, `import-reviews`, `recover-source`, `resolve-metadata`. Retrieval: `build-keyword`, `plan-embeddings`, `build-dense`, `evaluate-retrieval`, `trial-reranker`, `compare`, `compare-runs`, `draft-activation`, `activate-run` (→ `evaluation.activate_run` / `activate_decision` with actor `owner-cli:<name>`). Phase 4: `validate-gold`, `freeze-dataset`, `plan-run`, `run-answers`, `export-review`/`import-review`, `freeze-release`, `backup`, `restore-check`, `release-report`, `judge-*`. Budget: `configure-budget`, `paid`, `reconcile`, `settle`, `adjust`, `unresolved`, `audit`, `set-limit`, `set-envelopes`. These use `service.Resources(settings, dispatch=False)`, a ledger-only owner that never takes the gateway or a transport. `maintain` → `maintenance.run`. `check`/`load-check` run gates on temporary databases from `RFP_POSTGRES_TEST_DSN`.
