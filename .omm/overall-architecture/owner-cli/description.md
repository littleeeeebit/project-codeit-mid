`python -m rfp_assistant.cli <command>`. `main` enters `store.database_lifecycle(settings.db_path)`, runs `require_imported_database` (except for `init`) and `init_schema` (except for read-only `budget-report`), then dispatches through `COMMANDS`. `check` and `load-check` build isolated databases on `RFP_POSTGRES_TEST_DSN` with the fake provider. `restore-check` restores into `RFP_RESTORE_DATABASE_DSN`. Command groups: corpus (manifest, ingest, import-reviews, recover-source, identity, resolve-metadata, review, fidelity, ocr); index (build-keyword, plan-embeddings, build-dense); selection (evaluate-retrieval, trial-reranker, compare-runs, draft-activation, activate-run, report); gold and release (gold, validate-gold, freeze-dataset, plan-run, run-answers, latency-run, score-answers, export-review, import-review, freeze-release, release-report, judge-reference, judge-refit); operations (backup, restore-check, check, load-check); budget (configure-budget, budget-status, budget-report, reconcile, unresolved, settle, adjust, paid, audit, set-envelopes, set-limit, register-embedding-rate). Paid maintenance commands use `_paid_resources` → `service.Resources(settings)`, the same gateway and lock as the UI.
