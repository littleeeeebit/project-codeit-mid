`python -m rfp_assistant.cli` -> `main` dispatches subcommands (`init`, `manifest`, `ingest`, `fidelity`, `ocr`, `build-keyword`, `plan-embeddings`, `build-dense`, `evaluate-retrieval`, `trial-reranker`, `compare`, `compare-cap`, `activate-run`, `gold *`, phase-4 commands, `check`, `load-check`, `restore-check`, `configure-budget`, `budget-status`, and budget administration). Budget administration (`unresolved`, `settle`, `reconcile`, `adjust`, `paid`, `audit`) builds `service.Resources(settings, dispatch=False)`, a ledger-only owner that runs beside the serving app; each command requires `--actor` and a reason. Commands that dispatch (for example `build-dense`) build a full `Resources`, which needs the gateway lock. `check` and `load-check` use temporary databases on `RFP_POSTGRES_TEST_DSN`.
