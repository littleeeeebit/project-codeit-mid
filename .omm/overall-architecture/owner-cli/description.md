`python -m rfp_assistant.cli <command>` (argparse in src/rfp_assistant/cli.py) covers the owner workflows: init, manifest, ingest, ocr, fidelity, build-keyword, plan-embeddings, build-dense, evaluate-retrieval, compare, activate-run, maintain, stage-review, error-analysis, gold, run-answers, release-report, backup, restore-check, budget and paid commands, reconcile, check and load-check. Paid commands use `_paid_resources` → `Resources(settings)`, which shares the gateway lock with the server, so 'stop the UI first'. Budget administration uses `Resources(settings, dispatch=False)` beside the running app. `check` and `load-check` use temporary databases on RFP_POSTGRES_TEST_DSN with FakeTransport.
