`python -m rfp_assistant.cli` has 55 subcommands. These are the offline and owner-only paths: corpus ingestion and review, index builds, embedding plans and builds, retrieval and answer evaluation, comparison matrices, activation, the sealed run and release report, backup and restore-check, budget configuration and reconciliation. Every command except check, load-check and restore-check runs against `RFP_DATABASE_DSN` and refuses an unvalidated database.
