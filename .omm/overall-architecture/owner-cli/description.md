`python -m rfp_assistant.cli <command>` (argparse in `cli.py`). Commands: corpus (`manifest`, `ingest`, `fidelity`, `ocr`, `build-keyword`, `recover-source`, `resolve-metadata`), retrieval selection (`evaluate-retrieval`, `compare`, `compare-runs`, `activate-run`), evaluation (`plan-run`, `run-answers`, `latency-run`, `export-review`/`import-review`, `freeze-dataset`, `freeze-release`, `release-report`), judges (`judge-reference`, `judge-set`, `run-judges`), operations (`maintain`, `backup`, `restore-check`, `check`, `load-check`), and budget administration (`configure-budget`, `paid`, `set-limit`, `set-envelopes`, `unresolved`, `settle`, `reconcile`, `adjust`, `audit`). Paid commands build `service.Resources(settings)` (`_paid_resources`), which takes the gateway lock and therefore refuses while the UI owns it ('stop the UI first'). Budget admin commands use `Resources(settings, dispatch=False)`, a ledger-only owner that can run beside the serving app. `build-keyword` moves `active_index` only for the structural profile and only before any `activate-run` selection exists.
