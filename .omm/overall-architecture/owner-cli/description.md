`python -m rfp_assistant.cli <command>`: `cli.main` enters `store.database_lifecycle(settings.db_path)` and, for everything except `init`, requires a validated import. `check`, `load-check` and `restore-check` run against temporary or isolated databases (`RFP_POSTGRES_TEST_DSN`, `RFP_RESTORE_DATABASE_DSN`) with the fake provider. Paid owner commands (`build-dense`, `run-answers`, `compare --approve` builds) use `_paid_resources` = `service.Resources(settings)`, which takes the gateway lock and therefore refuses while the UI serves; stop the UI first. Ledger-only commands (`reconcile`, `unresolved`, `settle`, `adjust`, `paid`, `audit`, `set-limit`) use `Resources(dispatch=False)` and run beside the live server. Other groups: corpus (`manifest`, `ingest`, `fidelity`, `ocr`, `build-keyword`), selection (`evaluate-retrieval`, `compare`, `compare-runs`, `activate-run`), gold (`gold submit/decide/second-review/infer/check/repin`), and release (`freeze-dataset`, `plan-run`, `freeze-release`, `backup`, `release-report`).
