`python -m rfp_assistant.cli <command>`, wrapped on codeit by tools/infra/bidmate-cli.sh, which loads `/etc/bidmate/server.env` and runs as user bidmate. Command groups: corpus (init, manifest, ingest, ocr, fidelity, review, import-reviews, recover-source, identity, resolve-metadata); indexes (build-keyword, plan-embeddings, build-dense); selection (evaluate-retrieval, trial-reranker, compare, compare-runs, draft-activation, activate-run); phase-4 evaluation (validate-gold, freeze-dataset, plan-run, run-answers, latency-run, export-review, import-review, freeze-release, release-report); judges; maintain; backup and restore-check; budget administration (configure-budget, paid, settle, reconcile, adjust, set-limit, set-envelopes, unresolved, audit); and gates (check, load-check). Budget administration uses `Resources(settings, dispatch=False)` so it can run beside the serving app. Paid commands (build-dense, run-answers, latency-run, run-judges) use `_paid_resources` = `Resources(settings)`, which raises `GatewayLockError` while the UI owns the gateway, hence 'stop the UI first'.
