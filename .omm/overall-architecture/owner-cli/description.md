An argparse CLI in `cli.py` with about 60 subcommands. Corpus: init, manifest, ingest, ocr, fidelity, review, import-reviews, recover-source, identity, resolve-metadata. Retrieval: build-keyword, plan-embeddings, build-dense, evaluate-retrieval, trial-reranker, compare, activate-run. Evaluation and release: gold, validate-gold, freeze-dataset, plan-run, run-answers, freeze-release, backup, restore-check, release-report, maintain. Budget: configure-budget, paid, reconcile, settle, adjust, set-limit, unresolved, audit. The budget administration commands build `service.Resources(settings, dispatch=False)`, a ledger-only owner with no transport and no gateway lock, so they run beside the serving app. Paid maintenance commands use `_paid_resources`, which builds a full `Resources`; it raises `GatewayLockError` while the UI holds the advisory lock, so the UI must be stopped first. `build-keyword` moves `active_index` only for the structural profile and only while no `active_run` exists. `check` and `load-check` run against temporary databases on `RFP_POSTGRES_TEST_DSN`, and `restore-check` runs against `RFP_RESTORE_DATABASE_DSN`.
