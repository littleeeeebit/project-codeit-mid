src/rfp_assistant/cli.py dispatches argparse subcommands to `cmd_*` functions. Corpus: `manifest`, `ingest`, `ocr`, `fidelity`, `review`, `recover-source`, `resolve-metadata`. Index: `build-keyword`, `plan-embeddings`, `build-dense`. Evaluation: `evaluate-retrieval`, `compare`, `activate-run`, `plan-run`, `run-answers`, `freeze-release`, `release-report`. Ledger administration (owner only, each with `--actor` and a reason): `configure-budget`, `paid`, `unresolved`, `settle`, `reconcile`, `adjust`, `set-envelopes`, `set-limit`, `audit`. Gates: `check --phase`, `load-check` on temporary databases. Also `maintain` and `gold`. Paid commands build `service.Resources(settings)` (`_paid_resources`), which takes the gateway lock, so they refuse while the UI owns it.
