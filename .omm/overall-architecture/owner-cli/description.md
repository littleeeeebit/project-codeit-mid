python -m rfp_assistant.cli <command>. main() enters store.database_lifecycle, calls require_imported_database and init_schema (except for init and the read-only budget-report), and dispatches through COMMANDS. check and load-check run with provider=fake against isolated databases on RFP_POSTGRES_TEST_DSN, never the live one. restore-check uses RFP_RESTORE_DATABASE_DSN. Paid CLI commands (build-dense, run-answers, latency-run) construct service.Resources(settings), which must win the gateway advisory lock, so they fail with GatewayLockError while the API server owns it. That is why the README says to stop the UI first. Budget administration (unresolved, settle, reconcile, adjust, paid, audit) uses Resources(dispatch=False) and can run beside the server.
