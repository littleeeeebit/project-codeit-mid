`python -m rfp_assistant.cli` is the operator entry point, with about 100 subcommands registered in `cli.main`. The groups are: corpus (`manifest`, `ingest`, `ocr`, `fidelity`, `review`, `recover-source`, `identity`, `resolve-metadata`); indexes and vectors (`build-keyword`, `plan-embeddings`, `build-dense`); retrieval selection (`evaluate-retrieval`, `trial-reranker`, `compare`, `compare-runs`, `draft-activation`, `activate-run`); gold (`gold …`, `validate-gold`, `freeze-dataset`); answer evaluation and release (`plan-run`, `run-answers`, `freeze-release`, `release-report`, `backup`, `restore-check`); budget administration (`configure-budget`, `paid`, `settle`, `reconcile`, `adjust`, `audit`); `maintain`; `stage-review run`; and the `check`/`load-check` gates on temporary databases. Paid commands build a dispatching `service.Resources(settings)` and therefore need the gateway lock. Budget commands use `dispatch=False`. `activate-run` → `evaluation.activate_decision` validates the run (`decision_errors`) and, in one transaction, sets `active_run` and `active_index` and appends to `activations`; the 실험 비교 activate button calls the same function.
