`python -m rfp_assistant.cli <command>`. On the VM it runs through `tools/infra/bidmate-cli.sh`, which loads /etc/bidmate/server.env and runs as the bidmate user. For most commands, `main` opens the database lifecycle, requires a validated import and runs `init_schema`. The exceptions are init, budget-report (read-only, no schema statements), check and load-check (temporary databases on RFP_POSTGRES_TEST_DSN with the fake provider), and restore-check (RFP_RESTORE_DATABASE_DSN). Commands that dispatch paid calls build a full `Resources` (`_paid_resources`), so they fail while the UI holds the gateway lock. Ledger administration (`unresolved`, `settle`, `reconcile`, `adjust`, `paid`, `audit`, `set-limit`) uses `Resources(dispatch=False)`, which never takes the lock and runs beside the server. It records the typed `--actor` as the principal.
