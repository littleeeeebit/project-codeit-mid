`step_ingest` runs `import_manifest`, then `ingestion.ingest` with `ParseWorker` as the parse callable. `ParseWorker` uses one spawned child process (never forked from the serving process), reused across files. It waits up to 120 s for startup and then `parse_timeout_seconds` per file (default 120 s). On a timeout it kills the child's whole process tree (`taskkill /T` on Windows, `killpg` elsewhere) and raises `ParseTimedOut`, and the file keeps its previous extraction to be retried on the next run. On a cancel it raises `Stopped`. Every database write stays in the parent. Progress (done, total, current file, start time) is written to the run state before each original. Any `error` result fails the step. A source counts as changed only when its active extraction actually differs afterwards.
