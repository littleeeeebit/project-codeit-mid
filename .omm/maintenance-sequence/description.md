One command (`maintain --actor`) or 검증 → 유지보수 → 유지보수 실행 (`service.start_maintenance` → background `maintenance.run`) runs eight steps in order and writes `maintenance/state.json` after each step, plus `reports/<run>.json|md`. Every step reuses unchanged work, so a rerun with no changed input makes no provider call. A failed step stops the sequence. A paid embedding stops at `needs_approval`. Nothing is activated: the report checks that serving is unchanged. The `closing()` callback stops it between steps on service shutdown.
