`step_regression` runs `compare.regression`, which scores K1 and the serving configuration on both the served index and the rebuilt index (dev nDCG, support, whole-corpus nDCG, needle top-5, critical failures). A row that needs a paid estimate stops the run with `NeedsApproval`, and any incomplete row fails the step. `needs_evidence_review` lists questions whose pinned evidence a reparse replaced, and these make the run `unverified`.
