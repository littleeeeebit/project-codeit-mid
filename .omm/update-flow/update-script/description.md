The script steps are: `result running`, then `rm` the marker. Recover from `$STATE/deploying` if present, otherwise `PREV = rev-parse HEAD`. Require a clean tracked tree, fetch origin/main, and record `up_to_date` if it equals PREV. Require `merge-base --is-ancestor` and diff the changed files, refusing a changed `bidmate.service`. Save `web/out` to `web-out.prev`, write `deploying`, run `merge --ff-only`, then `pip install -e` if pyproject or requirements changed (or recovering) and `npm ci && npm run build` if `web/` changed (or recovering). Check that every absolute path in `server.env` exists, `systemctl restart bidmate`, and pass `healthy()` (a 401 from `/api/info` within 300 s). Any failure after the fast-forward calls `rollback`. git, pip and npm run as the service user via `runuser`.
