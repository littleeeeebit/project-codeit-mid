`bidmate.service` runs uvicorn with one worker on 0.0.0.0:8501, `ExecStartPre=start-postgresql.sh`, `KillSignal=SIGINT` and `TimeoutStopSec=120`. The stop runs `Resources.close()` through the atexit hooks, so running requests settle before the gateway lock is released. The restarted process recomputes `build_head()` and recovers any leftover queued/running requests and dispatching attempts.
