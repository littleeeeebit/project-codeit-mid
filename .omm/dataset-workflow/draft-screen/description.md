draft.tsx lists development-family documents only (GET /api/drafting/documents; no sealed source reaches drafting) and their elements filtered by text (GET /api/drafting/documents/{doc_id}/elements). It builds slots (POST /api/drafting/slots → `service.draft_slot`), prices them (POST /api/drafting/plan), starts a run with the consented maximum (POST /api/drafting/start), polls GET /api/drafting/runs, and sends a finished run to review (POST /api/drafting/runs/{run_id}/submit).
