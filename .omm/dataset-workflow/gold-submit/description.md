`submit_drafts` (service.py:3000) accepts only a completed, not-yet-submitted run with valid rows. It assigns evaluation families (`evaluation.assign_families`) and calls `gold.submit` (gold.py:324) with batch = run ID, dataset `dev` and drafter `drafting.DRAFTER`. Submission validates each row and inserts pending `gold_candidates`. Agents can also submit JSONL through `gold submit` (procedure in .wiki/gold-drafting.md).
