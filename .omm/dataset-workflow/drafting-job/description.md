`start_drafting` (service.py:2923) re-plans and refuses if the maximum grew past consent, if it does not fit, if there is no key or the service is closing, or if another drafting run is alive. It writes `drafts/<run>/request.json` and runs `drafting._generate` in a daemon thread on the serving gateway. Each call reserves `gold_drafting`/`gold_eval`, marks dispatching with a guard that refuses after shutdown begins, and settles. Valid drafts go to `output/candidates.jsonl` and invalid ones to `invalid.json`, with a receipt. A thrown error is written to error.txt or interrupted.txt; calls already settled stay settled.
