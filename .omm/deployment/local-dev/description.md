On a developer machine, the API runs on 8511 with BIDMATE_LOCAL_MEMBER, so there is no hub and every caller is that name. `npm run dev` serves the screens on 8510, and its rewrites forward /api/* to RFP_API_URL. `_Session` trusts writes from the :8510 Origin only with BIDMATE_LOCAL_MEMBER. `FakeTransport` (`provider: fake`) is for isolated UI checks only; it cannot establish real retrieval or answer quality.
