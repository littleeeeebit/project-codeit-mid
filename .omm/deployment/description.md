The live shared instance runs on the team GCP VM `codeit`, per the README and `tools/bidmate.service`. systemd runs `uvicorn ... --host 127.0.0.1 --port 8501 --workers 1` as user `bidmate` from `/srv/bidmate/app`. `ExecStartPre` runs `tools/start-postgresql.sh`, which brings up the pinned PostgreSQL container from `compose.postgresql.yaml` on port 55432 and generates `.runtime/postgresql.env` if it is missing. `/etc/bidmate/server.env` (root, mode 600) holds `RFP_DATABASE_DSN`, `RFP_CONFIG_FILE`, `RFP_SOURCE_DIR`, `RFP_DATA_DIR` and `RFP_PATH_MAP`, and never `OPENAI_API_KEY`: no file on the VM holds an API key. Each member enters their own key on the 설정 page; it lives only in the service's memory for that browser's session, so a browser without a key is refused before any paid dispatch and nobody shares another's key. Members reach the app through an SSH local forward of 8501.
