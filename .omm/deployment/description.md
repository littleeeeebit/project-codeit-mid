The live shared instance runs on the team's GCP VM `codeit`, not on a member's machine (README; runbook §3). systemd (`tools/bidmate.service`) runs `tools/start-postgresql.sh` before start, then one uvicorn worker on 127.0.0.1:8501 as user `bidmate`, with the database DSN and paths in the root-owned `/etc/bidmate/server.env`. Members open the app through an SSH local forward of 8501, enter their own OpenAI key on 설정, and their calls go out from the VM process.
