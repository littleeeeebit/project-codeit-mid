The live shared instance runs on the team GCP VM `codeit`, per the README and `tools/bidmate.service`. systemd runs `uvicorn ... --host 127.0.0.1 --port 8501 --workers 1` as user `bidmate` from `/srv/bidmate/app`. `ExecStartPre` runs `tools/start-postgresql.sh`, which brings up the pinned PostgreSQL container from `compose.postgresql.yaml` on port 55432 and generates `.runtime/postgresql.env` if it is missing. Secrets (`RFP_DATABASE_DSN`, `OPENAI_API_KEY`) come only from `/etc/bidmate/server.env`. Members reach the app through an SSH local forward of 8501.
