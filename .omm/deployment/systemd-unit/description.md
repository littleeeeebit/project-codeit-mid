`tools/bidmate.service` uses `Requires=docker.service`, `KillSignal=SIGINT` and `TimeoutStopSec=120`. SIGINT lets uvicorn end the loop so `Resources.close` (registered via `threading._register_atexit`) waits up to `shutdown_wait_seconds` for running requests to settle before releasing the gateway lock. `Restart=on-failure` with `RestartSec=10`; each restart runs recovery, so in-flight requests become `interrupted` and dispatching attempts become `unknown`.
