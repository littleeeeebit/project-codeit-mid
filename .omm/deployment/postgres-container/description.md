PostgreSQL 18.6 with pgvector 0.8.6 in Docker on loopback port 55432. Every pooled connection checks the server and extension versions. The application database is `bidmate_app`; `bidmate_pilot_archive` holds the phase-4 pilot with paid admission disabled. Rollback restores the newest verified dump into an empty database with `restore-check`, which leaves paid admission off until reconciliation and `paid on`.
