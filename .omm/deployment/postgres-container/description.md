The pinned PostgreSQL 18.6 + pgvector 0.8.6 container started by tools/start-postgresql.sh (Linux) or tools/start-postgresql.ps1 (Windows, loopback port 55432). The application database is `bidmate_app`; the Phase 4 pilot runtime lives in a separate `bidmate_pilot_archive` database with paid admission disabled. Verified pg_dump archives under `.runtime/archive/` are cold rollbacks that no code references; `restore-check` restores one into an empty database with paid admission left off, pending reconciliation of records written after the dump.
