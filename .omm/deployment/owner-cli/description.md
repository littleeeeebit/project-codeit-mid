`tools/bidmate-cli.sh <command>` sources `/etc/bidmate/server.env` and runs `python -m rfp_assistant.cli` as `bidmate`. Ledger commands (`dispatch=False`) run beside the live service. Paid maintenance commands that build `Resources(settings)` with a transport refuse with `GatewayLockError` while the service holds the gateway lock, so stop the service first or use the in-app 유지보수 button, which runs on the service's own gateway.
