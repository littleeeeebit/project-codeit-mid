`auth.Login.from_env` reads the hub settings and `BIDMATE_ALLOWED_USERS`. `/api/auth/login` redirects to the hub's authorize URL with a state cookie scoped to `/api/auth/`. `/api/auth/callback` compares the state with `secrets.compare_digest`, `Login.sign_in(code)` exchanges the code server-side and reads `/hub/api/user`, and only allowlisted usernames get a 12-hour in-memory session. `BIDMATE_LOCAL_MEMBER` replaces sign-in for one local developer and is refused next to the hub settings. The `auth.py` internals were read only at the signature level.
