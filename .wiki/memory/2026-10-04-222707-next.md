# Spec for LLM-as-a-judge (Luna) vs Jev judge comparison with a frontend screen and Korean translation bridge; PR #14 merged

The user asked for a single spec, without follow-up questions and with completion criteria chosen by the assistant. It was to survey today's work, then build LLM-as-a-judge on the evaluation dataset, bring in Jev as a second judge, compare the two in the frontend, and decide whether Jev can replace the LLM judge. The spec also had to solve Jev's poor Korean recognition. The assistant summarized the day's work (PostgreSQL/pgvector migration, PR #11 and PR #12). It then wrote a spec covering the Luna judge, the Jev judge, the head-to-head comparison, a fixed replacement rule and a translation bridge for Korean. The conversation ended with PR #14 merged after round 4 with no P2 left.

## Decisions

- Jev may replace the Luna judge only if three conditions all hold: its kappa against the reference is at most 0.05 below Luna's, it wrongly accepts no more items than Luna, and it gives a verdict on at least 90% of items. Failing any condition gives "not replaceable"; too few items gives "inconclusive". — The user delegated the completion criteria to the assistant. The rule was fixed in advance so the screen can't be argued into a verdict.
- Jev's weak Korean is handled by a translation bridge. No Hangul reaches Jev. Numbers, amounts, dates, codes and organisation names are replaced with placeholders, Luna translates with a fixed procurement glossary, and the placeholders are restored afterwards. A translation that alters a protected value or still contains Hangul is not sent to Jev and counts as an abstention. Critical numeric values are checked by deterministic Python, not by Jev. A small raw-Korean Jev run on the same items measures how much the bridge helps. The UI shows the Korean original next to the English bridge for each disagreement. — The user required the spec to say how Jev's poor Korean recognition is solved. Wiki-agent already works around it the same way.
- Judges are compared against the imported verdicts of development run A-9ef59b566d64, and the result is reported as agreement with those reviewed verdicts, not as agreement with human judgment. — That run has all 750 blind items judged by an independent reviewer, but the reviewer was an AI (gpt-6-sol rounds), not a person.
