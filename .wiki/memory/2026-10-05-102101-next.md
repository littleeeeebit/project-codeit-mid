# Remove every SQLite trace from docs, import the Phase 4 pilot DB into PostgreSQL, delete local SQLite files (PR #16 merged)

The user asked for next tasks. Three pull requests (#13 PostgreSQL-only hybrid serving, #14 Luna-vs-Jev judge comparison, #15 local Langfuse tracing) had been merged after the decisions the materials listed. The user chose to align the release report and the Phase 5 plan with PostgreSQL-only hybrid serving and to refresh the stale document index. The scope then grew to erasing SQLite from every tracked file, including decisions and memory, importing the Phase 4 pilot runtime into PostgreSQL and deleting every local SQLite file. The task was delivered as PR #16, merged in round 1 with no remaining P2.

## Decisions

- Remove every SQLite reference from all tracked files, including `.wiki/decisions/` and `.wiki/memory/`, not only claims that present SQLite as current — The user said every trace of SQLite must be erased entirely, so the Phase 5 plan and test guidance must also be PostgreSQL (rejected: Correct only current-state claims and leave dated history)
- Rewrite the Phase 5 plan (and the Phase 1 and Phase 4 plans) for PostgreSQL backup, restore and tests — The user said the Phase 5 plan must match PostgreSQL and tests must be PostgreSQL (rejected: Keeping the SQLite ledger and `sqlite3.Connection.backup()`)
- Import the Phase 4 pilot runtime SQLite database into PostgreSQL, then delete every local SQLite file — The pilot DB is the only copy of the Phase 4 evidence (181 gold candidates, the frozen sealed set and its first run, the answer runs) (rejected: Deleting the pilot DB without importing it)
- Bring the 2 unpushed local commits (session memory note and wiki corpus refresh) into this task's branch by rebasing
- Do not rewrite Git history; past commits keep the SQLite mentions — The user did not choose a history rewrite (rejected: Rewriting history)
